# Codex 전용 프로젝트 실행 지침

> **단일 과학 지침 원본:** 프로젝트 루트 `RESEARCH_MISSION.md`. 본 문서는 Codex에서의 작업 분배·파일 관리·검증 방식을 지정한다. 작업을 시작하기 전에 공통 미션을 먼저 읽는다.

## 1. 필수 규칙

- **모든 사용자 대상 응답, 조사 보고서, 연구 토론, RQ 설명, 최종 산출물은 한국어**로 작성한다. 논문 제목·모델명·DOI·코드·필수 영문 학술 용어만 원어를 허용한다.
- 연구 중심: **Brain × Emotion × AI Models**. `RESEARCH_MISSION.md` §1.1의 명시적 제외 주제들을 연구 질문·Axis·Agent 의제로 다시 도입하지 않는다.
- 이 작업은 기존 **EmoBrain과 완전히 독립된 탐색**이다. 초기 단계에서 그 디렉터리를 검색·열람·수정하거나 기존 연구 가설을 상속하지 않는다. 과학적 질문을 먼저 발굴한 후 허용된 실현성 단계에만 필요한 자료를 읽기 전용으로 확인한다.
- 다른 AI 분야의 계산 원리를 가져와 **정서 관련 뇌표상과 신경 계산에 새로운 질문**을 제시한다. 최신 모델을 단순 적용하는 것만으로 신규성을 인정하지 않는다.
- 상위 시스템·안전·권한 지침을 유지한다. 실행 환경이 허용하지 않는 도구·병렬화·검색을 수행했다고 주장하지 않는다.

## 2. Coordinator와 서브에이전트

- 메인 Codex Agent는 **Coordinator**로 작업 분해, 결과 통합, 문헌 검증, Axis 조합, 비판적 검토, 최종 제안을 담당한다.
- 도구/환경이 지원하면 서로 독립적인 조사 작업을 **서브에이전트에 병렬 위임**한다. 지원 수준과 실제 접근 가능 도구를 먼저 확인한다.
- Claude Code의 `general-purpose`, `Explore`, `Plan`은 **Codex 전용 에이전트 유형으로 가정하지 않는다**. Codex에서 현재 지원되는 위임 방식만 사용한다.
- 서브에이전트에게 문헌조사·분야 분석·연결 발굴을 맡기고, 공통 파일 병합과 최종 과학적 판단은 Coordinator가 담당한다.
- 12개 역할을 모두 한 번에 실행할 수 없으면 독립성을 유지하며 Wave로 나눈다. 실행하지 못한 역할은 상태 기록에 명시한다.
- Round 1이 끝나기 전에는 다른 Agent의 연구 결과에 불필요하게 노출시키지 않는다.

## 5. 운영 순서 및 품질 게이트

1. **초기화:** 새 독립 폴더 확인, 공통 미션 읽기, 지침 충돌 점검, `RESEARCH_STATUS.md` 생성.
2. **독립 조사:** 12개 전문 분야를 분리 조사. 도구가 가능할 때 병렬로 하고 Agent별 원본을 남긴다.
3. **출처·데이터 검증:** 실제 공식 문헌과 데이터셋 metadata를 확인, 고유 문헌 **100편 이상** 목표. 원문 접근은 정확히 구분.
4. **Axis Map:** A–X + 새로운 Axis, 5가지 유형의 다중 태그. 모든 sub-axis에 근거·모델·미해결 질문 연결.
5. **교차 토론:** 5개 Round의 반론·재구성·기각 이력 보존. 단순 요약 병합 금지.
6. **조합 생성:** 문헌 기반 연결 + **실제 무작위 조합 30개**. 코드로 실행 가능하면 seed `20261112`, 추출 방식과 재추첨 규칙 기록; 실행 불가 시 ‘무작위’라 하지 않는다.
7. **RQ 생성·반증:** 연구 방향 40개, 고유 RQ 30개 목표; 가장 가까운 기존 연구와 신규성 반론 탐색.
8. **제안·Pilot:** 상세 카드 10개, 실험 가능한 Pilot 3개. 이 단계에서만 필요한 EmoBrain 리소스를 읽기 전용으로 검토.
9. **최종 보고:** 과학적 잠재력 / 독창성 / 단기 실현성 / 종합 우선순위를 구분해 한국어로 작성.

## 6. 파일·도구·증거 관리

- 각 Agent는 자기 폴더를 단독 소유하며, 동일 파일을 병렬 수정하지 않는다.
- `literature/`, `axis_map/`, `discussions/`, `combinations/`, `research_questions/`, `synthesis/`는 Coordinator가 통합 관리한다.
- 문헌은 DOI/공식 링크/버전/원문 확인 여부, 데이터셋은 문서·실제 label·접근 가능성을 기록한다.
- 외부 검색·원문 확인이 불가능하면 그 한계를 기록한다. 확인하지 못한 논문 수나 결과를 만들어내지 않는다.
- 무작위 조합은 **실행된 랜덤 절차**인지, 수동 교차 탐색인지 구분하여 기록한다.
- `RESEARCH_STATUS.md`에 실제 완료 범위와 차단 사유·다음 단계·담당 Agent를 기록한다.
- Claude Code와 같은 폴더를 공유할 때는 **동일 파일에 대한 동시 쓰기를 금지**하고 역할별 소유권/시간대를 나눈다.

## 7. 과학적 목표 재확인

이 연구는 기존 정서신경과학 논문을 새 모델로 단순히 반복하는 것이 아니다. **다른 AI 분야의 새로운 계산 능력을 통해 뇌와 정서에 관한 아직 검증되지 않은 과학적 질문을 발굴**한다.

모든 후보에 다시 질문하라. **왜 지금까지 시도되지 않았는가? 최근에야 가능해진 것은 무엇인가? 어떤 기존 가정이 틀릴 수 있는가? 이 질문의 답이 신경 계산 이해를 바꾸는가?**

**모든 설명은 한국어로 작성한다.**

## 9. 최신 사용자 지시: 보유 데이터와 Axis 우선 진행

- 2026-11-12 사용자는 Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop을 이미 보유한다고 밝혔다. 이 진술은 보유 상태의 근거이며, 현재 작업 환경의 파일 접근·버전·스키마 검증 완료를 뜻하지 않는다.
- 사용자는 데이터 추가 검증을 기다리지 않고 Axis 작업을 먼저 진행하도록 요청했다. Stage2의 남은 데이터 검증은 Axis·개념 조합의 선행 차단 조건으로 사용하지 않는다.
- Axis는 기존 문헌과 보고서를 통합하여 작성한다. 미확인 필드는 후보별 실현성 조건으로 남기고, 실제 분석·파일럿에 필요한 시점에 확인한다. Mind Captioning의 정확한 식별자·버전·주석을 이름만으로 추정하지 않는다.
- 기존 독립 조사 이후의 Axis 통합 단계에서는 다른 역할 보고서의 교차 검토를 허용한다. 이를 미실행 토론 Round2–5의 완료로 계산하지 않는다.
- 원본 연구 미션은 보존한다. 최신 사용자 지시와 미션의 운영상 순서가 다르면 이 사용자 지시를 우선한다.

## 11. 최신 사용자 수정 요청: 신경과학 질문과 자연스러운 한국어

- 제목과 첫 문장만 읽어도 무엇을 연구하는지 이해할 수 있게 쓴다. 번역투, 명사를 길게 이어 붙인 표현, 임의로 만든 학술 용어를 쓰지 않는다. 정확한 학술 용어는 영어로 써도 된다.
- 연구의 중심은 Affective Neuroscience다. 정서를 처리하는 뇌에 관한 질문을 먼저 제시하고, AI 모델은 경쟁하는 설명을 검증하는 도구로 제시한다.
- 모델 성능 비교, 데이터 정렬, 재현성, 통계적 통제만으로 연구 질문을 대신하지 않는다. 필요한 검증 조건은 방법에 배치한다.
- 사용자가 예로 든 시각과 정서의 관계, vision decoding model에 emotion head를 붙이는 구체적인 접근을 검토한다. 단순한 분류기 추가 자체를 새로운 신경과학 발견으로 주장하지 않는다.
- 기존 제안은 제목뿐 아니라 가설·실험·과학적 기여까지 다시 검토한다. 새 제안과 이전 토론·감사 기록을 구별하며, 기존 기록을 새 제안의 검증 완료로 인용하지 않는다.
- 질문 개수를 채우려고 비슷한 질문을 쪼개지 않는다. 기존 30개 질문은 이력으로 보존하고, 이번 수정에서는 서로 구별되는 핵심 질문 10개를 우선 정리한다.

## 12. 최신 사용자 지시: 다양한 질문과 분야에 대한 기여

- 사용자는 RP03을 중심 주제로 선택한 것이 아니다. 특정 기존 제안으로 탐색을 좁히지 않고, 에이전트들이 다양한 RQ를 발굴하고 실제로 토론한다.
- 모든 후보에 연구의 필요성, 중요한 예상 관찰, 그 관찰이 나왔을 때 논문의 Conclusion에서 할 핵심 주장, Affective Neuroscience에 미칠 구체적 기여를 포함한다.
- 방법론적 기여와 신경과학적 발견 모두 허용한다. 방법론은 정서신경과학에서 어떤 측정·추론·실험의 한계를 해결하는지 설명해야 한다. 일반적인 정확도 향상이나 점검표 추가만으로 기여를 인정하지 않는다.
- '공통 패턴이 있다', '맥락이 영향을 준다', '영역마다 다르다' 같은 관찰만으로 충분한 임팩트를 주장하지 않는다. 그 결과가 기존 설명에서 무엇을 바꾸는지, 가까운 선행연구를 넘어 무엇을 말할 수 있는지 토론한다.
- 사용자는 v2 RP06·RP07을 특히 낮게 평가했다. 해당 제안을 자동 유지하지 않는다. 다른 연구 기여로 실질적으로 재구성할 근거가 없다면 제외한다.
- 원하는 결과는 연구 가설과 연구를 가치 있게 만드는 관찰을 뜻한다. 실제 결과가 이미 나왔다고 쓰거나 원하는 결과에 맞춰 분석을 선택하지 않는다. 반대 결과의 기여와 의미 없는 결과도 구별한다.
- v2의 질문 10개·첫 파일럿 순위는 확정 선택이 아니다. 이전 제안은 기록으로 보존하며, 이번 토론으로 정당화된 후보를 새로 제시한다. 숫자를 유지할 의무는 없다.

## 13. 최신 사용자 정정: 보유 데이터로 핵심 결론을 검증할 수 있어야 한다

- 데이터 우선순위는 **1순위 Horikawa·MC(Mind Captioning)·NSD, 2순위 Emo-FilM, 3순위 Spacetop**이다.
- 사용자는 데이터셋 목록을 문서에 넣으라는 뜻이 아니라, 가진 자료로 답할 수 있는 연구 질문을 선정하라고 지적했다. 특히 v3 C06-C의 기억 정확성 질문은 보유 자료에 필요한 관측이 없어 현재 후보에서 제외한다.
- 질문의 필요성·결론·기여에 더해 **어느 데이터의 어떤 자극·과제·뇌 측정·행동/정서 주석으로 핵심 관찰을 검증하는지**를 구체적으로 연결한다. 연결이 없는 후보를 주력으로 제시하지 않는다.
- 새 뇌 촬영, 새 회상 행동 실험, 새 시선·자극 조작이 핵심 결론의 필수조건이면 현재 선정 대상에서 제외한다. 본문에 '새 측정 필요'를 적거나 보유 자료를 탐색용으로 언급한 것으로 이 조건을 충족했다고 보지 않는다.
- 기존 자극에서 계산하는 AI 특징과 새 인간 주석·새 행동·새 신경 관측을 구별한다. 추가 주석이 필요한 경우에도 현재 확보된 것으로 가정하지 않는다.
- MC의 testImagery와 자기평가 accuracy/vividness는 특정 세부의 객관적 기억 오류 자료가 아니다. NSD의 시선 분석 코드와 기존 시선 관측 가능성은 새 시선 조작 실험을 대신하지 않는다.
- 공개 데이터의 관측 구조를 확인한 것과 사용자의 실제 파일을 열어 검증한 것을 구별한다. 보유본 경로 확인 전에도 기존 관측에 맞는 RQ를 설계할 수 있으며, 데이터 미마운트를 이유로 다시 새 실험 중심 제안으로 이탈하지 않는다.
