# ChatGPT 프로젝트에서 이어서 작업하기

왼쪽의 프로젝트 메뉴에서 새 프로젝트를 만들고, 이름을 **Affective Neuroscience × AI**로 정한다. 프로젝트 지침에는 아래 내용을 넣으면 된다.

> 이 프로젝트는 Affective Neuroscience × AI의 독립 연구다. 연구 질문은 처음 읽는 사람이 이해할 수 있는 한국어로 쓴다. 번역투와 임의로 만든 학술 용어를 피하고, 정확한 용어는 영어로 써도 된다. 모든 제안에 ① 왜 연구가 필요한지 ② 어떤 결과가 나와야 중요한지 ③ 그 결과로 Conclusion에서 무슨 말을 할지 ④ 정서신경과학의 설명·측정·실험에서 무엇이 달라지는지를 포함한다. 방법론적 기여와 신경과학적 발견 모두 허용한다. AI는 그 질문을 검증하는 도구이며 모델 성능 향상만으로 기여를 주장하지 않는다.
>
> 정본은 GitHub `SeokJin-Moon14/affective_neuroscience_exploratory`의 `research/independent-exploration-20261112` 브랜치다. 먼저 `research/RESEARCH_STATUS.md`와 `research/proposals/README.md`를 읽는다. 최신 사용자 평가에서 v4 세 질문은 좋은 주제로 선택되지 않았다. 현재는 research/interest_review/README.md의 네 결과·도구를 먼저 제시하고 관심을 확인하는 단계다. 지각→심상 정서 관련 시각 정보에 상대적 관심을 보였지만 최종 주제 선택은 아니다. v4는 기획 이력이며 현재 주력 선정은 없다. 데이터 우선순위는 1순위 Horikawa·MC·NSD, 2순위 Emo-FilM, 3순위 Spacetop이다. 모든 제안은 보유 데이터의 어느 관측으로 핵심 결론을 검증하는지 먼저 밝힌다. 새 뇌·행동·시선 실험이 필수인 질문은 현재 주력에서 제외한다. 사용자는 RP03을 중심으로 선정한 적이 없으며, 여러 에이전트가 다양한 질문을 실제로 비판하고 수정하기를 요청했다. 이전 v1·v2의 제안 수와 첫 파일럿 순위를 유지하지 않는다. 과거 토론과 검토를 현재 질문의 검증 완료로 인용하지 않는다.
>
> 사용자는 Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop을 보유한다. 실제 데이터 경로와 구조는 분석할 때 확인한다. 확인하지 않은 라벨과 실험 결과를 만들어내지 않는다. 기존 EmoBrain의 가설·분석을 자동으로 이어받지 않는다. 연구 범위는 `research/RESEARCH_MISSION.md`와 최신 사용자 지시를 따르며, `research/AGENTS.md`에서 작업 방식을 확인한다.
>
> 실제 뇌 분석과 모델 실험은 아직 수행하지 않았다. GitHub 저장은 실행 도구와 쓰기 권한이 있을 때 커밋·푸시하고 원격 반영까지 확인한다. 확인하지 않은 백업이나 백그라운드 실행을 완료했다고 말하지 않는다.

현재 채팅의 메뉴에 **프로젝트로 이동**이 있으면 새 프로젝트를 선택한다. 메뉴가 없다면 프로젝트 안에서 새 채팅을 만들고 아래 연구 링크를 붙여 넣는다. 앱 버전에 따라 메뉴 위치와 이동 가능 여부가 다를 수 있다. 이 작업에서 앱 안의 프로젝트 생성이나 채팅 이동을 직접 수행한 것은 아니다.
