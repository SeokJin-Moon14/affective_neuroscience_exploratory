# 연구 진행 상태

현재는 **사용자가 흥미롭게 볼 결과와 방법을 먼저 비교하는 단계**다. v4에서 작성한 세 파일럿 후보는 사용자가 좋은 주제로 선택하지 않았다. 현재 주력 선정은 없다.

사용자는 일반화·세밀한 정서 구별 방향이 EmoBrain과 겹칠 수 있다고 지적했고, 범주 경계 질문은 별로라고 평가했다. 심상 질문은 입증이 어렵고 임팩트가 약하다고 했으나 정서 관련 시각 정보를 지각→심상으로 추적하는 방향은 상대적으로 낫다고 했다. 이 반응을 주제 확정으로 읽지 않는다. EmoBrain 내용을 직접 열어 중복을 검증한 상태도 아니다.

이번에는 두 역할이 짧은 메모를 작성했고 [서로 다른 네 결과·도구](interest_review/README.md)를 제시했다. 기존 데이터와 관심 범위를 지키되, 새 장문 제안·심사·선정을 반복하지 않았다. 사용자의 관심 응답은 아직 받지 않았다. 답을 받기 전에 네 선택지를 새 주력 RQ로 자동 승격하지 않는다.

v4의 독립 원안10개·실제 비판·데이터 심사·저자 수정·세 파일럿 계획은 [이력](archive/v4/README.md)으로 보존한다. 공개 메타데이터 검산은 수행했지만 사용자의 BOLD·정서 feature 본체 분석은 아직 하지 않았다. 직접 선행 전체의 중복 검증도 완료하지 않았다.

자료 우선순위는 Horikawa·MC·NSD → Emo-FilM → Spacetop이다. 새 신경·행동·정서 평정이 핵심 결론에 필수인 질문을 현재 자료로 실행 가능한 것처럼 제안하지 않는다. 초기 미션의 모델 예시와 사용자가 직접 밝힌 선호를 구별한다.

공개 GitHub 연구 브랜치에 단계별 저장한다. 마지막 원격 성공은 저장소 backup/LAST_SUCCESS.json을 확인한다. 새 세션은 이 파일과 interest_review/USER_FEEDBACK.json을 먼저 읽고, 이전 세션의 에이전트 ID 존속이나 상시 백그라운드 실행을 가정하지 않는다.
