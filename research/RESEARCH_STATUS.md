# 연구 진행 상태

현재는 **보유 데이터로 검증 가능한 v4 RQ의 저자 수정과 최종 선정을 진행 중**이다. 사용자가 에이전트를 적극 활용하여 중간 승인 없이 전체 작업을 마치도록 지시했다. 다섯 제안 역할과 별도 데이터 검증 역할을 실제로 실행했다. v3의 새 실험 중심 네 방향은 철회된 상태다.

데이터 우선순위는 **1순위 Horikawa·MC·NSD → 2순위 Emo-FilM → 3순위 Spacetop**이다. 각 후보는 사용 자료의 실제 관측, 가능한 비교, 필요성, 조건부 Conclusion, 분야 기여를 연결해야 한다. [진행 기준](revision_v4/PROTOCOL.md).

사용자가 제시한 최근 Huang et al. 논문(U001)을 관련 후보의 필수 근접 선행으로 반영했다. 직접 원문 접속은 현재 네트워크 정책상403이라 사용자 제공 요약과 직접 확인을 구별한다. [참조 기록](revision_v4/REFERENCES.json). 단순 특징 encoding 비교·모델 또는 데이터셋 교체를 새 기여로 삼지 않는다.

다음 단계는 독립 후보 저장, 동료 교차 비판과 데이터 적합성 검토, 실제 저자 응답·수정, 중복 통합과 선정, 기존 자료로 실행할 최소 파일럿 계획, 최종 문서와 GitHub 저장이다. 종료·중단 시 실제 완료 단계와 남은 작업을 기록한다. 원자료 분석이나 모델 실행은 아직 수행하지 않았다.

보유 자료의 공개 관측 구조를 바탕으로 기획하며 사용자 원자료가 현재 환경에 마운트됐다고 가정하지 않는다. 새 세션은 이 파일과 revision_v4의 원안·검토·수정 기록을 읽어 이어간다. 역할 ID가 세션을 넘어 유지된다고 가정하지 않는다. 원격 저장 성공 기록은 저장소 backup/LAST_SUCCESS.json을 따른다.

## 이번 저장 지점

8개 원안에 대해 데이터 심사와 실제 동료 비판을 마쳤다. 다섯 MC 원안은 같은 핵심 질문으로 통합 중이다. 저자들이 반론에 답하고 수정하는 단계이며 아직 새 최종 목록을 확정하지 않았다. 데이터 심사 통과는 관측 구조에 대한 판단이고, 효과·검정력·실행 준비 완료를 뜻하지 않는다.
