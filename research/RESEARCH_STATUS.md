# 연구 진행 상태

사용자가 관심 방향으로 **A와 C**를 선택했다. A는 지각·심상에서 정서 관련 시각 단서를 비교하는 발견, C는 시각 뇌 디코더에 별도로 배운 emotion head를 붙이는 방법이다. [집중 검토](interest_review/ac/README.md)와 [자료 분리 설계](interest_review/ac/DESIGN.md)를 읽는다. 최종 RQ나 두 논문이 승인됐다는 뜻은 아니다.

A·C 담당 두 에이전트가 독립 메모를 쓰고 실제로 의견을 교환했다. 현재는 C를 도구로 개발하고 A의 신경과학 질문에 사용하는 한 연구가 자연스럽다고 판단한다. C의 단순 연결 구조는 Generic Object Decoding·UMBRAE, 시각 정서 표현의 뇌 판독은 Kragel et al. 2019와 가깝다. 새 방법론 기여로 인정할 핵심은 원영상에서 배운 head가 불완전한 뇌 판독 특징에서도 새 정서 목표에 재사용되는 기능이다. 기존 보정법으로 충분하면 C는 A의 기반 도구다.

MC의 제공 TimeSformer 특징은 영상별 요약이며 공식 설정에서 decoding을 건너뛴다. 패치별 시각 decoder가 준비돼 있다고 가정하지 않는다. 원영상에서 계산한 모델의 시각적 근거와 뇌에서 읽은 특징값을 구별한다. 심상 속 위치나 개인의 감정을 복원했다고 주장하지 않는다.

MC와 Horikawa의 원영상은 대부분 겹친다. 원ID 단위로 decoder 학습·head 학습·최종 평가를 분리하며, head용 영상을 남기면 decoder의 학습 영상 수가 줄어든다. 지각에서 추정한 오차 처리가 심상에서도 유효한지는 보장되지 않는다. 실제 심상 정답이 없는 상태에서 원영상 특징으로 심상을 다시 보정하지 않는다.

완료 범위는 관심 응답 반영, 두 담당의 검토·교환, 지정 선행 원문/공식 문서/코드 확인, 기존 ID 검산 재확인, 집중 설계와 출처 저장이다. **사용자의 BOLD·feature 본체 분석이나 모델 학습은 하지 않았다.** 직접 후속 선행 전체의 중복 검증도 완료하지 않았다. 다음 실험 단계에서는 보유본의 배열·허용 정서 항목·처리 window를 확인하고 Horikawa 지각에서 원영상 특징→head와 뇌 판독 특징→head의 차이부터 측정한다.

자료 우선순위는 Horikawa·MC·NSD → Emo-FilM → Spacetop이다. 새 신경·행동·정서 평정이 핵심 결론에 필수인 질문을 현재 자료로 실행 가능한 것처럼 제안하지 않는다. NSD는 선택적 시각 사전학습 자료이며 MC로의 자동 전이를 가정하지 않는다.

v4의 세 방향은 사용자가 좋은 주제로 선택하지 않았다. [당시 기획](archive/v4/README.md)을 이력으로 보존한다. EmoBrain 중복 가능성은 사용자 지적이며 내용을 직접 검토한 사실은 없다. v4 선정·검증 문서를 현재 추천으로 복원하지 않는다.

공개 GitHub 연구 브랜치에 단계별 저장한다. 마지막 원격 성공은 저장소 backup/LAST_SUCCESS.json을 확인한다. 새 세션은 이 파일과 interest_review/USER_FEEDBACK.json을 먼저 읽고 이전 세션의 에이전트 ID 존속이나 상시 백그라운드 실행을 가정하지 않는다.
