# 연구 진행 상태

**v4의 연구 기획 수정은 완료했다.** 기존 관측에 맞춘 독립 제안, 실제 동료 비판, 데이터 심사, 저자 응답·수정, 중복 통합과 선정, 상세 원고와 파일럿3개를 작성했다. 현재 결과는 [세 연구 질문](proposals/README.md)이다.

## 이번에 실제로 한 일

제안 역할7개가 원안10개를 작성했다. 데이터 담당은10개 모두의 관측 연결을 심사했다. 첫 다섯 역할의 MC 원안5개는 실제 합의로 한 연구로 통합했다. 지각 전용 B3개는 기여가 부족해 주력에서 보류했고, Geometry와 Systems 역할의 별도 원안2개는 서로와 다른 역할의 비판을 받아 수정했다. Coordinator의 정서 조합 발상도 별도 검토했지만 정식 원안이나 채택 수에 넣지 않았다.

공개 MC 이벤트와 사람 캡션을 읽고 ID·반복·학습/시험 중복을 검산했다. Horikawa5명의305개 이벤트와 캡션의 원ID 연결도 자료 담당이 확인했다. MC raw trainPerception 마지막 두 런에 시험72개가 들어 있으며, 제외하면58런2108개가 남는다. Horikawa의 공식15개 제외를 적용하면 MC 시험 대상은 최대71개다. 모든 참가자의 처리본·심상 window·정서 점수 본체까지 확인한 것은 아니다.

기존 문헌 장부103개를 유지하고, 최근 U001과 직접 MC 선행 U002를 별도 참조로 추가했다. P008·P009의 지정 원문을 다시 확인했다. U001은 사용자 요약과 접근 실패 기록, U002는 공식 문서·코드 확인 범위다. 최신 관련 논문을 모두 검색했거나103편의 본문을 모두 읽었다고 보고하지 않는다.

## 분석 전에 남은 확인

사용자의 BOLD·정서 feature 본체는 현재 환경에서 열지 않았다. 따라서 원고와 파일럿 계획이 완료된 것이며, 뇌 분석·모델 실험의 결과는 아직 없다. 기존 보유본에서 실제 항목·척도·범위·ID·ROI·유효 신호를 확인하고 [파일럿의 중단 조건](pilots/README.md)을 적용해야 한다. 자료의 관측 구조가 존재한다는 판단과 실제 효과를 판정할 수 있다는 판단은 다르다.

범주 경계 질문은 비교 가능한 주석 척도와 전환 부근 영상, 뇌 시스템 질문은 같은 정서 대비의 여러 내용군 중첩, 심상 질문은 기존 최대71개의 대비와 cue·후속영상 분리가 필요하다. 가까운 Horikawa·심상·범주지각 원문 전체의 중복 검토도 남아 있다. 각 조건은 상세 제안에 표시했다. 조건이 맞지 않으면 새 측정을 숨겨 추가하지 않고 해당 후보를 보류한다.

## 저장과 재개

사용자 지시에 따라 공개 저장소 `SeokJin-Moon14/affective_neuroscience_exploratory`의 `research/independent-exploration-20261112` 브랜치에 단계별 커밋·푸시한다. 마지막 원격 성공 여부와 HEAD는 저장소의 `backup/LAST_SUCCESS.json`을 확인한다. 이 상태 파일 자체가 푸시 성공의 증거는 아니다.

새 세션에서는 이 파일, `revision_v4/curation.json`, `proposals/README.md`, `pilots/README.md`를 먼저 읽는다. 이전 에이전트 ID의 존속을 가정하지 않고 역할별 원안·비판·수정 파일을 이어받는다. 앱 종료 후 무기한 실행이나 상시 자동 백업을 구성한 것은 아니다. 사용자 컴퓨터에 전체 연구 자료를 내려받을 필요는 없다.

v1~v3의 문헌·Axis·무작위 조합·토론 이력은 보존했다. 과거의 질문 수, 순위, 검사를 v4의 과학적 승인으로 사용하지 않는다.
