# v4 심상 후보의 공통 데이터 판정

대상은 첫 원안 D02-A·D03-A·D04-A·D05-A·D06-A다. 다섯 원안은 서로 다른 새 관측을 요구하는 다섯 실험이 아니라, 같은 MC 지각–심상 자료와 Horikawa 원영상 정서 주석을 사용하는 유사한 핵심 비교다. 이번 판정은 데이터 관측의 존재와 주장 범위만 다루며 신규성·기여·서로의 통합 여부를 승인하지 않는다.

**현재 판정: 기존 자료로 설계 가능.** 같은 원영상의 지각·심상 신경 반응, 반복, 사람 캡션, 기존 정서 feature라는 관측 구조가 공식 자료에 있다. 실제 원자료 배열을 아직 열지 않았다는 이유만으로 새 실험이 필요하다고 하지 않는다. 다만 아래 기존 파일 확인을 완료하기 전 실행 가능·검정력·가설의 판별 가능성까지 확정했다고 쓰지 않는다.

- **C1 원영상 연결:** MC `stimID`/`imageryID`와 Horikawa `stim_index`, 사람 캡션 `video_id`로 연결한다. `stimLabel`은 별도 처리 번호다. Horikawa 공식15개 제외를 그대로 적용하면 MC시험72개 중 원ID1이 빠져71개가 남는다. 숫자71은 해당 제외 정책의 결과이며 모든 분석의 고정 대상 수가 아니다. 코드북의 실제 항목·척도·값·행과 허용된 정서 주석 범위는 여전히 사용자 보유 feature에서 확인해야 한다.
- **C2 학습·평가:** MC sub-01 raw trainPerception60런의 마지막 두 런에 test72개가 들어 있다. 이들을 뺀58런2108개가 공식 처리본 설명과 일치한다. 원 raw task 이름만으로 분할하지 않는다. Horikawa에도 이 시험영상이 있으므로, 영상 자체가 새로운 상황으로 일반화한다고 주장할 때에는 그쪽 head/특징 선택 학습에서도 시험ID와 내용 중복을 제외한다.
- **C3 심상 시점:** 직접 확인한 첫 시험에서 준비cue 7초(32–39초) → imagery12초(39–51초) → rest2초 → 같은 목표 실제영상10초(53–63초) → rest2초 → accuracy/vividness평가6초 순서다. 다음 시행 cue는5초다. 시간별 BOLD에는 준비·심상·후속영상이 혈역학적으로 겹칠 수 있다. **공식 processed MAT의 심상 집계 window/회귀계수 생성법은 이번에 확인하지 않았다.** 이미 있는 raw events와 fMRI에서 구간·GLM·전처리를 확인하는 조건이며 새 측정을 요구하는 것이 아니다. 구별할 수 없으면 심상에서 정보가 선택적으로 유지됐다는 핵심 결론을 보류해야 한다.
- **C4 관측의 뜻:** 외부 인간 정서 주석은 원영상의 특성이고 MC사람 캡션은 자극 설명이다. 참가자가 심상 중 경험한 정서, 떠올린 내용의 직접 보고, 객관적인 기억 오류 정답은 아니다. accuracy/vividness로 그 정답을 만들 수 없다. 다섯 원안은 이 한계를 대체로 올바르게 명시했다.
- **C5 감도와 표본:** 실제 testPerception72영상×5반복은 sub-01에서 검산했고 imagery 첫세션72개와 대응한다. 모든6명의 유효5반복·ROI가 실제로 남는지는 처리본에서 확인한다. 반복·영상 쌍의 수를 독립 참가자 수로 세지 않는다. 같은 자료가 있어도 정서·내용 대비가 구별되거나 심상효과를 검출할 충분한 신뢰도가 있다고 보장되지는 않는다.

## 지각 전용 B 후보의 공통 범위

D02-B·D03-B·D04-B는 Horikawa의 기존 영상 시청 fMRI와 기존 정서/시각/의미 특징이 핵심이다. MC의 실제 사람 캡션과 기존 영상 특징을 원영상 ID로 연결하는 것은 기존 자료의 재분석이며 새 사람 주석·새 뇌 관측을 요구하지 않는다. 이들 후보는 심상 window 확인을 핵심 실험의 선행 조건으로 삼을 필요가 없다.

- **P1 실제 주석:** category/dimension 등의 그룹 이름과 valence를 사용하는 공식 코드가 있다는 사실은 확인했다. 그러나 사용자의 .mat/HDF5에서 개별 이름·척도 방향·값·결측·분포와 ID를 읽는 일은 남아 있다. 숫자 인덱스를 그대로 복사하거나 존재하지 않는 비정서 항목을 발명하지 않는다. valence를 사용한 직접 코드 근거는 `evidence/repos/horikawa_code/code/sub/draw_figure6AB.m`의87–97행이다.
- **P2 Horikawa 반복:** 같은 참가자에게 같은 원영상 ID가 독립 반복된 구조는 확인되지 않는다. 한 번의 관측으로 가능한 held-out 영상 예측과, 반복이 필요한 잡음 보정된 장면 거리를 구별한다. 후자가 필수면 기존 MC testPerception 확장으로 해결되는지 별도로 판단하되, 없는 Horikawa 반복을 만들지 않는다.
- **P3 자극/특징 연결:** MC 캡션과 Horikawa ID는 연결되지만 사전계산 TimeSformer/DeBERTa의 실제 row-to-ID는 본체 확인 전이다. 인덱스·제외·내용 중복을 맞추고, 설명문이 원영상과 같은 편집 내용을 다루는지 확인한다. 새 AI 특징은 기존 영상에서 계산할 수 있으나 그 점수를 새로운 사람 정서 정답으로 쓰지 않는다.
- **P4 결론 수준:** 새로 학습한 decoder나 계산한 모델 표현은 새 신경 관측이 아니다. 실제 BOLD와 기존 외부 정서 평정에서 그 표현의 정보 손실·범주 간 관계를 평가하는 것은 자료 범위에 맞는다. 결과를 개인 경험 정서, 뇌 영역의 인과적 중요도, 대형 모델 전반의 학습 법칙으로 확대할 수는 없다.
