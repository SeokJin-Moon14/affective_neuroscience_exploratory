## C01-01 — 자극 ID에서 내용 등가집합으로: 정서 신경 코드의 조합적 전이

내용 집합을 건너면서 객체·장면 의미가 달라져도 정서 관련 신경 대비가 재현되는가, 아니면 특정 내용과 정서의 결합에만 존재하는가?

축: AS31, AS01, AS28. 근거: P001, P015, P051. E3 새 가설; Round2 정보교환 완료; 실제 분석 미실행; 데이터 조건부

**1차 모델 적용:** 고정 영상 embedding으로 내용 중복/근접 그래프를 만들고, 정서 주석을 보지 않고 정한 내용 집합 안/밖의 검색 및 cross-validated 신경 대비를 비교한다.

**2차 과학 질문:** 정서 관련 표현이 자극 내용에 불변인 축인지, 내용에 따라 방향이 바뀌는 결합 코드인지 검증한다.

**3차 가정 도전:** 독립 ID에서 잘 예측되면 추상적인 정서 코드를 찾았다는 가정에 도전한다. 내용 집합을 넘지 못하는 결과도 코드의 적용 범위를 규정한다.

**신경 타깃:** 시각 및 transmodal 영역의 보류 내용 집합 간 신경 거리와 정서 관련 증분 예측

**주가설:** 충분한 공통 지지와 신뢰도에서, 시각·의미로 예측되지 않는 동일 정서 대비 방향이 새로운 내용 집합에서 유지된다.

**경쟁 설명:** 관측된 정서 대비는 객체·장면과 결합된 내용 특이 코드이며, 집합 간에는 방향이 회전하거나 사라진다.

**측정 대비:** 사전 지정 정서 대비의 within-content 대비 between-content 신경 방향 전이; 동일 표본수·정규화·주석 범위를 맞춘 content×emotion 상호작용모형 대 불변 축모형의 held-out 예측 차이.

**반증:** 원 뇌의 대비가 신뢰롭게 검출되는데도 내용 보류에서 불변 축이 실패하고 상호작용모형만 재현되면 불변 코드 가설을 기각한다. 내용/정서 공통 지지가 없으면 두 가설의 판별 불가다.

**차별점:** 새 디코더 정확도가 아니라 관측 단위를 내용 등가집합으로 변경해 불변 코드와 내용 결합 코드를 판별한다.

**신규성 위험:** cross-decoding·domain generalization과 매우 가깝다. 내용×정서 경쟁모형과 방향 전이까지 동일한 선행이 있으면 신규 RQ에서 낮춘다.

**기준선:** ID 무작위 분할은 누수 민감도 진단에만 사용; 저수준 영상+객체/장면 embedding-only 모델; 동일 rank ridge 및 내용×정서 상호작용모형; 내용 집합 보존 주석 순열

**데이터 계획:**

- primary: Horikawa: 기존 감사에서 확인한 stim_index와 공식 dupidx를 시작점으로 실제 영상 내용 그룹을 재확인. 자극 집계 정서 주석을 개인 상태로 해석하지 않는다.
- secondary: NSD는 영상 내용 전이·중복 검출 기준선만 담당. 정서 ground truth를 있다고 가정하지 않는다.
- split: 원본 영상/중복 내용 그룹 보류와 참가자 보류를 구분; 전체 특징 선택·잔차화·hyperparameter는 train 내부.
- fallback: 영상 미접근 시 공식 dupidx로 제한된 독립성 검사는 가능하나 내용 불변 코드 주장은 보류.

**미확인 실행 조건:** 실제 영상과 fMRI·정서 주석의 ID join; 정서 대비를 공유하는 독립 내용 집합의 충분한 수; 영역별 신뢰도 및 반복/런 분할 가능성

**여덟 탐색 질문:**

1. 미시도 여부는 E0. ID 독립성과 내용 독립성의 차이가 추상 코드 해석을 어렵게 했다는 추론이다.
2. 공식 중복 인덱스와 고정 영상 embedding으로 내용별 후보집합을 명시할 수 있다.
3. 새 ID 예측이 곧 새로운 내용에서의 정서 일반화라는 가정.
4. AI는 복잡한 객체·장면 근접성을 수치화하여 더 강한 내용 대조를 만든다.
5. 내용 embedding 밖에 남는 재현 가능한 정서 대비가 후보이며 아직 확인하지 않았다.
6. 검색의 hard negatives를 내용에 조건부인 신경 대비 검증에 전이한다.
7. Horikawa를 범주 정확도보다 코드의 일반화 단위 판별에 재사용한다.
8. 양성은 내용 불변 성분을, 음성은 내용 결합성 또는 자료의 비식별성을 구분하게 한다.

## C01-02 — 시간 샘플에서 사건 진행 단계로: 정서 신경 궤적의 시간척도

정서 관련 신경 궤적은 초 단위 경과시간에 묶이는가, 길이가 다른 사건에서도 진행 단계에 맞추어 재현되는가?

축: AS32, AS09, AS14, AS36. 근거: P002, P056, P060. E3 새 가설; Round2 정보교환 완료; 실제 분석 미실행; 데이터 조건부

**1차 모델 적용:** 정서/BOLD를 보지 않고 자극으로 사건 경계를 정의한다. 물리적 초 좌표와 0–1 사건 단계 좌표의 저차원 특징을 별도로 만든 뒤 각각 원래 스캐너 시간으로 되돌려 HRF 관측모형을 적용한다.

**2차 과학 질문:** 정서 관련 신경 계산의 통합 단위가 고정 시간창인지 가변 길이 사건의 진행 상태인지 검증한다.

**3차 가정 도전:** TR 또는 1Hz annotation이 신경 계산의 자연 단위라는 가정. 사건 단계 모형의 이득이 없으면 사건 단위 설명을 줄인다.

**신경 타깃:** Emo-FilM의 연속 BOLD에서 내용·경계·HRF를 통제한 사건 내 정서 관련 궤적

**주가설:** 훈련과 다른 길이의 보류 사건에서도 단계 좌표가 고정 시간창보다 정서 관련 신경 대비의 위치를 더 잘 예측한다.

**경쟁 설명:** 고정 HRF, 장면 경계, 움직임과 자기상관이 궤적을 만들며 사건 단계는 데이터 정렬 편의에 불과하다.

**측정 대비:** leave-film-out 평가에서 물리적 시간 상태모형 대 사건 단계 상태모형의 동일 자유도 예측차. 전체 BOLD 이득 외에 독립 주석과 연결되는 사전 지정 대비의 이득을 별도로 평가.

**반증:** HRF·경계·사건 길이·감각 특징을 맞춘 뒤 단계 이득이 사라지거나 경계 수를 맞춘 무작위 분할과 같으면 단계 코드 가설을 기각한다. 빠른 잠재 동역학이 식별되지 않으면 신경 시간 해상도 주장은 하지 않는다.

**차별점:** 샘플링 격자의 개선이 아니라 초 좌표와 사건 진행 좌표가 서로 다른 신경 계산 단위를 설명하는지 경쟁시킨다.

**신규성 위험:** 사건 분절·temporal receptive window와 중복 위험이 높다. 감각 사건 이득만 남으면 정서 RQ로 유지하지 않는다.

**기준선:** 고정 lag FIR/HRF encoding; 사건 시작/끝·duration·motion만 사용한 모형; 경계 수·길이 분포를 맞춘 pseudo-event; 자기상관 보존 시간 이동

**데이터 계획:**

- primary: Emo-FilM: 공식 1Hz consensus와 fMRI는 별도 코호트임을 유지하며 film-relative time과 실제 onset을 연결한다.
- secondary: Horikawa는 clip 평균 대비의 외부 기준선; 연속 사건 분석을 자동 가정하지 않는다. Spacetop은 실제 연속 주석/타이밍 확인 때만 추가.
- split: 영화 전체 보류. 평정 지연과 HRF 선택은 train 영화에서만 적합.
- fallback: 사건 길이 다양성이나 연속 신경신호가 없으면 시간창 관측 민감도 연구로 축소하고 단계 코드 RQ는 보류.

**미확인 실행 조건:** 원시 연속 주석·BOLD·영상 timebase; 독립적으로 정의할 사건 경계와 사건 길이 변이; 충분한 영화 수와 HRF 불확실성 평가

**여덟 탐색 질문:**

1. 미시도는 E0. 관측지연과 사건 단계가 얽혀 신경 시간 설명이 어려웠다는 추론.
2. 연속 주석·영상 표현과 명시적 관측모형을 동일 평가 틀에서 비교할 수 있다.
3. 고정 sampling bin이 계산 상태의 기본 단위라는 가정.
4. AI는 복잡한 사건 내용의 비선형 변화를 표현할 수 있으나 실제 우월성은 비교 대상이다.
5. 동일 영상 내용에서도 누적 맥락에 따른 신경 변화가 후보.
6. 형상 정렬의 좌표 비유일성 문제를 시간 궤적 해석에 전이한다.
7. Emo-FilM을 순간 정서 회귀 대신 시간 재매개화의 외부 전이에 사용한다.
8. 성공하면 사건 기반 상태표현, 실패하면 고정 시간·관측지연 설명의 범위를 명확히 한다.

## C01-03 — 합의 평균에서 주석 분포로: 정서 구조의 혼합을 뇌가 구별하는가

정서 평정 평균이 비슷하지만 독립 평정자들의 분포 모양이 다른 자극은 재현 가능한 신경 구조도 다른가?

축: AS33, AS14, AS24. 근거: P002, P051, P055. E3 새 가설; Round2 정보교환 완료; 실제 분석 미실행; 데이터 조건부

**1차 모델 적용:** 평정자 자료를 학습/검증 집합으로 나누어 평균·분산·혼합 형태를 추정하고, 평균과 영상 특징을 맞춘 자극 쌍에서 분포 거리의 추가 신경 예측을 평가한다.

**2차 과학 질문:** 뇌의 정서 관련 자극 표상이 평균 평가값만으로 충분한지, 자극이 지닌 해석의 다중성을 반영하는 관계 구조가 필요한지 검증한다.

**3차 가정 도전:** consensus 평균은 정서 관련 자극 구조의 충분통계라는 가정. 외부 평정자의 분포를 fMRI 참가자의 내적 상태 분포로 해석하지 않는다.

**신경 타깃:** 보류 자극의 평균 신경 패턴 및 신경 거리에서 주석 분포에 연결되는 성분

**주가설:** 평균과 감각/의미 내용을 맞춘 뒤에도 독립 평정자 집합에서 재현되는 분포 차이가 보류 자극의 신경 거리를 예측한다.

**경쟁 설명:** 평정 분산은 척도 사용·평정자 구성·낮은 신뢰도 또는 미측정 시각 의미 차이만 반영한다.

**측정 대비:** 평균-only 대 평균+분포특징 모형의 held-out neural RDM/encoding 차이. 같은 평균과 분산이지만 혼합 형태가 다른 사례가 충분할 때만 고차 분포 정보를 별도 검사.

**반증:** 평정자 교차검증에서 분포 모양이 재현되지 않거나 척도/내용 통제 뒤 신경 이득이 사라지면 다중성 코드 가설을 기각한다. 원평정이 없으면 평균 데이터에서 분포를 생성하지 않는다.

**차별점:** 신뢰도 보정용 분산이 아니라 평균으로 소실되는 주석 분포 구조를 신경 표현의 경쟁 설명으로 다룬다. 개인 느낌이나 개인의 정서 상태는 연구 타깃이 아니다.

**신규성 위험:** 분포적 의미·불확실성 부호화 연구와 가까움. 분포 추정 신뢰도 향상만 보이면 방법론 후보로 낮춘다.

**기준선:** 평균 정서 벡터; 평정자 random effect와 측정오차만 포함한 모형; 영상/의미 특징과 표본수; 같은 평균·유효 평정자 수를 맞춘 분포 순열

**데이터 계획:**

- primary: Emo-FilM: 44명 평정과 30명 fMRI가 별도 집단이라는 기존 공식 감사 사실을 유지. 원평정이 현재 보유본에 있는지 확인 후 수행.
- secondary: Horikawa 원평정 가용성이 확인되면 같은 측정 질문을 외부 검증. 합의 값만 있으면 사용하지 않는다.
- split: 평정자 split으로 분포 재현성, 영화/자극 split으로 신경 전이를 별도로 평가.
- fallback: 원평정 부재 시 독립 추가 평정 설계만 남기며 분석 가능이라 표시하지 않는다.

**미확인 실행 조건:** 개별 평정 원자료와 문항/척도 정의; 같은 시점 또는 같은 clip에 충분한 독립 평정자; 평균이 유사한데 분포가 다른 자극의 공통 지지

**여덟 탐색 질문:**

1. 미시도 여부 E0. 공개 consensus만으로 원분포를 복원할 수 없다는 자료 제약이 있다.
2. 계층 측정모형과 표현 비교로 분포 추정오차와 신경 대응을 분리할 수 있다.
3. 평정 평균만 같으면 정서 관련 자극 구조도 같다는 가정.
4. AI는 내용의 다중 해석 후보를 특징화할 수 있지만 AI 생성 평정을 정답으로 쓰지 않는다.
5. 평균 embedding으로 소실되는 자극 모호성과 관련된 신경 성분이 후보.
6. 혼합분포의 비식별성과 충분통계 개념을 consensus 해석에 전이.
7. Emo-FilM의 개별 평정이 있으면 QC를 넘어 신경 설명변수로 재사용.
8. 양성은 평균 중심 설명의 불충분성을, 음성은 분포가 측정오차를 넘는 설명을 못 한다는 범위를 보여준다.

## C01-04 — 라벨 좌표에서 관계쌍으로: 공통 정서 기하와 공통 신경 코드의 분리

주석 체계가 다른 데이터셋의 관계 기하를 정렬했을 때, 사용하지 않은 정서 관계와 신경 대비까지 운반되는가?

축: AS15, AS33, AS13. 근거: P001, P002, P057, P055. E3 새 가설; Round2 정보교환 완료; 실제 분석 미실행; 데이터 조건부

**1차 모델 적용:** 데이터셋별 훈련 자극 관계행렬로 GW 결합을 학습하고, 서로 다른 초기값/근접 최적 결합에서 독립 anchor의 관계 및 신경 대비를 예측한다. test 기하를 최적화에 넣지 않는다.

**2차 과학 질문:** 공유된 모양이 있는 것과 서로 다른 자료에서 같은 정서 관련 신경 관계를 갖는 것이 동일한 주장인지 검증한다.

**3차 가정 도전:** 같은 이름의 라벨 또는 낮은 관계 정렬비용은 같은 정서 신경 코드라는 가정. 대응이 불확정하면 보편적 코드 주장을 축소한다.

**신경 타깃:** 데이터셋별 자극쌍 신경 거리와 독립 공통 정서 대비의 외부 전이

**주가설:** 다양한 근접 최적 결합이 보류 anchor의 정서 관계와 독립 신경 대비에 대해 일치하는 예측을 낸다.

**경쟁 설명:** 감각/의미의 공통 구조 또는 거리행렬의 대칭만 맞아 의미적으로 서로 다른 결합도 동일한 비용을 얻는다.

**측정 대비:** GW 최적화에 사용하지 않은 anchor 관계의 예측오차와 결합 간 분산. 같은 비용대의 의미 순열 대응·Procrustes·감각-only 관계 모델과 비교.

**반증:** 낮은 수송비용에도 anchor 정서 관계/신경 대비가 chance이거나 대응에 따라 뒤집히면 공통 정서 코드 가설을 기각한다. anchor 없는 성공은 기하 유사성까지만 해석한다.

**차별점:** 데이터 결합을 위한 정렬 점수 대신 동일하게 좋은 대응들의 신경 의미 예측이 일치하는지를 검증하여 공통 코드 주장의 식별 범위를 정한다.

**신규성 위험:** domain alignment의 anchor 검증 자체는 새롭지 않다. 정서 관계와 실제 신경 대비의 이중 외부 검증이 없으면 일반 정렬 벤치마크다.

**기준선:** 주석 이름의 단순 대응; 감각/의미-only RDM 정렬; Procrustes 및 최근접 관계 대응; 거리분포와 대칭을 보존한 잘못된 대응

**데이터 계획:**

- primary: Horikawa–Emo-FilM은 서로 다른 자극·평정 체계를 보존하여 비교한다. 공통 자극이 있다고 가정하지 않는다.
- anchor: 새로 정한 bridge 자극을 독립 공통 척도로 평정하는 설계가 필요할 수 있다. 단순 평정 anchor는 의미 대응만 검증하며, 신경 전이 주장에는 양쪽 실제 측정의 독립 대비가 추가로 필요하다.
- secondary: Spacetop은 task별 실제 문항/자극 확인 뒤 별도 도메인. MindCaptioning은 사용자 보유 진술만 기록하며 식별자·모달리티·주석·caption 필드를 일절 추정하지 않는다.
- fallback: 공통 측정 anchor 부재 시 label-free 기하 비교까지만 하고 정서 코드 전이는 보류.

**미확인 실행 조건:** 정확한 주석 ontology와 척도; 독립 bridge/anchor의 실제 설계와 측정; out-of-sample 관계 예측 경로; 데이터셋별 신뢰도와 감각 도메인 차이

**여덟 탐색 질문:**

1. 미시도는 E0. 주석 ontology와 신경 측정 조건 차이로 외부 의미 검증이 어려웠다.
2. 관계 수송 구현으로 같은 자극이 없어도 다수 대응의 불확실성을 계산할 수 있다.
3. 잘 정렬되면 같은 의미라는 가정.
4. AI는 공통 감각 의미 관계의 강한 대체 설명을 제공한다.
5. AI 공통기하로 운반되지 않는 독립 정서 신경 대비가 후보.
6. 형상 정합의 대칭·비유일성을 정서 신경 코드 비교에 전이한다.
7. 서로 다른 목적으로 수집된 자료를 무리하게 라벨 병합하지 않고 공통 코드 주장의 반증에 쓴다.
8. 양성은 제한된 공통 관계를 지지하고 음성은 공통 모양과 공통 의미를 분리한다.

## C01-05 — 자극 평균에서 참가자×자극으로: 개인화는 좌표 보정인가 정보 복원인가

공유 시각 공간에서 사라지는 참가자×자극 신경 상호작용은 측정 잡음인가, 독립적으로 재현되는 정서 관련 관계 정보인가?

축: AS05, AS13, AS33. 근거: P001, P015, P060. E3 새 가설; Round2 정보교환 완료; 실제 분석 미실행; 데이터 조건부

**1차 모델 적용:** 동일 capacity의 자극공유 모형, 참가자별 선형 좌표보정 모형, 참가자×자극 저차원 상호작용모형을 적합하여 독립 반복/새 자극에서 비교한다.

**2차 과학 질문:** 정서 관련 신경 표현의 개인차는 공통 코드의 좌표·gain 변화로 충분한가, 자극 관계 자체의 참가자별 변형이 필요한가?

**3차 가정 도전:** 참가자를 평균내거나 공유 공간으로 정렬하면 관심 정보가 보존된다는 가정. 개인화 이득을 곧 개인 정서 경험의 차이로 해석하지 않는다.

**신경 타깃:** 반복/독립 run에서 재현되는 참가자×자극 신경 거리의 상호작용 성분

**주가설:** 공유 공간과 좌표 보정 후에도 반복되는 참가자×자극 관계 변화가 있으며 독립 자극 정서 대비와 연결된다.

**경쟁 설명:** 해부학적 정렬·HRF·영상 민감도·신호대잡음·overfit이 상호작용을 만들며 공통 코드+gain으로 충분하다.

**측정 대비:** 독립 run/반복에서 상호작용 RDM 재현성 및 새 자극 정서 대비 예측의 증분. 공유모형 대 선형 개인보정 대 동일 rank 상호작용모형을 자료량/파라미터에 맞춰 비교.

**반증:** 원 뇌 반복 신뢰도가 충분한데도 상호작용이 재현되지 않거나 시각 민감도/개인 HRF 보정으로 사라지면 개인별 관계변형 가설을 기각한다. 단순 이미지 retrieval 개선은 지지 증거가 아니다.

**차별점:** 개인화된 decoding 성능이 아닌, 좌표 보정으로 보존되는 공통 코드와 관계 자체를 바꾸는 재현 가능한 상호작용을 구분한다.

**신규성 위험:** individual differences·hyperalignment·shared/private 연구와 중복 위험이 높다. 정서 관련 독립 대비가 없으면 시각 신경 개인화 연구로 분류한다.

**기준선:** 공유 자극 효과+참가자 intercept/gain; 참가자별 선형 입력층을 둔 공통 latent; 차원수와 유효 자유도를 맞춘 ridge; 참가자 내 자극 교환 및 독립 반복 null

**데이터 계획:**

- primary: Horikawa 우선. 5명이라는 기존 감사의 범위를 유지하며 실제 반복/세션 독립성 확인 후 수행. 참가자를 대규모 모집단 표본처럼 해석하지 않는다.
- secondary: NSD는 반복 기반 시각 상호작용과 정렬 손실의 방법 대조이며 정서 주석은 새 독립 측정이 없으면 사용하지 않는다. Emo-FilM은 반복이 없으면 이 목적의 대체 자료라고 가정하지 않는다.
- split: 개인 적응은 train 자극으로, 평가에는 새 자극과 독립 반복을 사용. 새 참가자 zero-shot과 few-shot 결과는 분리.
- fallback: 반복 부재이면 신뢰로운 상호작용과 잡음을 분리할 수 없어 보류. 평균모형 비교만으로 개인 고유 코드라고 주장하지 않는다.

**미확인 실행 조건:** 참가자×자극의 충분한 공통 관측과 독립 반복; 반복별 BOLD 및 개인별 신뢰도; 실제 정서 대비와 감각 특징의 공통 지지

**여덟 탐색 질문:**

1. 미시도는 E0. 반복·정서 주석·같은 자극의 참가자 coverage 결합이 제약이라는 추론.
2. 공유 피험자 디코더의 중간 latent 접근으로 정보 보존을 단계별 비교할 수 있다.
3. 공유 시각 표현을 만들면 관련 정보도 모두 보존된다는 가정.
4. AI는 시각적으로 공유되는 정보를 강하게 추출하여 관계변형의 기준선을 만든다.
5. 공유 latent 밖에서 재현되는 정서 관련 자극 관계가 후보이나 현재 확인되지 않았다.
6. 대조학습의 many-to-one 압축과 기하 불변성을 관측단위 선택에 전이한다.
7. Horikawa/NSD를 평균 패턴 복원보다 참가자×자극 정보의 보존 시험에 재사용한다.
8. 양성은 단순 좌표 정렬을 넘는 설명 필요성을, 음성은 공통 코드+측정 차이의 충분성을 평가한다.
