## RP01 — 데이터통계검토자 (조건부)

정렬 목표에 따른 정서 대비의 판독 접근성 곡선은 검정할 가치가 있다. 원뇌의 대비 신뢰도·타깃 척도·학습표본량을 고정한 짝 비교를 조건으로 추진하며, 작은 probe의 실패를 정보 삭제로 결론내리지 않는다.

**원안→수정 평가:** Round2의 선택적 정보 소실이라는 표현을 Round4가 판독 접근성으로 낮춘 것은 핵심 개선이다. 다만 로그점수의 실제 관측모형과 fallback의 목적함수 비교 범위를 더 명확히 해야 한다.

**가장 약한 가정:** 원뇌/trunk/head의 보류 로그점수가 동일 정서 관측변수와 보정된 확률모형을 평가한다는 가정이다. 실제 라벨이 연속 강도·복수 범주 집계·ordinal 중 무엇인지 확인하지 않고 하나의 likelihood를 정하면 목표 간 차이가 scoring-model 부적합이 된다.

### 실제로 갈리는 예측

- **접근성변화:** 같은 원뇌·자극·학습표본·내용 보류에서 목표×표현단계의 paired proper-score 차이가 나타나고 제한 비선형 probe/훈련량 곡선에서도 그 형태가 재현된다.
- **좌표재부호화:** 선형 probe에서만 차이가 크고 알려진 역변환 또는 비선형 probe/추가 훈련량에서 회복된다. 이 경우 삭제 대신 표본/함수 복잡도의 증가로 해석한다.
- **측정한계:** 원뇌에서도 독립 정서 대비가 재현되지 않거나 가역 혼합 대조에서 기대된 회복을 못 하면 관심 정보의 접근성을 비교할 감도가 없다.
- **전체손상:** 정서와 난도/신뢰도가 맞는 비정서 대비가 비슷하게 악화되면 선택적 정서 접근성 저하가 아니라 일반 병목 손상이다.

### 필요한 수정

- 실제 주석의 척도·집계단위에 맞는 한 가지 proper scoring rule과 관측모형을 사전 고정한다. 범주 확률이면 적절한 log score, 연속이면 명시한 분포모형의 점수/보조 squared loss를 사용하며 결과에 따라 유리한 척도를 바꾸지 않는다.
- 동일 보류 자극별 score 차이를 계산한다. 클래스·주석문항·피험자×시행을 모두 독립 N으로 세지 말고 참가자와 내용/원영상 그룹의 의존성을 보존한다.
- 원뇌 대비 신뢰도, 외부 주석의 신뢰도, 접근성 차이의 CI를 분리한다. 반복이 없으면 가역/절단 모의 대조의 성공만으로 원뇌 신뢰도를 대체하지 않는다.
- 현재 fallback인 ridge→CLIP 비교는 접근성 탐색이다. 정렬 학습목표의 효과를 주장하려면 작은 동일 backbone·입력·split·최적화 탐색예산에서 masked/contrastive 목표를 실제 비교해야 한다.
- 가역 대조는 알려진 역변환이 있는 조건수 제한 선형변환과 제한된 비선형 혼합을 구분한다. 선형변환 효과가 정규화/최적화 때문인지 확인하고 비가역 절단은 독립 주입 신호의 제거를 알고 있는 양성 대조로 쓴다.
- 총 주석 예측과 의미조건부 증분은 같은 test 표본/타깃/score로 계산한다. 의미 통제가 정서 공통분산을 제거할 수 있으므로 조건부 감소를 정서 정보 부재로 해석하지 않는다.

**관측 단위:** 독립 자극/내용군에 대한 동일 참가자의 외부 주석 예측 점수. 반복은 신뢰도와 독립 평가에 활용하며 별도 자극으로 세지 않는다.

**측정 신뢰도:** Horikawa stim_index–처리 Label–원영상/중복그룹–정서 주석 join을 검증한다. 실제 반복별 반응과 주석 신뢰도 자료를 확인해 타깃 대비의 최소 감도를 개발자료에서 추정한다.

**분할:** 원영상/내용 중복을 한 fold에 묶고 외부 내용군을 보류한다. 모든 neural PCA·표준화·probe tuning·의미 조건화·calibration은 train/development 내부. 자료량 곡선은 동일 nested training subset으로 구성한다. 참가자별 결과와 참가자 모집단 일반화는 분리한다.

**null:** 내용군 안의 주석 순열·자극 ID가 보존되지 않는 뇌 교환·조건수 제한 가역변환·known-signal 비가역 절단을 각각 다른 실패원인 대조로 사용한다. 무작위 projection만으로 측정 감도를 충분하다고 보지 않는다.

**검정력·정밀도:** 사전 최소효과 δ는 개발자료의 점수 단위와 관심 대비 신뢰도에 근거해 정하고 최종 test를 보며 변경하지 않는다. 내용군/참가자 단위 재표집 CI와 반복 분할의 민감도를 제시한다. 5명에서 모집단 효과의 좁은 CI를 약속하지 않는다. 저신뢰 타깃에서는 검정력 부족과 동등성을 구분한다.

**양성 결과 해석:** 지정한 함수계열과 자료량 범위에서 정렬 목표가 정서 대비를 읽기 쉽게 또는 어렵게 만든다는 증거다. 총 정보량·신경 기전·인간 뇌의 학습목표는 입증되지 않는다.

**음성 결과 해석:** 원뇌 대비가 신뢰롭고 paired score 차이 CI가 ±δ 안이면 시험 범위에서 목표별 접근성 차이가 작다. probe 확대시 회복은 삭제 주장을 반박한다. 원뇌 신뢰도 부족이면 미식별이다.

**남은 불일치:** 유한한 probe와 표본량에서의 비회복은 정보론적 삭제의 증거가 아니다. 반대로 회복 가능한 표현이라도 유한 자료에서의 접근성 변화는 과학적 결과가 될 수 있다는 점은 유지한다. 이 결과가 인간 신경 계산의 동일 목적함수를 뜻하는지는 여전히 미해결이다.

### 판단을 바꿀 증거

- 조건부에서추진: 자극/주석 join·반복 신뢰도·가역/절단 대조·동일 objective 비교의 작은 실행이 통과하고 충분한 내용군 지지가 확인됨.
- 범위축소: 목표함수가 다른 동일 구조 비교를 구현할 수 없으면 모델/표현 비교의 방법적 접근성 탐색으로만 추진.
- 기각조건: 목표 효과가 label 누수·내용 중복·확률 보정 차이로 전부 설명되며 독립 정서 대비가 남지 않음.

### 실제 자원과 조건부 착수

- 현재환경: 공통 계획상 CPU quota 4개·메모리 32GiB. GPU 사용과 checkpoint load는 미확인이다. 5개 CPU 노출을 5개 보장 계산량으로 쓰지 않는다.
- 첫검정: 이미 추출된 특징과 작은 신경 projection·ridge·고정 용량 probe로 split/score/회복 대조를 검사한다. float32 N×K 크기 외에 신경행렬·CV 복사본·최적화 메모리를 실제 shape로 계산한다.
- 모델지원: CLIP ViT-B/32 공식 경로·해시가 식별됐지만 가중치 load/추론은 미확인이다. MindEye2의 원 입력/공유 head를 Horikawa에 바로 적용할 수 있다고 가정하지 않는다.
- 고비용조건: matched-objective 소형 재학습이 핵심 인과 비교이며, 원형 대규모 MindEye2 재훈련은 첫 검정의 필수조건이 아니다. 실제 한 batch의 shape·메모리·시간·수렴을 측정한 뒤 확장한다.
- 실행상태: 문헌 기반 설계 검토만 수행; 데이터/가중치/학습 실행 없음.

## RP05 — 데이터통계검토자 (수정)

독립 반복의 문맥 N_a가 보류 target Y_b의 정서 가중 대비를 개선하는지는 동시 잡음 공유를 배제하는 유용한 질문이다. 다만 입력 전체 경로의 target 의존성과 동일 자극의 추가 신경측정을 허용하는 평가 자원을 명시해야 한다.

**원안→수정 평가:** Round2의 잔차 지도 겹침을 Round4가 명시적인 A contrast loss와 독립 반복 비교로 바꾼 점은 실질 개선이다. 남은 취약점은 mask 순서가 문서상의 절차가 아니라 실제 입력의 함수적 독립성으로 검증되어야 한다는 점이다.

**가장 약한 가정:** 독립 반복 N_a에 target Y_a가 공간 전처리·정규화·tokenization을 통해 섞이지 않으며, 반복 a/b의 nuisance가 충분히 독립이라는 가정이다. 이미 평활화된 처리본에서 뒤늦게 mask해도 target 성분은 제거되지 않을 수 있다.

### 실제로 갈리는 예측

- **재현가능문맥:** train에서 고정한 모든 모형으로 새 자극의 다른 run/세션 반복 N_a를 사용했을 때 Y_b의 Δ_A가 양성이며, 같은 run 다른 자극과 의미/주석을 맞춘 다른 자극 N보다 크다.
- **동시잡음공유:** 동일 반복 N_b에서는 이득이 있으나 다른 run/세션의 N_a에서는 사라진다. 다만 N_a의 낮은 reliability·반복노출 변화가 같은 결과를 만들 수 있어 따로 측정한다.
- **숨은target복사:** target을 원 입력에서 perturb했을 때 보류 문맥 feature가 변하거나 mask buffer 확대에 따라 효과가 급감한다. 이는 target-free 문맥이라는 입력 정의의 실패다.
- **누락자극표현:** 독립 신경문맥의 이득이 검수 사건/관계 특징 보강 뒤 줄면 지정 S의 부족이다. 남는 이득도 자극 외 내부 상태를 증명하지 않는다.

### 필요한 수정

- 보유본이 이미 평활화/등록/전뇌 normalization된 자료인지 먼저 기록한다. source transformation H의 context←target 항이 0이라는 구현 검증 또는 target perturbation의 feature 불변성 검사 없이 target-free를 선언하지 않는다.
- mask 전에 수행된 비가역 전처리로 target이 섞인 경우 가능하면 검증 가능한 비평활/원입력 경로로 돌아간다. 불가능하면 결과를 반복 신호 복원의 방법 대조로 낮추고 독립 문맥의 고유 기여 해석을 보류한다.
- test 자극의 N_a를 제공하는 것은 허용된 추가 신경 관측이라는 평가 계약으로 명시한다. 해당 자극의 Y_a 또는 Y_b가 head 학습·표준화·hyperparameter 선택에 들어가서는 안 된다.
- N_a와 Y_b는 가능하면 서로 다른 run/세션에서 가져오고 반복 순서·경과시간·motion·global/run nuisance를 기록한다. 같은 자극 반복의 적응과 독립성을 구분한다.
- S+같은 run 다른 자극 N 외에 정서·내용 유사도와 context 신뢰도를 맞춘 다른 자극 N을 추가해 자극 identity·반복 신호의 일반적 이득을 구분한다.
- w의 합0/제곱합1과 Q의 train-only shrinkage를 고정하고 대비 조합 수를 독립 N으로 세지 않는다. 전체 Y, A 대비, 난도/신뢰도 일치 비정서 대비의 paired loss를 같은 단위로 병기한다.
- CortexMAE/Brain-JEPA는 입력을 읽은 latent를 반환할 뿐 target-masked head가 자동 제공되지 않는다. target perturbation·buffer·정규화 검사를 통과하는 raw-context ridge부터 사용한다.

**관측 단위:** 참가자×동일 자극×독립 run/반복쌍의 target 공간블록 대비. N_a→Y_b와 N_b→Y_a는 공유 신호를 가진 연관 평가이며 두 독립 참가자/자극으로 세지 않는다.

**측정 신뢰도:** 원 target 대비와 context N의 반복 신뢰도를 각각 추정한다. 반복 a/b의 nuisance 및 노출효과 차이를 확인한다. Q는 target test noise로 추정하지 않는다. Horikawa의 2,196 이벤트 수만으로 이 독립 반복 설계가 충족된다고 단정하지 않는다.

**분할:** 외부 fold는 원영상/내용 그룹과 필요한 참가자를 보류한다. 같은 자극의 모든 반복은 같은 외부 fold에 두되 test에서 context a만 제공하는 계약을 명시한다. head와 S 보강·개인 보정·Q·mask 폭 선택은 train/development에서만 결정한다. 반복b target은 최종 평가에만 사용한다.

**null:** 동일 run 다른 자극, 내용/정서/신뢰도 일치 다른 자극, 공간거리별 buffer, target perturbation, 시간자기상관 보존 surrogate를 각각 검사한다. 모든 null이 무엇을 보존하고 깨는지 기록한다. target-free 입력 검증을 통계적 순열로 대신하지 않는다.

**검정력·정밀도:** Δ_A의 최소 의미효과 δ를 개발자료의 정서 대비 신뢰도와 손실 단위에 근거해 정한다. 자극/참가자 단위 CI 및 반복 방향의 안정성을 보되 반복쌍과 많은 voxel을 독립 표본으로 증폭하지 않는다. neural block 수·mask 폭·의미 보강은 소수 사전 선택으로 제한하고 전체 민감도곡선을 보고한다.

**양성 결과 해석:** 검증된 target-free 경로의 독립 반복 N이 지정한 S와 관측모형에 추가 예측을 제공한다. 재현 가능한 조건부 예측가치이며 정서 고유 내부 상태 또는 인과 상호작용의 증거는 아니다.

**음성 결과 해석:** context/target 대비 신뢰도가 충분하고 Δ_A의 CI 상한이 δ 아래이면 시험한 반복 전이 이득은 작다. 동일 반복에만 남으면 공통 관측변동 설명과 양립한다. 반복 적응·낮은 N 신뢰도·입력 불일치가 있으면 미식별이다.

**남은 불일치:** 독립 반복에서 N이 추가 설명해도 그것은 지정 S가 놓친 재현 가능한 자극 신호일 수 있다. 뇌 문맥의 실질적 예측가치는 인정하지만 내부 상태나 자극 밖 정서 정보를 발견했다고 부르는 데는 동의하지 않는다. 비독립 nuisance와 반복 적응이 상반 효과를 낼 수 있어 단순 반복 유무 비교도 완전한 원인 분해는 아니다.

### 판단을 바꿀 증거

- 수정에서추진: 독립 반복의 실제 mapping, target perturbation 불변성, 전처리 의존성 감사, raw-context ridge에서 안정된 Δ_A 및 정서/비정서 대비 검사가 통과함.
- 방법후보로축소: 오직 이미 평활화된 feature만 있고 target 원천 유입을 검증할 수 없거나 독립 반복이 없어 공간복원 성능만 비교 가능함.
- 주가설기각: 충분한 감도에서 독립 반복 이득이 δ 미만이며 의미/측정 nuisance 대조가 양성 결과를 설명함.

### 실제 자원과 조건부 착수

- 현재환경: 공통 계획의 CPU quota 4개·32GiB에서는 작은 cortical block 및 고정 특징에 대한 ridge/paired contrast 계산이 첫 경로다. GPU와 가중치 load는 미확인이다.
- TRIBE: 공식 모델 카드의 공개 출력은 평균 피험자 fsaverage5 피질이다. 보유 target 공간과의 매핑, 개인 보정, config의 실제 TR 및 5초 offset을 확인해야 한다. subcortex를 자동 지원하지 않는다.
- brain모델: CortexMAE P/F/V 입력과 Brain-JEPA ROI 입력은 보유 beta/시계열에 자동 호환되지 않는다. target mask token 처리와 새 head는 실제 구현·실행 검증 과제다.
- fallback: 고정 자극 feature S와 검증된 원입력에서 target/buffer를 제외한 context N으로 cross-fitted ridge를 먼저 적합한다. 이것으로 반복 전이 대비를 판단할 수 있으면 대형 foundation model은 필수 아니다.
- 중단조건: 독립 반복이 없거나 target 유입을 배제할 입력을 만들 수 없으면 해당 신경문맥 가설의 실증 착수는 보류한다. 문헌·모형 계획은 완료할 수 있다.
- 실행상태: 신경 데이터·checkpoint를 읽거나 mask perturbation을 실행한 결과는 아니다.

근거: P026, P027, P029, P060, P100, P101

## RP06 — 회의적비판자 (조건부)

Round4가 국소 곡률 주장을 경계 초과거리로 좁힌 것은 수용한다. 그러나 자연 자극의 초과거리는 누락된 연속 내용 metric으로도 생기므로, 현 단계의 목표는 사전 지정 내용모형 아래 경계 관련 잔여거리라는 관측적 결과여야 한다.

**원안→수정 평가:** 본 Agent의 R3-01-C02-01 반론을 받아 곡률/변화율 주장을 철회하고 독립 경계 초과거리를 택한 점을 확인했다. 현재 남은 반대는 추정량의 존재가 아니라 그 양성 결과를 범주 고유기하로 해석하는 범위다.

**가장 약한 가정:** 복수 내용 metric과 motion·길이·밀도를 맞추면 경계 가로지름 이외의 중요한 신경 설명변수가 충분히 맞는다는 가정이다. 독립 metric들이 비슷한 pretraining/시각 입력을 공유하면 모두 같은 의미 요인을 놓칠 수 있다.

### 실제로 갈리는 예측

- **경계연관분화:** 독립 rater 경계의 확률적 가로지름 정도가 높은 자극쌍에서 smooth 내용모형의 잔여거리 초과량이 나타나며, 같은 강도·밀도·주석 확실성의 비정서 경계/가짜 경계보다 크고 새 사건 가족에 재현된다.
- **연속내용누락:** 관계·행동·사건 맥락 특징을 추가하거나 비정서 의미 경계를 난도에 맞추면 정서 경계 초과량이 줄거나 같은 크기의 pseudo 효과가 남는다. 이는 범주 고유기하보다 내용 metric 불충분성이다.
- **불확실성선택:** 효과가 고확신 경계만 선택했을 때 커지고 다른 평정자 split 또는 경계 확률 가중에서는 사라지면 주석 선택/불확실성의 영향이다.
- **pair의존:** 소수 원영상이 많은 경계쌍에 반복되어 효과를 지배하면 많은 쌍의 유의성은 독립 사건 가족 일반화로 재현되지 않는다.

### 필요한 수정

- 일차 주장을 사전 고정한 내용 metric 집합에 상대적인 정서 경계 초과거리로 제한한다. 양성 결과의 제목/결론에서 범주 고유 코드나 불연속 신경기하를 주장하지 않는다.
- binary boundary뿐 아니라 독립 주석자의 경계 crossing probability/불확실성을 사용한 연속 가중 분석을 등록한다. 이것을 신경 결과에 맞춰 선택하지 않는다.
- 내용 metric 선택과 matching 규칙은 개발자료에서 고정한다. 사전 지정 복수 metric에 대한 효과 범위 및 가장 강한 의미 기준에서도 남는지 보고하며 최선 p값을 선택하지 않는다.
- 비정서 semantic 경계는 단순 임의 label cut만으로 만들지 말고, 독립 주석·거리·확실성·밀도·개념 강도를 유사하게 맞춘다. 잘 맞는 대조가 없으면 정서 선택성 주장을 보류한다.
- 공유 자극으로 연결된 pair graph를 고려해 원영상/사건 가족 단위 재표집 또는 계층모형을 사용한다. RDM의 n(n−1)/2 쌍을 독립 N으로 세지 않는다.
- 경계 근처 실제 자극 지지가 부족하면 새 주석/새 실측 설계로 넘어간다. 생성 자극을 기존 BOLD와 임의 연결하거나 원자극 BOLD를 편집물의 응답으로 쓰지 않는다.

**관측 단위:** 자극쌍의 신경거리이되 독립 추론단위는 원영상/사건 가족과 참가자다. 평정자는 경계 측정의 별도 일반화 축이다.

**측정 신뢰도:** crossvalidated 거리에는 독립 반복/분할과 train-only noise precision이 필요하다. 원뇌의 정서 대비 신뢰도와 경계 위치의 평정자 재현성을 별도로 추정한다. 자극 집계 라벨을 개인 상태의 경계라 부르지 않는다.

**분할:** 경계·metric·pair matching·smooth model은 development/train에서 고정하며, 새 사건 가족의 neural distance에 최종 적용한다. 같은 원영상 내용중복과 공유 원본 자극은 외부 fold를 넘지 않는다. 주석자 split은 주석 측정의 독립 검증이지 신경 자극분할의 대체가 아니다.

**null:** 동일 밀도·확실성 pseudo-boundary, 비정서 의미경계, 사건가족 보존 boundary permutation, 강한 nonlinear smooth content model을 병행한다. 순열은 matched strata의 교환가능성이 있는 범위에서만 시행한다.

**검정력·정밀도:** 경계쌍의 개수가 아니라 충분한 독립 가족과 피험자에서 효과가 재현되는지 평가한다. δ는 개발자료 거리 단위·신뢰도에 근거해 사전 지정한다. 원 대비는 신뢰롭고 초과거리 CI가 ±δ 안이면 정보성 음성이다. 낮은 지지/폭넓은 CI는 기각 근거가 아니다.

**양성 결과 해석:** 검토한 내용모형·주석·자극 분포에서 정서 경계가 추가 신경거리와 연관된다. 곡률·불연속성·범주고유 인과·모든 의미 모델을 넘는 정서 기제는 결론낼 수 없다.

**음성 결과 해석:** 원 대비와 경계주석 신뢰도가 충분한데 최소효과 이하이면 해당 경계·내용군에서 별도 경계 초과량을 요구하지 않는다. 원 정서 정보나 범주 판독 가능성 자체를 부정하지 않는다.

**남은 불일치:** 관측자극에서 모든 의미 차이를 제거하는 것은 불가능하므로 양성 결과를 범주 자체가 신경거리를 만든다는 기전 설명으로 올릴 수 없다. 제안자가 제한된 잔여거리·외부 재현을 과학적 성과로 받아들이면 추진 가능하다. 새로운 자극 경로를 무작위 제시해도 측정된 편집효과 이상으로 순수 정서 요인을 식별하지는 못한다.

### 판단을 바꿀 증거

- 조건부에서추진: 독립 평정자/새 사건 가족·강한 비정서 경계·복수 내용metric에서 같은 방향의 초과거리와 충분한 효과 CI가 재현됨.
- 대안설명우세: 관계/사건 의미를 보강하자 초과량이 사라지거나 비정서 경계가 같은 효과를 내어 정서 경계의 추가성이 없어짐.
- 후속실험필요: 자연자료에는 경계와 내용변화의 공통 지지가 없고 사전 검증된 새 자극 가족에서만 판별 가능함.

### 실제 자원과 조건부 착수

- 현재환경: 고정 자극 feature와 neural distance의 자연쌍 분석은 공통 계획의 CPU quota 4개·32GiB에서 작게 시작할 수 있다. 전체 pair matrix가 필요하면 원영상 가족/블록 단위로 계산한다.
- 첫검정: 주석–stim_index join·dupidx·content-group mapping과 반복 기반 거리의 신뢰도를 우선 확인한다. 정확한 원평정이 없으면 새 독립 경계주석이 필요한 조건부 계획이다.
- AI역할: CLIP은 한 내용 metric일 뿐 정서 정답이나 완전한 의미 통제가 아니다. 다중 metric은 서로 독립된 오류를 갖는다고 자동 가정하지 않는다. 첫 판별에 diffusion 생성이 필수는 아니다.
- 후속확증: 자연경계 support 부족을 해결하는 새 편집 가족에는 독립 비목표 변화 검사·새 뇌 측정·별도 자원이 필요하다. 현재 환경에서 수행한 것으로 표시하지 않는다.
- 실행상태: 거리 계산·주석 수집·생성·실측은 수행하지 않은 제안 검토다.

근거: P001, P008, P051, P070, P077, P100
