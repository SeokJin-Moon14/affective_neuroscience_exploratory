# Agent 03 — Vision Decoding 독립 조사, Round 1

확인일: 2026-11-12. 담당 범위: 영상/동영상 검색·복원, brain-to-visual latent, 피험자 간 전이. 다른 Agent 결과와 EmoBrain은 열람하지 않았다. 본 보고서는 공개 공식 저장소만을 이용한 1차 조사이며 교차 토론·전체 신규성 검증·실험 결과가 아니다.

## 1. 핵심 판단과 증거 범위

가장 유망한 전이는 **복원 영상의 정서 판독이 아니라, 시각 디코더가 보존하거나 버리는 정서 관련 신경정보를 찾아 경쟁 설명을 구분하는 것**이다(E3). 좋은 영상은 강한 생성 prior로 만들어질 수 있고, 높은 검색 정확도는 자극 정체성을 잘 구분한다는 뜻일 수 있다. 두 지표 모두 정서 관련 뇌정보의 고유성을 자동 입증하지 않는다.

공식 저자 저장소에서 고유 연구 10건의 제목·저자·연도/학회 또는 preprint 연결을 확인했다(E2). 직접 확인한 공식 README·일부 모델/훈련/평가 코드 사실은 E1이다. **논문 본문·부록·Discussion 직접 접근 0건, 체크포인트 실물 검증 0건, 학습·추론 실행 0건**이다. 따라서 “논문 원문 10편 검증”으로 집계하면 안 된다. 문헌 단위 `evidence_level`은 E2로 두고 코드 근거를 별도 열에 명시했다. 원문이 없는 연구자의 future direction은 전부 미확인(E0)으로 남겼고, 본 보고서의 기회·질문·반론은 E3이다.

- 증거 자료: [papers.csv](papers.csv), [MODEL_CARDS.md](MODEL_CARDS.md), [sources/fetch_manifest.json](sources/fetch_manifest.json). URL·성공/실패·파일 SHA256 기록을 보존했다.
- 미션 §5.2의 실제 필드 목록은 30개이다. 이를 모두 유지하고 `evidence_scope`, `source_location`을 추가해 32열로 제공했다.
- arXiv와 Hugging Face 직접 요청은 proxy tunnel 403이었다. GitHub/raw는 가능했다. 학회 채택은 공식 저자 README의 진술까지 확인했으며 학회 사이트와 독립 대조하지 못했다.
- 원문 접근 한계를 보완하려고 공식 코드가 제시하는 계산 경로를 읽었지만, README 성능 주장을 재현 결과로 격상하지 않았다.

## 2. 먼저 바로잡아야 할 모델 식별

### MindEye2: 검색 방향 정정

VD01은 *MindEye2: Shared-Subject Models Enable fMRI-To-Image With 1 Hour of Data*, ICML 2024, arXiv:2403.11207이다. 공식 저장소 [MedARC-AI/MindEyeV2](https://github.com/MedARC-AI/MindEyeV2) README의 `Retrieval metric correction`은 기존 코사인 유사도 행렬의 전치로 **image retrieval과 brain retrieval 명칭이 교환되어 있었다**고 명시한다.

| 학습 자료 | 영상 검색: 뇌 질의→영상 후보 | 뇌 검색: 영상 질의→뇌 후보 |
|---|---:|---:|
| 1시간 | 57.4% | 79.0% |
| 40시간 | 98.3% | 98.8% |

이는 **수정된 공식 해석**이며 본 조사에서 재산출한 수치가 아니다. `final_evaluations.ipynb`의 cell11은 300개 후보를 30회 표집하고 top-1을 계산한다. 300-way와 2-way identification 또는 열린 후보군 검색을 섞어 비교하면 안 된다. 겹치는 30회 표집의 표준오차는 피험자/자극 모집단에 대한 독립 표본 불확실성과 같지 않다(E3 통계 검토).

또한 MindEye1의 CLIP ViT-L/14와 MindEye2의 실제 훈련 설정을 혼동하지 않는다. MindEye2 훈련 코드의 출력 목표는 OpenCLIP `ViT-bigG-14`, `laion2b_s39b_b160k`, 256×1664 token 표상이다. 피험자별 선형 입력층, 공유 `BrainNetwork`, 대조학습 head, diffusion prior, 선택적 저수준 경로가 구분된다. `models.py`의 사용되지 않을 수 있는 과거 CLIP helper만 읽어 최신 훈련 설정을 확정하지 않았다.

### Brain-IT: 정확한 실재와 다른 논문과의 구분

VD03은 [WeizmannVision/brainit-fmri](https://github.com/WeizmannVision/brainit-fmri)의 *Brain-IT: Image Reconstruction from fMRI via Brain-Interaction Transformer*이다. Roman Beliy, Amit Zalcher, Jonathan Kogman, Navve Wasserman, Michal Irani. arXiv:2510.25976이며 공식 README는 ICLR 2026 채택이라고 표시한다. 읽은 저장소 페이지의 commit은 `a7663eb5002e9ea5f899815326ff52d45be9a2f3`이다.

같은 저장소의 VD04 *The Wisdom of a Crowd of Brains: A Universal Brain Encoder*, arXiv:2406.12179는 **영상→fMRI encoder** 논문이다. Brain-IT의 **fMRI→영상 reconstruction**과 방향이 다르다. 현재 공유 코드가 2024 preprint의 모든 세부와 동일하다고 확인하지 않았다. Brain-IT transfer 문서는 실제 제공 절차가 NSD 내부의 held-out 피험자 전이임을 명시한다. “다른 데이터셋으로 쉽게 수정할 수 있다”는 README 표현은 Horikawa/Emo-FilM/Spacetop 검증 결과가 아니다.

## 3. 분야의 원래 계산 목표

| 목표 | 실제 최적화/경로 | 얻는 측정 능력 | 정서 해석에 필요한 추가 검증 |
|---|---|---|---|
| 자극 검색 | 뇌 예측 embedding과 대응 영상 embedding의 대조 정렬(VD01/02) | 생성기를 거치지 않는 후보 식별 | 의미·저수준 특징을 맞춘 후보에서도 정서 관련 정보가 남는가 |
| 영상 생성 | latent regression 또는 diffusion prior→사전학습 생성기(VD01/02/05/07) | noisy fMRI로부터 시각적으로 해석 가능한 출력 | prior-only 대조보다 뇌 조건이 추가하는 정보가 있는가 |
| 모듈별 복원 | 저수준·CLIP-text·CLIP-image·깊이·caption 경로(VD05/06/07) | 서로 다른 표현의 오류 양상과 중복성 비교 | 어느 모듈의 효과가 시각/의미 교란으로 설명되는가 |
| 피험자 전이 | 공유 trunk+개인 입력층, cycle, voxel cluster transfer(VD01/03/09) | 적은 새 피험자 데이터로 적응 | 공유 정렬이 정서 관련 잔차를 소거하는가 |
| 시공간 복원 | masked→multimodal contrastive→video diffusion(VD10) | 시간 문맥을 이용한 잠재 궤적 추정 | HRF·장면 전환·움직임 자기상관을 넘는 정보인가 |

대조학습은 대응 자극을 구별하도록 표현을 정렬하고, 생성은 사전학습 영상 분포를 통해 불완전 조건을 완성한다. 따라서 출력의 정서적 내용은 뇌 신호와 자극/생성 prior가 함께 결정할 수 있다(E3). 손실함수가 정서 주석을 사용하지 않았다는 사실만으로 정서 정보가 없다고 결론내릴 수도 없다. 보존 여부를 직접 측정해야 한다.

## 5. 미해결 문제 5개

1. **P1 — 생성 prior와 신경 기원의 분리.** VD01/02/05/07의 복원에서 정서 관련 내용 중 실제 뇌 조건이 더하는 것은 무엇인가? 낮은 fMRI 신뢰도 때문에 실패한 경우와 prior가 지배하는 경우를 나눠야 한다.
2. **P2 — 학습 목적에 따른 선택적 정보 소실.** VD08의 masked 뇌 학습과 VD01/02의 시각 대조 정렬은 정서 관련 분산을 서로 다르게 남기는가? 같은 architecture/자료량의 대조가 필요하다.
3. **P3 — 시각적으로 공유되는 신호와 정서 관련 개인 잔차.** VD01/03/09에서 정렬이 유지한 것은 시각 식별인가, 정서 관련 신경 구조인가? 개인 잔차는 신호와 잡음이 섞이므로 반복 검증이 필요하다.
4. **P4 — 시간 정보가 실제 뇌 측정으로 식별되는가.** VD10의 영상 궤적에서 사건 구조·HRF만으로 설명할 수 없는 정서 관련 변화가 있는가? 출력 FPS를 신경 시간 해상도로 사용할 수 없다.
5. **P5 — encoder의 범위를 벗어난 정보.** VD04로 예측되는 합성 뇌와 실제 뇌의 차이가 정서 관련 정보를 담는가? 차이는 시각 모델 누락·motion·noise도 포함하므로 “정서 잔차”로 미리 명명하지 않는다.

모두 E3 미해결 문제다. 문헌 원문에서 저자가 명시한 미해결 문제를 다섯 개 확보했다는 뜻이 아니다.

## 6. 방법론적 기회 5개

1. **O1 — 생성 전후 이중 평가(VD01/02/07).** 최종 영상만 보지 말고 뇌→latent, prior 출력, 생성 영상에서 같은 조건부 예측을 평가한다. 단계별 정보 증가가 신경정보인지 생성 보충인지 구분할 수 있다.
2. **O2 — 의미를 맞춘 hard-negative 검색(VD01/02).** 객체·장면·CLIP 유사도를 가까이 맞추고 정서 주석만 다른 후보군을 구성한다. 정서 주석이 실제 존재하며 충분한 공통 지지가 있어야 한다. 조건을 강하게 맞춰 비교 가능한 자극을 모두 없애는지 진단한다.
3. **O3 — 경로별 삭제와 교차 조건(VD05/06/07).** 저수준/텍스트/깊이 잠재조건을 교차 고정하고 실제 뇌 예측력으로 검증한다. “생성 변화=뇌 메커니즘 변화”라고 해석하지 않는다.
4. **O4 — 실제·합성 뇌 분리 학습(VD03/04/09).** 합성 fMRI의 비율을 바꾸고 실제 보류 뇌에서 평가한다. 시각 encoder가 설명 가능한 부분이 정서 판별을 독점하는지 조사한다.
5. **O5 — 정렬의 정보 보존 감사(VD01/03/09).** 동일 피험자/자료량으로 공유 latent와 개인 잔차의 반복 가능한 예측을 비교한다. 단순 이미지 검색 성능과 다른 목표를 명확히 둔다.

## 8. 예상 밖의 연결 3개

**C1. 검색 방향 정정 × 측정 이론(VD01+VD02).** 뇌→영상과 영상→뇌는 각각 다른 후보 집합의 구별 가능성을 측정한다. 방향 간 차이는 정서 정보의 비대칭일 수 있다는 매력적인 가설을 만들지만, 후보 밀도·embedding hubness·신뢰도만으로도 생긴다. 먼저 같은 후보와 동일 측정오차 모델에서 비교하고, 정서의 독립 기제로 해석하지 않는다. Geometry & Information/통계 측정 분야와 연결할 후보이며 아직 다른 Agent 결과는 읽지 않았다.

**C2. 합성 뇌 증강 × 모델 오류의 과학적 활용(VD03+VD04).** decoder를 강하게 만드는 합성 fMRI는 encoder가 아는 신호만 공급한다. 합성 증강으로 검색이 좋아져도 실제 뇌의 정서 관련 잔차가 덜 남는다면, 성능 향상과 관심 신경정보의 감소를 동시에 관찰할 수 있다. Brain Foundation/Encoding 및 Affective Neuroscience와 교차 검토할 가치가 있다.

**C3. 영상 시간 보간 × 신경 시간 식별성(VD10+VD01).** 정지영상 학습의 trial 시간·이전/이후 metadata 제공과 연속 영상 생성은 시간 정보를 다루는 출발점이 다르다. 생성기가 매끄러운 궤적을 낸다는 사실과 뇌 데이터가 그 궤적을 식별했다는 사실을 나누면, 정서 변화가 실제 자극/뇌 정보인지 temporal prior인지 시험할 수 있다. Multimodal Dynamics 및 Generative AI와 연결할 후보이다. MindEye2 README는 실제 훈련에 `behav`만 사용했다고 명시하므로 과거/미래 arrays가 이미 학습되었다고 주장하지 않는다.

세 연결은 각각 2개 이상 실제 공식 근거를 가진 연구를 바탕으로 한 E3이며, 연결 자체의 선행연구 역검색은 미완료다.

## 9. 신규 Sub-axis 3개

상세한 필수 등록 필드는 [subaxes.csv](subaxes.csv)에 있다.

- **G/X-VD1 생성 prior와 신경정보의 기여 분리**: 생성 전 latent·생성 후 영상에서 조건부 정보를 함께 평가. Model/Method + Neural + Inference/Measurement + Construct/Stimulus.
- **O/X-VD2 정렬 과정의 정서 관련 정보 보존**: 공유화가 유지하는 시각 코드와 소실시키는 반복 가능한 잔차를 구분. Neural + Structure/Dynamics + Inference/Measurement + Construct/Stimulus.
- **D/Q-VD3 생성 시간 해상도와 신경 식별 시간의 분리**: 연속 출력의 매끄러움과 fMRI가 실제 제공한 시간 정보를 구분. Structure/Dynamics + Neural + Model/Method + Inference/Measurement.

이들은 기존 Axis의 Sub-axis이며 독립된 새로운 대분류를 만들 필요성은 아직 입증하지 못했다.

## 10. 가장 구별력 있는 후보 질문 3개

### RQ-VD1: 시각 식별을 보존하는 정렬은 정서 관련 신경정보도 보존하는가?

1차 모델 적용: MindEye2 공유 trunk/CLIP head와 원 뇌의 예측력 비교.

2차 과학 질문: 시각·의미 특징으로 설명되지 않는 반복 가능한 정서 관련 신경 변동이 공유 시각 공간으로 이동하면서 보존되는가?

3차 가정 도전: “좋은 범용 시각 latent는 관심 있는 신경정보를 충분히 담는다”와 “목적함수는 시각 식별에 불필요한 정보를 버린다”를 구분한다. 원 뇌의 정서 관련 증분 정보가 없으면 이 실험에서 보존을 평가할 수 없으므로 실패를 정보 소실의 증거로 쓰지 않는다.

자료 조건: Horikawa의 실제 주석/자극·반복·fMRI 정합이 확인되면 우선. NSD는 정서 주석을 있다고 가정하지 않고 시각 전이 대조군으로 사용. 기준선: ridge→CLIP, 원 뇌 정규화 선형모형, 시각/의미-only 모델. 자극/피험자 이중 보류, 전체 전처리·잔차화 train 내부 수행.

### RQ-VD2: 합성 뇌 증강은 시각 복원을 개선하면서 정서 관련 신경 잔차를 지울 수 있는가?

1차: Brain-IT/Universal Encoder 방식의 실제+합성 학습 비율 비교.

2차: 영상으로 잘 예측되는 신호와 그 밖의 실제 뇌 변동 중 어느 부분이 정서 관련 정보에 기여하는가?

3차: “더 정확한 visual reconstruction은 더 완전한 신경표상”과 “encoder가 설명하는 정보에 편향된 복원”을 구분한다. 합성 뇌에서 정서 정보가 잘 예측되는 결과도 자극 특징이 정서 주석과 상관하기 때문일 수 있다. 실제 뇌의 추가 증분과 신뢰도 검증이 핵심이다. 전체 Brain-IT 재훈련 대신 고정 encoder와 작은 ridge decoder로 처음 판별할 수 있다.

### RQ-VD3: 영상 복원 궤적의 정서 관련 전환은 뇌 측정에서 왔는가, 생성 시간 prior에서 왔는가?

1차: 연속 뇌 조건의 MinD-Video 잠재표상과 생성 궤적 평가.

2차: 장면/움직임/HRF를 맞춘 상황에서 정서 관련 변화가 추가 신경정보를 갖는가?

3차: “매끄러운 재구성은 시간적 신경 코드를 복원”과 “시간 prior가 대부분 보간”을 구분한다. 자기상관 보존 뇌 교환에서도 같은 결과면 전자를 지지하지 못한다. Emo-FilM/Spacetop의 연속 주석·onset·영상 접근 확인 전에는 실행 가능하다고 확정하지 않는다.

세 후보의 신규성은 **잠정적**이다. 재구성/전이 문헌과의 근접성은 확인했지만 2024–2026 정서 적용 문헌을 충분히 역검색하지 못했다. 첫 질문은 가장 낮은 계산 비용으로 판별을 시작할 수 있지만, 이는 과학적 잠재력의 확정 순위가 아니다.

## 12. 강한 반론과 개선 방향

- **반론: 결국 정서 decoder 하나 더 만드는 것 아닌가?** 정확도 최고값이 아닌 정보가 소실되는 단계와 경쟁 원인을 사전등록한다. 차원이 큰 원 뇌의 단순 우위를 막도록 자료량·정규화·신뢰도·모형 용량을 맞춘다.
- **반론: CLIP 통제 후 남은 것은 모형 오차다.** DINO/저수준/장면·행동 특징 등 서로 다른 설명 모형을 함께 대조하고 공통으로 남는 반복 신호만 유지한다. 그래도 “정서 고유”라는 인과적 실체를 확정하지 않는다.
- **반론: residualization이 관심 신호도 지운다.** 총 예측과 조건부 증분을 같이 보고하고, 어떤 교란을 조건화했는지 명시한다. 정서와 의미가 공유하는 분산은 삭제된 증거가 아니라 공유된 것으로 보고한다.
- **반론: NSD 사전학습을 다른 데이터에 그대로 쓸 수 없다.** voxel 대응·전처리·자극 시간 체계가 달라 개인 입력 adapter를 새로 학습해야 할 수 있다. 데이터 접근과 최소 유효 표본을 검증하기 전 “즉시 재사용”으로 판정하지 않는다.
- **반론: 생성 영상의 평정도 원 영상 의미를 반영할 뿐이다.** 실제 뇌 조건과 prior-only·교환 뇌를 비교하며, 생성 영상 평정을 원 신경반응의 ground truth로 취급하지 않는다.
- **반론: 전이는 라이선스·메모리에서 막힌다.** 코드 라이선스와 checkpoint/데이터 라이선스를 별도로 확인한다. Brain-IT stage2 2×H200/4×H100을 기본 파일럿으로 삼지 않고 고정 특징+선형 경로로 첫 판별을 한다.

완료 범위는 독립 Round1이다. 후속 작업은 학회/원문/Discussion 접근, 정서 전이의 가장 가까운 선행연구 역검색, 데이터 Agent의 실제 측정 필드 확인, 교차 Agent 반론이다. 이 후속 단계는 본 보고서에서 실행한 것으로 기록하지 않는다.
