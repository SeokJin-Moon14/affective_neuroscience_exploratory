# NSD: 보유 자료 우선순위를 위한 관측 범위 확인

작성: Agent03 Vision Decoding · 2026-11-12. 기존에 저장된 공식 코드와 메타데이터 조사 기록만 읽었다. 새 인터넷 검색, 원자료 다운로드, 새 RQ 작성은 하지 않았다.

**NSD는 사용자가 이미 보유한다고 밝힌 1순위 자료다.** 이번 클라우드 확인은 공식 코드가 어떤 자료를 읽는지에 관한 확인이다. 사용자의 실제 보유본에 접근하여 이미지·뇌 배열·행동 표를 열었다는 뜻은 아니다. 보유본의 경로와 세부 구성이 미확인이라는 이유로 자료가 없다고 판단하거나 연구 구상 자체를 중단하지 않는다.

## 1. 실제 확인한 과제·자극·측정

| 항목 | 직접 확인한 범위 | 아직 확인하지 않은 범위 |
|---|---|---|
| 주 과제 | 정지 사진을 시행별로 제시하고 fMRI 반응을 추정한다. 공식 예제는 빠른 사건 관련 설계이며 인접 시행의 혈역학 반응이 상당히 겹친다고 설명한다. 행동 파일에는 정답 여부·반응시간·결측 표시가 있다. [S1, S2] | **old/new 연속 재인이라는 과제의 정확한 지시문, 제시 시간, 응답 선택지는 이번에 읽은 원자료에 명시되지 않았다.** 공식 README의 `nsd_recog`·기억 분석 항목만으로 이를 상세하게 복원하지 않는다. 자유 회상·심상 과제로 취급할 근거도 없다. |
| 자극 | 공식 예제의 전체 이미지 인덱스는 73k, 참가자별 인덱스는 10k다. 이미지 읽기 계약은 `/imgBrick`, 425×425 RGB `uint8`이다. 시행→개인 이미지→전체 이미지의 두 단계 연결이 필요하다. [S1] | 실제 사진 내용, 사용자 보유 이미지 수·손상 여부, COCO 원본 ID와의 매핑 실물. 73k 이미지 은행을 모든 참가자가 모두 본 것은 아니다. |
| 참가자·세션 | 공식 분석 코드는 8명, 세션 수 `[40,40,32,30,40,32,40,30]`을 사용한다. 세션당 750시행, 최대 30,000시행이다. [S2, S3] | 현재 보유본의 참가자·세션별 누락과 사용 가능한 시행 수. 위 숫자는 공식 코드의 설정이지 로컬 배열을 세어 얻은 결과가 아니다. |
| 뇌 측정 | 7T fMRI는 공식 데이터 논문 README에서 확인된다. 시행별 반응 크기인 beta, 기능 공간·표면 공간 자료, ROI와 잡음 상한 분석 코드가 있다. 1.8mm 공간과 TR 1.333초는 공식 예제에 명시된다. [S3–S5] | 원 acquisition header, 실제 coverage와 참가자별 품질, 특정 정서 관련 영역의 사용 가능한 신호. 1mm 파생 공간이 있다는 사실을 원 촬영 해상도로 읽지 않는다. |
| 반복 | 동일 이미지의 세 시행이 모두 있는 경우를 골라 평균·잡음 추정에 쓰는 공식 코드가 있다. 따라서 실제 반복 반응으로 이미지 간 차이와 반복 간 변동을 구별할 수 있다. [S1, S3] | 모든 이미지에 세 반복이 있다는 보장은 없다. 세션 미완료·결측을 반영하여 실제 반복 수를 확인해야 한다. 반복 세 번을 새로운 자극 세 개나 독립 참가자 세 명처럼 세면 안 된다. |
| 행동 | `responses.tsv`에서 `session`, `time`, `iscorrect`, `RT`, `missingdata`를 읽는 예제가 있다. RT는 ms, time은 날짜 단위다. [S2] | 실제 TSV의 헤더·값·응답 코드와 모든 행동 열. 정확도·RT를 정서 평정으로 바꿔 부를 수 없다. |
| 정서 주석 | 이번에 직접 읽은 공식 코드와 기존 주석 사전에서는 정서 범주·valence·arousal의 인간 평정 실물을 확인하지 못했다. [S6] | 관련 주석이 어느 배포본에도 없다고 확정한 것은 아니다. 사용자 보유 추가 주석·외부 주석·같은 이미지에 대한 평정의 존재와 연결 범위는 미확인이다. |
| 텍스트 주석 | 이번 확인에서 캡션 표와 COCO ID 연결 표를 직접 열지 못했다. | 원본 COCO 캡션을 결합할 수 있는지, 이미지별 캡션 수·출처·매핑은 확인 대상이다. 외부 캡션이나 AI 생성 문장은 NSD 참가자가 회상하거나 말한 내용이 아니다. |
| 시선 | 공식 데이터 논문 README는 `main/nsd_et*.m`의 **시선 추적 전처리·분석 코드가 있음**을 명시한다. [S5] | 시선 원자료의 현재 배포 상태, 보유 여부, 참가자·시행 범위, 정합·품질은 확인하지 않았다. NSD에 시선 정보가 전혀 없다고 단정하면 안 된다. 특정 시선을 유도한 새 실험이 있다는 근거도 아니다. |

부가적으로 README에는 fLoc와 pRF 실험 분석이 명시된다. 이는 기능적 영역 정의의 근거가 될 수 있지만, 정서 유발 과제나 정서 localizer가 제공된다는 증거는 아니다. [S5]

## 2. 클라우드에서 연 것과 아직 열지 않은 것

**직접 읽음:** Agent01이 저장한 공식 `nsdcode` README, `nsdexamples` README·자료 읽기·반복 beta·행동 예제, `nsddatapaper` README·잡음 추정 코드. 통합 `datasets/nsd/verified_spec.md`, `annotation_dictionary.csv`, `metadata_inventory.csv`도 읽고 원 코드와 대조했다. 후자의 CSV는 **우리 조사팀이 작성한 목록**이며 NSD 원배포 metadata 실물이 아니다.

**이 확인에서 직접 열지 않음:** 사용자의 `nsd_expdesign.mat`, `nsd_stimuli.hdf5`, beta 배열, `responses.tsv`, 시선 배열, 캡션·COCO 연결 표. 아래 경로는 공식 예제의 파일 계약이지 현재 사용자 보유본에서 발견한 절대 경로가 아니다.

- `nsddata/experiments/nsd/nsd_expdesign.mat`: `masterordering`과 `subjectim`.
- `nsddata_stimuli/stimuli/nsd/nsd_stimuli.hdf5`: `/imgBrick`.
- `nsddata_betas/ppdata/subjXX/func1pt8mm/betas_fithrf/betas_sessionXX.mat`: 시행별 `betas`.
- `nsddata/ppdata/subjXX/behav/responses.tsv`: 행동 표.

자료 읽기 예제의 정수 MAT beta는 `/300`으로 percent signal change로 환산한다. 다른 파일 형식까지 같은 변환을 일괄 적용할 수는 없다. 공식 잡음 추정 코드는 이미 변환된 HDF5·표면 beta를 별도로 취급한다. [S3, S4]

원 논문 본문·Methods·Discussion은 이 확인에서 읽지 않았다. 기존 `verified_spec.md`의 서지 미확인 표기는 후속 기록과 구분해야 한다. 현재 `literature/nsd_bibliography_evidence.json`과 canonical **P103**에는 eLife 공식 XML의 참고문헌에서 확인한 2021 preprint 서지가 있다. 이는 **서지 E2**이며 NSD 본문 열람으로 승격되지 않는다. 공식 코드 직접 확인은 **E1**, 미확인 본문은 **E0**로 남긴다.

## 3. 기존 자료가 허용하는 정서신경과학 관측

가장 직접적인 관측 단위는 **어떤 사진을 보았을 때 어느 참가자의 어느 영역이 어떻게 반응했는가, 같은 사진을 다시 볼 때 그 반응이 얼마나 유지되는가**다. 이 구조는 시각 내용으로 설명되는 뇌 반응과, 이미지에 독립적으로 부여된 정서적 의미와 관련된 뇌 반응을 비교하는 기반이 된다. 다만 정서적 의미를 표시할 인간 주석의 존재·범위는 아직 확인 조건이다.

| 기존 자료로 검토할 수 있는 범위 | 결론의 경계 |
|---|---|
| 이미지 특징과 영역별 반응의 관계, 반복에 따른 안정성, 새로운 이미지 내용으로의 일반화 | 이는 사진과 반응의 관계다. 정확도가 높다는 이유만으로 정서 처리 기제나 인과 관계를 입증하지 않는다. |
| 같은 이미지에 연결되는 독립 인간 정서 평정이 확보되는 경우, 내용이 달라도 유지되는 정서 관련 반응과 내용에 의존하는 반응의 구별 | 기존 주석이 없다면 **새 평정 수집**으로 기존 BOLD를 재분석할 수 있다. 새 뇌 촬영과는 다른 자원 요구다. 외부 평정은 사진의 정서적 의미에 대한 증거이며 촬영 참가자의 시행별 상태를 직접 측정한 값이 아니다. |
| 뇌에서 복원한 시각 정보가 정서 주석을 얼마나 보존하는지, 실제 사진·뇌 직접 예측과 비교 | decoder와 emotion head는 관측을 돕는 도구다. 세 경로의 정확도만으로 뇌 안에 같은 처리 경로나 공유 정서 기제가 존재한다고 결론 내릴 수 없다. |
| 시선 기록이 실제로 제공되고 시행별로 연결되는 경우, 기존 자발적 시선 차이가 사진·뇌 관계를 얼마나 설명하는지 | 관찰된 시선과 뇌 반응의 공변동이다. 시선 위치를 실험적으로 바꾼 효과는 아니다. 현재 이 분석의 파일 접근·품질은 미확인이다. |

AI가 사진에 정서 점수나 캡션을 붙이는 것은 계산한 특징을 추가하는 일이다. 독립 인간 정서 정답, 새 참가자 행동, 새 뇌 관측을 추가하는 일이 아니다. 반복이 있어도 사진 내용과 정서가 자연스럽게 함께 변하는 한계를 자동으로 해결하지는 못한다.

## 4. 기존 관측으로 대체할 수 없는 것

- 사진을 편집·생성하여 위험물 크기나 행동·관계를 바꾸어도 **그 편집본을 본 뇌 반응**이 생기지 않는다. 원래 촬영된 사진 사이의 자연적 차이는 분석할 수 있으나, 동일 장면 편집의 인과 효과와 같지 않다.
- 이미 기록된 시선이 있을 가능성과 **새로 지정한 위치를 보게 했을 때의 뇌 반응**은 다르다. 후자는 별도의 조작 자료가 필요하다.
- 같은 사진의 반복 제시와 정답·RT는 **사진 없이 장면을 회상하거나 미래 장면을 예상한 뇌 반응**의 대체물이 아니다. 이번 공식 근거에서 그런 시행 유형을 확인하지 못했다.
- fMRI 시계열과 시행별 beta가 있다는 이유로 밀리초 단위의 정서 처리 순서, 사진 속 사건이 실제로 전개되는 동안의 연속 반응을 관측했다고 할 수 없다.

따라서 이전 v3의 새 자극 조작·새 BOLD 실험을 NSD만으로 이미 실행 가능한 우선안이라고 제시하면 안 된다. **새 시선 조작이나 회상 과제에서만 핵심 결론을 검증할 수 있는 연구는 이번 보유 자료 중심의 주력 후보에서 제외해야 한다. C06-C의 기억 정확성 문제를 NSD의 일반적인 `iscorrect` 열로 해결했다고 할 수 없다.** 무엇에 대한 정답인지가 다르며, 이번에 확인한 사진 관찰 중 행동 정답은 회상 내용의 정확성이나 회상 당시 뇌 반응을 제공하지 않는다. 이는 나중에 파일 경로만 찾으면 해결되는 스키마 문제가 아니라 필요한 관측의 차이다.

반면 NSD를 이용한 기존 사진·반복 반응 분석은 1순위 자료에 맞는 출발점이다. 실제 분석 직전에는 보유본 manifest, 이미지 ID 연결, 반복 수, 관련 인간 주석과 시선의 존재를 작은 파일·헤더부터 확인하면 된다. 이번 범위에서는 그 확인을 수행했다고 주장하지 않는다. 새로운 RQ는 작성하지 않았다.
