## 읽은 범위

- 주요 README 8개와 Brain-IT transfer README의 서지·입출력·학습/추론 안내를 읽었다. Takagi README는 두 연구, Brain-IT README는 두 연구를 포함하므로 고유 연구10건이다.
- MindEye2 Train/final_evaluations 노트북은 `*_cells.txt`로 code/markdown만 추출해 입력층·출력 target·손실·retrieval cell을 검토했다. 노트북의 저장 출력은 새 실행 결과가 아니다.
- MindEye2 models/utils의 대조 손실·prior MSE·cosine/topk; Brain-IT encoder/decoder 훈련·transfer 및 모델 정의의 관련 부분을 확인했다. 전체 프로그램 감사·실행은 하지 않았다.
- `brainit_page.txt`, `mindbridge_page.txt`는 root tree와 commit 식별에만 사용했다.
- GitHub 검색 결과는 공식 저장소를 찾는 탐색 자료이며 자체로 논문 내용의 근거가 아니다.
- 실패한 BrainCLIP 추정 URL을 존재 부정이나 다른 저장소의 공식성 확인으로 사용하지 않는다. BrainCLIP은 이번 문헌 집계에서 제외했다.
- arXiv/Hugging Face403으로 본문/Discussion/가중치 실물 미확인. 논문 또는 checkpoint가 없다는 뜻이 아니다.
