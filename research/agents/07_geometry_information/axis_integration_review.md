# Agent07 Stage3 Axis 통합 검토

작성·검토일: 2026-11-12. 담당: Agent07. 상태: 기존 자료의 유한한 통합 검토. 네트워크 조회·모델/뇌 분석·새 데이터 감사는 수행하지 않았다. 이 문서만 작성하며 공유 Axis 파일을 수정하지 않는다. **Round2–5 토론 완료 기록이 아니다.**

## 1. 적용 범위와 근거

AGENTS.md §9의 최신 지시를 적용한다. **Horikawa·Emo-FilM·Mind Captioning·NSD·Spacetop의 보유는 사용자 진술로 확인된 전제**이며 Axis 등록과 개념 조합을 지금 진행한다. 보유 여부를 다시 검증하거나 스키마 확인까지 Axis 작업을 보류하지 않는다. 아래 ‘조건부’는 실제 분석에서 사용할 필드·측정 단위의 조건이며 데이터 미보유라는 뜻이 아니다. Mind Captioning은 정확한 식별자·버전·주석을 이름으로 추정하지 않는다.

검토 입력:

- `axis_map/candidate_subaxes.json`: 30개 후보의 ID·정의·근거·데이터 조건.
- `RESEARCH_MISSION.md` §1.1, §4와 §12, `axis_map/seed_taxonomy.csv`: 기존 A–X, 유형 태그, 제외 범위와 추론 한계.
- 6개 보고서: Agent01 `round1_independent_report.md`, `horikawa/verified_spec.md`, `emofilm/verified_spec.md`, `nsd/verified_spec.md`, `spacetop/verified_spec.md`; Agent05 `report.md`.
- Agent07 기존 `report.md`, `papers.csv`: 직접 검토한 공식 문헌·코드의 제한된 E1/E2 범위.

이 문서의 병합 판정·교차연결·예측은 모두 **E3 통합 제안**이다. Agent01/05의 E1을 이어받을 때도 기존 보고서가 실제 확인한 문서·코드·metadata 범위로 한정하며, 이번 단계에서 원문을 다시 직접 검증했다고 주장하지 않는다. 다른 역할 후보의 논문 ID는 출처 추적용이며 해당 원문을 재검토했다는 표지가 아니다. 30개 JSON에 없는 Agent01/05의 각 3개 Sub-axis도 보고서에서 명시적으로 가져왔다.

## 3. 핵심 교차연결 6개

모든 연결은 최소 세 유형을 **구체적인 역할**로 결합한다. 유형 약호: 현상=Construct / Stimulus, 신경=Neural, 방법=Model / Method, 구조=Structure / Dynamics, 추론=Inference / Measurement. 각 연결은 즉시 Axis에 등록 가능하다. 아래 실현성 조건은 분석 시작 시 확인한다.

### C1. 공통 정렬의 성공과 정서 관련 정보의 손실이 공존하는가?

- **연결:** G1 ↔ BF1 ↔ S10.1 ↔ 05a ↔ P-A01. A/B/C(현상), F/O(신경), G/H/J(방법), K/X(구조), Q/S/T(추론): 5유형.
- **경쟁 설명:** 공통 잠재공간이 필요한 정보를 충분히 보존한다 / 감각·의미에 좋은 공통 정렬이 신뢰 가능한 정서 관련 신경정보 일부를 제거한다 / 감소는 차원수·정규화·잡음 차이다.
- **관측·반증:** 용량·rank·입력·readout 튜닝 예산을 맞추고 정렬 전후 독립 정서 대비와 신경 설명량을 내용 보류 자극에서 비교한다. 정렬이 증가하면서 신뢰 가능한 정서 대비가 일관되게 줄어들면 충분성 설명을 반박한다. 감소가 신뢰도·rank·의미 통제로 소실되면 선택적 정보 손실 설명을 반박한다. 학습목표 변경과 사후 정렬 변경은 별도 실험 요인이다.
- **조건부 데이터 경로:** 보유 Horikawa의 자극–뇌–주석 결합을 일차 경로로 등록. Agent01이 확인한 실제 `stim_index`와 내용 중복 목록을 이용한 group split을 적용하고, 보유 처리본의 반복/신뢰도 추정 단위를 확인한다. NSD는 반복 기반 시각 통제·정렬 보정 경로이며 정서 정답을 자동 제공한다고 보지 않는다. Mind Captioning은 식별자와 paired caption–자극–뇌 단위가 확인되면 언어 압축 가지에 연결한다.
- **근거:** G07-P01/P02/P10; Agent05 P02/P03/P04; Agent01 Horikawa/NSD 명세. 신규 신경 결과가 아닌 E3.

### C2. 사건 단계에 정렬되는 기하가 시계시간·HRF 설명을 넘는가?

- **연결:** K07.2 ↔ 05 `C-D-05c`/`D-V-05b` ↔ A2-S2 ↔ Q-A01 ↔ SYS08.2. C/A(현상), F/E(신경), H/V(방법), D/K(구조), Q/T(추론): 5유형.
- **경쟁 설명:** 신경 정서 전이는 독립적으로 정의한 사건 단계에 안정적이다 / 시간 위치·편집 리듬·평정 지연·HRF로 정렬된다 / 학습한 정렬이 서로 다른 궤적을 강제로 같게 만든다.
- **관측·반증:** 정서/BOLD를 쓰지 않고 학습한 사건 정렬을 보류 영화에 적용한다. position-only·DTW·motion/컷·같은 과거 창 대조보다 기하 재현성이 개선돼야 한다. 시간/관측 null로 같은 결과가 재현되거나 미래 입력 차단 후 이득이 사라지면 사건 상태 설명을 반박한다. H0 연결성이 존재해도 방향성·attractor 증거로 부르지 않는다.
- **조건부 데이터 경로:** 보유 Emo-FilM의 1Hz 외부 consensus와 film-relative 시계, scan의 film onset을 연결한다. Agent01의 30명 fMRI와 44명 주석자는 별도 코호트이므로 개인별 연속 정답으로 사용하지 않는다. Spacetop alignvideo의 확인된 평정은 클립 후 단위이므로 클립 관계 검증에 연결하고 영상 내부 정서 궤적 검증으로 늘리지 않는다. Mind Captioning에 사건 순서 metadata가 있으면 별도 관측 경로로 추가한다.
- **근거:** G07-P06/P09/P10; Agent05 P08/P10/P11; Agent01 Emo-FilM/Spacetop 명세.

### C3. 좁은 공유 통로와 분산 신경정보의 비가산적 결합은 양립하는가?

- **연결:** 05 `M-X-05a` ↔ A2-S3 ↔ SYS08.1 ↔ X07.1의 PID 부분. A/B(현상), E/F(신경), M/H(방법), K/X(구조), Q/T(추론): 5유형.
- **경쟁 설명:** 각 정보원의 독립 기여를 더하면 충분하다 / 공유 통로는 좁아도 고유 경로의 결합이 추가 정보를 준다 / joint 이득은 단순 모델 용량·공통 원인·노이즈 평균화다.
- **관측·반증:** 동일 복잡도의 비선형 additive와 joint 모델, ROI/모달리티 가림, 공유+고유 대 공유-only를 비교한다. 가산 null에서 이득이 재현되면 시너지 주장을 기각한다. PID는 표적·정의·군집화·독립 블록 표본을 고정하고 안정성을 통과한 경우에만 정보량으로 해석한다. 통로 token 수를 bit나 신경차원으로 읽지 않는다.
- **조건부 데이터 경로:** 보유 Horikawa에서는 먼저 ROI 정보원 결합을 시행단위로 구성한다. 보유 Emo-FilM에서 실제 제시된 영상/오디오 스트림과 동기화가 확인되면 모달리티 결합 가지를 추가한다. 두 가지를 같은 분석으로 합치지 않는다. Spacetop은 클립 후 유효 정서 평정이 있는 단위로 연결하며 결측 선택을 모델링한다.
- **근거:** G07-P03/P08/P10; Agent05 P02/P03/P04; Agent01의 평정 단위/결측 기록. FactorCL 코드의 목적과 PID 정의는 구별한다.

### C4. 데이터 간 거리구조 정렬이 정서 의미의 대응을 실제로 운반하는가?

- **연결:** 좁힌 X07.1 ↔ Agent01 `X-A01` ↔ A2-S1 ↔ A12-S2. A/C(현상), F/O(신경), J/H(방법), K/X(구조), P/Q/S(추론): 5유형.
- **경쟁 설명:** 다른 자극·주석 체계에 공통 관계구조가 있다 / 정렬은 시각 의미만 맞춘다 / 유사한 거리구조의 대칭 때문에 의미 대응이 여러 개다 / 주석 척도 차이가 공통성처럼 보인다.
- **관측·반증:** GW 등으로 얻은 근접 최적 결합들의 불확실성을 보고하고, 정렬에 쓰지 않은 anchor 또는 별도 측정의 관계를 예측한다. 낮은 비용을 가진 다른 결합들이 상충하는 정서 대응을 만들거나 anchor 예측이 단순 의미 baseline을 넘지 못하면 ‘공통 정서 코드’ 해석을 반박한다. 훈련하지 않은 표적을 사후 같은 이름으로 맞추는 절차를 외부검증으로 부르지 않는다.
- **조건부 데이터 경로:** 보유 Horikawa–Emo-FilM–Spacetop을 관계 비교 경로로 등록한다. 자극 집계/외부 연속 consensus/클립 후 평정을 서로 다른 관측모형으로 둔다. 공통 문항·독립 anchor가 없으면 별도 공통 평정 또는 의미수준 검증으로 확장하며 Axis 자체는 유지한다. NSD는 시각기하의 참조 경로다. Mind Captioning은 식별과 측정단위 확인 후 ontology 그래프의 별도 노드로 연결한다.
- **근거:** G07-P02/P05/P07; Agent01 U5와 X-A01 및 네 데이터 명세. 동명 라벨을 곧바로 같은 구성개념으로 합치지 않는다.

### C5. 개별 잠재축이 불안정해도 정서 관련 부분공간은 식별 가능한가?

- **연결:** X07.1 ↔ R.FAI2 ↔ X.S10.3 ↔ A12-S2 ↔ H-F-X.BF2. A/C(현상), F(신경), J/H/R의 분석모형(방법), K/X(구조), P/Q/S/T(추론): 5유형.
- **경쟁 설명:** 의미 있는 개별 정서 축이 존재한다 / 좌표는 비유일하지만 관련 부분공간의 예측정보는 안정적이다 / 안정성은 감독·누락 의미·공통 자극의 산물이다.
- **관측·반증:** seed·dictionary 크기·표현가족·보조변수 설정을 바꾸어 개별 축과 부분공간을 별도로 평가한다. 개별 축이 바뀌어도 독립 자극의 정서 관련 신경 대비가 보존되면 단일축 해석은 약해지고 부분공간 해석이 남는다. 의미 특징군 확장이나 보류 환경에서 효과가 소실되면 정서 고유성 주장을 반박한다. seed 안정성만으로 iVAE의 조건부 독립·충분한 변화 조건을 입증하지 않는다.
- **조건부 데이터 경로:** 보유 Horikawa의 내용환경 보류를 기본 경로로 둔다. Mind Captioning에 원 캡션·생성 캡션·신경 측정의 출처와 단위가 확인되면 개념 집합 확장 검정을 연결한다. 이 필드의 존재를 이름으로 추정하지 않는다. NSD는 캡션/시각 표상 비교에 필요한 실제 mapping을 확인한 뒤 시각 대조군으로 사용한다.
- **근거:** G07-P03/P04/P05/P10; JSON의 R.FAI2/X.S10.3/H-F-X.BF2 정의; Agent01 P-A01. 다른 역할의 원문을 새로 확인한 것은 아니다.

### C6. 복원 영상의 정서 관련 특징은 신경 관측이 결정한 것인가, 생성 prior가 고른 것인가?

- **연결:** G/X-VD1 ↔ L09b ↔ G1 ↔ L09c. A/B/C(현상), F(신경), G/L(방법), K/X(구조), Q/T/P(추론): 5유형.
- **경쟁 설명:** 정서 관련 출력 특징은 뇌 조건에 의해 제한된다 / 여러 관측 등가 후보 중 prior가 선택한다 / 생성 전 정렬에서 정보가 사라졌지만 prior가 그럴듯하게 보충한다.
- **관측·반증:** 생성 전 latent·prior-only·뇌 조건 교환·다중 seed 후보를 내용 보류 자극에서 비교한다. 같은 신경 적합도 범위의 후보에서 정서 관련 특징이 크게 달라지면 단일 복원의 정서 식별 주장을 반박한다. prior 교체에도 특징이 안정적이고 올바른 뇌 조건이 교환 조건보다 독립 대비를 구별해야 관측의 제약이라는 설명이 남는다. 이 결과도 신경 인과성은 아니다.
- **조건부 데이터 경로:** 보유 NSD로 반복 기반 신경 적합도와 이미지 검색의 관측 등가성 평가를 구성하고, 보유 Horikawa의 검증된 자극 수준 정서 측정에 정서 대비를 연결한다. NSD의 정서 정답을 가정하지 않는다. Mind Captioning은 실제 뇌–캡션 자료로 식별되는 경우 텍스트 출력의 등가성 검증 가지를 추가한다. 추가 뇌 측정이 필요한 생성 자극 실험은 L09c의 후속 경로로 명시한다.
- **근거:** G07-P01/P03/P07/P10; JSON의 G/X-VD1/L09b/L09c 정의; Agent01 NSD/Horikawa 명세.

## 4. 상위 축 추가 여부

**현재는 새로운 상위 축을 추가할 필요가 없다.** 정렬·기하·정보보존이라는 공통 주제는 기존 K(구조), X(식별·분해), J(학습목표), O(개인/공유 정렬), Q/T(측정·평가)의 교차연결로 충분히 표현된다. ‘정보보존’ 상위축을 만들면 학습 과정의 손실, 관측의 비식별성, 의미 압축, 측정 잡음이라는 서로 다른 원인을 같은 범주로 뭉칠 위험이 있다.

대신 다음 운영 변경을 권고한다.

1. K는 비교/기하 추정량, X는 식별 가능한 주장과 동치류, Q는 관측·신뢰도 조건으로 역할을 명시한다. 여러 태그를 허용하되 각 RQ의 주된 판별대상은 하나로 쓴다.
2. G1의 완전 병합을 우선 반영하고 원본 ID 둘을 alias/provenance로 보존한다. G2·G5·G8은 가족 관계로 표현하여 서로 다른 실험 대비를 지우지 않는다.
3. X07.1의 PID 부분은 G5, 잠재식별/GW 대응 불확실성은 좁힌 X07.1로 연결한다. 한 하위축에 서로 다른 estimand가 과도하게 쌓이지 않게 한다.
4. 새 상위축은 기존 A–X의 조합으로 설명할 수 없는 독립 계산 문제와 고유 반증을 확보했을 때 검토한다. 현재 여섯 연결은 이 조건을 충족하는 별도 축이 아니라 기존 축 사이의 생산적인 조합이다.

## 5. 통합 시 그대로 보존할 한계

- 데이터 보유와 현재 파일 접근·버전·스키마 확인은 분리한다. Agent01/05의 과거 ‘접근 전 보류’ 표현은 **Axis 차단**으로 계승하지 않고 분석 조건으로 번역한다.
- Horikawa의 모든 ID가 달라도 내용 독립성이 보장되지 않는다. Emo-FilM 외부 consensus는 fMRI 참가자 개인의 연속 정답이 아니다. Spacetop 클립 후 평정은 영상 내부 연속 궤적이 아니다. NSD에 독립 정서 ground truth가 있다는 근거는 이번 자료에 없다.
- 정보보존·shared variance·상호작용 예측이득·PID synergy·식별 가능성은 서로 대체할 수 없다. CKA나 GW 비용도 MI의 추정값이 아니다.
- 후보의 문헌 중복·최신성은 기존 E3 상태다. 본 문서는 Stage3의 중복 판정과 연결 설계이며 검증된 신경 결과, 최종 RQ 승인, 데이터 분석 완료 또는 Round2–5 완료를 뜻하지 않는다.
