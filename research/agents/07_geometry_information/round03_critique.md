## R3-07-C08-01 — 지역 정보의 합으로 충분한가: 정서관련 분산 정보와 영역 간 결합의 분리

판정: **수정**

- Q1: P028/P067은 결합/상태 모형을 제공하지만 같은 정서 대비에 강한 가산함수가 충분한지는 남은 질문이다.
- Q2: L/D/N의 필요성 대비는 모델 교체를 넘는다. 단, bilinear의 정규화 이득만 남으면 방법 비교다.
- Q3: 주표적이 실제 정서 주석이라 전체 BOLD 개선과 구분됐다. 자극집계 주석이면 개인 상태나 실시간 통신으로 확장 불가.
- Q4: ROI별 시행대응·내용중복 그룹·반복 신뢰도·평정 생성단위를 분석시에 확인한다. 데이터 보유를 재확인할 필요는 없다.
- Q5: 비선형 공통자극이 두 ROI를 동시에 구동하면 실제 통신 없이도 곱항이 유용하다. stimulus-only와 additive를 모두 강화해야 한다.
- Q6: 통계적 비가산 readout과 영역 사이 통신 기전을 분리해야 한다. 전체 Gram/RDM만으로는 정보가 어느 ROI에 배분됐는지 식별하지 못한다.
- Q7: ROI 블록 내 가역변환과 블록 사이 혼합을 분리한 대조, 공통원인 비선형 생성 null, 같은 자유도의 additive spline이 더 판별적이다.
- Q8: D와 N의 등가성은 지정 ROI·표적·함수계열에서 상호작용 readout 필요성의 상한을 주며 뇌의 상호작용 부재는 아니다.

**가장 강한 반론:** 결합항의 이득은 영역 간 상호작용의 필요성이 아니라 ROI 분할에 조건화된 비가산 판독의 필요성이다. 전체 표현에 직교 회전을 적용해 Gram을 보존해도 ROI별 분산과 결합계수는 달라질 수 있어, 기하 일치만으로 영역 간 결합을 주장할 수 없다.

**필요 수정:**

- estimand를 사전 고정 ROI 분할에서의 비가산 판독 추가위험 감소로 명명한다.
- 생물학적 ROI 분할과 수치 좌표 재표현을 구별하고 블록 내부 변환에 결론이 안정적인지 검사한다.
- 모델 불일치로 test 자극을 선별한 조건부 효과와 전체 자극분포 효과를 따로 보고한다.

**더 판별적인 검정:** 실제 통신이 없는 비선형 공통입력 합성계와 실제 상호작용계 모두에 같은 L/D/N 파이프라인을 적용한다. 전자에서도 동일 이득이면 네트워크 기전 해석은 기각하되, 실제 자료에서 가산모형의 부족이라는 관찰은 유지한다.

**부정 결과의 가치:** 비가산 판독이 필요하지 않은 범위를 좁힐 수 있다. 정밀도가 낮으면 미결정이며 정보 분산 자체는 반박되지 않는다.

**미해결·소수의견:** 소수의견: 가산의 한계 자체도 신경표상 제약으로 충분히 가치 있다. 메커니즘 언어를 제한한 뒤 과학후보로 유지할 수 있으며 무조건 방법후보로 낮출 필요는 없다.

근거: P028, P067, P051, P053. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음

## R3-07-C08-02 — 감각–transmodal gradient의 긴 문맥 이득은 신경 통합인가 관측시간 효과인가

판정: **수정**

- Q1: P066/P068의 시간통합·공간조직과 매우 가깝다. 독립 정서 대비의 문맥×gradient 교호작용이 남은 부분이다.
- Q2: 단일 상태모델 순위가 아니라 관측모형과 문맥을 독립 변화시키는 경우 과학 질문이 된다.
- Q3: nested 정서주석 추가/제거 대비를 둔 것은 적절하나 total·conditional 효과와 평가단위를 명확히 나눠야 한다.
- Q4: native TR·film onset·주석시간·외부/독립 gradient·HRF 추정자료가 필요하다. 외부 consensus를 개인 연속 정답으로 쓰지 않는다.
- Q5: 더 느린 자극 feature와 넓은 HRF는 긴 신경통합과 비슷한 예측을 만들 수 있다. 유연한 FIR도 반대로 진짜 통합효과를 흡수할 수 있다.
- Q6: BOLD는 신경필터와 HRF의 합성 결과다. 같은 합성커널을 갖는 두 분해는 같은 시계열·거리구조를 주므로 예측우위만으로 각각의 시간상수를 식별할 수 없다.
- Q7: 독립 HRF 제약의 범위, convolution 동치 모의계, 같은 현재입력/상이한 과거의 보류 대비와 gradient 고유공간 안정성을 추가한다.
- Q8: 문맥 효과 부재는 관측모형을 넘는 추가 예측 필요성이 작다는 뜻이다. HRF가 불명확하면 신경통합 부재로 결론내리지 않는다.

**가장 강한 반론:** HRF와 신경적 시간통합의 convolution 분해가 관측상 비유일할 수 있다. 유연한 HRF를 통제했다는 사실만으로 신경시간상수를 고유하게 식별하지 못한다.

**필요 수정:**

- 독립 HRF 정보가 없으면 주장범위를 사전 지정 HRF family 밖의 추가 문맥 예측으로 한정한다.
- gradient 부호·근접 고유값의 회전 모호성을 독립 기준과 부분공간 분석으로 처리한다.
- 고유 정서분산과 주석을 공유하는 의미분산을 별도 estimand로 보고한다.

**더 판별적인 검정:** 짧은 신경필터+넓은 HRF와 긴 신경필터+좁은 HRF가 동일 BOLD를 내는 모의쌍을 먼저 구성하고 파이프라인이 둘을 잘못 구별하지 않는지 검사한다. 실제 판별은 독립 HRF 제약 또는 두 모형이 다른 예측을 내는 통제 이력 대비에서만 수행한다.

**부정 결과의 가치:** 현재 자료에서 식별 가능한 시간모형의 동치류와 HRF 가정에 의존하는 결론 범위를 얻는다.

**미해결·소수의견:** 소수의견: HRF 완전식별이 없어도 보류자극 문맥이득의 공간분포는 보고할 수 있다. 다만 이를 신경 통합시간의 지도라고 부르는 데 동의하지 않는다.

근거: P028, P066, P068, P051. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음

## R3-07-C08-03 — 정서관련 모델–뇌 지도의 공간 조직은 비정상적 신뢰도가 만든 모양인가

판정: **유지**

- Q1: P062/P063/P064가 공간 null의 한계를 이미 다루므로 제1종 오류 보정 자체는 신규 생물학 질문이 아니다.
- Q2: 원안이 방법 게이트로 축소할 조건을 명시했다. 그 분류를 유지하며 독립 과학 RQ로 중복 집계하지 않는다.
- Q3: 입력 지도가 독립 정서 대비로 정의돼야 한다. null calibration만 성공하면 정서 관련 발견은 없다.
- Q4: surface/mask·parcel 면적·반복 차이·지역별 smoothness를 확인해야 한다. 단일 SNR 요약만으로 비정상 noise field를 정하지 않는다.
- Q5: noise-only 계의 공간상관·자극 설계·반복구조를 실제 파이프라인과 맞추고 동일 지도에서 nuisance를 맞춰 신호를 흡수하지 않는다.
- Q6: 관측 지도가 특정 null과 양립하지 않는다는 결론은 해부학적 조직의 유일한 원인을 확정하지 않는다. variogram 동일성도 공동분포 동일성을 뜻하지 않는다.
- Q7: 독립 반복 차이로 잡음모형을 적합하고 정답을 아는 주입신호에서 국소 오류율·검정력·효과복원을 함께 평가한다.
- Q8: 지도 효과가 null에 재현되면 해당 공간주장의 근거를 축소한다. null 적합 실패는 신경조직의 양성증거가 아니다.

**가장 강한 반론:** 주검정이 제1종 오류와 검정력 calibration이면 이는 이미 유용한 공통 평가 모듈이다. 이를 정서 공간조직 발견이라는 독립 RQ로 세면 결과 수준을 부풀린다.

**필요 수정:**

- 현재의 방법 게이트 지위를 명시적으로 고정하고 AS18 공통 모듈로 배치한다.
- null 적합에는 정서 효과지도와 독립된 반복잔차/훈련자료를 사용한다.
- 단일 variogram 적합 외 지역별 covariance·분포·국소 오류율을 보고한다.

**더 판별적인 검정:** 같은 관측기하를 가지지만 신호 주입의 해부학적 위치만 다른 모의자료에서 좌표에 민감한 지도통계와 기하불변 통계가 각각 무엇을 검출하는지 확인한다. 고정 외부 위치가 없으면 해부학적 국소화는 판정하지 않는다.

**부정 결과의 가치:** 잘못된 null에서만 나온 공간 효과를 식별하며 후속 후보의 해석 범위를 교정한다.

**미해결·소수의견:** 소수의견: 독립 신경과학 RQ 집계에서는 제외하되 필수 방법 산출물로는 높은 우선순위다. 특정 위치의 경쟁 예측을 추가하면 과학후보로 승격할 여지는 남긴다.

근거: P026, P062, P063, P064. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음

## R3-07-C08-04 — 정서 변화와 동행하는 network-state는 자극 동기화 구조를 넘어서는가

판정: **수정**

- Q1: P067 상태모형과 P027 조건부 예측을 넘어 평균·covariance·정서 대비의 경쟁을 명시한 점은 남은 질문이다.
- Q2: HMM의 좋은 likelihood만 남으면 benchmark다. 현재안처럼 독립 주석 변화의 추가정보까지 요구해야 한다.
- Q3: BOLD likelihood와 정서 log score를 분리했다. 다만 상태 확률이 미래 BOLD를 사용하면 주석 변화의 예측 시점이 달라진다.
- Q4: 연속 런·표본수·관측 nuisance·정서 지연·state posterior의 filtered/smoothed 정의가 실제 필요하다.
- Q5: 잔차의 non-Gaussian 분포, 느린 분산변화, 불완전한 자극 이력은 covariance-state처럼 보인다. stationary Gaussian null 하나는 약하다.
- Q6: 평균 RDM이나 상태별 공간기하만 같아도 전이행렬은 다를 수 있다. 반대로 같은 관측 likelihood의 HMM은 상태라벨/분할이 달라 생물학적 상태가 고유하지 않다.
- Q7: 동일 emissions의 i.i.d. mixture·상태전이 없는 비정규 null·연속 변동 volatility 모형·과거전용 filtered 상태를 비교한다.
- Q8: covariance-state가 필요 없으면 해당 시간척도에서 평균/연속 모형으로 충분하다. 정서 대비 없는 likelihood 이득은 일반 동역학으로 분리한다.

**가장 강한 반론:** covariance HMM의 성공은 이산 신경 상태의 존재보다 비정규 관측분포나 연속 분산변화를 근사한 결과일 수 있다. 잔차화와 mean-only HMM만으로 이산 결합 상태를 식별할 수 없다.

**필요 수정:**

- 관측상태의 예측 이득과 이산 상태의 존재 주장을 분리한다.
- 시간 예측이면 posterior smoothing 대신 t까지의 filtered 확률만 사용한다.
- 상태라벨 순열에 불변인 전이/예측 통계를 쓰고 state 수 선택은 내부 fold에 둔다.

**더 판별적인 검정:** 상태별 평균/공분산을 고정한 채 전이만 제거한 mixture와, 같은 자기상관을 가지는 연속 covariance 모형을 보류 런의 순차 log score·독립 정서 대비로 비교한다. 기하가 같은 emissions에서 시간순서 통계가 추가 판별력을 제공해야 한다.

**부정 결과의 가치:** 정서 관련 예측에 필요한 정보가 공간분포인지 시간적 결합인지 좁힐 수 있으며 이산-state 해석은 실패해도 방법론 결과가 남는다.

**미해결·소수의견:** 소수의견: 이산 상태가 생물학적으로 실재하지 않아도 실용적 상태추상화는 허용한다. 명칭은 관측적 상태모형으로 제한해야 한다.

근거: P027, P029, P066, P067. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음

## R3-07-C08-05 — 내용이 같은 모델에서 계산 경로의 제약이 정서관련 신경정보를 가르는가

판정: **보류**

- Q1: P028/P029는 서로 다른 공간 prior를 이미 쓴다. 남은 것은 내용/접근 가능성을 고정한 관계 제약의 독립 효과다.
- Q2: 현재 graph·SSM·배열을 함께 비교하면 구조·접근범위·학습난도까지 달라 단일 계산 경로 질문으로 식별되지 않는다.
- Q3: 정서 대비를 명시했지만 일반 내용 성능 일치가 표현기하나 정보 접근의 일치를 보장하지 않는다.
- Q4: node ID·graph 생성규칙·SSM ordering·positional encoding·receptive field·ROI 범위를 구현 수준으로 명세해야 한다.
- Q5: 시간/공간 접근범위와 정규화 차이가 효과를 만들 수 있다. 같은 연결수/차수만으로 충분한 통제가 아니다.

**더 판별적인 검정:** 작은 정답모형에서 permutation-equivariance를 먼저 검증한다. 이어 node identity와 입력 feature를 고정해 관계만 바꾸고 동일 hop별 접근집합 또는 대응하는 content baseline을 통제한다. 이때 보류 정서 대비의 차이가 있어야 경로prior를 평가한다.

**미해결·소수의견:** 소수의견: 엄격한 방법 검증의 독립 출판 가치는 인정하지만, 프로젝트의 새로운 정서 신경 질문 수에 포함하는 데는 반대한다.

근거: P097, P100, P101, P051. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음

## R3-07-C12-05 — 공통 표상 밖의 안정적 정서 정보가 공유 ceiling에 가려지는가?

판정: **수정**

- Q1: P009는 공통/유형특이 코드 공존을 이미 보인다. 정렬이 버린 신뢰 가능한 정보라는 부분은 AS05/13과 중복하므로 병합이 적절하다.
- Q2: 같은 자료·대비라면 정보보존 후보의 validation 설계이며 별도 모델/데이터 교체 RQ로 세지 않는다.
- Q3: 잔차 재현성과 정서 대비를 둘 다 요구한 것은 적절하다. 자극 집계 주석으로 참가자 고유 정서 상태를 주장하지 않는다.
- Q4: 같은 참가자의 독립 반복과 test-independent alignment, 새 내용군 매핑 및 주석 불확실성 자료가 필요하다.
- Q5: 참가자별 가역 회전·자극 정체성·혈관/잡음 패턴이 안정적 잔차를 만든다. 반복가능성만으로 내용 고유정보를 입증하지 못한다.
- Q6: 참가자별 직교변환은 같은 표현기하와 동일 정보를 보존하지만 공유 좌표 차감 잔차는 크게 만들 수 있다. 따라서 잔차 크기≠공유화 정보소실이다.
- Q7: 훈련에서 추정한 가역 개인정렬 대 실제 rank-reducing 공유화, 공동/고유 동일차원 모델, 새 자극별 within-subject 평가를 비교한다.
- Q8: 가역정렬 후 고유 이득이 사라지면 좌표 차이 설명이 남는다. 비가역 축소 이후에도 재현 정서 대비가 추가되면 정보손실 주장이 좁게 지지된다.

**가장 강한 반론:** 안정적인 private 잔차가 존재해도 이는 같은 신경기하의 참가자별 좌표차이일 수 있다. 공통+고유 성능이 좋다는 사실만으로 공유화가 신경정보를 버렸다고 말하려면 가역 정렬과 비가역 압축을 분리해야 한다.

**필요 수정:**

- AS05/13의 정보보존 후보와 병합하며 target population별 ceiling 구분은 평가 모듈로 보존한다.
- 가역 개인정렬 후 남는 정보와 rank 감소로 잃는 정보를 별도 estimand로 둔다.
- 새 참가자 일반화와 같은 참가자의 새 자극 일반화를 같은 개인고유성 점수로 합치지 않는다.

**더 판별적인 검정:** 동일한 잠재표현에 참가자별 직교회전만 가한 positive-equivalence 대조에서는 공유 좌표 잔차가 있어도 정보소실은 0이어야 한다. 이어 독립적으로 알려진 private factor 또는 rank truncation을 추가한 자료에서만 실제 정보손실 검출력을 확인하고 실자료에 같은 절차를 적용한다.

**부정 결과의 가치:** private 성분의 필요성을 좌표 불일치·신뢰도·내용 특이성·실제 압축손실 중 어디에 귀속할지 범위를 좁힌다.

**미해결·소수의견:** 소수의견: 좌표 불일치 자체도 개인별 신경 배치의 중요한 결과다. 다만 정보량 차이와 구별해 별도 현상으로 보고해야 한다.

근거: P009, P051, P060, P100. E3 비판; 기존 문헌의 확인 범위 유지; 새 분석 없음
