### 가장 약한 가정

관계 설명 R과 예측력 일치 비관계 설명 Q의 단독 타깃 손실 L(A|O,R), L(A|O,Q)를 맞추면, 각각이 신경 신호 B와 공유하는 조건부 정보까지 같아진다는 가정이다. 단일 예측력 일치는 오류 구조·표본별 난이도·B와의 중복을 맞추지 않는다.

### 가장 강한 대안

관계·정서·여러 ROI가 관측되지 않은 공통 자극변수 U의 서로 다른 noisy 측정이다. 뇌 영역 간 직접 상호작용이 전혀 없어도 여러 noisy B를 결합한 비선형 추정이 가산 모형보다 좋을 수 있다. R이 U의 좋은 측정이면 N-D가 줄어든다. 이는 관계를 처리하는 특별한 신경 연산의 증거 없이도 주효과를 재현한다.

### 이미 알려진 부분

개념 병목의 불완전성, 입력 특징 추가에 따른 잔여 예측력 감소, 조건화 집합에 따른 상호작용 변화는 알려진 일반 문제다. P083/P084/P102는 방법상 근접 근거이며 정확히 같은 neural relational 대비의 직접 선행연구로 확정하지 않는다. TOP10_REVIEW가 명시한 직접 선행 공백은 남긴다.

### 추정대상과 함수족

- 모든 조건에서 같은 독립 측정 정서 타깃 A, 같은 외부 표본과 같은 손실을 고정한다. 정서 라벨을 조건별로 잔차화해 다른 Y를 비교하지 않는다.
- S=O, O+R, O+Q에서 g(S)=L(S+D)-L(S+N), 주효과 Δ=[g(O)-g(O+R)]-[g(O)-g(O+Q)]를 사용한다. 대수적으로 Δ=g(O+Q)-g(O+R)이므로 총손실과 g(O)도 반드시 보고한다. Δ만으로 원래 신경 상호작용의 설명량을 말하지 않는다.
- D가 의미 S에 따른 영역 내 변화를 허용하지 않고 N만 허용하면 S×ROI 상호작용을 ROI×ROI 효과로 오인한다. D=f0(S)+Σr fr(S,Br), N=D+영역간 항처럼 S 의존성·영역 내 비선형을 두 모형에 똑같이 허용하고 N의 추가 부분을 명시한다.
- 관측 feature 좌표와 모형군을 고정한다. 가산성은 비선형 재표현에 불변인 신경 성질이 아니다. 모델 파라미터 수뿐 아니라 regularization·하이퍼파라미터 탐색 예산·훈련곡선을 맞춘다.

### 판별 예측

고정 A와 공통 support에서 R의 효과가 Q보다 크고, 객체·관계 단어를 유지한 역할/관계방향 교란에서 선택적으로 약해지며, 원 영상의 강한 유연 의미모형·영역 내 비선형·공통입력 null을 추가해도 차이가 남아야 관계에 특정한 조건부 중복 설명을 지지한다. 관계 교란은 사람 검수로 자연스러움·정서답 누출을 확인하며 자동 문자열 섞기만으로 통제되었다고 하지 않는다.

### 필요한 수정

- R·Q 생성에는 평가 뇌반응·평가 정서 정답을 사용하지 않고, 생성모델·입력·검수의 provenance를 고정한다. 같은 BOLD에서 만든 Mind Captioning 결과를 독립 R로 쓰지 않는다.
- Q의 예측력 matching은 개발표본 안에서만 수행하고 실제 test에서는 불일치와 신뢰구간도 보고한다. 타깃별·내용층별·오류상관별 matching 민감도 분석을 추가한다. 공통 지지가 없는 관계/정서 조합을 외삽으로 해석하지 않는다.
- 원 감각 특징과 전체 비관계 의미를 이용한 유연한 기준모형을 포함한다. 관계 라벨만 명시적으로 분리한 약한 bag-of-objects와 비교해 승리를 선언하지 않는다.
- 공통 U→ROI들 및 U→R,A, 독립 영역잡음, HRF·측정잡음이 있는 no-coupling 생성 null에서 Δ가 생기는 정도를 조사한다. 실제 자극 구조를 보존한 null이 불가능하면 기전 주장을 포기하고 조건부 예측 결과로 제한한다.
- g(O)가 신뢰도와 최소 검출효과 기준에서 확인되지 않으면 감소 가설은 미검정으로 기록한다. 먼저 유의한 조건만 골라 후속 차이를 검정하는 선택은 독립 개발/검증 분할로 분리한다.

### 관측 독립성

- **unit**: Horikawa의 participant×stimulus 시행이 측정 행이고, 새로운 내용 일반화의 표집 단위는 내용그룹이다. 같은 영상의 여러 참가자·관련 clip을 독립 자극으로 세지 않는다.
- **split**: 내용그룹 보류와 참가자 일반화를 분리 보고한다. 동일 자극 주석은 참가자 행마다 복제되어도 독립 라벨 관측이 늘지 않는다. 모든 의미 선택·ROI·스케일·모형 선택은 훈련/개발자료에서만 한다.
- **annotation**: 외부 정서 주석과 관계 주석의 입력 독립성을 확인한다. 서로 다른 사람의 주석이어도 같은 자극의 의미를 공유하므로 통계적 독립 변수라고 가정하지 않는다.
- **inference**: 참가자와 내용그룹을 보존하는 계층적/교차 재표집 또는 적합한 군집 추론을 사용한다. Horikawa 참가자 5명의 모집단 일반화는 별도 불확실성으로 보고하며 ROI·voxel 수로 자유도를 부풀리지 않는다.

### 양성 결과 해석

강한 대조를 통과한 Δ는 명시된 의미 특징이 고정 정서타깃의 신경 결합 예측과 선택적으로 중복됨을 지지한다. 신경 통신의 제거, 순수 관계 코드, 인과적 기전의 증거는 아니다.

### 음성 결과 해석

Q도 같은 감소를 만들면 관계 특이 가설을 약화한다. g(O)가 없거나 측정 신뢰도가 낮으면 감소를 판단할 정보가 부족하다. 충분한 검정력에서 g가 유지되면 해당 관계 설명으로 신경 결합 예측을 대체하기 어렵다는 결과이며, 모든 관계 의미의 부재를 말하지 않는다.

### 판단을 바꿀 증거

정확한 직접 선행이 같은 고정타깃·함수족·관계대조를 이미 실행했다면 신규성 평가를 낮춘다. 반대로 관계역할 보존/교란, 강한 전체 의미 기준, 공통입력 null을 넘어 독립 내용에서 재현되는 Δ와 사전 최소효과 이상 신뢰구간이 있으면 수정에서 추진으로 올린다.

### 가장 약한 가정

생성 후보에 대한 forward model의 오차 분포가 자연 자극의 보류 반복에서 얻은 calibration과 교환가능하다는 가정이다. 모델 외삽 오차가 크거나 정서에 따라 편향되면 두 후보의 유지/배제는 신경정보보다 encoder 취약성을 반영한다.

### 가장 강한 대안

추가 반복이 신경 모호성을 줄인 것이 아니라, 첫 관측과 생성 최적화에 과적합한 후보가 독립 모델의 체계적 오차 때문에 탈락한다. 다른 모델 architecture도 같은 훈련자료·표현·자극 prior를 공유하면 독립 증거가 아니다.

### 추정대상과 관측

- 원 자극 i의 신경 관측 Y_i^(discovery)로 후보 x_i+,x_i-를 고정한다. 후보의 독립 인간 정서 주석 차이와 discovery 적합오차가 사전 문턱을 통과해야 witness로 등록한다.
- 독립 보류 신경 반복 Y_i^(holdout)는 같은 원 자극에 대한 추가 관측이다. 이는 후보별 forward 예측의 적합도를 검정할 뿐 생성 후보를 직접 보았을 때의 실제 뇌반응을 관측한 것이 아니다. 그 주장에는 두 후보를 새로 제시하는 측정이 필요하다.
- 주 통계는 고정 witness 중 holdout에서 한쪽만 허용범위를 벗어나는 비율 및 후보별 사전 고정 정서 신경대비 오차다. 둘 다 탈락, 둘 다 유지, 한쪽 탈락을 모두 보고하고 발견된 쌍이 없는 원 자극도 분모·탈락흐름에 남긴다.
- 양립성은 통상 검정에서 p>α라는 사실로 선언하지 않는다. 개발자료에서 정한 예측오차 허용폭과 calibration된 예측구간/동등성 기준을 사용하고, 불확실성 구간이 너무 넓으면 미결정으로 분류한다.

### 판별 예측

같은 원 자극에 대한 독립 반복이 늘 때, 사전 등록한 정서 상반 후보 가운데 한 후보만 신뢰도에 맞춘 오차 허용폭을 벗어나고 다른 후보는 유지되는 패턴이 독립 calibration에서 예측된다. 동일 관측 재사용이나 seed 증가에는 이 이득이 없어야 한다. 두 후보가 보류 관측 전부터 별도 forward에서 실패한다면 외삽 취약성 설명을 우선한다.

### 필요한 수정

- discovery 반복, threshold/calibration 자료, 최종 holdout 반복을 구별한다. witness 탐색·contrast 선택·ROI 선택·정규화·forward 선택·오차문턱에 최종 반복을 사용하지 않는다.
- 반복이 실제 같은 자극의 독립 획득인지 보유본에서 확인한다. 한 run을 나눈 voxel/ROI와 동일 원자료에서 만든 두 beta 추정은 자동으로 독립 반복이 아니다. 시간·전처리·공유 기준신호의 의존을 기록한다.
- 정서·의미 주석은 후보 생성에 쓰인 CLIP 점수가 아닌 별도 사람 측정으로 확보한다. 원본의 정서 주석이 생성 후보에도 그대로 적용된다고 가정하지 않는다.
- 평가 forward를 discovery와 분리하고, 원 자연자극에서 정서층·감각층별 오차와 신뢰구간 coverage를 확인한다. 생성 후보의 분포 이동을 별도 gate로 둔다. 모델 간 일치는 외삽 타당성의 충분조건이 아니다.
- 하나의 주 contrast·주 witness 정책·예산을 먼저 고정한다. 여러 후보쌍/ROI/contrast를 선택하면 family 단위 오류를 통제하거나 독립 선택표본을 쓴다. 보고할 쌍의 선택은 holdout을 보기 전에 종료한다.
- 정서 차이 witness와 감각 차이 witness, 자연 matched 후보와 생성 후보, 알려진 식별/비식별 합성 문제를 함께 둔다. 유한 search 미발견은 유일성 증명이 아니며 전체 해집합을 포괄했다고 하지 않는다.

### 관측 독립성

- **unit**: 독립 자극/내용그룹과 참가자에 걸친 반복 획득이 신경 관측 단위다. 같은 원 자극에서 나온 수백 seed·후보쌍은 동일 관측을 공유하는 search 결과이며 독립 시행이 아니다.
- **noise_model**: 공유 run drift·HRF·정규화·회귀 잔차 상관을 train-only covariance에서 추정한다. 다변량 오차를 쓰면 shrinkage와 유효차원도 개발자료에서 고정한다. 단순 ROI 분할로 독립성을 주장하지 않는다.
- **split**: 내용/원 자극 단위로 discovery·개발 외삽 점검을 나누고, 최종 반복은 후보 고정 후만 연다. 참가자 보류는 같은 참가자 반복 보류와 다른 일반화 질문이다.
- **inference**: 원 자극과 참가자의 군집 구조를 보존한다. 한 원 자극의 여러 후보쌍을 군집으로 취급한다. 가능한 조건에서는 독립 반복 추정의 상관까지 반영한 paired uncertainty를 보고한다. 참가자 수가 적을 때 모집단 추론은 제한한다.

### 신뢰도·검정력·null

- 정서 대비별 반복 신뢰도와 forward bias를 개발자료에서 추정하고, 알려진 후보 예측분리 δ를 주입한 합성 관측에서 오배제율·한쪽 배제 검출력·둘 다 탈락률을 측정한다. 실제 반복수·효과크기 미확인이므로 수치 검정력을 만들어 쓰지 않는다.
- 영가설은 같은 잠재 평균을 가진 두 후보예측 또는 지정 허용폭 이내 차이다. 쌍의 순서를 바꾸는 permutation이 자동으로 유효하지 않다. 교환가능성 조건을 점검하고 의존 잡음을 보존한 parametric/군집 bootstrap calibration을 사용한다.
- 충분한 관측에도 두 후보를 구별하지 못함을 의미 있게 말하려면 사전 최소분리 δ를 검출할 설계 민감도가 있어야 한다. 넓은 구간의 비유의 결과는 비식별성 확증이 아니다.
- 관측 수 증가가 precision만 늘리는지, 새로운 ROI/시간창이 mean prediction 자체를 구별하는지 분리한다. 추가 ROI는 같은 noise source를 공유할 수 있어 새 정보와 독립 측정을 동의어로 쓰지 않는다.

### 보유 자료와 착수조건

사용자가 5개 자료를 보유한 사실은 확정이다. Horikawa의 2,196 events나 5명이라는 숫자만으로 같은 자극의 독립 반복을 확보했다고 추정하지 않는다. 보유본에서 반복·처리 파이프라인이 확인되면 우선 경로다. NSD는 반복/시각 방법 대조 후보이나 정서 ground truth가 확인되지 않아 정서 연구에 자동 전용하지 않는다. Emo-FilM의 다른 참가자 동일 영화는 개인 내 반복과 다르며 외부 consensus는 개인별 정답이 아니다.

### 양성 결과 해석

독립 관측이 지정된 finite pool의 모델조건부 정서 상반 witness 하나를 배제했다는 증거다. 전체 가능한 자극의 유일성, 신경정보의 전역 상한, 생성 후보 실제 신경반응의 동일/비동일성은 입증하지 않는다.

### 음성 결과 해석

둘 다 유지되고 검정력이 충분하면 그 관측량이 해당 두 후보를 구별하지 못한다는 반례를 보존한다. 둘 다 탈락하면 encoder 외삽 또는 witness 구성 실패가 우선이다. witness 미발견은 search 한계와 실제 유일성을 구별하지 못한다.

### 판단을 바꿀 증거

독립 반복·후보 주석·분포별 calibrated forward 및 합성 검출력 gate가 확보되면 조건부에서 추진으로 바꾼다. 생성 후보에서 calibration이 계속 깨지면 자연 후보의 제한적 검정으로 축소한다. 독립 반복이 없고 새 측정도 계획하지 않으면 신경 배제율 주장을 기각하고 방법 탐색만 남긴다.

### 새 신경과학 질문인 이유

기하 일치와 의미 일치의 차이 자체는 기존 문제다. 새 대비는 동일 관측예산에서 일반 시각·의미 대응이 미사용 정서 신경대비까지 충분히 결정하는 범위와 실패하는 조건을 측정한다. 성공은 정서 전이에 필요한 감독을 줄일 수 있음을, 실패는 현재 관측 제약만으로 정서 의미를 식별하지 못함을 보인다. 어느 쪽도 별도 정서 회로나 모듈의 존재를 자동으로 말하지 않는다.

### 구체적 설계

- 첫 경로는 Horikawa 내부의 참가자/내용그룹 분할이다. 자극 ID의 paired 대응을 anchor 정답으로 쓰되 선택정책은 개발 자극의 시각·의미 특징과 허용된 개발 신경관측만 본다. 평가 정서 주석과 평가 자극 대응은 선택에 노출하지 않는다. ID를 이미 알고 있다는 이유로 전체 대응을 학습에 넣지 않고 동일 anchor 예산으로 숨김/공개를 통제한다.
- 학습 기하·거리척도·질량분포·정규화·GW 목적함수를 고정한다. random, coverage, disagreement 기반 비정서 선택과 같은 수·신뢰도·support의 정서 감독 선택을 비교한다. 정서 감독에 사용한 대비와 최종 보류 정서 대비를 분리한다.
- 한 objective에서 train-only noise calibration으로 정한 ε-cost 이내 해를 여러 초기값으로 탐색한다. 같은 보류 예측을 만드는 해는 예측동치류로 묶는다. entropy regularization 변경은 다른 objective의 민감도 분석이지 같은 해의 posterior sampling이 아니다.
- 학습 결합으로 source→target out-of-sample readout을 훈련자료에서만 고정한 뒤 새 내용의 source 신경반응에 적용한다. test geometry까지 정렬에 쓰는 transductive 분석은 별도 부차 경로로 표시한다. GW coupling만 얻고 새 자극 일반화가 가능하다고 생략하지 않는다.
- 보류 정서 대비는 독립 측정 주석의 사전 고정 가중치 a_c(i)로 δ_target,c=Σ_i a_c(i)Y_target,i와 δ_hat,c=Σ_i a_c(i)f(Y_source,i)를 만들고, 훈련에서 고정한 noise metric의 대비 예측오차를 평가한다. 같은 test BOLD로 a_c, ROI, metric을 고르지 않는다. 필요한 반복이 있으면 독립 반복으로 대비 오차의 noise bias와 신뢰도를 추정한다. 반복 부재시 미보정 오차와 신뢰도 한계를 그대로 보고한다.
- 주 결과는 보류 대비의 예측위험, 표본/참가자 일반화 불확실성, 유한 예측동치류 간 범위의 세 가지다. 범위 축소만 성공으로 세지 않는다. 정서 anchor 추가이득이 사전 허용폭 이내인지 동등성 기준으로 평가하며 비유의 차이를 충분성으로 바꾸지 않는다.

### 판별 예측

고정 예산에서 비정서 선택이 coverage 대조보다 보류 정서 대비 오차를 줄이고, 수치적으로 동등한 기하의 잘못된 의미 대응을 배제하며, 정서 anchor 추가이득이 사전 충분성 허용폭 안으로 들어오는 조건을 예측한다. 일반 시각/의미 target의 개선을 함께 측정해 단순 전반 정렬 개선과 구별하되 정서 효과만 선택 보고하지 않는다.

### 필요한 수정

- 정서 감독 미사용과 정서 정보 제거를 구별해 제목·본문의 비정서를 정의한다. 시각 모델 사전학습 정보와 semantic feature의 정서 연관은 불가능한 완전 제거를 주장하지 않고 민감도로 기록한다.
- ε-cost 대칭 permutation은 synthetic에서 알려진 정확한 대칭으로, 실제 자료에서는 동일 objective 비용과 noise 문턱을 확인한 근사 반례로 구성한다. 임의 permutation이 원 기하를 보존한다고 가정하지 않는다.
- 선택정책의 개발·anchor 공개·최종 내용/정서대비 평가를 분리한다. 적응정책이 최종 정서 성능을 최대화하도록 tuning되면 비정서 조건이 아니므로 제외한다.
- Procrustes/선형 paired alignment와 동일 예산의 완전 대응 대조를 포함한다. GW의 필요성이 없으면 더 단순한 모형으로 같은 과학 질문을 유지한다.
- P077의 정확한 DAD 구현을 필수로 두지 않는다. likelihood·prior·관측 조건독립이 확인되지 않으면 fixed disagreement heuristic으로 명명하고 EIG나 posterior라고 부르지 않는다.
- 자료간 비교는 공통 자극/독립 의미 anchor와 정서 측정모형의 공통 지지가 확인될 때만 별도 확장한다. Horikawa 자극 집계 주석·Emo-FilM 외부 연속 consensus·Spacetop clip 후 평정을 같은 target으로 바로 합치지 않는다.

### 관측 독립성

- **unit**: anchor 개수는 공개한 paired 대응의 수이지 독립 참가자 수가 아니다. 하나의 신경 거리행렬의 여러 entry, 여러 optimizer seed, 여러 수송해를 독립 표본으로 세지 않는다.
- **split**: 내용그룹 일반화와 참가자 일반화를 별도 estimand로 평가한다. 같은 자극을 공유하는 참가자 데이터는 자극 수준에서 의존한다. 새 참가자로의 전이를 주장하려면 평가 참가자 정보 접근 범위를 고정한다.
- **null**: 동일 기하의 잘못된 의미 대응이 존재하는 알려진 대칭 synthetic을 positive ambiguity control로 둔다. 실제 자료의 비용 일치 오대응, 무의미 anchor, random/coverage 대조를 쓰되 교환가능하지 않은 unrestricted label shuffle은 사용하지 않는다.
- **uncertainty**: 참가자×내용그룹 구조를 보존한 재표집으로 예측위험과 정책 차이를 평가한다. 탐색한 해 범위는 최적화 민감도이며 그 자체를 표본 신뢰구간 또는 전체 identification set으로 부르지 않는다.

### 양성 결과 해석

일반 시각·의미 제약과 명시한 표현/모형군이 보류 정서 신경대비의 대응에 경험적으로 충분한 조건을 찾는다. 신경계산 동일성, 모든 정서 개념의 식별, 정서 코드가 일반 의미로 환원된다는 결론은 아니다.

### 음성 결과 해석

정서 감독만 개선하고 비정서 anchor의 coverage·신뢰도·수렴이 충분하면 해당 관측예산의 일반 제약이 부족하다는 결론이다. 정서 anchor도 실패하면 공통 support·측정 신뢰도·out-of-sample 함수군을 먼저 점검한다. 적응정책이 coverage를 넘지 못하면 active selection의 필요성을 기각하되 anchor 충분성 질문은 남는다.

### 판단을 바꿀 증거

독립 내용과 보류 정서대비에서 오차와 동치류 범위를 동시에 줄이고 동등성 검정이 사전 허용폭을 지지하면 조건부에서 추진으로 올린다. exact active alignment 선행이 같은 감정 감독 대조까지 수행했다면 신규성을 낮춘다. 신뢰 가능한 paired/공통 anchor와 평가 support가 전혀 없으면 자료간 경로를 철회하고 자료 내부 질문만 유지한다.

### 남는 이견

유한 multi-start의 일치만으로 의미 대응이 결정되었다는 강한 표현은 허용하지 않는다. 주장은 지정 알고리즘·관측예산·평가대비에서의 실증적 충분성이다. 더 강한 식별성 증명에는 해집합의 포괄성과 추가 모델가정이 필요하다.

### 자원 실현성

현재 환경에서는 작은 고정 특징·ROI/parcel 기하, linear/Procrustes, 제한된 multi-start와 synthetic 대칭 검정을 우선한다. n개 anchor의 dense float64 거리행렬 하나는 약8n²바이트이지만 GW solver의 중간 텐서와 반복비용은 별도 측정해야 한다. 전체 voxel·전 영화 GW 및 DAD 재학습을 즉시 실행계획에 넣지 않는다. 보유 feature가 있으면 새 GPU 추출 없이 첫 대조를 설계할 수 있고, CLIP checkpoint load 성공은 아직 미확인이다.
