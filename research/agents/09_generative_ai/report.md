# Agent09 독립 조사: Generative AI & Counterfactual Modeling

작성·검증일: 2026-11-12. 단계: Round 1 독립 조사 완료. 다른 Agent의 결과와 EmoBrain은 열람하지 않았다. 모델·뇌 분석·자극 생성·새 피험자 실험은 실행하지 않았다.

## 1. 결론과 증거 범위

생성 모델의 가장 유용한 전이는 **정서 관련 뇌표상의 경쟁 설명을 구별할 자극 후보를 만드는 능력**이다. 자연스러운 편집, 텍스트 지시 이행, 높은 재구성 정확도는 각각 자극의 의미 보존, 정서 요인의 선택적 조작, 신경 메커니즘 식별과 다르다. 따라서 생성 품질보다 **편집의 타당성·불확실성·경쟁 모델의 판별력**을 연구 대상으로 삼는 방향이 유망하다. 이 판단은 문헌에서 직접 검증된 신경과학 결론이 아니라 E3 제안이다.

고유 문헌 10편의 제목·저자·연도·공식 출처를 확인했다. Prompt-to-Prompt, AudioLDM, Deep Adaptive Design은 공식 PDF를 확보하고 관련 방법·한계·Discussion 또는 대응 절을 직접 읽었다. 나머지 7편은 공식 저자 저장소/프로젝트 문서·일부 구현을 확인했으며 논문 본문을 읽었다고 하지 않는다. E1 공식 코드·문서와 E1 논문 본문을 `papers.csv`의 추가 필드로 분리했다. 기본 E1 표시는 접근한 공식 자료의 종류를 나타내며 논문의 모든 실험 결과가 검증되었다는 의미가 아니다.

`evidence/manifest.json`에 URL, 접근 날짜, HTTP 결과, 바이트 수, SHA-256을 보존했다. PMLR는 공식 `mlresearch` 권별 저장소에서 PDF·서지를 직접 제공한다. 외부 논문 호스트는 현 환경 허용 목록에 없고 Coordinator가 접근 실패를 알려주었으므로 이 조사에서는 우회하거나 재시도하지 않았다. 404 경로도 숨기지 않았다. README는 가변 main 브랜치의 2026-11-12 스냅숏이며 commit 고정 검증은 하지 않았다. 공개된 후속 링크만으로 2026년 논문을 검증 완료로 세지 않았다.

## 3. 직접 읽은 저자 한계와 후속 제안

아래 세 항목만 저자의 명시적 후속 제안으로 취급한다. 그 다음 전이는 모두 Agent09의 E3 추론이다.

1. **G09-02, §5 Limitations, PDF p.9**: 실제 이미지 inversion의 왜곡과 프롬프트 기술의 어려움, 낮은 해상도의 attention, 객체 이동 불가능을 명시한다. 더 높은 해상도 층의 cross-attention과 이동 제어를 후속 과제로 제안한다. §4 p.9는 CLIP·perceptual similarity가 인간 평가의 품질·현실성을 충분히 반영하지 못한다고 설명한다. → **E3 기회:** 편집 성공을 생성 모델과 독립적인 사람의 객체·사건·정서 주석 및 저수준 지표로 평가해 의미 보존의 다중 기준을 만든다.
2. **G09-06, Appendix F p.15·H p.16**: 제한된 평가 분포에서 좋은 수치가 넓은 일반화와 일치하지 않을 수 있고, 사람의 지각에 더 맞는 평가를 제안한다. 32/48 kHz 등 더 높은 sampling rate와 별도 학습 모듈 간 정렬·end-to-end fine-tuning도 후속 방향으로 제시한다. → **E3 기회:** 환경음 편집에서 생성 품질·사건 정체성·독립 정서 주석을 분리하고, 단순 CLAP 일치 점수를 타당성의 정답으로 사용하지 않는다.
3. **G09-09, §7 Discussion, PDF p.9**: 명시적 likelihood, 잠재 파라미터 조건부 관측 독립성, 연속 설계를 현재 제약으로 밝히며 model-based reinforcement learning과의 연결을 제안한다. → **E3 기회:** fMRI에서는 독립 시행의 단순 likelihood 대신 HRF·런·시간 의존성을 포함한 모형을 사전 검증하거나, 첫 단계에서는 독립 자극 묶음의 오프라인 선택으로 제한한다.

## 5. 미해결 문제 5개

1. **P1 선택적 개입의 식별:** 정서 주석만 달라졌다고 보이는 편집에서 실제로 변한 의미·감각 요소의 집합을 어디까지 열거할 수 있는가? 독립 주석과 통제 지표를 통과해도 미측정 특징이 남는다. G09-02/04/10, E3.
2. **P2 여러 역해의 정서적 동등성:** 같은 관측을 설명하는 posterior 후보들이 공유하는 정서 관련 특징과 생성 prior가 채운 특징을 구별할 수 있는가? 근사 sampler의 빈도를 곧바로 신뢰할 수 없다. G09-03/08, E3.
3. **P3 영상 편집의 시간 범위:** 짧은 프레임 일관성이 긴 사건 흐름·정서 주석 변화의 보존으로 이어지는가? HRF로 겹친 반응과 frame-wise artifact를 구별해야 한다. G09-05, E3.
4. **P4 모달리티별 조작 크기의 공통 척도:** 이미지·환경음·음악 latent의 동일 수치 변화가 지각적/정서적 동일 크기를 뜻하는가? modality-specific 관측과 사람의 조작 확인이 필요하다. G09-02/06/07, E3.
5. **P5 유익한 자극과 편향된 자극:** 정보 이득 최적화가 실제로 경쟁 신경 모형을 가르는가, 단지 그 모형의 약점을 악용하는가? 생성기와 encoding 모델의 공통 학습 편향을 통제해야 한다. G09-08/09/10, E3.

## 6. 방법론적 기회 5개

1. **O1 편집 대조의 계층화:** 원본→무편집 재구성→목표 편집→동일 강도의 비목표 편집을 분리한다. inversion/VAE 손실과 목표 조작을 구분하는 최소 설계다. G09-01/02/03.
2. **O2 보존 제약을 갖는 편집 집합:** 하나의 성공 이미지 대신 객체·사건·저수준 허용오차를 통과한 여러 seed·여러 생성기의 후보 분포를 보존한다. 생성기 특유의 해를 과학적 요인으로 오인할 위험을 줄인다. G09-02/04/10.
3. **O3 한 장의 재구성 대신 역해 집합:** 관측과 양립하는 후보의 공통 특징·변동 특징을 보고하고, prior-only·shuffled observation·likelihood-only 가능한 baseline을 비교한다. G09-08; 뇌 측정 연산자로의 확장은 E3.
4. **O4 분리된 영상·오디오 개입:** 사건 정체성을 확인한 자극에서 영상만/환경음만/둘 다/둘 다 무편집의 요인 설계를 사용한다. auditory speech feature는 의제로 삼지 않는다. G09-05/06.
5. **O5 모델 판별 중심 자극 선택:** 특정 ROI의 예측값 최대화 대신 감각·의미·정서 기여에 관한 경쟁 encoding 모형의 예상 관측 분포를 가장 구분하는 후보를 고른다. calibration·noise ceiling·분포 지원 범위를 제한한다. G09-08/09.

모두 E3 제안이며 구현·실증 결과가 아니다. 데이터 규모가 작으면 최신 생성기보다 원 자극의 자연 변동·matched retrieval·단순 영상/음향 필터가 더 강한 baseline일 수 있다.

## 8. 예상 밖의 연결 3개

1. **역문제의 여러 해 × 측정 이론:** 재구성 후보의 다양성은 뇌의 표상이 풍부하다는 증거일 수도, 측정이 불충분하다는 증거일 수도 없다. 관측을 바꿔도 지속되는 다양성과 prior를 바꾸면 사라지는 다양성을 분리하면 ‘뇌가 어떤 정보를 구별하도록 측정되었는가’라는 질문으로 전환할 수 있다. 근거 G09-03+08. Agent03·07·12와 이후 연결 가능. E3.
2. **편집 transport 비용 × 의미 측정 불변성:** 가장 작은 latent 이동이 사람의 사건 의미를 보존하는지 검증하면 생성모델의 metric과 인간/뇌의 불변성의 불일치를 측정할 수 있다. 단순 거리 상관이 아니라 교차 생성기에서 같은 의미 대비가 보존되는지가 판별점이다. 근거 G09-02+07+10. Agent07·10과 이후 연결 가능. E3.
3. **실험 설계 × 생성 실패 감지:** EIG 최적화와 편집 타당성의 불확실성을 함께 다루면, 매우 유익해 보이지만 의미가 훼손된 후보를 제외하는 과학적 자극 선택 문제가 된다. ‘정서별 예쁜 샘플’이 아닌 ‘모형을 구분할 수 있고 실제로 조작이 성립한 샘플’의 집합을 찾는다. 근거 G09-06의 평가 한계+G09-09. Agent04·12와 이후 연결 가능. E3.

위 연계는 제안 가능한 협업 상대를 지정한 것이며 실제 교차 토론은 수행하지 않았다.

## 11. 데이터 실현성과 가장 작은 유익한 단계

이 독립 조사에서는 Horikawa·Emo-FilM·Spacetop·NSD의 실제 자극·label·metadata를 열람하지 않았다. 따라서 각 자료에 특정 라벨·audio track·시간별 정서 주석·반복 시행이 있다고 가정하지 않는다. 우선순위는 미션대로 Horikawa → Emo-FilM → Spacetop → NSD이나 아래는 **조건부 실현성**이다.

- **기존 관측으로 가능한 단계:** 자극과 실제 뇌 반응을 확보·정렬할 수 있다면 held-out encoding 검증, 자연 자극의 matched retrieval, 기존 관측의 역해 불확실성 연구를 설계할 수 있다. RQ09-3이 가장 가깝지만 신규성·calibration 점검이 선행되어야 한다.
- **추가 주석이 필요한 단계:** 자극만 확보되어도 무편집 왕복·편집 대비의 의미/사건 보존과 자연성 검증은 가능하다. 이는 생성 도구의 타당성 평가이며 뇌 효과를 검증한 것이 아니다. 정서 라벨이 없으면 사람의 독립 주석을 별도 수집해야 한다.
- **추가 뇌 측정이 필요한 단계:** 새로 편집한 자극에는 원본 자극의 BOLD를 붙일 수 없다. RQ09-1/2/4/5/6/7/8의 편집 효과 주장은 실제 새 자극 제시와 뇌 측정을 필요로 한다. 무작위 자극 배정도 자극 조작의 효과만 다루며 특정 신경 회로나 latent 축의 인과 메커니즘까지 입증하지 않는다.

가장 작은 유익한 준비 단계는 ① 소수의 원본 자극·무편집 왕복·목표/비목표 편집으로 독립적인 의미 보존 평가를 정의하고, ② 자연 자극 matched control과 생성기 교차검증을 설계하고, ③ 이 기준을 통과한 후보만 실제 실험 설계 대상으로 남기는 것이다. 수치 문턱은 관찰 후 임의 결정하지 말고 별도 개발 자료에서 정한 뒤 고정해야 한다. 이 보고서는 해당 생성이나 평가를 실행하지 않았다.

구현 메모: 공식 README에서 Prompt-to-Prompt는 최소 12GB VRAM, InstructPix2Pix는 >18GB VRAM에서 시험했다고 한다. FateZero 공식 문서의 예시는 8프레임·12GB GPU에서 설정에 따라 CPU 메모리 6/15/100GB를 기록한다. 이는 저자 조건의 보고이며 현재 환경 추정치가 아니다. Flow Matching 저장소는 checkpoint를 배포하지 않는다고 명시한다. FlowEdit는 SD3·FLUX 예제를 제공하지만 해당 가중치의 접근·라이선스·다운로드·현재 환경 실행은 미검증이다. 코드 라이선스와 기반 모델 라이선스를 합쳐 판단하지 않는다.

## 12. 가장 강한 반론과 수정·보류

| 반론 | 대응·결정 |
|---|---|
| 생성 이미지가 자연스럽더라도 encoding 모델에 off-manifold다 | 수정: 자연 자극 최근접 대조, 여러 생성기, 독립 사람 평가, 강도별 지원 범위, held-out 실제 반응으로 검증. 생성 likelihood 한 개로 on-manifold를 선언하지 않는다 |
| ‘의미 보존’은 검사한 주석 차원에 한정되며 미측정 의미 변화가 남는다 | 수정: 객체·행위·사건·맥락을 분리 주석하고 ‘완전 보존’ 대신 사전정의한 차원에서의 동등성을 주장. 조작 확인이 실패한 후보를 제외 |
| 정서 변화가 사람 라벨과 생성 prompt에 의해 순환 정의된다 | 수정: prompt 생성자·편집 선택자와 독립된 주석, 생성 지시 비공개 평가, 동일 feature로 선택·평가 금지 |
| 뇌를 예측하는 모형으로 자극을 최적화한 뒤 같은 모형에서 효과를 보여주는 것은 동어반복이다 | 보류: in-silico 단계에서는 후보 발굴만 주장. 선택에 쓰지 않은 encoding 모델, 참가자, 자극과 실제 새 뇌 관측에서 최종 검증 |
| posterior 샘플의 차이를 뇌 불확실성이라 부른다 | 수정: sampler·prior·encoding 파라미터·관측 잡음을 분리하고 simulation calibration을 요구. 정확한 posterior 주장 금지 |
| DAD의 독립 관측 가정이 fMRI·긴 영상에서 깨진다 | 수정: 첫 단계는 오프라인 자극 묶음 선택; 순차 설계는 HRF·시간상태를 포함한 likelihood를 검증한 뒤 진행 |
| 최신 모델로 기존 자극 최적화를 반복한 것일 수 있다 | 미해결: 목적을 activation 증가에서 의미 보존 및 관측 등가 집합의 식별성으로 좁힘. adversarial novelty search 전에는 최초·독창성 확정 표현 금지 |

통계 설계에서는 원본과 모든 편집·seed를 같은 자극 family로 묶어 split한다. 생성 후보 수를 독립 표본 수로 세지 않는다. 참가자·원본 자극의 계층 의존성을 보존하고, ROI 선택·feature 선택·정규화·편집 문턱 결정은 훈련/개발 자료에서 수행한다. 가능한 반복 측정으로 noise ceiling·신뢰도를 확인하며 HRF·자기상관·run 경계를 통제한다. 여러 ROI·여러 편집 대비에는 다중 비교 계획이 필요하다.

## 13. 미션의 여덟 탐색 질문에 대한 답

1. **왜 아직 시도되지 않았는가?** 개별 편집의 그럴듯함은 기존에도 가능했으나 같은 사건에서 비목표 변수를 보존하는 대량의 검증된 자극과 새 뇌 측정의 비용이 크다. 관련 연구가 없었다는 주장은 아직 검증하지 못했다.
2. **최근 가능해진 것은?** 실제 이미지 inversion, attention 기반 영상 일관성, 지시 기반 편집, flow의 직접 편집 경로가 선택 가능한 조작 범위를 넓혔다. 빠른 생성 자체보다 여러 독립 조작 경로를 비교할 수 있다는 점이 새 검증 능력이다.
3. **어떤 가정이 틀릴 수 있는가?** latent 근접성=의미 보존, 생성 자연성=encoding 지원 분포, 불확실성=정보 이득이라는 세 가정이다.
4. **AI가 더 잘 포착할 수 있는 것은?** 많은 시각·환경음 특징의 결합과 관측에 양립하는 다양한 해를 체계적으로 탐색하는 능력이다. 실제 뇌과학 모델보다 우수함은 별도 비교할 E3 가설이다.
5. **뇌가 표상하지만 AI가 놓칠 수 있는 것은?** 같은 caption/재구성 아래 구별되는 미세한 정서 관련 단서와 긴 사건 맥락이다. 잔차를 발견하더라도 먼저 측정 잡음·특징 부족·HRF 오지정을 배제해야 한다.
6. **다른 분야의 방법이 무엇을 밝힐 수 있는가?** inverse problem의 비유일성과 Bayesian design의 가설 판별 목적을 가져와 ‘잘 복원되는가’에서 ‘어떤 정보가 식별되는가’로 질문을 바꾼다.
7. **기존 자료의 다른 용도는?** 자극·뇌 정렬이 확인되면 encoding likelihood와 natural control pool을 만드는 데 사용할 수 있다. 새 편집 자극의 반응이 기록된 것처럼 재해석할 수는 없다.
8. **신경 계산 이해를 바꾸는가?** 감각·의미 모형이 동등하게 예측하는 조건에서 실제 뇌 대비가 재현되거나, 역해 집합이 정서 정보를 결정하지 못함을 보이면 표상 설명의 경계가 달라진다. 생성 품질 개선만으로는 이 기준을 충족하지 않는다.
