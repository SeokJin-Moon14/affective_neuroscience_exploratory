## R3-09-C10-01 — 수정

1. **선행이 답한 부분과 남은 부분:** P081은 언어 병목을, P015는 뇌 decoding 경로를 제공한다. 정서 대비의 선택적 손실은 확인한 선행의 직접 결론이 아니다.
2. **모델/benchmark 교체 여부:** 차원별 모델 순위라면 교체 연구다. 정서 대비 보존/비정서 대비 보존의 상호작용이 있어야 독립 질문이다.
3. **정서 대비와 전체 BOLD 분리:** 전체 BOLD 성능과 정서 대비를 분리한 점은 적절하다. 모델 압축으로 실제 신경 대비의 재현성 자체가 감소한다는 문구는 수정해야 한다.
4. **필요한 실제 자료 필드:** 실제 병목 용량별 체크포인트·토큰 접근, 반복, 독립 주석, 같은 객체 난도의 정서 대비가 필요하다.
5. **ID·motion·semantics·HRF 대안:** 객체 정확도가 같아도 질감·관계·장면 정보 손실은 다르다. 같은 backbone만으로 내용 보존을 보장하지 못한다.
6. **예측·대응·기전·인과 수준:** 관찰 데이터의 모델 표현 비교로 가능하다. 압축이 인간 뇌 정보를 없앴다는 인과 표현은 불가하다.
7. **더 강한 대조:** 동일 차원 PCA 외에 동일 reconstruction distortion/비정서 판별력의 bottleneck 대조와 고정 seed·선택 예산이 필요하다.
8. **부정 결과의 가치:** 선택적 손실이 없으면 해당 압축·readout·관측 수준에서 정서 대비가 유지됨을 말할 수 있으나 보편 충분성은 아니다.

**가장 강한 반론:** 차원·객체 식별력 일치는 정보량·비목표 의미 보존을 맞추지 못한다. 더구나 고정된 신경반응의 신뢰도는 모델 병목 용량이 바뀌어도 달라지는 종속변수가 아니다.

**필수 수정:** 종속변수를 반복으로 고정한 실제 신경 대비에 대한 held-out 예측 보존율로 정리한다. 정서·객체·관계·질감 대비의 강도/신뢰도와 일반 압축 손실을 맞추고 선택성 상호작용을 사전정의한다.

**더 판별적인 검정:** 같은 원본 자극에서 직접토큰/Q-Former/캡션과 distortion-matched 비언어 bottleneck을 비교한다. 전체 정보 손실량을 맞춘 뒤 정서 대비의 추가 손실이 새로운 원본 family에서 재현되는지 평가한다.

**부정 결과의 가치:** 정서 선택성 없는 감소는 언어 목적 특이 결손 대신 일반 압축 설명을 지지한다. 신뢰도가 부족하면 손실 부재가 아닌 판별 불가.

**기존 관측으로 가능한 범위:** 기존 자극·BOLD·주석으로 충분한 모델 수준 보존 감사가 가능하다.

**새 측정의 조건:** 단순 모델 비교에는 새 뇌 측정이 필수는 아니다. 실제 자극 표현을 변경해 인간 뇌 효과를 주장하는 확장은 새 제시·측정이 필요하다.

**남은 이견:** 완전한 내용 등가성을 유한한 비정서 과제로 확인할 수 있는지는 남는다. 따라서 언어에 본질적으로 없는 정서 정보라는 결론에는 동의하지 않는다.

**근거:** P081, P015, P051, P100

## R3-09-C10-02 — 수정

1. **선행이 답한 부분과 남은 부분:** P083/084는 개념 병목의 구성 근거다. P066/067의 상태 분석 코드가 영역 간 N-D 식별성을 직접 입증하지는 않는다.
2. **모델/benchmark 교체 여부:** 개념 목록 추가만이면 feature engineering이다. 조건화 집합×신경 결합 방식의 고정 표적 대비가 핵심이다.
3. **정서 대비와 전체 BOLD 분리:** 독립 정서 주석을 표적으로 명시했으나 관계 설명을 넣으면 남은 표적 변산/ceiling이 달라져 N-D 감소를 만들 수 있다.
4. **필요한 실제 자료 필드:** 관계·사건의 독립 주석, 동일 표본 overlap, ROI 신뢰도, 캡션의 뇌와 독립된 provenance가 필요하다.
5. **ID·motion·semantics·HRF 대안:** 관계 정보가 감각·motion·ID를 더 담는 효과와 정서-의미 공유분산 제거를 분리해야 한다.
6. **예측·대응·기전·인과 수준:** N-D 예측 이득은 관측적 비가산 readout의 필요성이다. 신경 영역 간 통신이나 생물학적 상호작용과 다르다.
7. **더 강한 대조:** 같은 원 정서 표적을 예측하는 의미-only/의미+D/의미+N의 nested 성능 차이를 같은 held-out 표본에서 비교한다.
8. **부정 결과의 가치:** 관계 추가 뒤 N-D가 작아지면 정보 중복을 배울 수 있으나 기존 N 이득이 허위였다는 결론은 성립하지 않는다.

**가장 강한 반론:** 관계 설명의 조건화가 정서와 실제로 공유되는 정보를 제거하면 N-D 감소는 기전 반증이 아니라 estimand 변경이다.

**필수 수정:** 원 표적은 고정하고 객체 및 관계 조건별 nested predictor를 비교한다. total 예측과 조건부 증분을 병기하고 잔차 표적에 바뀐 분산을 그대로 성능 비교하지 않는다.

**더 판별적인 검정:** 객체→관계 추가의 이득을 의미-only와 의미+D, 의미+N에서 각각 추정한다. 관계와 정서가 불일치하는 자연 자극의 overlap 층에서도 N-D가 감소하는지 별도 확인한다.

**부정 결과의 가치:** N이 처음부터 불필요하면 분산 가산으로 충분한 관측 범위를 설정한다. 관계에 따라 추가 예측만 줄면 정보 중복으로 해석한다.

**기존 관측으로 가능한 범위:** 기존 자극에 독립 관계 주석을 추가하면 관찰 검정 가능; 새 뇌 측정은 필수가 아니다.

**새 측정의 조건:** 관계 조작의 인간 뇌 인과효과로 확장하려면 관계만 바꾼 실제 자극과 새 뇌 측정이 필요하다.

**남은 이견:** 관계 의미를 제거한 잔차가 더 순수한 정서라는 해석은 수용하지 않는다. 중복과 비가산성은 함께 존재할 수 있다.

**근거:** P083, P084, P100, P102

## R3-09-C10-03 — 수정

1. **선행이 답한 부분과 남은 부분:** P085/086의 언어 encoding과 P066 사건 분석이 근접 선행이다. 내용량·순서·관측 지연의 분리는 미해결 비교 후보다.
2. **모델/benchmark 교체 여부:** 긴 문맥 모델 교체는 부족하다. 동일 사건집합과 동일 관측 연산자하의 ordered/unordered 경쟁이면 판별적이다.
3. **정서 대비와 전체 BOLD 분리:** 정서 주석 관련 대비를 일차 평가로 고정해야 전체 서사 예측 이득이 정서 효과로 대체되지 않는다.
4. **필요한 실제 자료 필드:** 사건 시간좌표, 과거전용 모델 입력, BOLD·주석 정렬, 독립 영화 수와 실제 HRF 지원구간이 필요하다.
5. **ID·motion·semantics·HRF 대안:** 순서교환은 문법 외에도 개연성·예측난도·임베딩 smoothness를 바꾼다. 시간상관 보존 대조만으로 해결되지 않는다.
6. **예측·대응·기전·인과 수준:** 모델 특징의 순서 민감성과 인간의 순서 개입 효과를 이미 구별한 점은 적절하다. 결론에서도 이 경계를 유지해야 한다.
7. **더 강한 대조:** 원순서 paraphrase·자연스러움 일치 재서술·시점별 특징 자기상관 매칭 및 causal bag baseline을 추가한다.
8. **부정 결과의 가치:** bag/FIR와 동등하면 관측 해상도에서 순서 특이 표현의 추가 필요성이 약하다. 신경에서 순서 계산이 없다는 뜻은 아니다.

**가장 강한 반론:** 순서를 섞은 특징이 원 영화 BOLD를 덜 설명하는 것은 모델이 이상한 입력에 놓였기 때문일 수 있어, 순서라는 독립 계산 요소를 식별하지 못한다.

**필수 수정:** 관찰 일차 질문을 원 관측에 대한 순서 정보를 포함한 특징의 증분 예측으로 제한한다. OOD·문법·개연성·특징 smoothness를 별도 보고하고 순서 특이 모델 증거와 실제 자극 개입을 분리한다.

**더 판별적인 검정:** 원순서 의미보존 paraphrase를 포함한 반복 표현 대조와 시간 smoothing을 맞춘 causal unordered predictor를 비교한다. 자연 자료에서 내용집합은 유사하고 순서가 다른 구간이 있으면 독립 영화 전이를 추가한다.

**부정 결과의 가치:** 이득이 자연스러움·smoothness 통제로 사라지면 특정 표현의 부적합을 배운다. 실제 순서 효과 부재로 과장하지 않는다.

**기존 관측으로 가능한 범위:** 기존 영화·BOLD의 관찰적 encoding 비교는 가능하다.

**새 측정의 조건:** 동일 사건집합을 실제 다른 순서로 제시했을 때의 반응 주장은 새 자극·인간 뇌 측정 필요. 이 조건은 관찰 단계의 차단 사유가 아니다.

**남은 이견:** 고정 사건집합도 순서가 달라지면 사건 의미 자체가 바뀔 수 있다. 순서와 의미를 완전히 분리했다는 표현은 보류해야 한다.

**근거:** P085, P086, P066, P100

## R3-09-C10-04 — 수정

1. **선행이 답한 부분과 남은 부분:** P015/021/087은 생성 prior와 신경 조건이 결합하는 경로를 제공한다. 정서 서술의 조건별 출처 검증은 직접 해결되었다고 확인하지 못했다.
2. **모델/benchmark 교체 여부:** 기본 decoder ablation과 중복될 수 있다. 의미 hard-negative에서 생성 전후 정서 정보의 증분을 고정해야 한다.
3. **정서 대비와 전체 BOLD 분리:** 유창한 정서 단어 빈도와 독립 정서 주석·신경 조건의 정보는 다르다. 외부 판별을 사용한 방향은 적절하다.
4. **필요한 실제 자료 필드:** Mind Captioning 정식 식별자, conditioner 입력, 모델 weights·prompt, 독립 참조·주석과 생성 provenance가 필요하다.
5. **ID·motion·semantics·HRF 대안:** 의미 매칭은 특정 embedding에서만 성립할 수 있고 신경 조건 교환이 참가자·SNR·ID 분포를 바꿀 수 있다.
6. **예측·대응·기전·인과 수준:** 관측된 신경 조건에 의한 출력 민감성은 decoder 정보 출처다. 캡션 문장의 정서가 인간 뇌의 원인이라는 주장은 불가하다.
7. **더 강한 대조:** 같은 사람/런·신뢰도/내용 층에서 조건 교환하고, 생성 없는 retrieval 및 비정서 hard-negative를 함께 둔다.
8. **부정 결과의 가치:** 생성 전 정보는 있으나 출력에 없으면 decoder 손실, 양쪽 없으면 해당 측정에서 출처 미식별, 출력에만 있으면 prior 보충 후보로 구분한다.

**가장 강한 반론:** 언어 prior가 주어진 신경 condition을 보완하는 과정을 단순한 진짜 대 교환 차이로 모두 분해할 수 없다. condition 교환의 분포 이탈이 차이를 만들 수 있다.

**필수 수정:** 조건 교환을 관측 support 안에서 시행하고 평균/영 벡터는 주분석에서 제외한다. 출력 스코어는 독립 정서 대비와 비정서 내용 판별로 나누고 생성 전·후 2단계 결과의 네 경우를 사전정의한다.

**더 판별적인 검정:** 내용·참가자·런·SNR가 맞는 condition swap × prior 설정 × latent/output 평가. same-decoder matched swap이 가능한 표본이 없으면 latent retrieval 관찰 분석으로 축소한다.

**부정 결과의 가치:** 출처 구분 실패는 감정 서술의 신경 기원을 주장할 수 없다는 한계를 준다. 낮은 신뢰도와 prior 지배는 별도 원인으로 남긴다.

**기존 관측으로 가능한 범위:** 실제 보유 신경 조건·출력 경로와 참조가 확인되면 기존 관측으로 가능하다.

**새 측정의 조건:** 생성된 캡션/영상이 뇌에 미치는 효과는 새 제시·측정 필요하지만 정보 출처 감사에는 필수가 아니다.

**남은 이견:** Agent09 C09-01과 관측–prior 분리 서명이 겹친다. 모달리티만 다른 두 독립 RQ로 세기보다 캡션 출력 단계의 선택적 정보 손실을 하위 비교로 묶는 방안을 권고한다.

**근거:** P015, P021, P087, P076, P100

5. **ID·motion·semantics·HRF 대안:** 긴 선행 경로는 motion·컷·적응·일반 기억·기대와 HRF 잔류를 함께 바꾼다. 짧은 직전 구간 일치만으로 제거되지 않는다.
6. **예측·대응·기전·인과 수준:** 모델 state reset은 모델 메커니즘 검사다. 실제 자극 경로 무작위화도 특정 신경 상태변수나 attractor를 인과 식별하지는 않는다.
7. **더 강한 대조:** 독립 HRF 추정, 공통 구간 길이 여러 수준, 정서가 비슷한 내용차이 경로와 내용이 비슷한 정서차이 경로를 교차한다.
8. **부정 결과의 가치:** 유연 HRF/일반 사건 모형이 충분하면 정서 특이 지속상태의 추가 필요성을 낮출 수 있다. 상태가 전혀 없다는 뜻은 아니다.

**가장 강한 반론:** 동일 현재 자극 이후 오래 남는 차이는 지속 정서 상태뿐 아니라 장기 내용 기억·적응·예측오차의 누적으로도 생긴다. 상태 모델과 오차 모델이 서로를 표현할 수 있으면 소멸 곡선만으로 구별되지 않는다.

**필수 수정:** 모형을 독립 자료로 fit하고 HRF 후 예측이 실제로 갈리는 경로·공통 구간을 개발 단계에서 고른다. 정서 경로 차이와 일반 사건 차이를 교차한 설계로 지속성의 정서 관련성을 제한적으로 검정한다.

**더 판별적인 검정:** 선행 경로의 정서 주석 차이/내용 차이 × 공통 종점 길이의 요인 설계. 모든 조건에 동일 목표 영상, 무작위 순서와 독립 HRF calibration을 두고 held-out 소멸 곡선의 상대 예측을 비교한다.

**부정 결과의 가치:** 모형 등가이면 상태 대 오차의 검정 불가를 배운다. 정서 대비 없이 일반 이력만 남으면 일반 문맥 효과로 분류한다.

**기존 관측으로 가능한 범위:** 자연 영화의 기존 관측으로 경로 후보·모형 불일치를 찾을 수 있으나 동일종점 대조의 대체는 아니다.

**새 측정의 조건:** 기존 보유본에 동일종점/상이경로의 실제 반복이 없으면 새 무작위 자극 제시·인간 뇌 측정 필요; 기존 BOLD 재조합 금지.

**남은 이견:** 지속상태라는 말의 허용 범위를 관측적 장기 이력 정보로 둘지 신경 상태변수로 둘지 남는다. 후자는 이 설계만으로 확정하지 않는다.

**근거:** P008, P089, P090, P077, P100

## R3-09-C02-05 — 수정

1. **선행이 답한 부분과 남은 부분:** P005/009는 분산·공통/특이 표상의 배경이고 P093은 계산 gate 도구다. gate 변화가 생물학적 routing이라는 답은 제공하지 않는다.
2. **모델/benchmark 교체 여부:** MoE가 더 잘 맞는다는 비교라면 교체다. 동일 정서 대비의 내용별 readout 전이 손실과 기능적 gate 교환이 핵심이다.
3. **정서 대비와 전체 BOLD 분리:** 내용군마다 동일한 정서 대비·범위가 있어야 한다. content-only 모델이 같은 예측을 하면 정서 분산 조직의 증거가 아니다.
4. **필요한 실제 자료 필드:** 내용군 내 label overlap, 독립 ROI·반복·voxel 규모, gate 입력 provenance와 보류 내용 정의가 필요하다.
5. **ID·motion·semantics·HRF 대안:** 내용별 SNR와 정서 라벨 분포가 gate를 결정할 수 있다. ROI별 잡음 공분산과 motion·run confound를 검사해야 한다.
6. **예측·대응·기전·인과 수준:** gate 교환은 모델 내 조작이다. 관찰 decoder의 조건부 읽기 규칙을 실제 신경 연결이나 정보 전달로 해석하면 안 된다.
7. **더 강한 대조:** expert permutation에 불변인 예측 함수와 ROI별 기여 안정성을 사용하고 support 안의 조건부 교환을 대조한다.
8. **부정 결과의 가치:** 정적 모형과 동등하면 해당 관측에서 고정 읽기 규칙으로 충분하다. 유의한 gate라도 seed 불안정이면 신경 해석 보류.

**가장 강한 반론:** gate와 지역표현을 임의로 교환하면 학습 중 없던 결합을 만든다. 성능 저하는 조건부 신경 조직보다 모델 입력의 off-manifold 교란일 수 있고, 다른 gate parameter가 같은 예측 함수를 구현할 수 있다.

**필수 수정:** 무조건 gate 교환을 주근거에서 내리고, 내용·정서·SNR support 안의 matched 교환과 예측함수 동등성 검사를 병기한다. gate 자체의 seed 일치 대신 permutation-invariant 효과와 정적/nonlinear additive 경쟁을 평가한다.

**더 판별적인 검정:** 동일 정서 대비·내용 난도·SNR를 맞춘 새로운 내용군에서 고정 D 대 조건부 D의 예측 차이를 먼저 확인한다. 그 후 overlap 안/밖의 gate 교환을 분리해 손실이 외삽 거리와 함께 증가하는지 본다.

**부정 결과의 가치:** 교환 손실이 support 밖에서만 나타나면 model artifact로 분류한다. 조건부 readout의 관찰적 이득은 여전히 별도로 남길 수 있다.

**기존 관측으로 가능한 범위:** 기존 여러 내용군의 실제 신경 관측으로 조건부 예측·전이 분석 가능하다. model gate 조작만으로 추가 뇌 측정을 요구할 필요는 없다.

**새 측정의 조건:** 생물학적 routing의 인과 주장에는 관찰 decoder와 별개의 식별 근거·실제 신경 개입 등 추가 증거가 필요하다. 본 제안은 관찰적 readout 범위로 제한.

**남은 이견:** 고정 중복과 조건부 접근성을 완전히 배타적인 조직으로 볼 수 없다. 같은 분산 신호에도 여러 readout이 가능하므로 두 특성의 공존을 허용해야 한다.

**근거:** P005, P009, P093, P053, P100
