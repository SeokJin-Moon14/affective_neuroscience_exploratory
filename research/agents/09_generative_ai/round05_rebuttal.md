## RP07

### R09-07-01 · 03_vision_decoding / 회의적비판자 · 수용

**실제 비판:** 추가 반복의 한쪽 배제는 일반 SNR 향상이나 발견 관측에 과적합한 encoder 취약점의 제거로 설명할 수 있다.

**제안자 응답:** 수용한다. 참조 원본을 포함한 유한 자연 후보군을 일차 경로로 바꾸고, 정서 차이 큰/작은 witness를 감각거리·객체/사건 관계·초기 오차·난도에서 맞춘다. 같은 추가 관측량에서 배제 이득의 차이를 일반 시각/SNR 모형과 비교한다. 동일 관측 재사용, 독립 반복 평균, 동일 총 관측량의 대조를 둔다. 배제 이득이 모든 후보군에 균일하면 정서 신경과학 기여를 주장하지 않고 측정 방법 결과로 낮춘다.

**남은 이견:** 측정한 의미 공변량 밖의 차이는 남는다. 정서 관련 관측 제약이라는 표현은 허용하지만 정서 특이 계산으로 승격할 조건은 아직 충족되지 않았다.

### R09-07-02 · 03_vision_decoding / 회의적비판자 · 수용

**실제 비판:** 반복을 늘려 계속 검사하면 오배제가 누적되며, 둘 모두 탈락·참조 탈락을 모호성 해결로 셀 위험이 있다. 유한 내부 근사는 실제 뇌 허용집합이 아니라 지정 모형 집합에 대해서만 성립한다.

**제안자 응답:** 수용한다. 일차 추가 관측량 k* 하나를 개발 단계에서 고정하고 곡선은 사전 그리드의 보정된 이차 분석으로 둔다. 별도 calibration 자극에서 각 k의 covariance·참조 오배제율과 누적 검사 오류를 보정한다. 정확히 한쪽 배제+다른 쪽 양립+참조 양립일 때만 지정 witness 판별로 기록한다. 둘 모두 탈락, 참조 탈락, 두 후보 유지, 불확실, 미발견을 별도 보고한다. sample min/max나 미발견을 전역 경계·유일성으로 해석하지 않는다.

**남은 이견:** 오지정 forward의 허용집합은 실제 뇌의 참 해집합에 대한 내부 근사라는 보장도 없다. 자연 참조 calibration 성공이 생성 후보의 coverage까지 보증하지 않는다.

### R09-07-03 · 07_geometry_information / 데이터통계검토자 · 수용

**실제 비판:** discovery/calibration/test 분리, 실제 반복 독립성, p>α와 양립성의 구별, 후보의 분포 이동·계층 의존성 통제가 필요하다.

**제안자 응답:** 수용한다. 자극 family를 train/calibration/evaluation으로 먼저 나누고 evaluation 원본의 discovery 획득과 최종 holdout 획득을 분리한다. witness 선택·ROI·정규화·허용폭·forward 튜닝에 holdout을 쓰지 않는다. 개발에서 정한 예측오차 허용폭과 보정된 오차 구간으로 양립/배제/미결정을 판정하며 비유의를 양립으로 치환하지 않는다. run drift·HRF·공유 전처리 상관을 반영한 shrinkage covariance와 참가자×원본 군집 추론을 사용한다. 생성 후보에는 별도 분포 이동 gate를 두고 seed나 모델 수를 신경 표본 수로 세지 않는다.

**남은 이견:** 생성 후보의 오차가 자연 calibration과 교환가능하다는 보장은 없다. 정서층·감각층별 참조 유지와 합성 오류 통제는 필요한 검사이며 실제 뇌 coverage의 충분조건은 아니다.

### R09-07-04 · 07_geometry_information / 데이터통계검토자 · 수용

**실제 비판:** Horikawa 반복·NSD 정서 주석을 가정할 수 없고, 원본의 보류 반복은 생성 후보를 제시한 실제 반응이 아니다.

**제안자 응답:** 수용한다. Horikawa의 내용 중복·61런·2196 이벤트를 개인 내 독립 반복으로 사용하지 않는다. NSD는 검증된 정서 정답이 없으므로 첫 작은 단계는 시각 역문제 방법검정이다. 정서 질문에는 원본과 후보의 새 독립 인간 주석 또는 실제 확인된 기존 주석이 필요하다. 원본 반복이 부족하면 새 원본 반복 측정이 필요하며, 두 후보 자체의 신경 동등성/차이를 주장하려면 두 후보를 새로 제시한 BOLD가 별도로 필요하다. Horikawa 공통 자극에 독립 참가자를 추가하는 관찰 분기는 집단 자극 표적과 train-only 개인 mapping을 가진 별도 질문으로 표시한다.

**남은 이견:** 보유본의 정확 반복·주석·mapping은 아직 실물 검증 전이다. RP07은 첫 3개 파일럿에서 제외된 장기 카드이며 개인 반복 경로를 실행 준비 완료로 표시하지 않는다.

### R09-07-05 · 03_vision_decoding / 회의적비판자 · 미해결

**실제 비판:** 정서 상반 witness 배제가 새로운 정서 신경 계산인가, 기존 역문제 정밀도 개선을 정서로 재명명한 것인가가 남는다.

**제안자 응답:** 이견을 보존한다. 과학 질문은 측정된 정서 대비가 큰 고정 후보의 배제 곡선이 의미·감각·초기 오차·SNR 대조와 다른가로 좁힌다. 현재의 설계만으로 정서 고유 계산을 약속하지 않는다. 자연 후보에서 같은 비용의 직접 판독·retrieval이 설명하는 결과를 넘어서는 대비가 없으면 방법 기여만 남긴다. 별도 forward 일치도 공통 훈련자료의 오류 독립성 증거로 사용하지 않는다.

**남은 이견:** 최신 근접 선행의 전수 확인과 실제 효과가 없어 독창성과 정서 특이성의 최종 판단은 미결이다. 비판자의 수정 판정을 조건부 유지와 함께 카드에 남긴다.

## RP10

### R09-10-01 · 06_frontier_ai / 회의적비판자 · 수용

**실제 비판:** 동강도 편집·CLIP 유사도·제한된 평정은 정서 외 모든 의미를 보존하지 않으며 실제 효과는 자극 묶음의 효과다.

**제안자 응답:** 수용한다. A는 새 독립 인간이 측정하는 자극의 부정적 정서 내용 강도로 명시하고 객체·행동·관계·사건 결과·가림·색/대비·자연성을 보존/감각 차원으로 따로 기록한다. 목표 A 변화의 하한과 비목표 차이의 상한을 구분하며 A 변화 자체를 양 조건에서 매칭해 없애지 않는다. 결론은 S_f=1 family에서 실제 목표−비목표 자극 묶음이 만드는 신경 대비다. 무작위 자극 할당으로부터 정서 단일 잠재 요인·회로의 인과성을 추론하지 않는다.

**남은 이견:** 정서 단서와 사건 의미는 구성적으로 겹칠 수 있다. 독립 평정 통과 이후에도 미측정 의미 차이가 남으므로 정서만의 효과는 주장하지 않는다.

### R09-10-02 · 06_frontier_ai / 회의적비판자 · 수용

**실제 비판:** 목표 편집의 artifact와 내용 변화가 paired 신경 대비를 설명할 수 있으며 같은 함수족의 강한 기준과 여러 realization이 필요하다.

**제안자 응답:** 수용한다. 원본·무편집 왕복·감각 변형량을 맞춘 비목표·자연 matched 대조를 둔다. 같은 실제 Y와 family split에서 감각, 감각+독립 관계 의미, 이에 A 또는 목표 대비를 추가한 ridge 모형을 같은 정규화·선택 예산으로 비교한다. prompt를 독립 정서 정답으로 쓰지 않는다. 최소 두 realization을 family 내부 반복으로 두고, 가능한 두 지정 editor의 효과 및 상호작용을 고정효과로 보고한다. 공유 backbone/data 때문에 두 editor의 일치도 독립 생성기 모집단 증거가 아니다.

**남은 이견:** 자연 matched 자극으로의 전이가 없으면 공통 생성 artifact가 남는다. 강한 내용 기준을 넘는 예측 개선도 미측정 의미를 제거하지 못한다.

### R09-10-03 · 10_llm_semantics / 데이터통계검토자 · 수용

**실제 비판:** family 단위 S와 목표 모집단, 개발/검증/신경확인의 분리, 허용 실패·S=1 내부 누락을 명시해야 한다.

**제안자 응답:** 수용한다. 원본·목표·비목표·무편집의 완전한 family가 공동 지지를 갖는 S_f를 개발 주석에서 동결한다. 독립 검증 주석은 고정 절차의 조작/보존 타당성을 검사하고 결과에 맞춘 재선택은 새 개발 라운드로 처리한다. 새 BOLD는 그 뒤 별도 확인 표본에서 수집한다. 모든 생성시도·seed·prompt·오류·탈락·누락과 원본별 통과율을 남기며 한쪽만 통과한 family를 성공 pair로 메우지 않는다. S=0을 가중치로 복원하거나 S=1의 누락을 무시한 원모집단 일반화를 하지 않는다.

**남은 이견:** 관찰 가능한 모집단은 허용된 family와 실제 표집 참가자로 제한된다. 확인 표본이 부분 교차라면 이상적인 E_f E_s보다 좁은 대상만 식별할 수 있다.

### R09-10-04 · 10_llm_semantics / 데이터통계검토자 · 수용

**실제 비판:** 고정 신경요약 v와 최소효과, 참가자×family 추론, 타당한 null·검정력 계획이 필요하며 기존 BOLD는 새 편집물에 붙일 수 없다.

**제안자 응답:** 수용한다. 독립 개발 신경표본에서 v의 방향과 스케일을 고정하고 d_sf=v^T(Y_target−Y_control), theta=E_f E_s[d_sf|S_f=1]를 주추정량으로 둔다. v를 정당화할 수 없으면 test 전 비부호 cross-validated 거리 질문으로 변경하고 별도 등록한다. 참가자·family·run·반복/seed 의존성과 순서/적응 효과를 반영하며 실제 무작위 배정이 허용하는 제한적 null 또는 계층 모의자료로 오류율을 검증한다. 새 독립 주석과 새 편집 자극 BOLD가 필수이고 개발 분산·통과율로 최소효과의 검출력/등가성 정밀도를 산정한다.

**남은 이견:** 새 신경표본·반복 신뢰도·효과크기가 아직 없어서 N을 확정할 수 없다. 새 family와 참가자에 대한 일반화도 실제 표집설계가 충족하는 범위에 한정한다.

### R09-10-05 · 06_frontier_ai / 회의적비판자 · 미해결

**실제 비판:** 생성 편집이 자연 matched 자극보다 과학적으로 필요한지는 통과율·대비 크기·비용을 보기 전 미결이다.

**제안자 응답:** 이견을 보존한다. 처음에는 생성 없는 자연 matched 비교를 기준으로 만들고, 생성 경로가 독립 검증에서 더 큰 A 대비와 유사한 비목표 차이의 family를 제공하는지 비용·실패까지 함께 비교한다. 이득이 없으면 생성 확장을 중단하고 자연 자극의 관찰 질문 또는 타당성 방법 연구로 낮춘다. 생성모델 사용이나 성공 영상 자체를 신규성으로 계산하지 않는다.

**남은 이견:** 현재 생성·인간 주석·새 BOLD를 실행하지 않았으므로 생성의 필요성과 제한된 신경 가설의 실현성은 모두 조건부다.
