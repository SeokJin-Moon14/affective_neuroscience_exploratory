# 의미·문맥·표상 압축 축의 통합 검토

작성: Agent10, 2026-11-12. 최신 `AGENTS.md` §9와 공통 미션을 적용했다. `axis_map/candidate_subaxes.json`의 기존 30개 후보, Agent01 `round1_independent_report.md`와 Agent05 `report.md`의 추가 하위축 6개, Agent10의 기존 독립 조사에 근거한 **Axis 통합 검토**다. 새 문헌·네트워크·모델·신경 분석은 수행하지 않았다. 실제 토론 Round2–5의 완료를 뜻하지 않는다. 아래 통합·연결·검증 제안은 E3이며, 다른 보고서의 원출처를 이번에 독립 재검증했다고 주장하지 않는다.

## 1. 즉시 적용할 통합 판단

사용자가 Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop을 보유한다고 밝힌 사실을 반영해 **다섯 자료를 연결 후보에 포함하고 Axis 작업을 진행한다.** 정확한 버전·파일 경로·스키마·주석을 확인하는 일은 개별 분석을 구체화할 때의 조건이다. 기존 보고서의 “확인 전 보류”는 전체 Axis 생성의 차단 조건으로 사용하지 않는다. Mind Captioning은 보유 자료의 명칭으로만 취급하고 특정 논문·태스크·참가자·신경측정·캡션 종류를 추정하지 않는다.

36개 후보는 상위 비교 원리를 공유하지만 모두 같은 축은 아니다. 통합 시 **무엇을 바꾸는가(표현 변환), 무엇을 예측하는가(타깃), 무엇을 고정하는가(조건화 집합), 어떤 자료 밖으로 검정하는가(일반화 단위)**를 기록하면 중복과 구별이 선명해진다. 의미·문맥·압축이라는 이름이 겹쳐도 이 네 요소가 다르면 하위축을 보존한다.

## 3. Mind Captioning의 조건부 연결 네 가지

각 행은 지금 Axis 지도에 연결할 수 있다. 조건은 데이터 설명의 추정이 아니라 실제 분석 시 선택할 분기다. 특정 버전이나 실제 필드명을 만들지 않았다.

| 연결 | 연결 축·과학 질문 | 자료가 다음 정보를 포함한다면 가능한 비교 | 포함하지 않는 경우 유지할 범위 |
|---|---|---|---|
| MC-1. 언어 압축과 신경정보 보존 | X.S10.1 + J-X-Q.BF1 + G/X-VD1. 언어로 표현 가능한 정보와 생성 prior가 보충하는 정보를 구별할 수 있는가? | 대응되는 신경 관측·자극·텍스트와 텍스트 생성 출처가 있다면, 직접 자극 특징/외부 설명/신경 조건 생성 결과를 구분. 동일 생성기에서 유효한 신경 조건과 대조 조건의 외부 참조 일치 차이를 평가 | 신경–자극 대응이 없다면 텍스트 압축의 방법론 검증만 가능. 신경 조건 생성 태스크가 아니라면 prior 대조를 적용하지 않음 |
| MC-2. 캡션의 개념 완전성과 잔차 | X.S10.3 + X07.1 + X-A01. 캡션에서 빠진 관계·사건이 정서 관련 신경 잔차를 만드는가? | 자극과 연결된 설명 및 독립 신경 타깃이 있다면 객체→관계→사건 정보를 단계적으로 추가하고, 표현 가족·검수자 사이 안정성을 비교. 독립 정서 주석이 있는 자료와 연결 가능한 경우에만 정서 대비까지 평가 | 캡션만으로 정서 정답을 만들지 않음. 독립 주석이 없으면 의미 누락의 분석을 수행할 축으로 남기고 정서 결과 주장을 하지 않음 |
| MC-3. 서사 순서와 관찰 가능한 과거 | C.S10.2 + D-V-05b + C-D-05c + Q-A01. 내용량이 같은 과거에서 순서·경계가 추가로 필요한가? | 실제 시간 순서·시점 대응·과거 입력을 확인할 수 있다면 같은 사건 집합의 원래 순서/순서 교환, 사건경계 reset/길이 일치 reset을 비교. Emo-FilM·Spacetop 등의 시간 문맥 후보와 공통 대비 연결 | 정지 자극이나 독립 시행만 있다면 서사 시간축으로 확장하지 않음. 텍스트 생성 토큰 순서를 자극의 관측시간으로 치환하지 않음 |
| MC-4. 자료를 가로지르는 의미와 측정 불변성 | S.FAI3 + A2-S1 + P-A01 + X-A01. 공통 의미 표현이 새 내용에서도 같은 신경 대비를 보존하는가? | 독립 자극 ID·내용·설명 출처가 있으면 Horikawa·NSD 등과 공통 표현 추출 절차를 정하고 자료별로 평가. 정서 타깃을 연결할 경우 문항 대상·척도·평정자·집계 수준을 별도로 모형화 | 자료 간 공통 자극·참가자·정서 ontology를 가정하지 않음. 동일 의미 공간에 투영했다는 사실만으로 동일 신경 공간이나 동일 정서 측정을 주장하지 않음 |

특히 MC-1과 MC-2에서 **같은 신경반응 Y로 생성한 캡션을 독립 설명변수로 넣어 다시 Y를 설명하면 정보가 되돌아오는 순환**이 생긴다. 해당 텍스트는 디코딩의 출력으로 외부 참조에 평가하거나, 독립 반복·분리된 자료에서의 관계로 평가해야 한다. 자극만 보고 생성한 캡션, 인간이 작성한 설명, 신경 조건으로 생성한 캡션은 출처가 다른 관측이다. 어느 종류가 실제로 보유돼 있는지는 여기서 확정하지 않는다.

## 4. 과학적으로 구별되는 핵심 검증 대비

| 대비 | 경쟁 설명 | 고정·변경할 것 | 반증 가능한 결과 |
|---|---|---|---|
| V1. 압축의 선택성과 단순 용량 | 정서 관련 대비를 선택적으로 보존함 vs 모든 정보가 용량에 따라 함께 감소함 | 같은 자극·backbone·읽기 모델·분할에서 병목 용량 변경. 언어 병목과 모달리티 교환 병목을 별도 계열로 평가. 전체 신경 타깃과 독립 정서 주석 관련 대비의 곡선을 함께 보고 | 감각·사건·정서 대비가 동일한 용량 의존성을 보이면 정서 선택적 압축 설명 약화. 두 종류 병목 결과가 다르면 한 압축 원리로 병합하지 않음 |
| V2. 순서와 사건집합 | 누적 내용량으로 충분함 vs 사건 순서가 필요함 | 과거 길이·사건 집합·현재 입력을 맞추고 순서만 변경. bag-of-events 기준 포함. 미래 입력 차단 | 순서 교환에도 외부 신경 예측·정서 대비가 유지되면 순서 필요성 약화. 모델 입력 조작 결과만으로 실제 뇌의 순서 개입 효과라 부르지 않음 |
| V3. 사건경계와 일반적인 시간 효과 | 사건경계에서 상태 재설정 vs HRF·경과시간·창 길이 효과 | 실제 과거 범위를 고정; 사건경계 reset과 횟수·간격을 맞춘 대조 reset; 관측지연 모형을 별도로 비교 | 실제 경계의 추가 판별력이 없으면 경계 특이 재설정 설명 약화. 이 검정은 V2와 달리 상태 지속의 경계를 시험 |
| V4. 잔차의 의미 누락과 안정적 추가 정보 | 캡션이 빠뜨린 사건으로 설명됨 vs 검토한 표현을 넘는 안정적 주석 관련 정보 | 독립적으로 검수한 개념 확장, 다른 VLM/LLM, 잔차 concept probe. 모든 선택·잔차화는 훈련 fold 내 수행 | 개념 추가로 효과가 사라지거나 잔차에서 기존 의미가 복원되면 의미 독립성 주장 기각. 남더라도 “고유 정서 실체”가 아니라 검토한 모델군에 조건부인 정보로 제한 |
| V5. 생성 prior와 신경 조건의 기여 | 생성기가 그럴듯한 설명을 보충함 vs 신경 조건이 외부 검증 가능한 내용을 제공함 | 실제 태스크가 신경 조건 생성일 때만 동일 생성기·설정에서 유효 조건/분포를 고려한 대조 조건 비교. 유창성과 내용 일치를 분리 | 자연스러움은 유지되지만 신경 조건에 따른 독립 내용 일치 이득이 없으면 신경정보 보존 주장 약화. 조건 섞기로 발생한 OOD 영향도 경쟁 설명 |
| V6. 의미 일반화와 반복 내용·주석 오차 | 새 내용에도 안정적임 vs 중복 내용·평정 집계에 의존함 | ID 분할과 내용 그룹 분할, 새로운 사건 조합, 독립 평정자/반복 측정 평가를 구분 | ID 분할에서만 유지되면 내용 일반화 주장 축소. 신뢰도·집계 수준을 반영했을 때 달라지면 표상 차이와 측정 차이를 구분 |

V1·V4·V6은 정적·자극 단위 자료에도 연결 가능한 구조다. V2·V3은 실제 연속 시간 또는 사건 순서 자료가 있는 경우의 분기이며, V5는 실제 생성 과제인 경우의 분기다. 다섯 보유 자료 중 어느 자료가 어느 분기에 해당하는지의 미확인은 **분기형 Axis를 작성하는 일을 막지 않는다.**

정서 관련 신경 타깃은 모델 정서 점수와 구분한 독립 주석에 연결한다. 신경 예측 증가만 관찰되면 일반 표상 결과로 해석한다. 상호작용은 강한 비선형 가산 기준과 비교하고, 정확한 정보이론적 synergy나 신경 인과성으로 자동 해석하지 않는다.

## 5. U Memory/Imagery 축의 경계

**Mind Captioning이라는 보유 이름만으로 U축의 실증 근거나 하위축을 채울 수 없다.** 명칭은 기억 인출·심상·외부 입력 없는 신경 기록·회상 지시·유지 구간의 존재를 보장하지 않는다. 신경 조건 텍스트 생성이 확인되더라도 그것만으로 기억이나 심상 측정이 되는 것은 아니다.

현재의 긴 문맥, 상태 유지, 과거 사건 누적은 C/D/V축에서 연구할 수 있다. 재귀 모델이 상태를 갖는다는 이유로 U에 이중 등록하지 않는다. U를 활성화하려면 최소한 과제가 외부 자극 지각과 내부 재현을 구별하는 조건 또는 시간 구간을 제공하고, 그 조건의 신경 관측을 타깃과 독립적으로 연결할 수 있어야 한다. 정서와 연결하려면 이 조건에 적합한 독립 정서 주석 또는 명시적 검증 대비도 필요하다.

따라서 Axis 지도에는 U를 **“공통 미션의 탐색 축; 이번 36개 후보 통합에서 독립적인 실증 연결 미확정”**으로 남기는 편이 정확하다. 향후 실제 태스크가 확인되면 지각 때의 의미표현과 외부 입력 없는 재현의 대응을 독립 후보로 추가할 수 있다. 이는 조건부 개방 경로이며 현재 보유 자료가 그 과제를 포함한다는 주장이 아니다. 해당 조건이 없다면 U를 채우기 위해 다른 문맥 축의 이름을 바꾸지 않는다.

## 6. Coordinator에 넘길 유한한 권고

1. 상위 노드는 **표현 변환의 정보 보존 / 과거 문맥과 시간 좌표 / 의미·주석의 식별 / 생성 출력의 정보 출처**로 연결하되, 위 표의 조작·타깃 차이를 하위축에 보존한다.
2. Agent01의 세 축은 사후 체크리스트가 아니라 일반화 단위·시간 관측·주석 측정이라는 연구 비교 차원으로 포함한다. Agent05의 세 축은 언어 압축·서사 문맥과 연결하되 모달리티 고유정보·미래누수·사건단계 대비를 지우지 않는다.
3. Mind Captioning을 MC-1~4의 조건부 연결로 지금 등록할 수 있다. 자료별 상세 필드는 실제 분석 설계 시 확인할 조건으로 남기며, 새 데이터 검증을 기다리는 상태로 Axis 작업을 되돌리지 않는다.
4. U축은 공백을 명시한다. 기억·심상 자료가 있다는 추정으로 채우지 않는다. 이 공백은 다섯 보유 자료의 의미·문맥·압축 연구 진행을 제한하지 않는다.

작성 결과는 이 파일 하나다. 공유 후보 JSON·상태 파일·다른 Agent 파일은 수정하지 않았다.
