# Agent 10 독립 조사: 언어 의미표현의 경계와 정서 관련 신경정보

- 작성·검증일: 2026-11-12
- 담당: Agent 10 — LLM, Semantic Representations & Context
- 단계: Round 1 독립 탐색 완료. 다른 Agent의 결과와 EmoBrain을 열람하지 않았다.
- 범위: 시각–언어 정렬, 이미지 설명의 압축, 계층적 개념, 사건·서사 문맥, 의미 잔차의 식별. 언어 내용과 문맥만 연구에 사용하며 Speech Features를 연구 축으로 삼지 않는다. 나머지 명시적 제외 주제도 제안하지 않는다.
- 실행: 공식 출처 다운로드와 텍스트·코드 열람만 수행했다. 모델 추론·학습, 뇌 분석, 자극·모델 가중치 다운로드, Agent 간 토론은 수행하지 않았다.

## 1. 가장 중요한 결론

**언어 모델이 설명하지 못한 뇌 신호는 곧바로 비언어적 정서 정보가 아니다.** 캡션에서 빠진 객체·사건, 모델의 짧은 문맥, 정규화와 차원 차이, 측정 잡음도 같은 잔차를 만든다. 반대로 언어 특징으로 설명된 정서 관련 신경분산이 뇌의 언어적 계산을 증명하지도 않는다. 언어 특징이 시각적 사건을 대신 나타낼 수 있기 때문이다. 따라서 우선 질문은 “정서를 잘 예측하는 LLM은 무엇인가”보다 **어떤 설명의 압축·맥락·개념 선택에도 유지되는 정서 관련 신경 대비가 존재하는가**가 된다. 이는 본 조사에서 만든 E3 가설·방법론 판단이다.

서지가 확인된 고유 문헌 10편을 정리했다. 출판사 공식 GitHub 저장소의 본문 PDF 4편에서 선택 절을 직접 검토했고, 나머지 6편은 공식 코드·데이터 문서를 확인했다. **본문 PDF 접근과 실제 검토 범위는 다르며, 코드 확인을 논문 전체 결과 검증으로 세지 않는다.** 서지와 링크는 `papers.csv`, 출처별 실제 열람 위치·해시·실패는 `source_manifest.csv` 및 `sources/fetch_log.json`에 있다. 2024–2026 최신성을 체계적으로 감사하지 못했고, 선정된 논문은 2020–2023에 집중한다. “현재 최고 성능”이나 “최초 연구”라는 주장은 하지 않는다.

## 4. 숨겨진 가정 세 가지

**A1. 언어 임베딩은 자극 의미를 충분히 대표한다.** CLIP은 정렬 목적, BLIP-2는 텍스트에 유용한 정보 선택, LF-CBM은 선택된 개념 집합에 의존한다(E1: S10-01/03/06). 이 구조가 과학적 분석에서 의미의 충분성을 보장한다는 결론은 추가 가정이다. 최근 이용 가능한 복수 captioner, 병목 이전/이후 특징, 명시적 개념 목록으로 이 가정을 시험할 수 있다. 캡션을 늘리거나 중립적 사건 설명을 추가할 때 “정서 잔차”가 사라지면 비언어적 해석을 약화시킨다. 보존되더라도 모델군의 공통 결손 가능성은 남는다.

**A2. 더 높은 brain alignment는 더 적절한 정서 계산을 뜻한다.** 언어 벤치마크와 의미 인코딩 코드는 예측 비교를 가능하게 한다(E1: S10-07/08/09). 전체 뇌 예측이 늘었다고 정서 관련 조건부 대비도 늘어난다는 보장은 없다. 같은 읽기용 선형 모델, 특징 차원·규제·학습량·문맥 범위를 통제한 모델 계열 비교로 전체 신경 예측과 정서 주석 관련 증분을 따로 측정해야 한다. 전체 성능이 오르면서 정서 대비는 일정하거나 줄어드는 결과도 의미 있다.

**A3. 계층의 이름과 모델 깊이가 동일한 의미 추상화 순서를 나타낸다.** 객체→관계→사건→장기 문맥이라는 분석용 계층은 유용하지만 뇌의 고정 순서로 확정되지 않았다(E3). 공식 벤치마크가 문맥 순서의 불일치를 사후 수정한 점(S10-07)은 정확한 입력 이력이 중요함을 보여준다. 문장 수·길이·구체성·정보량을 맞춘 명시적 계층과 모델 층을 교차하고, 깊이 하나에 모든 추상성을 귀속하지 않는다. 계층 우위가 입력 길이 통제로 사라지면 “추상화 수준” 해석을 기각한다.

## 5. 문헌에서 도출한 미해결 문제 다섯 가지

1. **의미의 충분성 경계:** 인간이 확인한 객체·사건 설명을 단계적으로 늘려도 정서 주석과 관련된 신경분산이 남는가? S10-01/02/03/06의 서로 다른 압축 원리가 근거다. 남은 분산의 원인을 고유 정서 정보로 확정할 수 없다는 것이 핵심 공백이다(E3).
2. **문맥 순서 대 내용 누적:** 장기 문맥의 효과가 사건의 순서 때문인가, 더 많은 객체·사건 정보를 포함했기 때문인가? S10-07의 문맥 구성 기록과 S10-08의 문맥 특징 추출이 비교 도구를 제공한다. 순서를 섞은 모델 입력은 계산 대조군이며, 참가자가 그 순서를 경험한 신경반응은 아니다(E3).
3. **개념 이름 대 계산 기능:** 같은 개념명을 갖는 특징이 실제로 같은 정보를 사용하며, 정서 관련 뇌 대비를 같은 방식으로 설명하는가? S10-05/06의 개념 구성·개입 계산을 검증 문제로 뒤집는다. 개념 좌표의 해석 가능성만으로 해당 신경기능을 명명할 수 없다(E3).
4. **captioner 의존성 대 신경 규칙성:** 서로 다른 VLM의 설명이 갈리는 자극에서 관찰되는 신경정보는 누락된 시각 사건인가, 더 일반적인 정서 관련 대비인가? S10-02의 복수 captioner 제안과 S10-03의 병목이 근거다. 모델들 간 일치도도 공통 사전학습 편향의 영향을 받는다(E3).
5. **일반 언어 정렬 대 정서 대비:** 신경 예측력이 높은 LLM이 정서 관련 대비를 독립적으로 더 많이 설명하는가? S10-07/08/09의 인코딩 계산은 시험 경로를 제공하지만, 해당 논문이 목표 정서 데이터에서 이를 이미 증명하지는 않는다(E3).

## 7. 다른 분야에서 가져오는 전이 다섯 가지

1. **데이터 정제 → 의미 측정 오차:** CapFilt(S10-02)의 목적은 더 나은 사전학습 데이터다. 이를 복수 중립 캡션과 검수된 사건 목록의 측정 모형으로 바꾼다. 목표는 정서 예측 최고점이 아니라 설명의 불완전성이 신경 잔차에 미치는 영향을 추정하는 것이다(E3).
2. **설명 가능한 분류 → 의미 제거 감사:** CBM/LF-CBM(S10-05/06)은 해석·수정 가능한 분류기를 만든다. 이를 의미를 제거했다고 주장하는 잔차 경로의 개념 누출 검사로 뒤집는다. 정서 라벨로 개념을 먼저 고른 뒤 같은 라벨의 신경 효과를 검정하는 순환을 금지한다(E3).
3. **효율적 VLM 연결 → 신경정보 보존 검사:** BLIP-2(S10-03)의 경량 병목을 뇌의 알고리즘으로 가정하지 않고, 통제된 표현 손실을 제공하는 계기로 사용한다. 동일 자극·동일 시각 backbone에서 병목 전후 대비가 가능하다는 점이 새 측정 능력이다(E3).
4. **언어 벤치마크 → 문맥 충실도 검사:** S10-07의 실제 자극 제시와 모델 문맥 구성의 차이를, 영화·서사 특징 추출의 감사 원리로 가져온다. 미래 사건의 텍스트가 현재 특징에 섞이지 않도록 시간별 입력을 고정하고 기록한다(E3).
5. **언어 디코딩 → 신경설명 잔차의 독립 평가:** S10-09의 GPT 특징→신경 예측과 훈련 이야기 기반 잡음 추정 구조를 활용해, 뇌→텍스트 복원이 잘되는지를 목적에 두지 않고 언어 특징으로 설명되는 범위의 불확실성을 평가한다. 남은 신경정보와 독립 정서 주석의 관계가 다른 자극 집합에 전이되는지 검사한다(E3).

## 8. 예상 밖의 연결 세 가지

**C1. 개념 우회 경로 문제 × 의미 잔차의 정서 해석.** S10-05는 누락 개념을 보완하는 직접 경로가 단일 개념 개입을 흐릴 수 있다고 명시한다. S10-06은 더 큰 언어 기반 개념 집합을 쉽게 구성한다. 두 결과를 연결하면, “의미 통제를 강화할수록 잔차에 정서가 더 순수해진다”는 직관을 시험할 수 있다. 통제가 정서와 공유된 사건 정보까지 제거할 수 있어 완전 제거를 목표로 삼기보다 공유·증분 예측량을 함께 보고해야 한다. Agent07(식별성과 분해), Agent12(누수 감사)와 연결 가능하나 실제 교차 토론은 아직 하지 않았다(E3).

**C2. 캡션 앙상블 × 잡음 상한.** S10-02의 여러 captioner와 S10-08의 반복 신경 측정 ceiling을 연결한다. 입력 설명의 불확실성과 신경반응의 불확실성을 별도로 추정하면, “모델이 설명 못하는 뇌”의 경계를 두 종류의 측정 오차로 나눌 수 있다. 반복 캡션은 독립 모델·독립 검수 없이 독립 표본이 아니며, 이중 불확실성의 분해는 식별 가정이 필요하다. Agent01·07과 연결 가능하다(E3).

**C3. 멀티모달 병목 × 사건 기억 길이.** S10-03의 언어 관련 시각 정보 병목과 S10-07/08의 문맥 구성을 연결한다. 짧은 장면 단위에서 사라진 정보가 긴 사건 서술에서 되살아나는지 비교하면 “비언어적”으로 보였던 신경 대비가 사실은 문맥 누락 때문인지 구분할 수 있다. 현재 이미지 중심 BLIP-2가 영상의 장기 문맥을 학습했다는 뜻은 아니다. 명시적 과거 사건 텍스트와 영상 모델을 따로 구성해야 한다. Agent05·08과 연결 가능하다(E3).

## 11. 공통 판별 설계와 가장 강한 반론

관측 변수는 신경반응 Y, 저수준 시각·운동 특징 V, 검수된 비정서적 사건·의미 특징 S, 과거에만 의존하는 문맥 특징 C, 독립적으로 수집된 정서 주석 A로 구별한다. A가 자극 집계값이면 참가자 개인의 측정으로 해석하지 않는다. AI가 생성한 정서 서술을 A에 넣지 않는다.

주요 비교는 같은 훈련 분할에서 적합한 `Y ~ V + S + C`와 `Y ~ V + S + C + A`의 외부 검증 성능 차이, 그리고 표현 교체·정보 삭제에 따른 그 차이의 안정성이다. 정서 주석이 자극 특성과 공유하는 정보도 별도 보고한다. 이 증분은 **지정된 모델군에 조건부인 예측량**이며, 고유 신경 코드·인과 효과·완전한 정보 분해가 아니다. 비선형 상호작용 모형도 같은 외부 분할에서 비교하고, 읽기 모델의 유연성 증가 자체가 결과를 바꾸는지 확인한다.

1. **가장 강한 반론: 의미와 정서의 공선성 때문에 식별 불가능하다.** 회귀 잔차를 고유 정서로 부르지 않고, 최소한의 허용 해석을 “검토한 의미 표현을 넘어선 독립 주석 관련 예측량”으로 제한한다. 의미상 유사하지만 주석이 다른 자극을 독립 시험에 넣고 표본 지지가 약하면 보류한다.
2. **최신 모델 대신 간단한 사건 목록으로 충분하다.** bag-of-objects, 사건 단어 평균, 비맥락 문장 임베딩, 차원 맞춘 선형 모형을 강한 기준으로 둔다. 이들이 충분하면 LLM 필요성을 기각하며 과학적 결론은 보존한다.
3. **긴 문맥과 정서 변화 모두 시간 자기상관이다.** 영화/이야기/런 단위 외부 분리, train-only 변환, HRF·지연 처리, 블록 기반 불확실성, 경계·시간 이동 대조군이 필요하다. 인접 프레임 무작위 분할을 사용하지 않는다.
4. **VLM 설명은 자극과 정서 단어를 이미 결합한 학습 편향이다.** 정서 단어 제거만으로 편향이 제거되었다고 가정하지 않는다. 중립적 인간 사건 설명·비언어 시각 기준·서로 다른 사전학습 목적을 비교한다.
5. **뇌와 모델의 정렬은 동일 계산의 증거가 아니다.** 결과는 표현의 충분성·조건부 예측으로 해석한다. 실제 자극 조작·신경 측정이 없는 모델 내부 편집은 신경 인과 실험이 아니다.

모든 특징 선택·개념 선택·정규화·잔차화·층 선택은 훈련 fold 안에서 수행한다. 반복 자극은 같은 분할에 묶고, 독립 자극·피험자 수를 통계 단위에 반영한다. ROI/whole-brain 다중비교와 noise ceiling을 분리해서 보고한다. 동일 인터넷 이미지가 사전학습에 들어갔을 가능성은 완전히 판별하지 못할 수 있으므로 새 자극 집합 전이 결과가 중요하다.

|---|---|---|
| Horikawa | RQ10-1/2/4/5/6의 자극 단위 대비를 우선 검토 | 접근 가능한 정확한 자극, 반복/분할 정보, 신경반응, 독립 정서 주석의 정의·신뢰도 필요. 정지영상/연속영상 여부도 여기서 확정하지 않음 |
| Emo-FilM | RQ10-3의 시간적 문맥 후보 | 연속 사건 시간, fMRI 정렬, 시간별 정서 주석의 실제 존재·해상도 검증 전까지 E0 |
| Spacetop | 문맥 일반화 후보 | 사용 가능한 과제·자극·주석·시간 정렬에 따라 다름; 자료 이름만으로 정서/서사 라벨 존재를 주장하지 않음 |
| NSD | 객체·사건 의미 통제의 방법론 기준 후보 | 정서 주석이 검증되지 않으면 의미 표현의 검증만 가능. 정서 가설에는 별도 독립 주석 또는 다른 자료 필요 |

S10-10의 외부 언어 데이터 문서는 구현 원리 확인용이다. 이를 목표 네 자료와 동일한 신경·주석 조건으로 결합하지 않는다. 모델별 가중치 접근·라이선스·GPU/메모리는 이번 작업에서 검증하지 않았고 코드 공개와 실행 가능성을 동일시하지 않는다.

## 13. 미션의 여덟 질문에 대한 응답

1. **왜 아직 시도되지 않았는가?** 완전히 미시도인지 확인하지 못했다(E0). 이 조사에서 식별한 어려움은 정서–사건 공선성, 캡션 불완전성, 시간 주석 부족, 표현 가족별 측정 오차다(E3).
2. **최근에 가능해진 것은 무엇인가?** 검증한 2020–2023 계산 변화는 자연어 기반 시각 특징, 지시 가능한 이미지 설명, 고정 모듈 사이 병목, 라벨 없는 개념 구성, 효율적인 LLM 의미 인코딩이다(E1). 2026년 최초 가능하다고 주장하지 않는다.
3. **어떤 가정이 틀렸을 수 있는가?** 단일 언어표현의 충분성, 전체 brain alignment의 정서 설명 우월성, 모델 깊이와 의미 추상화의 동치다(E3).
4. **AI가 더 잘 포착할 수 있는 것은?** 객체 목록보다 관계·사건·과거 문맥의 조건부 표현을 체계적으로 구성하고 서로 다른 압축 수준을 비교할 수 있다(E3). 목표 데이터에서 기존 모델을 이겼다는 결과는 없다.
5. **뇌가 표상하지만 AI가 놓치는 것은?** 아직 특정할 수 없다(E0). 검수된 의미·시각 대조군을 바꾸어도 재현되는 신경 대비를 후보로 찾을 수 있으며, 모델 공통 결손과 잡음을 계속 경쟁 설명으로 둔다(E3).
6. **다른 분야 방법이 새 사실을 밝힐 수 있는가?** 개념 병목의 우회 경로 감사, 캡션 앙상블의 측정 오차, 모듈 사이 압축의 정보 보존 비교가 정서 관련 신경 해석의 범위를 가를 수 있다(E3).
7. **기존 데이터의 다른 용도는?** 새로운 정서 분류기를 만드는 대신, 기존 정서–신경 관계가 언어 설명의 선택·문맥 범위에 얼마나 의존하는지 시험하는 자료로 재사용한다. 실제 적합성은 metadata 감사 뒤 결정한다(E3/E0).
8. **답이 신경 계산 이해를 바꾸는가?** 조건부 대비가 안정하면 특정 의미 압축으로 환원하기 어려운 정보의 경계를 좁힌다. 더 상세한 사건 설명으로 모두 사라져도 정서 특이적이라고 해석된 신경 대비의 경쟁 설명을 강화한다. 어느 결과도 단독으로 뇌의 알고리즘·인과성을 확정하지 않는다(E3).
