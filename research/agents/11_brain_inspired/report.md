# Agent 11 독립 조사: 뇌 영감 계산을 정서 신경 계산의 판별 도구로 전이

- 확인일: 2026-11-12. 담당: Agent 11 Brain-inspired & Neuromorphic AI.
- 범위: 공식 저자 저장소의 논문 식별 정보, 문서, 핵심 구현을 직접 읽은 8개 연구. 모델 학습·추론·뇌 데이터 분석은 실행하지 않았다.
- 독립성: 루트 지침과 공통 미션만 읽었으며 EmoBrain과 다른 Agent의 결과는 열람하지 않았다. 외부 자료와 산출물은 이 전용 폴더에만 저장했다.
- `source`, `verified_on`, `confidence`, `needs_followup`, `origin_agent`는 아래 출처 표와 `source_manifest.csv`에 기록했다. 문헌별 30개 필드는 `papers.csv`, 하위축은 `subaxes.csv`에 있다.

## 1. 핵심 판단과 근거 수준

가장 유용한 전이는 **예측된 상태와 예측오차, 재귀 반복과 공간적 깊이, 경로 선택과 전문가 내용, 스파이크와 발화율, 추론 구조와 학습 규칙을 각각 분리하여 비교하는 것**이다. 모두 정서 신경계산에 대한 새 가설(E3)이다. 현재 확인한 논문들이 정서 관련 뇌 자료에서 이 구별을 이미 입증했다는 뜻은 아니다.

우선순위는 N11-1 예측오차/상태의 판별, N11-2 경로 선택/내용의 판별, N11-3 생물학적 제약의 관측 가능성 순이다. 단기에는 공개 모델의 내부 변수를 추출하는 N11-1이 상대적으로 명료하다. 과학적 잠재력은 학습 규칙과 추론 구조의 비식별성을 직접 시험하는 N11-3도 크지만, fMRI만으로 실제 학습 규칙이나 밀리초 스파이킹을 판정할 수는 없다.

- **E1:** 실제 읽은 공식 코드·공식 문서의 특정 내용. 논문 전체 본문을 읽었다는 표시가 아니다.
- **E2:** 저자 README의 서지·초록·성능 요약. 저자 주장과 독립 재현을 구분한다.
- **E3:** 본 보고서의 정서 관련 전이, 가설, 반증 설계, 비판적 추론.
- **E0:** 정확한 실재·서지·버전·가용성 등을 확인하지 못함.

**논문 Discussion은 8편 모두 직접 읽지 못했다. 저자의 미래 연구 제안으로 집계한 항목은 0개다.** 코드 주석·README의 제약은 그 문서의 내용으로만 인용한다. `papers.csv`의 E1은 코드 범위로 제한되며, 서지와 README의 결과 설명은 E2다.

## 4. 숨겨진 가정 3개와 시험 방법

| 가정 | 어떤 자료가 점검을 촉발했는가 | 왜 아직 판별이 어려운가 | 판별 설계(E3) |
|---|---|---|---|
| A1. 생물학적인 모양을 가진 모델은 더 생물학적인 알고리즘을 사용한다 | BI02의 CORnet-R/RT 시간 전개 오류 수정 공지; BI04의 Dale 법칙 미적용; BI03의 전체 기울기 기반 검증 | 구조·학습·정확도·계산량이 함께 달라짐. 구조의 이름이 동일성 주장을 유도 | 구조×학습 규칙 요인 설계, 성능·표현 차원·계산량 대조, 모델 내부 시간과 실제 뇌 시간을 구분 |
| A2. 예측오차와 입력/상태 표상을 별도 회귀항으로 넣으면 고유 기능을 식별할 수 있다 | BI01에서 E는 A와 Ahat의 결정적 함수; BI08에서 오차와 갱신이 긴밀히 연관 | 상관된 특징과 비선형 관계, HRF 평활화가 고유 설명분을 불안정하게 함 | 자극 홀드아웃에서 모형 불일치가 큰 구간을 먼저 찾고 독립 데이터로 검정; 조건부 분석과 신호 주입 복구 검증; 식별 실패도 결과로 기록 |
| A3. 전문가 번호가 안정적인 기능 경로 또는 뇌 영역에 해당한다 | BI05 gate가 입력과 load-balancing 손실에 의존 | expert label permutation, 학습 seed, 객체·패치 위치·부하 균형에 의해 분업이 달라질 수 있음 | 번호 자체 대신 경로 분포·겹침·엔트로피와 seed 간 정렬을 비교; 무작위 gate와 균형 gate를 대조 |

이 표의 가정은 해당 논문 저자가 그대로 주장했다는 인용이 아니라, 본 연구에서 쉽게 범할 수 있는 해석을 Agent가 명시적으로 드러낸 것이다.

## 5. 미해결 문제 5개

1. **U1 상태–오차 비식별성:** 예측오차의 뇌 설명분이 정서 관련 변화, 장면 전환, 운동량 또는 영상 품질 중 무엇을 반영하는지 구별되지 않았다. BI01+BI08에서 나온 E3 문제다.
2. **U2 재귀–깊이 동등성:** 반복 계산이 유리해도 가중치 공유, 파라미터 수, 유효 깊이, 분류 성능 중 무엇이 설명하는지 미정이다. BI02+BI04 기반 E3.
3. **U3 경로–내용 혼동:** routing이 신경반응을 예측해도 전문가가 처리한 내용의 재표현일 수 있다. BI05+BI01 기반 E3.
4. **U4 학습–추론 혼동:** 고정된 모델의 성공만으로 뇌의 실제 학습 알고리즘을 역추론할 수 있는가? BI03+BI08 기반 E3. 두 학습 규칙이 동일한 관측 표상을 낳으면 판별은 불가능하다.
5. **U5 스파이킹 관측 한계:** 발화 시점 차이가 HRF·공간 집계 후 사라지면 fMRI로 스파이크 원리를 시험할 수 없다. BI04+BI06+BI07에서 나온 E3 측정 문제다.

모두 Agent가 생성한 질문이다. 논문 Discussion에서 추출한 저자의 미해결 질문으로 표시하지 않는다.

## 6. 방법론 기회 5개

1. **M1 내부 변수 분리:** PredNet의 A, Ahat, R, 양·음 E를 별도 추출하여 동일 읽기 모델과 nested cross-validation으로 비교. 모델을 갈아 끼우는 성능 비교보다 계산 가정에 직접 대응한다.
2. **M2 구조 통제 계열:** 가중치 공유 재귀, 같은 횟수로 펼친 비공유 모델, 재귀 없는 모델을 비교. 파라미터·FLOPs·인식 성능을 동시에 완벽히 맞추기 어려우므로 여러 대조군을 사용하고 잔여 차이를 보고한다.
3. **M3 gate–content 분해:** 전문가 출력, gate 확률, gate×출력 상호작용을 구분한다. 보조 손실 세기와 무작위 gate를 바꿔 생기는 변화를 통제한다. feature 수와 정규화 선택은 훈련 fold 내부에서 결정한다.
4. **M4 학습 규칙 통제:** 동일 구조·목표·학습 자료를 두고 e-prop형 근사, surrogate-BPTT, 예측부호화형 갱신을 가능한 범위에서 비교. 서로 다른 알고리즘을 단순 교체할 수 있다는 가정부터 검토하며, 구현되지 않은 비교는 계획으로 남긴다.
5. **M5 관측 연산자 통과 후 판별:** 모델 차이를 집계·HRF·샘플링·잡음 연산에 통과시켜 남는 차이를 검토한 뒤 뇌 실험을 설계한다. 이는 측정 가능성 점검이며 모델 신호를 실제 BOLD 생성 과정으로 확정하는 것이 아니다.

## 8. 예상 밖의 연결 3개

1. **예측부호화 × 비식별성:** BI01은 상태와 오차를 직접 열어 보이지만 BI08은 계산 방식이 서로 유사해질 수 있음을 탐구한다. 내부 변수가 많아진 사실이 기전 판별력을 자동으로 늘리지 않는다. 따라서 Agent 07의 표현 기하·조건부 분해와 연결해 **모델들이 관측상 갈라지는 자극**을 찾는 질문이 생긴다(E3). 다른 Agent 결과를 읽고 도출한 것은 아니다.
2. **MoE 부하 균형 × 신경 경로 전문화:** BI05의 분업에는 계산 자원 배분 목적이 섞여 있다. BI02의 해부학적 모듈 해석과 결합하면, 전문화가 기능 필요성인지 자원 배분 제약인지 비교할 수 있다. Agent 08의 네트워크 수준 분석과 연결하되 expert–ROI 일대일 대응을 전제하지 않는다(E3).
3. **국소 학습 × 관측 시간척도:** BI03의 eligibility trace는 가중치 학습의 변수이고 BI04의 막전위/스파이크는 추론 상태다. 둘의 시간적 지속을 같은 종류의 신경 기억으로 묶으면 오류다. Agent 05의 시간 분석 및 Agent 01의 실제 측정 주기 감사와 연결해, 자료가 식별할 수 있는 상태와 식별할 수 없는 학습 규칙을 구분한다(E3).

## 11. 강한 반론, 수정안, 초기 검증 계획

**반론 1: “기존 encoding에 모델 feature만 추가했다.”** 수정: BI-RQ01에서는 상태/오차 모형의 서로 다른 예측이 나오는 자극 또는 구간을 훈련 자료에서 사전 규정하고 별도 테스트에서 평가한다. 추가 상관만 보고하는 분석은 방법 검토로 낮춘다. 미관측 신규 자극에 대한 뇌 예측이 가능하다면 판별력이 더 강하지만, 이번에는 실행하지 않았다.

**반론 2: “정서 효과는 의미 또는 자극 구성 효과다.”** 수정: 저수준 영상, 객체/장면, 의미, 운동, 사건 경계의 강한 baseline을 사용한다. 의미를 너무 유연하게 제거하면 관심 정보도 제거할 수 있으므로 총 설명분, 조건부 설명분, 공유 설명분을 모두 보고한다. 조건부 분해를 인과적 정서 분해로 부르지 않는다.

**반론 3: “fMRI가 구분하지 못하는 시간을 모델 반복수로 대체했다.”** 수정: 반복수와 생리적 시간을 동일시하지 않는다. 실제 TR, HRF, 주석 시간 해상도와 run 경계를 확인하고, 시간 검정이 불가능하면 자극별 표현 비교로 질문을 줄인다.

**반론 4: “생물학적 제약과 성능을 분리하지 못했다.”** 수정: 하나의 맞춤 baseline으로 해결됐다고 하지 말고, 성능 맞춤/파라미터 맞춤/계산량 맞춤 비교를 별도로 둔다. 예측부호화·e-prop·BPTT의 완전한 호환성이 검증되지 않으면 학습 비교를 후속 단계로 미룬다.

**반론 5: “새로운 정서 예측부호화나 경로 연구가 이미 존재한다.”** 수정: 이번 독립 조사는 계산 원리·코드 확인에 집중했으며 정서×모델의 2024–2026 선행연구 반례 검색은 완료하지 않았다. RQ는 신규성 잠정 후보로만 통합한다. 기존 emotion predictive coding, recurrent affective encoding, conditional routing의 동등 연구를 확인하면 판별 조건을 좁히거나 기각해야 한다.

**최소 유익한 첫 검증(E3, 미실행):** Agent 01이 Horikawa의 실제 자극 접근, 신경반응 단위, 정서 주석, 반복·run 구조를 확인한 뒤 BI-RQ01의 가능 여부를 먼저 판단한다. 프레임·시간 자료가 없으면 영상 오차 궤적 검정은 보류한다. 추출 가능할 경우 PredNet R/Ahat/E와 저수준·의미 baseline의 차원/정규화를 훈련 fold 안에서 결정하고, 동일 자극의 반복·근접 프레임이 fold를 넘지 않도록 분리한다. 참가자/자극 수준 불확실성, 다중 비교, 신뢰도 상한을 함께 평가한다. 모델 차이가 재현되지 않거나 측정 신뢰도가 차이보다 낮으면 기전 주장을 하지 않고 중단한다. 데이터와 모델을 실제로 내려받아 실행할 때 라이선스와 의존성부터 다시 확인한다.

## 12. 공통 미션의 여덟 질문에 대한 답

1. **왜 아직 시도되지 않았는가?** 역사적 부재를 확인하지 않았다. 구조·목표·성능의 혼동과 느린 신경 측정 때문에 판별이 어려웠을 것이라는 E3 설명만 제시한다.
2. **최근에야 가능해진 것은 무엇인가?** 현재 공개 코드에서 상태/오차/gate/spike 변수를 읽을 수 있고, BI07 같은 2024년 아키텍처가 더 강한 SNN 대조군을 제공한다. 이 능력이 2024년에 처음 가능해졌다는 주장은 하지 않는다.
3. **어떤 가정이 틀렸을 수 있는가?** 생물학적 외형→생물학적 학습, 상관 특징의 회귀 분리→기능 식별, 전문가 번호→고정 신경 경로라는 A1–A3이다.
4. **AI가 기존 뇌과학 모델보다 더 포착하는 것은 무엇인가?** 영상 예측의 고차원 상태·오차, 입력별 선택 경로, 반복 단계별 표현을 동일 구현에서 측정할 수 있다. 실제 뇌 설명력이 더 높다는 결론은 아직 없다.
5. **뇌가 표현하지만 AI가 놓치는 것은 무엇인가?** 독립 자극·피험자에서의 정서 관련 신경 잔차가 후보지만, 잡음·불완전한 의미 baseline과 먼저 구별해야 한다. 잔차를 새로운 정서 메커니즘이라 명명하지 않는다.
6. **다른 분야의 방법이 새로운 사실을 밝힐 수 있는가?** 자원 배분용 MoE와 국소 신용 할당의 원리를 기능적 경로와 학습/추론 구분의 대조군으로 옮길 수 있다. T1–T5가 그 E3 전이다.
7. **기존 자료의 새 용도는 무엇인가?** 정서 범주 예측 정확도 대신 계산 모형의 불일치와 관측상 비식별성을 평가한다. Horikawa→Emo-FilM→Spacetop→NSD 순으로 실현성을 확인하되 어느 자료에 어떤 필드가 있다고 가정하지 않는다. 특히 NSD에 해당 정서 라벨이 있다고 가정하지 않는다.
8. **신경 계산 이해가 달라지는가?** 양성 결과는 특정 계산 변수의 관측상 필요성을 좁힌다. 음성 결과는 그 모델/자료로 구별할 수 없는 계산 원리를 규정한다. 어느 경우도 encoding 상관만으로 동일 알고리즘·회로 인과성을 입증하지 않는다.
