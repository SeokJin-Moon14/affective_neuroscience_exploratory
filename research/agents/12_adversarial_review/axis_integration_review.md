# Stage3 Axis 통합 감사 — 30개 후보와 추가 6개

작성일 2026-11-12. 담당 Agent12. `AGENTS.md` 최신 §9 및 `RESEARCH_MISSION.md`의 범위·증거 규칙을 적용했다. 이번에 허용된 실제 열람은 `axis_map/candidate_subaxes.json` 30개, Agent01 보고서의 추가 3개, Agent05 보고서의 추가 3개와 기존 문헌 목록이다. **Stage3 통합 검토이며 Round2–5 토론 완료가 아니다.** 공유 파일은 수정하지 않았다. 새 네트워크 검색·실물 데이터 감사·모델 실행은 하지 않았다.

사용자가 Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop을 보유한다는 사실을 전제로 Axis 작업을 진행한다. 보유 사실과 현재 환경의 버전·필드 확인은 구분하되, 후자를 Axis 생성의 선행 차단 조건으로 삼지 않는다. 모든 후보의 신경과학 전이는 E3 가설이며 모델명·코드 존재가 신경 결과의 검증을 뜻하지 않는다.

## 3. 분류·범위·과학적 과장 문제

### 분류를 평탄하게 만들지 말 것

1. **현상·방법·검증 조건의 수준이 섞여 있다.** `A2-S1` 같은 현상과 `A12-S3` 같은 검증 절차를 동일한 연구 질문 수로 세면 중복이 늘어난다. 다중 type tag는 유지하되 `role = phenomenon / computational_hypothesis / measurement / evaluation / intervention_design` 같은 보조 역할을 둘 수 있다. 이는 기존 다섯 유형을 대체하지 않는다.
2. **태그 구문이 일관되지 않다.** `Model/Method`와 `Model / Method`, `Structure/Dynamics`와 `Structure / Dynamics`를 정규화해야 한다. Python/JSON list와 세미콜론 문자열로 섞인 `representative_papers`, `models`도 명시적 배열로 통일한다. `axis_id` 안의 `:`·`/`는 의미를 추측해 분해하지 말고 원본 ID와 상위 A–X 연결을 별도 저장한다.
3. **원본 ID가 상위 축의 뜻과 어긋날 수 있다.** `P-A01`의 핵심은 인과성이 아니라 자극 독립성·분할이고, `X-A01`은 관측 척도·평정 불확실성이다. 원본 ID는 provenance로 유지하면서 각각 S/T/Q/B/C, Q/A/P 등의 상위 링크를 정의에 맞게 추가한다. 여러 태그 수가 많다는 이유로 과학적 우선순위를 올리지 않는다.
4. **기존 후보 30개에 Agent01·05 6개가 아직 누락되어 있다.** 누락된 후보를 단순 중복이라고 버리지 않는다. 특히 `X-A01`의 측정 불확실성과 `C-D-05c`의 사건단계 대 물리시간은 별도의 판별 질문을 제공한다.

### 과장 위험과 교정 문구

| 위험 | 수정 권고·폐기할 주장 |
|---|---|

| ‘긴 문맥/SSM/masked predictor = 관찰자의 미래 예측’ | 관찰 가능한 과거 입력을 명시한다. Agent05가 확인한 VideoMamba·AVE의 양방향 구현을 지운 채 예측 부호화의 근거로 쓰지 않는다. `A2-S2`의 ‘인과적 접근제한’은 **미래입력 차단**으로 풀어 쓰고 causal identification과 구별한다. |
| ‘일반화/불변성 = 인과 원인’ | 내용 환경이나 참가자 변화에서의 예측 유지라는 관찰 주장으로 제한한다. IRM 등의 방법명만으로 정서 원인 식별을 주장하지 않는다. |
| ‘분해 안정성/feature intervention = 뇌의 필요조건’ | 모델 안의 개입과 실제 뇌의 개입을 분리한다. `R.FAI2`의 세 증거—방향 재현성·모델 계산 사용·신경 대응—를 합산한 인과 점수로 만들지 않는다. |
| ‘편집된 영상/생성된 시간 변화 = 관측된 신경 효과’ | model-only 예측과 새 자극 제시로 측정한 뇌 효과를 구분한다. `L09a/c`의 설계 가능성은 현재 관측 증거와 다르다. |
| ‘높은 정렬/통합 이득 = 정서 계산’ | BOLD 전체의 예측 향상 외에 사전에 정한 정서 관련 관측 대비가 필요하다. 이 조건은 Axis 생성을 막는 조건이 아니라 후속 RQ의 판별 기준이다. |

명시적 제외 주제를 새 축으로 도입하는 후보는 이번 36개 정의에서는 발견하지 못했다. 다만 Agent05의 오디오 전이는 음악·환경음 수준을 유지하고 Speech Features로 확대하지 않는다. Mind Captioning은 사용자 보유 데이터명으로 등록하되 이름만으로 캡션 스키마, 정서 ground truth, task 또는 연구 범위를 추정하지 않는다.

## 4. 통합 수정 권고 — 지금 실행 가능한 순서

1. **36개 원본을 우선 등록한다.** 30개 CSV/JSON 후보에 Agent01·05의 6개를 추가한다. 원본 ID·작성자·파일·원문 정의를 보존한다. 추가 후보의 축약 문헌 ID를 확장한다.
2. **공통 상위 정의만 묶고 대조를 보존한다.** 위 표의 중복군에 canonical group을 부여하고, 조작·관측 대상·경쟁 설명이 다른 하위 항목은 유지한다. 한 candidate가 여러 묶음에 연결되는 것을 허용한다. 묶음 개수로 RQ 목표 수를 충족했다고 보고하지 않는다.
3. **근거 상태를 두 층으로 적는다.** `support_status = verified_bibliography / code_or_document / pending_bibliography`, `claim_status = observed / literature_inference / new_hypothesis`를 분리한다. 현재 대부분 신경 전이는 new_hypothesis다. 위 pending 참조를 명시하되 해당 Axis 전체를 동결하지 않는다.
4. **자료 가용성 문구를 최신 지시에 맞춘다.** ‘Horikawa 확보 필요’, ‘Emo-FilM 실물 필요’, ‘네 데이터셋’은 현재 사용자의 보유 진술과 어긋난다. 다음처럼 갱신한다: **‘사용자 보유 확인; 분석 시 필요한 버전·관측 단위·주석 대응 확인. Axis/개념 조합 진행 가능.’** 다섯 데이터셋을 모두 가용 자원 목록에 포함하되 모든 후보가 다섯 자료에 적용된다고 쓰지 않는다.
5. **자료마다 반증에 필요한 조건만 연결한다.** 예: 역사 의존성에는 원본 시간축과 관측 가능한 과거, 측정 불확실성에는 평정 집계·반복 정보, 모달리티 질문에는 실제 자극 모달리티, 일반화에는 내용 그룹 단위가 필요하다. 이 필드는 후속 분석 준비 요구이며 현 Stage3 차단 사유가 아니다.
6. **우선순위는 자료 확인 여부 하나로 정하지 않는다.** 내용 일반화, 공유/고유 충분성, 과거 상태 대 현재 내용, 사건 단계 대 물리시간을 판별 질문으로 먼저 전개할 수 있다. 단기 실현성은 별도 조건부 열에 둔다. 네트워크 재확인 없이 기존 근거로 Axis 통합을 마칠 수 있다.

이번 감사의 실질적 결과는 **개념 묶음에 대한 병합 권고, 유지해야 할 반증 구별, 보류/누락 참조 4종과 ID 구문 문제의 확인**이다. 원문 서지 보완, 새 데이터 검증, 후보의 신규성 확정, 반론에 대한 타 Agent의 실제 응답·수정은 이번 보고서에서 완료했다고 주장하지 않는다.
