## A12-F1-01 · high · 수학적 결과 판정의 결함

**대상:** agents/10_llm_semantics/proposal_RP02.json:proposed_analyses.reduction_gate; falsifiable_outcomes.positive; core_question

**검토 주장:** g(O)>ε_g와 δ=g(O+B)−g(O+R)>0가 관계 정보의 비가산 이득 감소/대체를 지지한다.

**문제:** 이 두 조건은 실제 감소 r_R=g(O)−g(O+R)>0를 함의하지 않는다. 예를 들어 g(O)=0.10, g(O+R)=0.20, g(O+B)=0.30이면 기준 이득과 δ는 모두 양수지만 관계·비관계 정보를 추가한 후 비가산 이득은 각각 증가한다. 현재 positive 조건은 이 경우를 선택적 중복/대체의 양성으로 잘못 분류할 여지가 있다. δ에서 g(O)가 소거됨을 정직하게 적은 것만으로 감소 방향의 검증이 생기지 않는다.

**필요 수정:**

- 감소/대체 해석의 사전 공동 기준에 r_R의 최소 의미양수 문턱과 불확실성을 추가하고 δ의 차등 감소 기준과 별도로 보고한다.
- r_R≤0이지만 δ>0인 경우는 관계/비관계 조건 사이의 차등 변조 또는 증가 정도 차이로 명명하며 실제 감소·대체를 주장하지 않는다.
- g(O),g(O+R),g(O+B),r_R,r_B,δ를 같은 표본의 paired loss로 모두 보고하고 여러 gate를 test 선택에 사용해 새 효과를 골라내지 않도록 joint inference/사전 판정규칙을 고정한다.

근거 범위: 카드 수식의 대수적 반례; 외부 자료나 신경실험 불필요

집계 영향: RQ 개수 변경 사유 아님; 동일 질문의 판정규칙 수정

## A12-F1-02 · high · 숨은 RQ 중복에 대한 독립 검토 판단

**대상:** research_questions/landscape.json:RQ25,RQ30; research_questions/candidate_crosswalk.csv:C11-02,C11-01

**검토 주장:** gate 좌표의 읽기 효율과 prediction-error 좌표의 읽기 효율을 각각 고유 신경과학 RQ로 센다.

**문제:** 두 질문은 현재 완전한 입력정보를 공통으로 제공한 상태에서 결정적으로 계산되는 좌표를 추가하고, 제한된 readout·표본예산의 정서/비정서 신경 예측 효율을 비교한다. 충분한 함수족에서 이득 소멸, 일반 시각 대비와 같은 이득이면 특수성 축소라는 반증도 같다. gate 대 error라는 모델 내부 변수 이름만으로 관측대상·경쟁 신경설명의 차이가 확보되지 않는다. RQ25 자체도 C08-05 방법후보와 병합된 상태다.

**필요 수정:**

- 동일정보의 파생좌표가 정서 신경 대비에 주는 접근성/표본효율이라는 하나의 RQ로 통합하고 gate/error는 계산좌표 분기로 보존한다.
- 두 개를 유지하려면 같은 관측과 같은 readout 함수계열에서 routing 가설과 error 가설이 서로 다른 부호·조건 상호작용을 예측하는 신경 대비를 명시한다. 특정 모델의 추출부담이나 이름 차이는 충분하지 않다.
- 재분류 전에는 32개를 독립성이 확정된 RQ 수라고 보고하지 않는다.

근거 범위: 두 원문의 관측·조작·반증 서명 비교에 근거한 감사자 판단; Coordinator/제안자의 반론 가능

집계 영향: 최소 이 쌍의 중복 해소 전 고유 32 인증 보류; 새 개수는 통합 후 계산

## A12-F1-03 · medium · 과학RQ/방법후보 분류의 경계

**대상:** research_questions/landscape.json:RQ22; research_questions/directions.csv:D26

**검토 주장:** 함수 보존 재매개화 아래 개념 feature 안정성, 모델 개입 효과와 신경 대응의 분리를 독립 정서 신경 계산 RQ로 유지한다.

**문제:** 현재 명시한 핵심 반증은 동일 함수를 좌표 재표현하면 unit 중요도가 바뀐다는 분석 식별성, 개입 off-manifold 손상, SAE 대 PCA/random의 방법 가치이다. 다음사건 모델 손실과 신경 대비 예측 손실을 따로 측정하는 것은 적절하지만 이것만으로 서로 다른 정서 신경 계산 가설이 정의되지는 않는다. 무엇이 인간 뇌의 가능한 설명을 가르는지 추가되지 않으면 모델 해석/QC 모듈에 가깝다.

**필요 수정:**

- 개별 feature/분해좌표의 식별성 및 모델 내 기능 감사는 방법후보로 우선 분류하고 독립 신경RQ 수에서 제외한다.
- 유지하려면 계산적으로 구별되는 최소 두 가설이 새로운 독립 정서 신경 대비에서 어떤 반대 예측을 내는지 명시한다. 함수 동등 모델의 임의 좌표 중요도 차이를 신경 가설 차이로 삼지 않는다.
- 좌표/기전 해석을 엄격하게 제한했다는 장점은 삭제하지 말고 공통 해석 검증 모듈로 보존한다.

근거 범위: 과학적 분류에 대한 감사자의 소수 의견; 현재 문서가 인간 인과성을 과장한다는 판정은 아님

집계 영향: 방법후보로 확정하면 고유 과학RQ 수에서 제외
