# 흥미를 확인하기 위한 방법론 출발점 두 개

이번 문서는 연구 주제의 신규성 심사를 통과한 제안서가 아니다. 사용자가 무엇을 만들어 보고 싶은지 고를 수 있도록, 완성됐을 때의 모습과 데이터 연결을 먼저 적었다. 지각→심상의 시각 정보 질문을 다시 표현한 후보는 넣지 않았다. 미션에 나온 모델 이름은 탐색 예시이며 사용자가 각각을 선호한다고 가정하지 않는다.

## 1. 뇌를 보고 배운 AI는 장면의 정서를 다르게 판단할까?

1. **만들 시스템:** 영상의 정서 정답만 배우는 AI와, 같은 정서 정답에 더해 사람의 시청 중 뇌 반응을 따라가도록 배우는 AI를 만든다. 학습이 끝나면 둘 다 영상만 보고 정서를 예측한다. 뇌 자료는 AI의 학습을 돕는 정보로 쓴다.
2. **보고 싶은 한 장:** 같은 시험 영상에서 보통 AI가 틀리고 뇌를 함께 배운 AI가 고친 사례들을 보여 준다. 특히 낯선 장면에서 인간의 기존 정서 평정에 가까워졌는지, 그 변화가 물체·색깔 같은 쉬운 단서만 따라간 결과인지 함께 보여 준다.
3. **왜 재미있는가:** 뇌를 AI로 설명하는 데서 끝나지 않고, 뇌 자료가 AI에게 무엇을 가르칠 수 있는지를 묻는다. 성공하면 정서 라벨만으로는 잘 배우지 못한 구별을 신경 관측이 보완할 수 있다는 방법론 기여가 된다. 정서 전용 뇌 회로를 알아냈다는 결론은 아니다.
4. **지금 쓸 자료:** Horikawa의 기존 영상·fMRI·외부 정서 평정이 핵심이다. MC의 기존 사람 캡션으로 어떤 내용에서 판단이 달라지는지 해석할 수 있다. NSD는 일반 시각 뇌 학습을 비교하는 선택적 확장이다. 새 인간 평정·새 영상의 BOLD는 필수가 아니다.
5. **평범한 연구로 끝나는 경우:** 평균 정확도가 조금 오르거나, 임의의 보조 학습 목표를 넣어도 같은 효과가 나면 부족하다. 학습량과 모델 용량을 맞춘 비신경 보조 목표·섞은 뇌 반응 등과 비교해, 뇌 자료를 사용한 이유가 결과에 남아야 한다. NSD와 Horikawa의 차이를 곧바로 정서 특이성으로 해석하지 않는다.
6. **가까운 선행과 미확인:** 사용자가 소개한 *Brain-Aligned Multimodal LLMs*가 직접 중복할 가능성이 크다. 정확한 논문·학습 목표·평가 범위를 아직 확인하지 않았다. U001의 encoding 비교와 방향이 다르다는 사실만으로 새롭다고 하지 않는다. 이 선택지가 끌릴 때 먼저 볼 것은 ‘뇌 정렬을 했다’ 이후 정서 학습에서 무엇이 달라지는가다.

## 2. 정서 정답을 주지 않고 학습한 뇌 디코더에, 나중에 정서 판독 기능을 붙일 수 있을까?

1. **만들 시스템:** 뇌 디코더는 영상의 시각 특징만 복원하도록 학습한다. 별도의 영상 집합에서는 기존 인간 정서 평정으로 emotion head를 학습한다. 두 부분을 연결해, 뇌 디코더를 다시 학습하지 않고 여러 정서 항목을 읽는 시스템을 만든다. 정서 라벨을 어디에도 쓰지 않는다는 뜻은 아니다.
2. **보고 싶은 한 장:** 하나의 고정된 뇌 디코더에 정서 판독 기능을 차례로 붙였을 때의 결과다. 각 정서에 맞춰 뇌 디코더를 새로 학습한 경우와 비교해, 무엇은 그대로 읽히고 무엇은 시각 표현을 거쳐서는 읽히지 않는지 보여 준다. 모두 기존 인간 평정이 있는 보류 영상에서 평가한다.
3. **왜 재미있는가:** 기존 visual decoding 자료를 정서마다 새로 학습하는 대신, 정서 연구에 재사용할 수 있는 하나의 도구를 만드는 방향이다. 성공하면 정서 라벨이 없는 뇌 학습 자료와 뇌가 없는 정서 영상 자료를 연결할 수 있다. 단순 head 추가를 넘어, 두 종류의 학습 자료가 겹치지 않아도 작동하는지가 핵심이다.
4. **지금 쓸 자료:** Horikawa의 기존 영상을 세 부분으로 나눌 수 있다. A는 뇌–영상 특징 학습에만, B는 영상–기존 정서 평정 학습에만, C는 최종 뇌–정서 평가에 쓴다. B의 뇌 관측과 A의 정서 평정을 학습에 쓰지 않는다. NSD는 시각 표현 사전학습 후보지만 새로운 참가자·영상 과제로의 이동이 자동으로 된다고 가정하지 않는다. MC 심상은 첫 검정의 필수가 아니다.
5. **평범한 연구로 끝나는 경우:** 같은 자료로 decoder와 emotion head를 학습하고 정확도 한 줄만 비교하면 이미 익숙한 두 단계 판독이다. 서로 분리된 데이터로 배운 두 기능을 연결하는 이득, 새 목표를 붙일 때 뇌 디코더를 다시 학습할 필요가 없는 범위, 잘 안 되는 목표를 설명할 수 있어야 한다. NSD에는 확인하지 않은 정서 정답을 만들어 붙이지 않는다.
6. **가까운 선행과 미확인:** *MindEye2* 등 visual decoding과 *Emotion schemas are embedded in the human visual system*의 시각 정서 모델이 직접 출발점이다. 여기서는 기존 문헌 장부의 서지만 확인했고 이 조합의 후속 연구를 새로 검색하지 않았다. ‘범용 visual decoder+정서 head’ 자체의 신규성은 약할 수 있다. 새로운 neural training 없이 추가 목표를 평가하는 기능에 실제 기여가 있는지 먼저 대조해야 한다.

두 방향은 사용 시점의 입력부터 다르다. 1번은 **뇌를 함께 학습한 뒤 영상만으로 정서를 판단하는 AI**, 2번은 **뇌에서 시각 표현을 읽고 다른 자료로 배운 정서 기능을 연결하는 decoder**다. 현재의 목적은 이 차이 중 무엇이 더 흥미로운지 확인하는 것이다.
