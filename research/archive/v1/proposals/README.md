# 상세 연구 제안 10개

각 제안은 미션의16개 본문 항목과 실제 Round5 비판 응답을 포함한다. 우선5와 확장5를 구별하며, 순위는 가중합 자동선정이 아니라 경쟁 설명·다양성·착수 조건에 대한 Coordinator 판단이다.
