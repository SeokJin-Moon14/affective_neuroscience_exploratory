# 공통 방법과 데이터 조건

세 파일럿은 뇌와 정서에 관한 설명을 비교하는 작은 분석에서 시작한다. 데이터와 모델을 확인하기 위한 절차는 아래처럼 공통으로 두며, 이 절차 자체를 연구의 기여로 삼지 않는다.

## 무엇을 정답으로 쓰나

사람이 실제로 평가한 정서 항목을 사용한다. AI가 영상이나 뇌 반응에서 만든 정서 점수를 인간 평정으로 취급하지 않는다. 집단의 영상 평정과 스캔 참가자 개인의 정서 반응도 구별한다.

Horikawa에서는 실제 코드북과 평정 파일을 열어 사용할 항목을 정한다. 공식 코드에 여러 주석 그룹이 있다는 사실만으로 구체적인 라벨과 값이 모두 확인됐다고 하지 않는다. 영상과 이벤트를 연결하는 실제 필드는 `stim_index`다. 내용이 겹치는 영상을 동일 자극의 독립 반복 측정으로 세지 않는다.

Emo-FilM의 외부 연속 합의 주석은 영화의 정서적 특성을 설명한다. 스캔 참가자 각자의 연속 정서 상태를 측정한 자료는 아니다. 영화 시간과 촬영 시간을 구분하고 HRF를 고려한다. BOLD의 시차만으로 어느 뇌 영역이 먼저 계산했다고 판단하지 않는다.

Spacetop의 자극 후 평정은 해당 자극 단위로 사용한다. NSD에서 측정된 정서 라벨은 아직 확인하지 않았다. Mind Captioning은 정확한 자료와 텍스트 출처를 확인한 뒤 사용 범위를 정한다. 현재 5종 모두 사용자가 보유하고 있지만 이 클라우드에서 실제 원자료를 열어 분석한 상태는 아니다.

## 무엇을 학습과 평가에 나누나

같은 원영상에서 나온 프레임·클립과 중복 영상을 한쪽에 모은다. 연속 영화에서는 시간점을 무작위로 섞는 대신 영화나 충분히 떨어진 구간을 나눈다. 표준화, 특징 선택, 차원 축소와 모델 선택은 학습 자료 안에서 한다.

뇌 영역은 정서 예측 결과를 보기 전에 정한다. 서로 다른 영역의 입력 수와 신호 품질을 함께 확인한다. 원래 뇌 신호와 작은 시각 모델을 기준으로 두고, 대형 모델이 필요하다는 근거가 있을 때 확장한다.

예측의 차이는 참가자와 독립 자극 묶음별로 보고한다. 수많은 영상 쌍이나 시간점을 서로 독립적인 참가자처럼 취급하지 않는다. Horikawa의 참가자 5명으로 얻은 결과는 개인별 탐색과 자극 범위 안의 검증으로 해석하고, 사람 전체에 대한 결론은 별도 자료에서 확인한다.

## 결과를 어디까지 설명하나

모델의 예측 향상은 입력 정보가 측정된 신경반응 또는 정서 평정을 설명하는 데 도움이 된다는 근거다. 그 모델과 같은 계산을 뇌가 실제로 수행한다거나, 특정 영역이 정서를 일으킨다는 인과 증거는 아니다.

자연 영상에서 함께 변하는 요인을 비교하는 분석과, 같은 장면의 요소를 바꿔 새로 측정하는 실험을 구분한다. 생성 모델로 만든 새 영상에는 새 인간 평정과 새 신경 측정이 필요하다.

예측 실패를 해석하기 전에는 입력 정보 자체를 읽을 수 있었는지, 비교할 정서 범위가 충분했는지 본다. 감도가 부족한 분석으로 신경 표현의 부재를 주장하지 않는다.
