# 장면이 달라져도 유지되는 정서의 뇌 패턴 찾기

PILOT02 · [RP03](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/bd56335c91f309620fd37ed2c30b2767c7f98e20/research/proposals/RP03.md) · NQ03

예를 들어 동물 영상에서 학습한 정서 패턴이 전혀 다른 종류의 장면에서도 통하는지 본다. 정서를 예측하는 모델이 특정 장면을 알아본 것인지, 내용이 바뀌어도 유지되는 뇌 패턴을 찾은 것인지 구별한다.

## 예상하는 차이

정서에 공통된 뇌 패턴이 있다면 영상의 내용이 달라져도 정서 예측이 유지될 것이다. 내용과 정서의 조합마다 다른 패턴이 필요하다면, 같은 내용 안에서는 예측하더라도 새로운 내용에서는 예측이 약해질 것이다.

## 첫 분석

1. PILOT01에서 만든 Horikawa 대응표를 활용한다. 사물·장소·행동 등 영상 내용으로 장면 묶음을 만든다. 정서 평정과 뇌 반응은 이 묶음을 만드는 데 사용하지 않는다. 서로 다른 묶음에 공통으로 충분한 정서 평정 범위가 있는지 확인한다.

2. 가능한 정서 항목 하나에 대해, 내용 A에서 학습하고 내용 B에서 평가하는 비교를 설계한다. 구체적인 내용 A와 B는 자료 분포를 본 뒤 결정한다. 특정 내용에만 존재하는 정서를 억지로 비교하지 않는다.

3. 시각피질과 연합피질에서 각각 뇌 활동으로 정서를 예측하는 작은 모델을 학습한다. 내용이 섞인 평가와 내용이 완전히 다른 평가를 같은 표본 수로 비교한다. 모델 선택은 평가할 내용 묶음을 보지 않고 마친다. 먼저 A내용에서 학습해 새 A내용에서 평가하고, B내용에서도 같은 비교를 한다. 각 내용 안에서 예측이 되는지 확인한 뒤 A에서 B로, B에서 A로 바꿔 평가한다.

4. 영상 특징만 쓰는 모델도 같은 방식으로 평가한다. 뇌 모델의 일반화가 영상 모델의 일반화와 얼마나 겹치는지 조사하고, 색·움직임·사물·장면 의미를 설명하는 특징을 보강해 결과가 유지되는지 본다.

5. 주된 결과는 새로운 내용에서의 예측 오차와 같은 내용에서의 예측 오차 차이다. 참가자별 결과와 내용 묶음별 결과를 모두 보고한다. 독립적인 표본이 아닌 수많은 영상 쌍을 참가자 수처럼 세지 않는다. 정서 평정이 비슷하지만 내용은 다른 영상의 뇌 패턴도 비교해, 예측 성공과 활동 패턴의 공통성이 함께 나타나는지 본다.

## 자료와 준비

우선 Horikawa에서 수행한다. Emo-FilM이나 Spacetop으로 넘어갈 때는 같은 정서 항목과 측정 단위가 있는지 별도로 확인한다. 데이터셋의 라벨 이름이 비슷하다는 이유로 바로 합치지 않는다.

- PILOT01의 자극·뇌·평정 대응표
- 정서 점수를 보지 않고 만든 영상 내용 분류
- 내용 묶음 사이에 겹치는 정서 범위와 충분한 표본

PILOT01의 영상 특징과 ROI를 재사용한다. 주된 추가 비용은 내용 묶음을 검토하고 학습·평가를 다시 나누는 작업이다. 대형 생성 모델이나 새 뇌 모델을 처음부터 학습할 필요가 없다.

## 남길 결과

실행 계획. 데이터 분석과 모델 학습은 아직 수행하지 않음.
