# 첫 분석에 필요한 자원

현재 환경에서 확인한 자원은 CPU 4개 할당과 RAM 32GiB다. GPU 추론이나 모델 가중치 로드는 아직 실행하지 않았다. 아래는 예산과 선택에 관한 계획이다.

| 작업 | 먼저 사용할 방법 | 필요한 것 |
|---|---|---|
| 장면 특징 추출 | CLIP ViT-B/32의 프레임 특징 또는 검증한 기존 캐시 | 영상 접근, 실제 특징 캐시 또는 특징 추출 자원 |
| 뇌에서 시각 특징 예측 | ridge regression | 자극과 연결된 뇌 반응, 학습·평가 분할 |
| emotion head | 작은 회귀 모델 | 실제 인간 정서 주석 |
| 뇌 패턴의 내용 간 일반화 | 같은 작은 모델을 다른 내용에서 평가 | 내용 분류와 겹치는 정서 범위 |
| 영화 맥락의 효과 | 현재 특징과 과거 특징을 비교하는 encoding model | 영화·뇌·주석 시간 대응, 미래를 보지 않은 맥락 특징 |

CLIP의 공식 코드와 checkpoint URL은 이전에 확인했다. 가중치 다운로드와 실제 실행은 별도 단계다. 코드의 MIT 라이선스 확인을 모든 가중치·자극의 사용 조건 확인으로 확대하지 않는다. [확인 기록](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/bd56335c91f309620fd37ed2c30b2767c7f98e20/research/pilots/model_evidence/manifest.json).

MindEye2는 뇌에서 시각 정보를 읽는 방법의 참고 사례다. NSD에서 학습한 모델을 Horikawa에 바로 적용할 수 있다고 가정하지 않는다. 첫 비교에는 작은 decoder를 사용하고, 실제 이득이 필요한 단계에서 참가자·자료 적응을 검토한다.

큰 영상 모델이 꼭 필요하면 먼저 소수 영상으로 처리 시간과 메모리를 측정한다. 현재 질문에 필요한 비교가 기존 특징과 작은 모델로 가능하면 그 결과를 먼저 확인한다. 원 사용자 데이터나 모델 가중치를 공개 GitHub에 업로드하는 작업은 이 계획에 포함하지 않는다.
