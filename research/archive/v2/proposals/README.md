# 정서를 처리하는 뇌에 관한 연구 제안

시각 정보, 장면의 맥락, 시간에 따른 변화가 뇌의 정서 표현과 어떻게 관계되는지 묻는다. 각 제안에서 먼저 과학적 질문과 경쟁하는 설명을 제시하고, 이를 구별할 AI 모델과 실험을 설명한다.

첫 분석 후보는 [RP01 시각과 정서가 공유하는 정보](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/bd56335c91f309620fd37ed2c30b2767c7f98e20/research/proposals/RP01.md), [RP03 내용이 바뀌어도 유지되는 정서 패턴](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/bd56335c91f309620fd37ed2c30b2767c7f98e20/research/proposals/RP03.md), [RP05 장면의 맥락](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/bd56335c91f309620fd37ed2c30b2767c7f98e20/research/proposals/RP05.md)이다.
