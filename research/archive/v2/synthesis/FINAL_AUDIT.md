# v2 기획의 검토 결과

새 제안 10개와 파일럿 계획 3개의 질문·경쟁 설명·예상 결과를 검토했다. 검토한 원고에서 추가로 수정해야 할 중대한 논리 오류는 발견하지 못했다. 이는 문서 검토 결과이며, 신규성이나 실제 데이터로 가설을 검증했다는 뜻은 아니다.

초기 파일럿 검토에서 나온 다섯 항목을 반영했다.

- 첫 파일럿의 제목을 뇌에 관한 질문으로 바꾸고, decoder의 실패와 뇌 정보의 부재를 구별했다.
- 내용이 바뀐 평가에 앞서 각 내용 안에서는 정서를 예측할 수 있는지 확인하도록 했다.
- 현재 사건과 과거 사건을 같은 수준으로 설명해, 더 풍부한 의미 특징의 효과를 과거 맥락의 효과로 오인하지 않도록 했다.
- 사건 변화는 비슷하지만 정서 평정 변화가 다른 구간을 비교하도록 했다.
- 추가 효과가 작다는 결과와 모델 전체가 실패해 판단하지 못하는 결과를 나눴다.

RP01과 RP03은 각각 시각 표현에 담긴 정보의 충분성과 내용 사이의 뇌 패턴 공통성을 묻는다. RP05·RP06·RP07은 현재 장면의 맥락적 해석, 앞선 정서의 영향, 사건의 예상 가능성을 다룬다. 실제 영화에서 이 요인을 나눌 수 없다면 같은 결과를 별개의 발견으로 세지 않는다.

RP03은 공통·자극별 정서표상 연구와 가깝고, RP09는 기존 분산 정서표상 연구와의 차이가 아직 약하다. 제안서와 우선순위에 이 점을 남겼다. 단순한 모델 교체나 정확도 향상을 새로운 신경과학 발견으로 제시하지 않는다.
