# Mind Captioning — 보유 확인, 명세 확인 전

2026-11-12 사용자가 보유를 명시했다. 현재 기록의 이름만으로 특정 논문·공개 릴리스·참가자 수·측정 방식·캡션 종류·정서 주석·기억/심상 태스크를 확정하지 않는다.

Axis 진행 상태: 가능. [조건부 연결 MC-1~4](https://github.com/SeokJin-Moon14/affective_neuroscience_exploratory/blob/75df2e876de57cd139e1bb0c22a58ae81312a217/research/datasets/ownership_and_readiness.md)를 등록했다. 정확한 버전·파일 접근·필드는 실제 분석에 필요한 단계에서 확인한다. 원본 데이터의 재다운로드는 요구하지 않는다.

검증된 내용: 사용자 보유 진술. 미확인: 공식 식별자, 버전, 스키마, 실제 데이터 값. 이 파일의 이름은 공통 디렉터리 규약을 따른 것이며 전체 데이터 명세가 검증되었다는 뜻이 아니다.
