# Axis Encyclopedia v1

통합일: 2026-11-12. **A–X 24개 상위축, 36개 출처 추적 가능한 하위축, 8개 탐색 묶음**이다. 12개 역할의 원본 제안을 모두 수록했다. 서로 다른 판별 질문을 유지하고, 겹치는 방법은 묶음·교차연결로 관리한다.

36개는 원본 제안 등록 수이며 고유 RQ 수가 아니다. AS05·AS13은 공통 중복군 DG05로 묶고 피험자 정렬과 일반 변환이라는 세부 비교를 보존했다. 이후 동일 조작·표적·반증이면 하나의 RQ로 집계한다.

사용자는 Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop 보유를 확인했다. 데이터 상세 검증은 Axis 진행을 막지 않는다. 이 문서는 연구 가설 지도이며 분석 결과·신규성 확정·최종 제안이 아니다. 기존 문헌 근거를 통합했으며 이번 단계에서 새 원문을 확인하거나 신경 분석을 실행하지 않았다.

`last_verified`는 원 제안의 기록일이고 `review_date`는 이번 통합 검토일이다. 스키마·실험 검증 날짜를 뜻하지 않는다. 하위축 가설은 E3이며 인용 문헌의 서지·본문·코드 확인 범위는 각각 다르다.

### AS01. 내용 환경을 넘는 정서 차원

자극내용 변화와 측정불확실성을 넘어 유지되는 정서관련 신경 차원

- **연결:** A × F × K × Q × S; F04. 유형: Construct / Stimulus; Neural; Structure / Dynamics; Inference / Measurement.
- **질문:** 고차원 구조가 객체/장면 하위군에 불변인가
- **경쟁 설명:** 환경을 넘는 정서 차원 vs 객체·장면 구성비
- **기각·축소 관측:** 내용군 보류에서 효과가 사라지고 신뢰도 보정으로도 회복되지 않으면 보편 차원 주장을 축소한다.
- **필수 대조:** 내용군별 분할; 평정 신뢰도; 저수준·의미 기준모형
- **모델·방법:** 공식 Horikawa 선형기준; 조건부 kernel 비교; CLIP
- **전이 기회:** 분포 밖 일반화; 계층 측정오차
- **보유 데이터 경로·분석 조건:** Horikawa: 실제 주석·내용 ID 대응. Emo-FilM: 영화 단위 외적 평가.

### AS02. 현재 내용과 이력 의존 정서 코드

동일 현재내용에 대한 신경 예측이 선행이력에 의해 달라지는 구조

- **연결:** A × C × D × H × V; F02. 유형: Construct / Stimulus; Neural; Model / Method; Structure / Dynamics; Inference / Measurement.
- **질문:** 프레임 설명과 맥락 상태를 구별할 수 있는가
- **경쟁 설명:** 이력 의존 신경 상태 vs 현재 자극 설명
- **기각·축소 관측:** 입력 정보량·HRF를 맞추면 이력 이득이 사라지는 경우 지속 상태 필요성은 지지되지 않는다.
- **필수 대조:** 동일 현재 입력; 문맥 길이 일치; HRF 계열; run 경계
- **모델·방법:** EmoNet; V-JEPA2/2.1; 미래 입력 차단 encoder 비교
- **전이 기회:** 잠재 미래예측; 능동 모델구별
- **보유 데이터 경로·분석 조건:** Emo-FilM 연속 자극·BOLD·주석 정렬. Horikawa는 이용 가능한 시간 단위에 맞춤.
- **근거:** [P008 Emotion schemas are embedded in the human visual system](https://raw.githubusercontent.com/canlab/Neuroimaging_Pattern_Masks/master/Multivariate_signature_patterns/2019_Kragel_Emotion_Schemas/Kragel_2019_SciAdv_emotion_schemas.pdf); [P013 V-JEPA 2: Self-Supervised Video Models Enable Understanding, Prediction and Planning](https://raw.githubusercontent.com/facebookresearch/vjepa2/main/README.md); [P014 V-JEPA 2.1: Unlocking Dense Features in Video Self-Supervised Learning](https://raw.githubusercontent.com/facebookresearch/vjepa2/main/README.md)

### AS03. 분산 정서 코드의 결합과 중복

영역들이 공유하는 예측정보와 공동관찰로 얻는 추가정보를 구별

- **연결:** A × E × F × K × X; F03. 유형: Construct / Stimulus; Neural; Structure / Dynamics; Inference / Measurement.
- **질문:** 분산성은 중복인가 새로운 결합인가
- **경쟁 설명:** 영역 간 정보 결합 vs 중복·가산 정보
- **기각·축소 관측:** 복잡도를 맞춘 가산 모델이 joint 모델과 같으면 결합 계산의 필요성은 약해진다.
- **필수 대조:** ROI 선택 독립성; nonlinear additive; 신뢰도·복잡도 일치
- **모델·방법:** PINES; MPA2; 용량맞춤 결합모델; 정보분해 추정기는 후속검증
- **전이 기회:** 결측센서 강건성; 조건부 정보분해
- **보유 데이터 경로·분석 조건:** Horikawa 시행별 신경값·주석·ROI. 정보이론적 synergy는 별도 추정 정의 필요.
- **근거:** [P005 A Sensitive and Specific Neural Signature for Picture-Induced Negative Affect](https://raw.githubusercontent.com/canlab/Neuroimaging_Pattern_Masks/master/Multivariate_signature_patterns/2015_Chang_PLoSBiology_PINES/Chang_2015_PLoSBiol_PINES.pdf); [P009 Common and stimulus-type-specific brain representations of negative affect](https://raw.githubusercontent.com/canlab/Neuroimaging_Pattern_Masks/master/Multivariate_signature_patterns/2021_Ceko_MPA2_multiaversive/Ceko_2022_NatNeurosci_MPA2_negative_affect.pdf); [P010 A Bayesian Model of Category-Specific Emotional Brain Responses](https://raw.githubusercontent.com/canlab/Neuroimaging_Pattern_Masks/master/CANlab_Meta_analysis_maps/2015_Wager_Kang_etal_Emotion_Meta_BSPP/Wager_2015_PlosCompBiology.PDF)

### AS04. 생성 prior와 신경정보의 기여 분리

생성 전 latent·prior 출력·생성 후 영상에서 뇌 조건의 추가 정보를 각각 검증

- **연결:** G × I × L × X × T; F05. 유형: Model / Method; Neural; Inference / Measurement; Construct / Stimulus.
- **질문:** 정서 관련 내용이 신경 조건의 정보인가 생성 prior의 보충인가?
- **경쟁 설명:** 뇌 조건이 제공한 정보 vs 생성 prior가 채운 정보
- **기각·축소 관측:** 뇌 조건을 교환하거나 제거해도 평가가 같으면 해당 정서 내용의 신경 근거를 주장하지 않는다.
- **필수 대조:** 생성 전 latent; prior-only; 조건 교환; 생성기 교체
- **모델·방법:** MindEye2; MindEye; Brain-Diffuser; ridge latent decoding
- **전이 기회:** hard-negative retrieval; 조건 교환; latent와 출력 이중 평가
- **보유 데이터 경로·분석 조건:** Horikawa 자극–신경–주석 정렬. NSD는 시각 대조; 측정 정서 주석은 별도 확인.
- **근거:** [P015 MindEye2: Shared-Subject Models Enable fMRI-To-Image With 1 Hour of Data](https://github.com/MedARC-AI/MindEyeV2); [P016 Reconstructing the Mind's Eye: fMRI-to-Image with Contrastive Learning and Diffusion Priors](https://github.com/MedARC-AI/fMRI-reconstruction-NSD); [P019 High-resolution image reconstruction with latent diffusion models from human brain activity](https://github.com/yu-takagi/StableDiffusionReconstruction); [P021 Brain-Diffuser: Natural scene reconstruction from fMRI signals using generative latent diffusion](https://github.com/ozcelikfu/brain-diffuser)
- **추적:** [03_vision_decoding / G/X-VD1](../agents/03_vision_decoding/subaxes.csv); 원 제안 2026-11-12, 통합 2026-11-12. 가설 E3; 역할: 경쟁 계산·표상 가설; 중복군: DG04.

### AS05. 정렬 과정의 정서 관련 정보 보존

공유 시각 latent 정렬이 유지하는 정보와 버리는 반복 가능한 신경 잔차를 분리

- **연결:** F × G × O × X × Q; F01. 유형: Neural; Structure / Dynamics; Inference / Measurement; Construct / Stimulus.
- **질문:** 영상 검색이 유지되는 동안 정서 관련 신경정보는 소실될 수 있는가?
- **경쟁 설명:** 공유 latent의 충분성 vs 정렬이 지운 개인 신경정보
- **기각·축소 관측:** 잔차가 독립 반복에 재현되지 않거나 조건부 표적을 설명하지 못하면 정보 소실 주장을 축소한다.
- **필수 대조:** 정렬 전후 정보; 자극·피험자 보류; 반복 신뢰도
- **모델·방법:** MindEye2; Brain-IT; MinD-Vis; MindBridge
- **전이 기회:** domain adaptation; masked 대 contrastive 학습; cycle consistency 감사

- **질문:** ID가 다른 자극의 내용 중복을 제거하면 정서 관련 신경정보의 일반화는 유지되는가?
- **경쟁 설명:** 새 내용에 대한 일반화 vs ID만 다른 반복 내용
- **기각·축소 관측:** 중복 내용 그룹 분할에서 이득이 사라지면 내용 일반화 주장을 기각한다.
- **필수 대조:** 파일 해시+지각 중복; content-group split; provenance
- **모델·방법:** perceptual fingerprint; group CV
- **전이 기회:** 데이터 중복 감사와 의미적 그룹 분할
- **보유 데이터 경로·분석 조건:** Horikawa 영상·ID·dupidx 우선; NSD 자극 ID; 다른 자료는 사용 단위별 적용.
- **근거:** [P001 The neural representation of visually evoked emotion is high-dimensional, categorical, and distributed across transmodal brain regions](https://raw.githubusercontent.com/OpenNeuroDatasets/ds002425/3f94b2bf9a75ddb62637c529d30dc40dd4ab5ba1/dataset_description.json)
- **추적:** [01_dataset / P-A01](../agents/01_dataset/round1_independent_report.md); 원 제안 2026-11-12, 통합 2026-11-12. 가설 E3; 역할: 측정·평가 조건; 중복군: DG31.

### AS32. 시간 좌표와 관측지연

영화 시간의 주석과 clip 평정 구간을 관측 단위로 구별하고 scanner onset·HRF에 정렬한다.

- **연결:** D × H × Q × X; F07. 유형: Neural; Structure / Dynamics; Inference / Measurement.
- **질문:** 주석 집계와 관측지연을 분리한 뒤에도 신경적 시간 통합의 설명이 필요한가?
- **경쟁 설명:** 신경 통합 지연 vs 주석 집계·scanner·HRF 정렬
- **기각·축소 관측:** 관측 시계 정정만으로 장기 통합 이득이 사라지면 신경 시간상수 주장을 축소한다.
- **필수 대조:** 영화시간–scanner onset; 관측 단위; HRF; clip 경계
- **모델·방법:** 상태공간 관측모형; FIR/HRF
- **전이 기회:** 시계열 관측모형과 타임베이스 감사
- **보유 데이터 경로·분석 조건:** Emo-FilM 주석과 clip 검증은 같은 영화 시간의 다른 단위; scanner onset은 별도 대응.
- **근거:** [P002 Emo-FilM: A multimodal dataset for affective neuroscience using naturalistic stimuli](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004892/cdf68fe448ad180a476fa2371473a1a6ed063774/dataset_description.json)

### AS33. 주석 불확실성과 공유 표상

평정자·타깃·척도 차이를 측정모형으로 분리하여 자료 간 공유 표상 주장의 범위를 정한다.

- **연결:** A × O × Q × S × X; F04. 유형: Construct / Stimulus; Model / Method; Inference / Measurement.
- **질문:** 공유 요인의 차이가 신경표상 차이인가 평정자·척도의 차이인가?
- **경쟁 설명:** 자료 간 공유 표상 vs 평정 척도·주체 차이
- **기각·축소 관측:** 공통 anchor에서 측정 불변성이 실패하면 직접적인 표상 크기 비교를 보류한다.
- **필수 대조:** 평정자·타깃·척도 명시; hierarchical error; 공동 anchor
- **모델·방법:** 계층 측정모형; measurement invariance

- **보유 데이터 경로·분석 조건:** Emo-FilM/Spacetop 평정 자료 우선. 다섯 보유본 공통 척도 존재는 가정하지 않음.
- **근거:** [P002 Emo-FilM: A multimodal dataset for affective neuroscience using naturalistic stimuli](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004892/cdf68fe448ad180a476fa2371473a1a6ed063774/dataset_description.json); [P003 A massive multimodal fMRI dataset unifying naturalistic processes with a rich array of experimental tasks](https://raw.githubusercontent.com/spatialtopology/ds005256/a90932e8eb31036b89eeb4488ba1ef705baad2a2/dataset_description.json)

### AS34. 공유 통로의 충분성과 고유정보의 필요성

동일 자극의 공유 성분과 뇌 예측에 추가로 필요한 모달리티 고유 성분을 구별한다.

- **연결:** B × H × J × M × X; F03. 유형: Model / Method; Structure / Dynamics; Inference / Measurement; Neural.
- **질문:** 공통 잠재만으로 충분한가, 공유·고유 정보의 결합이 필요한가?
- **경쟁 설명:** 공유 통로의 충분성 vs 모달리티 고유 정보 필요성
- **기각·축소 관측:** 강한 가산 모델이 joint 모델과 같으면 상호작용 필요성을 축소한다.
- **필수 대조:** 동일 용량 nonlinear additive; 공통원인 null; 합성 양성대조
- **모델·방법:** ImageBind; CAV-MAE; FactorCL; MBT
- **전이 기회:** 멀티뷰 분해와 정보 교환량 제약
- **보유 데이터 경로·분석 조건:** Emo-FilM 또는 Horikawa 실제 영상·음악/환경음 존재 확인. 음성 특징을 연구 축으로 확장하지 않음.

### AS35. 관찰 가능한 과거와 잠재 예측오류

입력 가용시간을 제한한 상태와 예측 잔차를 신경 전이에 비교한다.

- **연결:** C × D × J × M × V; F02. 유형: Structure / Dynamics; Model / Method; Inference / Measurement; Neural.
- **질문:** 장기 문맥 이득은 과거 상태의 필요성인가 미래 입력의 유출인가?
- **경쟁 설명:** 과거 상태의 예측력 vs 미래 프레임·bidirectional 정보
- **기각·축소 관측:** 미래 접근을 차단하면 효과가 사라질 때 과거 예측 상태 주장을 철회한다.
- **필수 대조:** 원 입력 t에서 절단; bidirectional 경로 검사; reset 대조
- **모델·방법:** VideoMamba; V-JEPA2; VideoPrism

- **보유 데이터 경로·분석 조건:** Emo-FilM 연속 자료. 모델명만으로 causal 입력을 가정하지 않음; Spacetop 시간 정서 주석은 추가 조건.
- **근거:** [P043 VideoMamba: State Space Model for Efficient Video Understanding](https://github.com/OpenGVLab/VideoMamba); [P013 V-JEPA 2: Self-Supervised Video Models Enable Understanding, Prediction and Planning](https://raw.githubusercontent.com/facebookresearch/vjepa2/main/README.md); [P044 VideoPrism: A Foundational Visual Encoder for Video Understanding](https://github.com/google-deepmind/videoprism)

### AS36. 사건 단계와 경과시간의 분리

사건 진행 좌표를 시계시간·편집 리듬과 경쟁시키는 정렬을 평가한다.

- **연결:** C × D × K × M × V; F02. 유형: Construct / Stimulus; Structure / Dynamics; Model / Method; Inference / Measurement.
- **질문:** 신경 전이는 사건 단계에 정렬되는가 단순 경과시간에 정렬되는가?
- **경쟁 설명:** 사건 진행 좌표 vs 경과시간·편집 리듬
- **기각·축소 관측:** position-only 또는 DTW가 같거나, 타깃을 이용한 정렬에만 의존하거나 비신경 감독 정렬의 효과가 보류 사건에 일반화하지 않으면 사건 단계 계산 주장을 축소한다.
- **필수 대조:** 정서·신경 타깃 없는 정렬; position-only; DTW; 보류 사건
- **모델·방법:** AVE; TCC; VideoPrism
- **전이 기회:** 비신경 감독 사건 정렬과 시간왜곡 통제
- **보유 데이터 경로·분석 조건:** Emo-FilM 사건 경계·다양성 확인. Mind Captioning은 사건 순서/주석 존재 확인 시에만 연결. Mind Captioning의 텍스트 출처를 구분하며, 같은 신경반응으로 생성한 캡션을 독립 입력으로 되넣지 않음.
- **근거:** [P041 Audio-Visual Event Localization in Unconstrained Videos](https://github.com/YapengTian/AVE-ECCV18); [P042 Temporal Cycle-Consistency Learning](https://github.com/google-research/google-research/tree/master/tcc); [P044 VideoPrism: A Foundational Visual Encoder for Video Understanding](https://github.com/google-deepmind/videoprism)
- **추적:** [05_multimodal_dynamics / C-D-05c](../agents/05_multimodal_dynamics/report.md); 원 제안 2026-11-12, 통합 2026-11-12. 가설 E3; 역할: 경쟁 계산·표상 가설; 중복군: DG36.
