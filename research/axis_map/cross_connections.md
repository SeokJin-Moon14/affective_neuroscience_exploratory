# 핵심 교차연결 8개

2026-11-12 실제 Axis 검토를 바탕으로 Coordinator가 선택한 수동 문헌 연결이다. 실제 무작위 조합 30개와 구별하며 그 목표에 포함하지 않는다. 최종 고유 RQ로 확정한 목록도 아니다. 충분한 신뢰도·검정력에서 경쟁 예측을 평가한다.

유형은 현상·자극, 신경, 모델·방법, 구조·동역학, 추론·측정이다. 유형 수 자체를 과학적 우선순위로 사용하지 않는다.

- **유형:** Construct / Stimulus; Neural; Model / Method; Structure / Dynamics; Inference / Measurement
- **경쟁 설명:** 공통 잠재가 충분함 / 정렬·압축이 신뢰 가능한 정보를 제거함 / 차원·용량·잡음 효과
- **판별 관측:** rank·readout·평가 예산을 맞춘 뒤 정렬 성능은 늘고 독립 정서 대비는 줄어드는지 평가한다. 신뢰도·내용 통제로 감소가 소실되면 선택적 손실 설명을 축소한다.
- **보유 데이터 경로:** Horikawa 주석–자극–뇌 대응 우선; NSD는 시각 정렬 대조; Mind Captioning은 실제 텍스트–자극–신경 대응과 출처가 있을 때 언어 병목 가지.

- **유형:** Construct / Stimulus; Neural; Model / Method; Structure / Dynamics; Inference / Measurement
- **경쟁 설명:** 독립 기여의 합으로 충분함 / 고유 경로·비가산 결합 필요 / 공통원인·용량·잡음 평균화

## CC04. 거리구조 정렬이 정서 의미를 운반하는 조건

- **연결:** [AS15](AXIS_ENCYCLOPEDIA.md#as15), [AS33](AXIS_ENCYCLOPEDIA.md#as33), [AS01](AXIS_ENCYCLOPEDIA.md#as01), [AS29](AXIS_ENCYCLOPEDIA.md#as29), [AS28](AXIS_ENCYCLOPEDIA.md#as28)
- **유형:** Construct / Stimulus; Neural; Model / Method; Structure / Dynamics; Inference / Measurement
- **경쟁 설명:** 공통 정서 관계구조 / 시각·의미 대응만 유지 / 대칭에 따른 비유일성 / 측정 척도 차이
- **판별 관측:** 근접 최적 수송 결합들을 정렬에 쓰지 않은 anchor로 평가한다. 동등 비용의 결합이 반대 정서 대응을 만들거나 측정 불변성이 실패하면 공통 정서 코드 해석을 보류한다.
- **보유 데이터 경로:** Horikawa–Emo-FilM–Spacetop은 관측 단위를 따로 모델링. NSD는 시각 참조. Mind Captioning은 스키마 확인 뒤 독립 의미 노드. 공통 anchor가 없으면 추가 평정 조건.
- **출처 추적:** Agent07 C4; Agent10 MC-4. 인용별 원문·문서 범위는 연결된 하위축과 [출처 목록](reference_catalog.csv)에 기록.

- **유형:** Construct / Stimulus; Neural; Model / Method; Structure / Dynamics; Inference / Measurement
- **경쟁 설명:** 뇌 관측이 특징을 제한함 / prior가 관측 등가 후보를 선택 / 정렬이 잃은 정보를 prior가 보충
- **판별 관측:** 생성 전 latent·prior-only·뇌 조건 교환·다중 prior를 독립 참조에 평가한다. 신경 적합도가 같은 후보 사이 특징이 달라지면 단일 출력의 식별 주장을 축소한다. 조건 교환의 OOD도 통제한다.
- **보유 데이터 경로:** NSD의 시각 관측 대조와 Horikawa의 측정 정서 대비를 구별. Mind Captioning이 실제 신경 조건 생성 태스크라면 텍스트 출력의 별도 평가. 새 편집 자극의 뇌효과는 새 측정 필요.

- **판별 관측:** 인간 설명·자극 기반 AI 설명·신경 조건 출력의 출처를 나눈다. 같은 Y로 만든 캡션을 독립 encoding 입력으로 사용하지 않는다. 개념 확장과 독립 반복/외부 참조 평가로 순환 없이 남는 대비를 확인한다.

- **판별 관측:** 동일 입력·용량에서 오차/상태, gate/expert, 계산 제약을 별도 요인으로 비교하고 합성 관측 회복을 검사한다. 집계 후 차이가 없으면 해당 측정의 식별 한계로 보고한다. 생물학적 기전 자체를 반박했다고 해석하지 않는다.
- **보유 데이터 경로:** Horikawa 자극 단위와 Emo-FilM 연속 자료에 맞는 관측모형; NSD 시각 대조 가능. spike timing·학습규칙의 직접 판별은 추가 측정 조건.
