# Axis 통합 판정과 검토 이력

2026-11-12. Coordinator가 12역할의 36개 원 제안을 등록하고, Agent07·10·12에게 실제 교차 검토를 요청하여 결과를 반영했다. 이는 Stage3 통합 검토다. 토론 Round2–5, 최종 RQ 확정, 새 데이터 분석은 아직 수행하지 않았다.

## 근거와 참조 감사

36개 제안이 사용하는 출처는 **94개**다. 이 중 통합 서지·출처 확인 목록에 속하는 문헌 86개, 서지 보류 4개, 논문 수에 포함하지 않는 공식 코드·문서 4개다. 이는 새로 확인한 문헌 수가 아니다. 전체 연구 문헌 집계는 고유103편 중 엄격 서지확인100편·보류3편으로 유지된다. 네 번째 보류 출처 `A12-P02`는 그 103편 밖에 있던 Agent12의 보조 코드·문헌 후보다.

| 출처 | 처리 |
|---|---|
| P003 / A01-SPACETOP2024 | 공식 metadata는 사용하되 저자 표기 충돌은 보류. 데이터 보유와 서지 보류를 구별. |
| P058 / G07-P08 | PID 코드·문서와 완전 서지 상태를 구별. 정확한 neural synergy의 검증 근거로 승격하지 않음. |
| P091 / BI03 | e-prop 구현의 존재와 최종 출판연도 검증을 구별. |
| PENDING-A12-P02 | Agent12 pending_papers.csv에 연결하여 끊어진 참조 해결. 고유103편·확정100편에 새로 더하지 않음. |
| DOC-SAE·DOC-TRANSCODER·DOC-CIRCUIT·DOC-DOMAINBED | 공식 문서 전용 ID로 등록. 논문 본문 검증이라고 표시하지 않음. |

기계 판독본의 `verified_bibliography_refs`, `pending_bibliography_refs`, `supporting_document_refs`로 상태를 분리했다. `representative_papers`는 기존 필드 호환을 위한 전체 근거 ID 목록이다. `reference_catalog.csv`에서 실제 근거 종류와 열람 범위를 확인한다.

Agent05 보고서의 축약 P01–P04 등을 MD05-P01…04로 확장했다. 문자열/배열 혼용과 태그 공백을 정규화했다. 원본 30개 JSON은 수정하지 않고 추가6개를 포함한 `source_proposals.json`, 원본↔통합 ID 대응표를 별도로 생성했다. Agent01 Q-A01은 기존 사실검사에 맞춰 영화 시간의 다른 관측 단위와 scanner onset을 구별하도록 서술을 교정했다.

## 검증 범위

`scripts/build_axis_registry.py` 실행으로 36개 고유 등록 ID, 12역할, 필수12필드, A–X 참조, 다중 유형 태그, 원본 경로와 모든 문헌 ID 대응을 검사했다. 교차연결과 문서 링크도 별도 구조 검사했다. 충분한 검정력·신뢰도 없이 비유의성을 정보 부재로 해석하지 않는 공통 조건을 넣었다.

데이터 보유는 사용자 진술로 확인했다. 이 단계는 데이터 본체를 다시 받거나 모델을 학습하는 단계가 아니다. 원문 추가 확인·스키마 확인·모델 실행·신규성 역검색은 완료했다고 주장하지 않는다.
