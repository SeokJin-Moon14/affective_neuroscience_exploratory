# 보유 데이터와 Axis 연결

2026-11-12 최신 사용자 진술: **Horikawa, Emo-FilM, Mind Captioning, NSD, Spacetop을 이미 보유**한다. 데이터 확보를 다시 요청하지 않고 Axis를 진행한다. 보유 사실, 현재 클라우드 파일 접근, 정확한 버전·스키마 검증은 서로 다른 상태다.

| 데이터 | 사용자 보유 | 현재 근거 | 지금 등록한 연구 경로 | 실제 분석 시 확인할 조건 |
|---|---|---|---|---|
| Horikawa | 확인 | 기존 공식 metadata·코드·305개 이벤트 감사 | 내용 일반화, 정서·의미 분해, 정렬의 정보 보존, ROI 결합, 생성 prior | 보유본의 주석·feature와 stim_index 대응, 내용 중복 단위, 처리 공간, 반복·신뢰도 |
| Emo-FilM | 확인 | 공식 metadata·코드·주석 구조 확인; 숫자 주석 실물 미감사 | 과거 상태·사건 순서·통합시간, 멀티모달 공유/고유 정보 | 영화시간–scanner onset–HRF, 외부 consensus의 관측 단위, 실제 자극 스트림 |
| Mind Captioning | 확인 | 사용자 진술; 정확한 식별자·버전·스키마는 미확인 | 언어 압축, 개념 누락, 생성 정보의 출처, 조건부 시간 문맥 | 자극·텍스트·신경 관측의 실제 대응, 텍스트 생성 주체, 순서 정보, 독립 정서 주석 존재 여부 |
| NSD | 확인 | 공식 코드·서지 근거; 데이터 실물 미감사 | 시각 표상·정렬·생성 복원의 대조, 언어/시각 병목 비교 | 보유본의 반복·ID·신경처리 공간. 측정 정서 ground truth는 현재 확인 근거 없음 |
| Spacetop | 확인 | 공식 metadata·일부 이벤트·평정 단위 확인 | 클립 단위 정서 대비, 데이터 간 측정·의미 정렬 | 유효 분석 cohort·결측, 사용 태스크와 평정 연결. 확인된 clip 후 평정은 영상 내부 연속 주석을 대신하지 않음 |

위 조건은 **해당 분석을 착수할 때의 요구사항**이다. Axis, 문헌 기반 연결, 후보 질문 작성의 차단 조건이 아니다. 이번 단계에서는 사용자 보유 원본 데이터나 개인 자료를 GitHub에 새로 업로드하지 않았다.

## Mind Captioning 연결 분기

| 분기 | 연결 | 존재하면 사용할 관측 | 없을 때의 범위 |
|---|---|---|---|
| MC-1 언어 압축·생성 prior | AS22·AS07·AS04 | 신경–자극–텍스트 쌍 및 텍스트 출처 | 신경 대응이 없으면 방법 비교; 생성 태스크가 아니면 prior 대조 제외 |
| MC-2 개념 누락·잔차 | AS24·AS15·AS33 | 자극의 객체·관계·사건 설명과 독립 신경 타깃 | 독립 정서 주석 없으면 의미 분석 범위; AI 캡션을 정서 정답으로 바꾸지 않음 |
| MC-3 순서·과거 문맥 | AS23·AS35·AS36·AS32 | 실제 자극 순서·시점 대응·관찰 가능한 과거 | 독립 정지 시행이면 시간 궤적으로 확장하지 않음 |
| MC-4 자료 간 의미·측정 | AS12·AS01·AS31·AS33 | 독립 ID·내용·설명 및 측정 단위 | 공통 자극·참가자·정서 ontology를 가정하지 않음 |

동일 신경반응에서 생성한 텍스트를 독립 설명변수로 다시 그 신경반응에 넣으면 순환이다. 디코딩 출력으로 외부 참조에 평가하거나, 독립 자료·반복의 대응을 사용해야 한다. 자극 기반 AI 설명·인간 설명·신경 조건 생성 텍스트는 구별한다.

Mind Captioning이라는 이름만으로 기억·심상 조건이 있다고 판단하지 않는다. 실제 과제에 그런 조건이 확인되면 U축의 별도 경로를 확장할 수 있다.
