# 먼저, 어떤 결과를 보고 싶은가

사용자는 v4의 세 방향을 좋은 주제로 선택하지 않았다. 범주 경계 질문은 매력이 없다고 평가했고, 일반화·세밀한 구별 질문은 EmoBrain과 겹치는 것 같다고 지적했다. 심상 질문도 입증이 어렵고 임팩트가 약하지만, **정서와 관련된 시각 정보가 지각에서 심상으로 어떻게 남는지**는 상대적으로 낫다고 했다. 이를 최종 주제 선택으로 해석하지 않는다.

이번 목록은 새 RQ 심사를 통과한 제안서가 아니다. 무엇을 발견하거나 만들어 보고 싶은지 확인하기 위한 출발점이다. 원안 수를 늘리거나 세 질문을 다시 선정하지 않았다. 초기 미션의 모델 목록은 탐색할 예시이며, 각각을 사용자의 선호로 간주하지 않는다.

## A. 지각과 심상에서 읽히는 시각 단서를 나란히 보여주기

같은 영상에 대해 실제 영상, 볼 때의 뇌 반응에서 읽은 시각 특징, 떠올릴 때의 뇌 반응에서 읽은 특징을 비교한다. 정서 점수 하나를 맞히는 데서 그치지 않고, emotion head가 어떤 형태·움직임·장면 단서를 이용하며 그 단서가 심상에서도 읽히는지 보여주는 방향이다.

보고 싶은 결과는 시각 특징마다 다른 변화가 나타나는 것이다. 예를 들어 배경에 관한 특징과 정서 판단에 쓰이는 특징이 같은 비율로 약해지지 않을 수 있다. 이는 설명용 예상이며 특정 특징이나 효과가 실제 자료에서 확인됐다는 뜻은 아니다. 생성 이미지의 그럴듯함을 심상 내용의 정답으로 삼지 않는다.

MC의 기존 지각·심상 반응과 Horikawa 원영상의 기존 정서 주석을 사용한다. 현재 알려진 최대71개 시험영상, cue·후속 실제영상과의 분리, 특징을 실제로 해석할 수 있는지가 장애물이다. 사용자가 상대적으로 낫다고 한 방향을 구체화한 것이며, v4와 다른 새 연구라고 세지 않는다. P008과 MC2025 이후 무엇을 더 밝힐 수 있는지는 별도 검토가 필요하다.

## B. 뇌에서 배운 것이 AI의 정서 판단을 바꾸게 만들기

한 AI는 영상과 정서 평정으로 학습하고, 다른 AI는 같은 자료에 사람의 뇌 반응을 추가로 배운다. 학습이 끝난 뒤에는 둘 다 영상만 본다. 뇌가 학습을 도와주는 방향이다.

보고 싶은 결과는 평균 정확도가 조금 오르는 것보다 구체적이다. 일반 AI가 특정 물체나 배경에 기대어 틀리는 새 장면에서, 뇌를 함께 배운 AI가 다른 시각 단서를 이용해 오류를 고치는 모습을 보고 싶다. 이런 오류와 변화가 실제로 있어야 하며, 단순한 보조 학습 효과와도 구별해야 한다.

Horikawa의 기존 영상·fMRI·정서 평정으로 설계할 수 있다. 성공한다면 신경 관측을 정서 AI의 학습에 활용하는 방법론 기여가 된다. 다만 사용자가 언급한 Brain-Aligned Multimodal LLMs와 가까운 방향이다. 뇌 정렬을 추가했다는 사실만으로 새롭다고 하지 않으며, 이 취향이 맞으면 해당 선행과 가장 먼저 대조한다.

## C. 시각 뇌 디코더에 여러 정서 판독 기능을 나중에 붙이기

뇌 디코더는 시각 특징만 복원하도록 학습한다. emotion head는 뇌 자료 없이 별도의 영상과 기존 인간 정서 평정으로 학습한다. 두 부분을 연결해 정서 항목을 바꿀 때마다 뇌 디코더를 다시 학습하지 않는 도구를 만든다. 정서 정답을 어디에도 쓰지 않는다는 뜻은 아니다.

보고 싶은 결과는 서로 겹치지 않는 자료로 배운 두 기능이 실제로 연결되고, 고정된 뇌 디코더에 여러 정서 목표를 추가할 수 있는 모습이다. 정서별 뇌 학습을 반복하는 방식에 비해 무엇을 얻고 어떤 목표는 읽히지 않는지 함께 평가한다.

Horikawa를 뇌–시각 특징 학습, 별도 영상–정서 head 학습, 최종 평가로 나누어 기본 검정을 할 수 있다. NSD는 시각 사전학습의 선택적 자료이며 정서 정답이 있다고 가정하지 않는다. MindEye 계열과 시각 정서 모델의 단순 연결만으로는 신규성이 약할 수 있다. 사용자가 처음 예로 든 visual decoder + emotion head를 재사용 가능한 방법으로 발전시키는 것이 흥미로운지 확인하는 선택지다.

## D. 영화의 정서 흐름과 뇌 활동의 구간을 함께 보여주기

영화 타임라인에 컷·내용 변화, 기존 정서 평정, 뇌 활동이 전환되는 구간을 겹쳐 놓는다. 보고 싶은 것은 컷이 바뀌어도 뇌 상태가 이어지는 경우와, 같은 장면 안에서 정서가 바뀌는 부근에 뇌 상태도 전환되는 경우다. 이 차이가 다른 영화에서도 예측되는지 본다.

이는 정서가 연속적인 영상을 뇌에서 묶는 방식과 어떻게 연결되는지 보는 발견 방향이다. 앞선 장면의 영향이 얼마나 남는지, 예상 밖의 사건에 얼마나 반응하는지를 다시 묻는 제안은 아니다. 다만 시간적 조직 자체가 관심 밖이면 더 발전시키지 않는다.

이 방향은 **2순위 Emo-FilM**의 연속 fMRI와 기존 외부 정서 평정을 쓴다. 개인이 느낀 감정이나 기억의 경계를 측정한 것으로 해석하지 않는다. 사건 의미·소리·정서의 동시 변화와 시간 지연이 어렵고, 정서와 event segmentation의 직접 후속 선행을 아직 대조하지 않았다. 따라서 새로운 주력 추천이 아니라 다른 종류의 흥미를 확인하는 선택지다.

## 이번에 확인하려는 것

네 방향은 각각 **시각 단서를 보는 발견 / 뇌로 AI를 가르치는 방법 / 재사용할 뇌 판독 도구 / 영화 속 신경 상태의 시간적 조직**을 목표로 한다. 어떤 결과가 실제로 보고 싶은지를 먼저 듣고, 그 방향에서 가까운 선행·가능한 방법·기존 자료의 한계를 깊게 검토한다. 어느 선택지도 신규성·실행 준비가 확정된 주제는 아니다.
