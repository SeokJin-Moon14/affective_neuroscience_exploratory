# A와 C를 연결할 때 지켜야 할 자료 분리

이 문서는 현재 확인한 관측 구조와 제안한 구현을 구별한다. 실제 보유 BOLD·feature 배열을 열어 실행한 분석은 아니다.

## 지각에서 C를 먼저 시험한다

| 집합 | 학습에 사용하는 관측 | 역할 |
|---|---|---|
| D | 뇌 반응·일반 시각 특징 | decoder 학습과 내부 분할을 이용한 특징 오차 추정 |
| H | D와 다른 원영상의 시각 특징·기존 인간 정서 평정 | emotion head 학습. H의 뇌 반응은 학습에 사용하지 않음 |
| T | 두 학습에서 제외한 원영상의 뇌 반응·기존 평정 | 최종 지각 평가. 모델 선택이나 오차 보정에 사용하지 않음 |

D의 정서 평정으로 decoder나 정서별 교정기를 맞추지 않는다. T에 대한 원영상 특징→head는 같은 평가 영상에서 시각 모델의 기준 성능을 확인하는 비교이며, 실제 뇌 기반 사용 시점에 원영상을 입력으로 받는 설계는 아니다.

직접 뇌→정서 학습은 별도의 비용·성능 참조로 둘 수 있지만 자동적인 성능 상한은 아니다. 여러 목표를 평가하더라도 그 모두를 기준으로 오차 처리 방법을 선택한 뒤 '새 목표'라고 부르지 않는다. 새 head로의 재사용을 주장할 때는 방법 선택에 쓰지 않은 기존 정서 목표를 평가용으로 남긴다.

## A까지 함께 시험할 원ID 계획

공개 sub-01 이벤트에서 MC raw trainPerception은2180개 원ID이며, 그중72개가 시험 영상이다. 마지막 두 학습 런을 빼면 공식 처리본 설명과 같은2108개다. Horikawa 공식15개 제외를 적용하면 MC에서 사용 가능한 공통 원ID는2172개이고, 그중 시험 영상은71개다. 따라서 공통 풀에서 시험을 제외한 D/H 후보는**2101개**다. 이는 실제 feature·영상 QC 전의 수다.

시험72개를 먼저 잠그고, 허용되는 최대71개에서 지각·심상 평가를 계획한다. D/H는 남은 원ID에서 분리한다. head에 영상을 배정한 만큼 decoder의 학습 영상은 줄어든다. 공식2108개 전체로 decoder를 학습하는 경우와 같은 학습량이라고 보고하지 않는다. 서로 다른 ID의 내용 중복·유사 편집본도 확인해야 한다.

원영상을 공유한 decoder/head로 먼저 작동 가능성을 살펴볼 수는 있다. 다만 이는 탐색이며 **서로 겹치지 않는 자료로 학습한 두 기능의 재사용 검증**과 구별한다. 두 데이터셋의 참가자나 voxel을 직접 같은 것으로 합치지 않는다.

계수는 [기존 ID 검산](../../agents/01_dataset/evidence/revision_v4/mc_sub01_id_checks.json)과 [연결 보고](../../agents/01_dataset/revision_v4_data_bridge.md)에서 재확인했다. 모든6명의 실제 처리본과 유효 반복을 검사한 수가 아니다.

## 시각 단서를 보여주려면 필요한 구현

MC 공식 data README의 TimeSformer 특징은 `nVideos × nUnits`의 영상별 특징이다. 보존된 공식 `mcap_setParams.m`은 `decSkipModels={'timesformer'}`로 설정돼 있다. 따라서 제공된 파일에 패치·프레임별 decoded visual map이나 실행된 시각 decoder가 있다고 가정하지 않는다.

기존 영상에서 dense token·patch·frame 특징을 새로 계산하고 기존 지각 BOLD로 decoder를 학습하는 것은 새 인간 관측 없이 가능하다. 다만 feature 해상도를 늘린다고 뇌에서 읽는 성능이 좋아지는 것은 아니며, 이 부분은 실제 학습과 평가가 필요하다.

첫 결과는 두 패널로 구분한다. 원영상의 특정 부분을 가리키는 그림은 **영상 모델이 쓰는 근거**다. 지각·심상 비교는 **그 근거에 대응하는 특징축에서 뇌 반응으로 읽은 값**이다. 원영상의 saliency를 심상 속 공간 위치로 옮기거나, 특징의 상관을 정서 유발의 인과 증거로 해석하지 않는다.

## 심상 분석의 경계

기존 cue·심상12초·휴식2초·후속 실제영상10초의 순서와 실제 처리 window를 확인한다. 개인의 심상 이미지·정서 정답은 없다. 같은 원영상의 특징이 심상에서도 동일해야 한다고 두고 보정기를 학습하지 않는다.

지각에서 정한 오차 처리를 고정해 적용한 결과와 보정하지 않은 결과를 함께 본다. 하나의 보정에서만 생기는 차이를 선택적 시각 재현으로 단정하지 않는다. 반복은 안정성을 평가할 수 있지만 원영상과 심상 내용이 같다는 근거도, 지각 보정이 심상에서 정확하다는 근거도 아니다.

특정 특징의 정서 관련성은 독립 영상의 기존 인간 평정에서 확인한다. A에서 비교할 일반 시각 특징도 지각 단계의 판독 감도 등을 고려한다. 여기서 시각 단서의 실재·정서 관련성·지각/심상 차이를 각각 확인해야 하며, 그럴듯한 생성 이미지 한 장으로 세 조건을 대신하지 않는다.
