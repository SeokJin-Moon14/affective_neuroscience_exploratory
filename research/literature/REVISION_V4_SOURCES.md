# v4 문헌의 실제 확인 범위

[최근 선행과 후보별 차이](../revision_v4/PRIOR_COMPARISON.md)와 [U001·U002 참조](../revision_v4/REFERENCES.json)를 따른다. 기존 canonical 장부103개는 그대로 보존했다. 새 후보가 인용한 각 논문의 실제 접근 범위는 상세 원고의 `nearest_prior`에 적었다.

P008·P009의 지정 원문/Discussion을 직접 다시 읽었다. P001은 공식 코드·문서와 일부 실제 이벤트를 확인했고 원문 전체를 새로 읽었다고 하지 않는다. U001은 사용자 요약과403 접근 기록, U002는 저자 공식 저장소의 서지·코드·문서·캡션·일부 이벤트 확인이다. 범주지각·정서 추상화·심상 관련 직접 후속 선행 전체를 검증한 상태는 아니다.

논문의 Discussion에서 실제 읽은 내용, 자료 코드에서 확인한 동작, 에이전트가 제안한 가설을 구별한다. 이번 후보들은 새로운 계산 관찰의 가능성을 제시하며 최초성 확정이나 문헌 전체 검색 완료를 주장하지 않는다.
