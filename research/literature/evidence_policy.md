# 근거 집계 원칙

확인일 2026-11-12. 문헌 개수와 내용 검증 범위를 분리한다.

- 공식 저장소 README/BibTeX로 제목·저자·연도·논문 식별자를 확인하면 서지 검증 후보가 된다. 코드를 보았다는 이유로 논문 본문을 읽었다고 표시하지 않는다.
- E1은 논문 본문·부록·공식 코드·데이터 문서의 실제 확인 범위다. `full_text_access`와 `discussion_access`는 별개로 집계한다.
- E2는 공식 요약 또는 서지 확인이다. 저자 Discussion의 직접 제안으로 전환하지 않는다.
- E3는 조사자가 만든 연결·가설이며 결과 또는 저자 주장으로 인용하지 않는다.
- E0는 미확인 후보로 남기고 검증 문헌 목표에서 제외한다.
- 서지 일부 누락, 잘못 추정한 저장소 주소의 404, 검색 결과 부재는 논문의 부재를 증명하지 않는다.
- 미션이 이름을 제시한 모델도 확인 전에는 실재·체크포인트·입출력을 가정하지 않는다.
- preprint와 출판본은 같은 연구로 병합하고 모든 근거 행은 원본 파일과 함께 남긴다.
- 2026년 날짜는 실행일과 출처에 표기된 연도를 구별한다. 2026년 논문도 현재 출처를 읽은 경우에만 확인 상태로 쓴다.
- 시뮬레이션, 실제 뇌 분석, 모델 실행, 다운로드를 하지 않았으면 수행으로 기록하지 않는다.
