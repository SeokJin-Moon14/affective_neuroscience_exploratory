# Top10 근접 선행연구와 강한 중복 반론

Coordinator가 32개 질문의 코퍼스 역검색 결과와 기존 문헌 표를 실제 내용 수준에서 대조했다. 자동 토큰 상위순위는 관련성 보장이 없어 아래에서 직접 선행연구·전이 원리·범용 방법 근거를 구별했다. 새 원문 열람이나 전 세계 논문 검색의 완료를 뜻하지 않는다. 외부 학술 인덱스는 CONNECT403 제약이 있었고 GitHub 검색은 보조 자료다. 특히 RP02의 정확한 최근 직접 선행연구는 추가 확인이 필요하다.

## RP01: 시각 정렬 목표가 정서 대비의 판독 접근성을 바꾸는 조건

비교 문헌: P001, P015, P016, P022, P023.

시각 복원·공유 참가자 정렬은 이미 연구되어 있다. 정렬 모델의 단순 교체는 차별점이 아니다.

같은 정보입력·같은 test에서 정서 대비의 판독 접근성, 가역 재매개변수화, 비선형 회복과 검증 가능한 비가역 병목을 분리하는 대비만 남긴다.

판정: 유지·범위 축소. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP02: 관계 의미의 설명력과 비가산 신경 예측의 중복을 고정 타깃에서 구별

비교 문헌: P083, P084, P102, P001.

관계 의미 feature와 비가산 예측은 각각 알려진 발상이다. 현재 코퍼스에서 정확히 같은 neural relational 대비의 최인접 선행연구를 확정하지 못했다. P067은 일반 시간 계층 근거이고 직접 선행연구라고 내세우지 않는다.

정서 주석으로 고정한 동일 신경 타깃에서 관계 feature 추가×가산/비가산 모형을 교차하고 원 감각·전체 의미 함수족을 맞춘다. 새 캡션이 독립 정답이라는 주장을 배제한다.

판정: 조건부 유지·직접 선행연구 공백 명시. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP03: 경계 단서와 과거 소거를 분리한 상태 갱신의 필요성

비교 문헌: P066, P042, P089, P044.

사건 경계·과거 문맥 변화는 P066이 가장 직접적인 신경 선행연구다. P089/P044의 새 모델명만으로 신규성이 생기지 않는다.

경계 indicator 추가와 실제 과거 state reset을 구별하는 동일 입력 모형, 경계 오차·HRF·편집 단서 대조 후 정서 대비의 추가 설명으로 제한한다.

판정: 유지·P066 직접 비교 강화. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP04: 공유 병목의 용량을 넘어 남는 모달리티 정보의 예측 충분성

비교 문헌: P037, P038, P035, P053.

shared/private 멀티모달 분해와 bottleneck은 이미 있다. private 잔차 이득만으로 생물학적 고유 경로를 증명하지 못한다.

공유 병목 용량곡선과 원 모달리티 전체 접근의 강한 기준을 맞추고, 동일 자극의 정서/비정서 대비 차이를 검정한다.

판정: 유지·조건부 예측 충분성으로 축소. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP05: 독립 반복의 신경 문맥이 자극모형 밖 정서 대비 예측을 회수하는가?

비교 문헌: P026, P027, P029, P001.

자극 encoding과 신경 masked completion은 기존이다. 신경 입력이 더 많아 성능이 높은 것은 새 발견이 아니다.

독립 관측의 신경 문맥에서 같은 표적 대비가 회수되는지 확인하되, 반복이 없는 자료에서는 해당 신경 주장을 착수하지 않는다. 동시 공간완성과 과거→미래는 별도 관측 분기다.

판정: 조건부 유지·즉시 착수 제외. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP06: 내용 거리와 주석 불확실성을 맞춘 정서 경계의 초과 신경 거리

비교 문헌: P001, P004, P008, P006.

고차원 정서 범주 및 distributed code는 P001에서 직접 연구되었다. 범주 decoding을 재실행하는 것은 중복이다.

연속 감각·의미 거리와 주석 불확실성을 맞춘 국소 경계 초과거리, 독립 split과 거리 신뢰도 검정을 핵심으로 둔다.

판정: 유지·경계 효과에 한정. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP07: 독립 관측이 배제하는 정서 상반 witness 쌍

비교 문헌: P076, P015, P016, P053.

역문제의 비식별성과 diffusion prior 기여 자체는 알려져 있다. 제한적 sampling의 다양성은 neural 정보 상한이 아니다.

같은 고정 관측과 양립하는 정서 상반 witness 쌍을 독립 측정이 배제하는지 검정한다. 쌍을 못 찾았다는 사실은 유일성 증명이 아니다.

판정: 유지·finite pool 반례 검증으로 한정. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP08: parcel 평균이 지운 내부 공간 대비는 정서 관련 예측에 필요한가?

비교 문헌: P026, P051, P001.

공간 평균이 세부 패턴을 잃는 것은 선형대수적으로 자명하다. P081은 요약 병목의 전이 원리이며 fMRI 공간 병목의 직접 선행연구가 아니다.

고정 parcel 평균의 null-space가 신뢰도·해부학·자극 공변량을 넘어서 정서 대비에 선택적인 예측 이득을 갖는지 묻는다. 풀링 손실의 존재 자체를 신규성으로 삼지 않는다.

판정: 조건부 유지·정서 대비와 공통검증 필요. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP09: 비정서 anchor 선택으로 정서 의미 대응을 결정할 수 있는가

비교 문헌: P057, P052, P051, P023, P077.

기하 구조 일치가 의미 일치를 보장하지 않는 것은 기존 식별성 문제다. anchor를 추가했다는 사실만으로 새 이론은 아니다.

정서 감독을 쓰지 않은 anchor 정책의 정보량별 정서 의미 대응을 완전히 보지 않은 내용·target에서 시험하고 동등 기하의 잘못된 대응을 negative control로 둔다.

판정: Discovery 유지·주석 및 공통 지지집합 조건. 실제 Round5 응답과 최종 카드를 함께 읽는다.

## RP10: 사전 허용집합 안에서 검증하는 정서 관련 편집 신경 대비

비교 문헌: P070, P078, P069, P071, P097.

생성 편집으로 자극을 만드는 것은 기존이며 accepted subset만 분석하면 선택 편향이 생긴다.

실제 BOLD를 보기 전 허용집합·정서 주석·편집 실패를 고정하고 새 신경 측정에서 paired 대비를 검정한다. 효과는 검증된 자극 묶음의 차이며 latent 정서의 순수 인과 효과라고 하지 않는다.

판정: Discovery 유지·새 주석·뇌 측정 필요. 실제 Round5 응답과 최종 카드를 함께 읽는다.
