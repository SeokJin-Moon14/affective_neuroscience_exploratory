# 파일럿 선정 이유

RP01은 사용자가 제시한 vision decoder와 emotion head를 구체적인 신경과학 질문에 연결한다. 장면을 설명하는 뇌 정보가 정서 설명에도 충분한지 비교할 수 있어 첫 번째로 둔다.

RP03은 특정 장면과 정서의 연관을 넘어서는 뇌 패턴이 있는지 묻는다. RP01과 데이터 준비를 공유하지만, 평가할 핵심은 시각 모델의 충분성이 아니라 새로운 내용으로의 일반화다.

RP05는 영화의 앞선 맥락이 현재의 정서 관련 뇌 반응을 설명하는지 묻는다. 시간 정보를 포함해 앞선 두 질문에서 다루지 못하는 문제를 검토한다.

생성형 모델로 자극을 바꾸는 RP02와 시청각 조건을 직접 바꾸는 RP08은 신경과학적 잠재력이 있지만 새로운 평정과 뇌 측정이 필요하다. 개인차를 다루는 RP10은 참가자 수와 개인별 신뢰도를 먼저 확보해야 한다.

이전의 학습목표 비교와 parcel 평균 비교는 필요한 경우 쓰는 방법 점검으로 옮겼다. [이전 계획](../archive/v1/pilots/README.md)은 새 파일럿의 실행 기록이 아니다.
