# 기존 파일에서 확인할 입력

사용자는 다섯 데이터셋을 보유한다. 아래 목록은 새로운 자료 수집 요청이 아니라, 분석이 시작될 때 기존 보유본에서 연결해야 할 관측이다. 현재 환경에서는 공개 이벤트·캡션·공식 코드만 직접 확인했으며, 사용자의 BOLD·feature 본체는 열지 않았다.

| 입력 | 연결 키와 단위 | 실제로 확인할 내용 |
|---|---|---|
| Horikawa BOLD | 참가자·run·원영상 `stim_index` | 5명의 영상별 반응, mask/ROI, 전처리, 관측 제외. 동일 원ID의 개인 내 독립 반복을 가정하지 않는다. |
| 기존 정서 주석 | 원영상 ID·항목명 | category/dimension 값, 항목 정의·척도 방향·결측. 공식 코드의 숫자 인덱스를 보유본 코드북으로 대신하지 않는다. 제외된 연구 축의 항목은 주력 정서 목표로 쓰지 않는다. |
| 기존 내용·시각 특징 | 원영상 ID·모델·layer | 영상의 실제 길이와 편집본, feature 행 순서, 중복 내용. 기존 영상에 새 AI 특징을 계산할 수 있지만 그 점수를 인간 정서 정답으로 부르지 않는다. |
| MC 사람 캡션 | `video_id` | 공개 CSV는2196개 원영상에20개씩, 총43,920행. 캡션20개를 한 문장으로 대체해 정보가 없다고 판정하지 않는다. |
| MC 지각 반응 | 참가자·run·`stimID` | `stimLabel`은 원영상 ID가 아니다. raw 학습 마지막 두 런의 시험72개 중복을 제외하고 공식 처리본2108개와 대조한다. |
| MC 심상 반응 | 참가자·run·`imageryID` | cue·심상·후속 실제영상의 구간과 처리 window, 유효 반복. accuracy/vividness는 객관적 기억 오류나 정서 정답이 아니다. |

NSD는 반복 시각 반응을 사용하는 선택적 확장에 적합하다. 확인하지 않은 인간 정서 평정을 있다고 가정해 주력 검정에 끼워 넣지 않는다. Emo-FilM과 Spacetop도 과제·주석 단위가 다르므로 같은 정서 정답으로 직접 합치지 않는다.

## 현재 실행한 검산

`python scripts/check_v4_metadata.py`는 보존된 공개 TSV와 캡션 CSV를 실제로 읽는다. MC sub-01에서 raw 학습60런, testPerception10런, testImagery 첫 세션6런을 검사했다. 학습 마지막 두 런을 빼면58런2108개이며 시험72개와 원ID가 겹치지 않는다. Horikawa 공식15개 제외를 그대로 적용하면 시험72개 중 최대71개가 남는다. 이 숫자는 추가 QC 이전의 상한이다.

[검산 결과](metadata_check.json)는 뇌 배열, 모든 참가자, 정서 주석 본체, 실제 대비의 검정력을 검증한 기록이 아니다. 사용자의 데이터를 마운트한 뒤 추정해야 하는 결과를 만들어 넣지 않았다.

## 분석 때 남길 산출물

`input_manifest.json`에는 실제 파일 경로·버전·해시·원ID 연결과 제외 이유를 기록한다. `feature_dictionary.csv`에는 항목명·정의·척도·평정 주체를 남긴다. `split_manifest.csv`에는 참가자·원ID·내용 집단·학습/보정/평가 역할을 기록한다. 이 세 파일은 실제 배열 확인 후 생성해야 하므로 현재 확인된 입력인 것처럼 빈 양식을 채워 게시하지 않는다.
