# 장면을 떠올릴 때 어떤 정서 관련 차이가 남는가

연결 후보: D02-A와 통합한 D03-A·D04-A·D05-A·D06-A. 목적은 정서를 분류할 수 있는지 확인하는 데서 끝내지 않고, 같은 영상들의 뇌 표현이 지각에서 심상으로 바뀔 때 어떤 관계가 달라지는지 검정하는 것이다. 새 촬영·새 기억 과제·새 사람 정서 평정은 필요하지 않다.

## 필요한 기존 관측

MC testPerception과 testImagery의 같은 원영상 반응과 유효 반복, Horikawa 원영상의 기존 정서 주석, MC 영상별20개 사람 캡션, 기존 영상에서 얻는 시각 특징을 사용한다. Horikawa 공식 제외를 적용하면 시험 대상은 최대71개다. 실제 허용 정서 항목·결측·전처리 QC에 따라 더 줄어든다. 참가자는 공식 문서상6명이며 이번 raw 이벤트 검산은 sub-01에 한정됐다.

## 먼저 확인할 것

1. 원영상 ID·feature 행·제외 목록을 연결한다. MC raw trainPerception 마지막 두 런의 시험72개를 제외하고 공식 처리본2108개와 대조한다. Horikawa에서 정서 판독기나 특징을 학습하더라도 시험 원ID와 내용 중복을 제외한다.
2. 공식 처리본의 심상 window 또는 회귀계수 생성법을 확인한다. cue 뒤에12초 심상,2초 휴식,10초 실제영상이 이어지는 기존 사건 구조를 반영한다. 필요한 경우 기존 raw fMRI와 events로 cue·심상·후속영상 회귀항을 분리한다. 설계의 분리 가능성과 실제 추정 감도를 함께 확인한다.
3. 뇌 결과를 보기 전에, 최대71개 기존 영상에서 정서 관계와 풍부한 내용 관계가 서로 다른 예측을 하는지 확인한다. 실제로 대비가 없으면 이 자료로 질문을 판정할 수 없다. 유리한 영상이나 정서 항목을 뇌 결과에 맞춰 고르지 않는다.

1번의 공개 ID·분할 검산 일부는 [실행 기록](metadata_check.json)에 있다. 정서 평정 본체와 뇌 반응을 사용하는2·3번은 실행하지 않았다.

## 최소 분석

첫 모델은 공식 자료에 기술된 TimeSformer 영상 특징과 DeBERTa-large 캡션 특징을 사용한다. 실제 제공 feature와 원ID를 확인한 뒤 정규화한 두 특징을 결합하며, layer·정규화·ridge 강도는 학습 자료 안에서 선택한다. 새 대형 모델의 학습은 첫 파일럿의 조건이 아니다. 지각 자료에서 정한 시각·내용 표현과 정서 주석의 관계를 고정한다. 새 영상의 관계를 평가할 수 있도록 원영상 단위로 학습·평가를 나눈다. 사람 캡션과 영상 특징을 함께 쓰는 내용 모델을 두어, 정서를 제외한 빈약한 물체 목록만 경쟁 모델로 삼지 않는다.

지각·심상 양쪽에서 동일 대상의 장면 관계를 추정한다. 반복은 추정 오차와 감도를 평가하는 데 사용한다. 훈련에서 선택한 관계 변화가 남은 영상과 독립 반복에서도 나타나는지 살핀다. 핵심 지표는 정서 관계와 내용 관계의 상대적 변화이며, 전체 정서 예측 정확도나 전뇌 평균 RSA 상승은 보조 결과다.

전체 신호가 약해지는 설명, 일반적인 내용만 남는 설명, 정서 관련 차이가 상대적으로 더 남는 설명, 정서 관련 차이가 더 줄어드는 설명을 함께 비교한다. 지각 때 구별 난도와 반복 신뢰도가 다른 두 특징을 그대로 비교해 선택적 보존이라고 부르지 않는다. 노이즈만 늘린 지각 자료가 실제 심상의 관계 변화를 재현하는지도 감도 분석으로 확인한다.

첫 확인의 주분석은 공식 WB mask를 사용한다. 시각 영역 분석은 보유 mask와 해부학 정의를 확인한 뒤 평가 결과를 보기 전에 정한다. 결과를 본 뒤 정한 영역은 탐색 결과로 구분한다. 시각 decoder와 시각 ROI는 같은 결론을 설명하는 보조 분석이다. 이를 별도 연구 다섯 개로 세지 않는다.

## 어떤 결과를 다음 단계로 넘길 것인가

정서와 내용 모델이 다르게 예측한 관계에서 실제 변화 방향이 반복되고, 전체 감도 저하만으로 설명되지 않으면 전체 참가자로 분석을 넓힌다. 정서 차이가 더 남는 경우뿐 아니라, 내용은 남는데 정서 차이는 더 줄어드는 경우도 중요한 결과다. 어느 경우든 검사한 단서 기반 심상 과제와 영상 범위에 대한 결론이다.

기존 영상에서 대비가 없거나, 기존 구간으로 심상을 구분할 수 없거나, 신경 감도가 낮아 방향을 판정하지 못하면 이 후보를 보류한다. 자료를 더 모아야만 성립하는 새 연구로 바꿔 현재 파일럿이 성공했다고 쓰지 않는다. 직접 심상 선행과 MC 원문에 같은 비교가 이미 있다면 독립 논문 기여를 재평가한다.

## 분석 결과와 구분할 것

원영상의 외부 정서 주석은 참가자가 심상 중 느낀 정서가 아니다. 정확한 기억·기억 오류·정서 조절을 측정하는 연구도 아니다. 모델에서 정서를 읽을 수 있어도 뇌의 처리 경로나 정서 전용 회로를 알아낸 것은 아니다.

분석이 실행되면 실제 대상 ID, 모델 선택과 분할, 참가자별 관계 변화, 불확실성, 제외·실패 이유를 함께 저장한다. 현재는 그 실행 계획과 공개 메타데이터 검산을 완료한 상태다.
