# 현재 연구 제안 상태

**v3에서 제시한 네 방향의 주력 선정을 철회했다.** 특히 “정서적인 장면을 잘 기억한다는 것은, 그 모습을 정확히 기억한다는 뜻일까?”는 현재 가진 자료에 핵심 검정을 위한 행동 관측이 없어 현재 후보에서 제외했다. 본문에 새 실험이 필요하다고 적어 둔 것은 해결책이 아니었다.

현재 기준은 **1순위 Horikawa·MC·NSD → 2순위 Emo-FilM → 3순위 Spacetop**이다. 필요한 뇌·행동 관측이 이미 있는지부터 대조하며, 새 실험이 필수인 질문을 보유 자료로 가능한 제안처럼 제시하지 않는다.

[네 방향을 제외한 이유와 새 선정 기준](../revision_v4/DATA_FIT_REVIEW.md) · [데이터별 확인 범위](../datasets/DATASET_INTELLIGENCE_REPORT.md).

새 RQ의 선정은 다시 열었다. 이 문서는 이전 제안의 오류를 정정한 것이며, 새 질문 선정이 완료됐다는 보고가 아니다. 다음 제안에는 필요성·중요한 결과·Conclusion·분야 기여와 함께 **어느 데이터의 어떤 관측으로 결론을 검증하는지**를 필수로 적는다.

[이전 v3 원고와 실제 토론](../archive/v3/README.md)은 이력으로 보존한다. 이전 원고의 발전·통합 표기는 현재 우선 선정으로 읽지 않는다.
