# 보유 데이터에서 출발한 연구 질문

7개 제안 역할이 만든 10개 원안을 데이터 담당과 동료들이 검토하고 저자가 수정했다. 서로 같은 MC 원안 5개는 1개로 합쳤고, 기여가 부족한 3개는 주력에서 보류했다. 현재 남긴 것은 아래 3개 파일럿 후보다. 모두 기존 관측으로 설계했지만 실제 주석·뇌 배열의 지원 범위와 직접 선행의 중복을 확인해야 하며, 검증된 발견이나 최초성이 확정된 주제라는 뜻은 아니다.

각 질문의 필요성, 중요한 관찰, 조건부 Conclusion, 분야 기여를 먼저 적었다. 공개 메타데이터 검산과 실제 뇌 분석의 실행 상태는 구별한다.

## 비슷한 정서라도 범주가 달라지면 뇌에서 더 다르게 표현될까?

V4-01 · 파일럿 후보로 선정. 주석의 척도와 경계 주변 영상이 실제 검정을 지원해야 한다.

**왜 필요한가.** 뇌 활동으로 정서 이름을 잘 맞힌다고 해서 뇌가 정서를 범주별로 나눈다고 말할 수는 없다. 연속적인 차이에도 이름을 붙여 분류할 수 있기 때문이다. 정서 범주가 실제 뇌 표현의 구조와 연결되는지 묻는다.

**어떤 결과가 중요한가.** 정서 평정과 장면 내용의 차이가 비슷한 영상들을 비교한다. 그중 두 정서의 점수 우열이 바뀌는 지점에서 뇌 반응의 차이가 더 커지고, 다른 종류의 장면에서도 같은 양상이 나타나야 한다.

**Conclusion.** 그 결과가 나온다면, 검사한 정서 범주는 단순한 분류 이름을 넘어 가까운 장면들을 구별하는 뇌 표현의 구조와 연결된다고 말할 수 있다. 그 구조를 연속 모델이 잘 설명하는지는 별도의 질문이다.

**분야 기여.** 정서의 범주가 뇌에 어떻게 나타나는지에 대해, 분류 정확도나 군집 그림보다 직접적인 근거를 제시한다. 반대로 충분한 감도에서도 이런 구조가 없다면 범주 예측 성공의 해석 범위를 좁힌다.

**쓸 자료.** Horikawa의 기존 영상별 fMRI·category/dimension 평정. 기존 영상 특징과 MC의 영상별 20개 사람 캡션으로 내용 차이를 비교한다. 새 측정은 필수가 아니다.

**채택 전 확인.** 범주 점수의 비교 가능한 척도, 실제 전환 부근의 영상·내용 겹침을 먼저 확인한다. 집계 점수의 전환을 개인이 느끼는 감정의 경계로 해석하지 않는다. P001과 범주지각 직접 선행의 중복 확인은 남아 있다.

## 장면이 달라도 같은 정서를 나타내는 뇌 패턴은, 비슷한 정서도 잘 구별할까?

V4-02 · 파일럿 후보로 선정. 기존 주석·내용의 겹침을 확인한 뒤 첫 분석 대상으로 권고한다.

**왜 필요한가.** 장면이 바뀌어도 같은 정서를 나타내는 능력과, 비슷한 정서들의 차이를 남기는 능력은 다르다. 장면 변화에 잘 견디는 뇌 패턴이 정서를 더 세밀하게 구별하는지, 여러 뇌 영역이 서로 다른 정서 차이를 보존하는지 묻는다.

**어떤 결과가 중요한가.** 같은 평가 영상과 같은 정서 대비를 사용했을 때, 어느 영역은 장면이 비슷할 때 세밀한 차이를 잘 구별하고 다른 영역은 새로운 장면에서 그 차이를 더 잘 유지할 수 있다. 중요한 것은 평균 성능의 역전뿐 아니라 어떤 정서 차이가 남고 줄어드는지를 새 영상에서 맞히는 것이다.

**Conclusion.** 영역별 전체 감도와 내용 민감도만으로 설명되지 않는 관계 차이가 나온다면, 장면을 넘어 일반화하는 능력과 세밀한 정서 구별이 하나의 순서로 좋아지지는 않는다고 결론내린다. 검사한 뇌 표현들이 서로 다른 정서 차이를 보존한다는 조직상의 발견이다.

**분야 기여.** 내용에 민감한 시각 영역의 정서 표현을 단순히 덜 완성된 표현으로 보지 않게 한다. 정서 모델도 평균 정확도뿐 아니라 어떤 구별을 일반화하고 어떤 차이를 보존하는지 뇌와 함께 설명해야 한다.

**쓸 자료.** Horikawa의 영상 시청 fMRI와 기존 연속 정서 평정. 기존 semantic·시각 특징과 MC 사람 캡션으로 내용군을 정한다. MC 반복은 선택적 보조이며 핵심 검정은 Horikawa에서 한다.

**채택 전 확인.** 여러 정서 대비가 서로 다른 내용군에도 있어야 한다. 동일 평가 영상을 고정하고 학습 내용군만 바꾼다. 한 대비의 성능 차이만 남거나 내용·감도 차이로 충분하면 표현의 분업을 주장하지 않는다. P001 및 직접 후속 선행과의 중복은 확인해야 한다.

## 장면을 떠올릴 때, 정서와 관련된 차이는 다른 장면 정보보다 더 잘 남을까?

V4-03 · 다섯 원안을 한 파일럿 후보로 통합. 기존 MC 시험영상과 심상 구간이 비교를 지원하는지 먼저 확인한다.

**왜 필요한가.** 머릿속에 떠올린 장면에서 물체와 사건을 읽어냈다고 해서, 장면들 사이의 정서적 차이도 그대로 남았다고 볼 수는 없다. 장면을 떠올리면 모든 정보가 비슷하게 약해지는지, 정서와 관련된 차이는 더 남거나 더 줄어드는지 묻는다.

**어떤 결과가 중요한가.** 같은 영상을 볼 때와 떠올릴 때의 뇌 반응을 비교한다. 물체·행동·사건의 정보를 자세히 나타낸 AI 모델로 예상한 것과 달리, 정서가 다른 장면들의 구별이 더 남거나 줄어드는 양상이 반복돼야 한다. 전체 신호가 약해지는 설명과 장면의 의미가 남는 설명도 함께 검토한다.

**Conclusion.** 그 결과가 나오면, 검사한 심상 과제에서 장면의 정서 관련 관계는 다른 내용과 같은 비율로 유지되지 않았다고 말할 수 있다. 정서 차이가 더 잘 남는 결과와 더 크게 줄어드는 결과 모두 장면 재구성의 성격을 알려 준다.

**분야 기여.** 뇌가 장면을 되살릴 때 무엇을 보존하는지 설명하고, 물체·사건의 복원만으로 정서 관련 관계의 복원까지 평가할 수 있는지 밝힌다. 단순한 지각→심상 정서 판독의 성공은 기여로 세지 않는다.

**쓸 자료.** MC의 같은 원영상에 대한 testPerception·testImagery, 기존 사람 캡션과 Horikawa 원영상의 정서 주석. 공식 제외를 적용하면 시험 대상은 추가 QC 전 최대 71개다.

**채택 전 확인.** 기존 71개 안에서 정서와 내용 설명이 실제로 다른 예측을 내야 한다. cue·심상·후속 실제영상의 신호와 처리 window를 확인한다. 개인의 심상 중 감정이나 객관적 기억 오류를 측정한 것으로 해석하지 않는다. U002와 직접 심상 선행의 동일 분석 여부도 남은 확인이다.
