# RP05. 독립 반복의 target 제외 신경 문맥이 지정 자극모형의 정서 대비 예측을 보완하는가?

연결: RQ13. 문헌 기반 제안이며 실제 신경 결과가 아니다. 실현성은 명시한 데이터·모델 조건에 따른다.

## 1. RQ ID / Working Title

RQ13 — 독립 반복의 target 제외 신경 문맥이 지정 자극모형의 정서 대비 예측을 보완하는가?

## 2. 핵심 질문

추가로 관측한 동일 자극의 독립 반복 문맥 N_a가, 그 입력 경로에서 target 신호가 배제되었을 때, 고정 자극모형 S보다 반복 b의 독립 A 신경 대비를 더 잘 예측하는가?


## 3. 과학적 동기

추가 신경 입력을 가진 모델이 더 높은 전체 BOLD 성능을 얻는 것은 새로운 발견이 아니다. 필요한 구별은 같은 반복 잡음 공유, 독립 반복에 남는 자극 반응, 누락 사건 의미와 target 복사의 어느 경우가 지정 A 대비 회수를 설명하는지다. 이 결과는 신경문맥의 상대적 측정가치를 제한하며 내부 정서 기전의 식별로 확장하지 않는다.

## 8. 계산 모형

**baseline:** S: cached 저수준·검수 중립 객체/관계/사건 특징→target Y ridge. N: 검증된 원입력에서 target+buffer를 제거한 raw-context→같은 target Y ridge. 추가 신경 관측을 제공한 S+N과 S-only는 서로 다른 입력 예산임을 명시하고 같은 N 입력의 head 간 비교도 보고한다.

**adaptation:** 모든 feature scale/PCA/head/개인 보정/Q/의미·mask 선택은 outer training에서 적합한다. test N_a는 허용된 입력이고 Y_a/Y_b는 fitting·선택에 넣지 않는다. target 자체의 다른 반복 제공은 신뢰도 기준으로 분리한다.

**loss:** head는 training Y squared error로 적합; 외부 일차 평가는 A contrast loss. 전체 Y loss는 보조.

**target free gate:** 선형 H를 알면 H_context,target=0을 확인한다. 원 target에 여러 크기/방향 perturbation을 가한 후 고정 전체 pipeline의 N feature 불변성을 수치허용오차와 함께 검사한다. nonlinear 경로는 구조 감사와 병행한다. 이미 비가역적으로 혼합되어 확인 불가이면 착수 보류.

**extensions:** - S baseline: 실제 자극의 cached low-level/검수 사건/시각 특징→같은 target Y 또는 c_A. image-only CLIP ViT-B/32는 시각 특징 기준이며 시청각 또는 시간 상태 전체를 제공하지 않는다.
- TRIBE v2는 video/audio/text→평균 참가자 fsaverage5 피질 예측이다. 공개 output을 개인 target voxel이나 subcortex likelihood로 간주하지 않는다. 공통 cortical mapping·개인 보정·checkpoint config의 TR 및 5초 offset 확인이 필요하다.

## 9. 신경 표적

같은 cortical target 공간의 Y_b와 외부 A로 정한 c_A(Y_b). 피질 표적을 subcortex로 확대하지 않고 집계 A를 개인의 정서 상태로 해석하지 않는다.


## 10. 분석·검증 계획

**estimand:** w는 독립 A 차원/고저 대비로 사전 고정하며 sum w=0,sum w²=1. c_A(Y)=Σ_i w_iY_i. L_A=||c_A(Y)-c_A(Yhat)||²_Q, Δ_A=L_A(S)-L_A(S+N); Q는 train-only shrinkage/diagonal 기준. 같은 test 표본·target 척도에서 모든 입력조건을 비교한다.

**conditions:** - S-only
- S+동일 반복 target제외 N_b
- S+다른 run/session 동일 자극 target제외 N_a
- S+같은 run 다른 자극 N
- S+내용/A/context 신뢰도 일치 타자극 N

**nuisance:** 의미 강화 전체 곡선·buffer거리·반복순서·경과시간·global/run/motion·context reliability를 보고한다. 표적 perturbation 검사를 통계적 null로 대체하지 않는다.

**splits:** 자극 내용 family를 outer fold에 묶고 같은 자극의 모든 반복은 모델 적합의 train/test 경계를 함께 지킨다. test 반복 a의 N을 b 예측에 쓰는 것은 명시된 관측 입력이며 training label이나 test target는 아니다. 의미/feature/ROI/head 선택과 normalization은 train 안에서만 한다.

**null:** known shared stimulus/잡음/target-copy 생성 문제에서 recovery를 확인하고 실제 matched 타자극 대조를 사용한다. 시간점 iid 또는 무조건 label permutation을 조건부 독립 증명으로 쓰지 않는다.

**inference:** Horikawa 참가자5명의 개별 효과를 모두 제시한다. 참가자 조건부 새 자극 추론과 사람 모집단 추론을 구별한다. n=5 양측 exact sign-flip의 최소 p는 2/32=.0625이며 자극·voxel·atlas seed를 사람 N으로 세지 않는다. 계층/모수 CI는 작은 n 가정 민감도와 함께 표시하고, 비유의성을 동등성으로 읽지 않는다.

**multiplicity:** 일차 A차원1개·target 블록1개·미리 고정한 mask curve. 다차원/다블록 확장은 별도 test와 가족별 교정.

**reliability:** context와 target 신뢰도를 별도 추정할 실제 독립 반복이 필요하다. 없으면 반복 결과·noise ceiling 없음으로 기록한다. 모델기반 오차는 반복 신뢰도와 다른 가정적 추정이다.

**branch B:** 과거→미래 확장은 본인/타인/자극 과거와 nuisance를 같은 물리시간 창에서 비교하며 미래접근·HRF/annotation lag를 별도 감사한다. RP05-A 성능과 합치지 않는다.



## 11. 경쟁 설명

N이 회수하는 것은 미측정 사건 의미·감각 이력 또는 run/global·평활화 잡음일 수 있다. 독립 반복에 전달되어도 안정적인 자극 유발 반응과 내재 상태의 기원을 구별하지 못하며, 이를 내부 정서 계산으로 명명해서는 안 된다.


## 12. 긍정·부정·혼합 결과

**positive:** 검증된 target-free 독립 N의 Δ_A가 최소효과를 넘고 타자극/내용/신뢰도 대조에서 유지되면 지정 S의 상대적 충분성이 반박된다. 내부 상태나 순수 정서는 아니다.

**negative:** 충분한 신뢰도와 precision에서 Δ_A CI상한이 사전δ 아래면 그 입력·표적에서 추가 N의 실용가치가 작다.

**mixed:** 동일반복만 이득이면 공통잡음 또는 낮은 독립 N 신뢰도/반복적응; 의미 보강후 소실이면 미모형화 자극; 타자극에서도 같으면 nuisance.

**unidentified:** 반복·target-free 경로 미확인 또는 CI가 넓으면 미식별이며 신경 회수 주장 착수/확증을 보류한다.



## 13. 신경과학과 모델링 기여

**neuroscience:** 현재 자극표현이 어느 관측조건에서 독립 A 대비를 충분히 예측하지 못하는지 제한한다.

**modeling:** 입력예산·target 전파·반복 nuisance를 명시한 두 조건부 예측의 평가계약. 대형 AI 모델 신규 개발은 필수 기여가 아니다.



## 14. 한계와 위험

- 현재 독립 반복과 target-free 전처리 경로가 미확인되어 신경분석 착수 보류.
- 비선형 의미 완전성·nuisance 독립성은 유한 검정으로 완전히 확정할 수 없다.
- 같은 참가자 반복은 적응·순서·기억이 달라질 수 있으며 독립 측정이 잡음 완전 독립을 뜻하지 않는다.
- Horikawa 사람5명의 모집단 일반화는 제한됨.
- 현재 모델 load·GPU비용·원자료 경로·실물 주석은 미검증.


## 15. 최소 정보 파일럿

**status:** PILOT03으로 선정된 질문이 아니며 RP05의 별도 조건부 최소계획이다.

**pre gate:** 공식 스키마 대응·반복 mapping·target perturbation을 먼저 확인. 실패하면 실제 신경 회수 실험으로 진행하지 않음.

**planned subset:** 게이트 충족 자료에서 첫 QC는 반응값을 보지 않고 고른 1명·최대32개 실제 반복 자극쌍·target block1개. 과학검정은 최소관심 효과의 독립 cluster 검정력이 충족된 새 자극 subset으로 확대하며 32쌍을 충분한 power라고 가정하지 않는다.

**steps:** - manifest/provenance
- synthetic target-copy null
- raw S/S+N ridge
- matched 타자극/의미/buffer 대조
- 외부 A loss/CI

**expand:** 반복/입력게이트와 synthetic calibration이 통과하고 raw baseline의 안정된 대비가 있을 때만 더 많은 내용군/모델로 확대.

**stop:** 반복 또는 target-free 경로 없음, 신뢰도 부족, 의미 보강으로 설명됨이면 보류/방법후보로 축소.
