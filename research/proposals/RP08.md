# 영상과 소리가 서로 다른 정서를 전할 때 뇌는 두 정보를 어떻게 함께 처리할까?

RP08 · NQ08 · 연구 기획 v2

평온한 숲 영상에 긴장감을 주는 음악이 흐르면, 뇌 반응은 영상과 소리 중 어느 쪽을 더 따를까? 이 연구는 두 정보의 영향이 섞이는 것만으로 뇌 반응을 설명할 수 있는지, 서로 다른 정서의 조합이 별도의 반응을 만드는지 묻는다. 음악과 환경음을 대상으로 하며, 말소리의 특징이나 사회적 감정 이해는 다루지 않는다.

## 이 질문으로 알아내려는 것

정서를 처리하는 뇌가 영상과 소리의 정보를 각각 유지한 채 비중을 조절하는지, 둘의 조합을 통해 다른 표현을 만드는지 알 수 있다. 앞 장면의 영향이나 예측 위반보다, 같은 시점에 들어오는 두 감각 정보의 관계를 중심에 둔다.

## 어떤 설명을 비교하나

| 설명 | 맞다면 관찰할 결과 |
| --- | --- |
| 영상과 소리의 정서 정보가 서로 다른 비중으로 섞인다. | 영상만 또는 소리만 제시했을 때의 뇌 패턴에 비중을 주어 더하면, 함께 제시했을 때의 패턴을 설명할 수 있다. 두 정서가 다를 때는 더 뚜렷하거나 믿을 만한 단서의 영향이 커진다. |
| 영상과 소리의 조합이 각 정보의 합으로 설명되지 않는 반응을 만든다. | 정서가 일치하는 경우와 어긋나는 경우의 뇌 패턴 차이를, 각 감각의 반응과 단서 강도를 조합한 설명만으로는 충분히 예측하지 못한다. 같은 영상·소리 특징 사이의 관계를 고려해야 설명되는 차이가 남는다. |

## 뇌에서 무엇을 보고, AI를 어떻게 쓰나

시각피질과 청각피질, 상측두 영역, 편도체 및 내측 전전두피질의 활동 패턴을 비교한다. 함께 본 조건의 패턴이 각 감각만 본 조건의 조합으로 설명되는지 살핀다. 한 영역의 반응이 더 크다는 사실만으로 감각 통합의 위치나 독립적인 정서 정보를 확정하지 않는다.

1. 먼저 기존 스캔에서 실제로 소리가 제시됐는지 확인한다. 영상 파일에 음원이 있다는 사실만으로 시청각 뇌 자료로 취급하지 않는다. 적합한 영화 구간에서 별도 평가자가 무음 영상과 소리만 듣는 조건을 나누어, 각 자극이 전달하는 정서와 단서의 뚜렷함을 평가한다.

2. 영상과 소리가 같은 사건을 가리키는지도 별도로 평가한다. 정서가 어긋난다는 이유가 단순히 엉뚱한 소리가 붙었기 때문인지 구별하고, 대사 이해에 의존하는 구간은 제외한다.

3. ImageBind의 고정된 영상·오디오 인코더에 실제 제시된 각 신호를 따로 넣어 두 벡터를 얻는다. 두 벡터가 뇌 활동에 미치는 영향을 더하는 모델과, 같은 벡터 사이의 조합을 추가로 사용하는 작은 모델을 비교한다. 서로 다른 사전학습 모델의 성능 차이를 감각 통합의 증거로 삼지 않는다.

4. 학습에 쓰지 않은 영화에서 정서가 일치하거나 어긋나는 장면의 뇌 패턴을 얼마나 설명하는지 비교한다. 소리 크기, 음악의 존재, 화면 변화, 사건의 의미상 일치도와 각 단서의 강도를 고려한다. 기존 자료에서 조합 모델이 유리한 결과는 통합에 관한 단서로만 해석한다.

5. 직접 검증에는 같은 영상을 서로 다른 음악·환경음과 함께 제시하는 새 실험이 필요하다. 정서가 일치하는 조합과 어긋나는 조합, 영상만 제시하는 조건, 소리만 제시하는 조건에서 뇌를 새로 측정한다. 각 감각의 반응을 이용해 예상한 조합과 실제 시청각 반응이 어떻게 다른지 비교한다.

## 결과를 어떻게 해석하나

| 관찰 결과 | 과학적 의미 |
| --- | --- |
| 단서 강도에 따른 비중을 고려한 두 감각의 조합으로 시청각 뇌 패턴을 설명할 수 있다. | 검사한 자극과 영역에서는 두 정보의 영향이 섞인다는 설명이 충분하다. 뇌에서 상호작용이 전혀 없다는 뜻은 아니다. |
| 정서 불일치에 따른 차이가 각 감각의 비중과 의미상 불일치를 고려한 뒤에도 남는다. | 두 정서 정보의 관계가 뇌 표현에 영향을 준다는 근거다. 새 실험의 감각별 조건까지 확인해야 단순한 혼합으로 설명되지 않는 효과를 더 직접적으로 판단할 수 있다. |
| 실제 소리 제시를 확인하지 못하거나, 정서 불일치가 사건의 불일치와 항상 함께 나타난다. | 기존 자료로 두 설명을 구별할 수 없다. 이는 감각 통합이 없다는 음성 결과가 아니다. |

## 기존 연구에서 더 나아갈 부분

시청각 통합과 음악이 영상의 정서적 해석에 미치는 영향은 기존 연구 주제다.

정서 불일치를 사건의 의미상 불일치와 구분하고, 뇌 패턴이 각 감각의 영향에 비중을 준 조합으로 설명되는지 직접 비교한다.

이 비교의 최초성은 확정하지 않았다. 정서적 시청각 불일치와 감각별 뇌 패턴을 함께 측정한 선행 연구를 추가로 확인해야 한다.

## 보유 자료로 시작할 범위

Emo-FilM 등 보유 영화 자료에서 실제 오디오 제시가 확인된 구간만 관찰 비교에 사용한다. 기존 외부 합의 정서 주석은 시청각 자극 전체에 대한 참고값이며, 영상과 소리 각각의 정서 주석을 대신하지 못한다. 두 감각을 나눈 추가 평가가 필요하다. 기존의 함께 제시된 BOLD를 영상만 또는 소리만 본 반응으로 간주하지 않는다. 음원을 바꾼 자극과 감각별 조건의 뇌 반응은 새로 측정해야 한다.

먼저 할 일: 실제 오디오가 제시된 것으로 확인된 영화에서 대사에 의존하지 않는 구간 16개를 골라, 영상만 본 집단과 소리만 들은 집단의 정서 평가를 받는다. 사건의 의미는 맞지만 정서는 어긋나는 후보가 있는지 먼저 확인한다. 후보가 확보되면 같은 영상·오디오 벡터를 쓰는 단순 조합 모델과 조합 관계를 추가한 모델의 소규모 뇌 비교를 계획한다. 아직 제시 기록 확인이나 모델 실행을 수행하지 않았다.

## 해석할 때 남는 한계

- 자연 영화에서는 영상과 소리가 대개 의도적으로 맞춰져 있어 정서 불일치 사례가 부족할 수 있다.
- 조합 모델이 더 잘 예측하더라도 특정 뇌 영역이 비선형 통합을 수행한다는 인과적 증거는 아니다. 누락된 자극 특징이 대안 설명일 수 있다.
- AI에서 영상·소리 벡터를 나눌 수 있다는 사실은 뇌에 독립적인 정보 경로가 있다는 뜻이 아니다.
- 말소리 특징, 대사의 사회적 의미, 참가자의 주관적 느낌은 연구 대상에서 제외한다. 영상·음악·환경음이 전달하는 정서와 뇌 반응을 비교한다.

## 관련 문헌

- [P035 · ImageBind: One Embedding Space To Bind Them All](https://arxiv.org/abs/2305.05665): 실제로 제시된 영상과 소리를 각각 표현하는 AI 도구로 사용한다.
- [P038 · Attention Bottlenecks for Multimodal Fusion](https://arxiv.org/abs/2107.00135): 두 감각의 단순 조합과 상호작용을 구별하는 모델 설계에 참고한다.
- [P041 · Audio-Visual Event Localization in Unconstrained Videos](https://arxiv.org/abs/1803.08842): 시청각 정보가 같은 사건을 가리키는지와 정서가 일치하는지를 구분하는 데 참고한다.
- [P002 · Emo-FilM: A multimodal dataset for affective neuroscience using naturalistic stimuli](https://doi.org/10.1038/s41597-025-04803-5): 실제 오디오 제시 여부를 확인한 뒤 사용할 수 있는 자연 영화 뇌 자료다.
