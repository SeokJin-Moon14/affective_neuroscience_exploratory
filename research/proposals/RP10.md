# RP10. 사전 허용집합의 정서 관련 편집은 새 신경표본에서 재현되는가?

연결: RQ27. 문헌 기반 제안이며 실제 신경 결과가 아니다. 실현성은 명시한 데이터·모델 조건에 따른다.

## 1. RQ ID / Working Title

RQ27 — 사전 허용집합의 정서 관련 편집은 새 신경표본에서 재현되는가?

## 2. 핵심 질문

독립 인간 주석으로 목표 정서 변화와 지정 감각·관계 의미의 보존을 확인한 원본 family에서, 실제 목표−비목표 편집 자극의 신경 대비가 무편집 왕복·일반 내용 변화 대안을 넘어서 새 family와 참가자에 재현되는가?


## 3. 과학적 동기

**gap:** 생성기가 바꾼 latent나 prompt는 사람에게서 어떤 내용이 바뀌었는지를 보장하지 않는다. 필요한 질문은 실제 자극이 독립 평가에서 목표 차이와 보존 조건을 동시에 만족할 수 있고, 그 제한된 범위의 차이가 새 신경 측정에 나타나는가이다.

**neural significance:** 관찰 자료에서 얽힌 자극 정서 내용과 감각/관계 의미의 설명을 실제 제시 자극 대비로 더 좁힐 수 있다. 그러나 사건 의미와 정서 단서가 완전히 분리된다는 가정은 하지 않으며 얻는 효과는 검증된 자극 묶음의 효과다.

**hypothesis status:** E3 발견 경로. 생성물·사람 주석·새 BOLD를 아직 만들거나 측정하지 않았다. 모형 단독 counterfactual을 뇌 인과 증거로 사용하지 않는다.

## 6. 가장 가까운 선행연구와 신규성

**closest:** P070/P071/P078의 통제 편집과 기존 무작위 자극·paired 실험 원리가 가장 가깝다. 이미지 편집 또는 신경 예측기에 생성물을 입력했다는 사실 자체는 신규성이 아니다.

**exact difference:** 독립 주석으로 고정한 family 허용집합에서만 새 실제 신경 대비를 검정하고, 전체 실패·선택 coverage·같은 용량의 감각/관계 의미 기준·자연 matched 대조를 함께 제시한다. 지정 두 editor 확인은 동일 공통 family에 한정한다.

**overlap and counterargument:** 좋은 자극 통제 실험을 생성형 AI로 구현한 것에 그칠 수 있다. 생성이 자연 matched 후보보다 더 큰 목표 차이와 유사한 비목표 변화의 조합을 만들거나 신경 대립 예측을 구별하지 못하면 기술적 필요성은 약하다.

**search limit:** TOP10_REVIEW의 근접 선행 중복 반론을 수용했다. 새 외부 전수 역검색을 하지 않았고 최신 생성 자극 신경실험과의 최초성은 미확정이다.

## 7. 데이터와 메타데이터

**primary pool:** 이미 보유한 NSD의 정적 원본 이미지 중 접근·재사용 조건과 stimulus ID가 확인된 것을 첫 원본/자연 matched 후보 pool로 한다. NSD에는 이 프로젝트에서 검증된 정서 라벨이 없으며 새 주석을 받는다. 기존 NSD BOLD는 원본의 자연 자극 대조·분석절차 개발에만 쓴다.

**verified vs unverified:** 공식 nsdcode 경로와 사용자 보유 사실은 확인됐다. 실제 파일 경로·이미지 버전·stimulus ID/반복 beta 대응·처리 공간은 보유본 확인 조건이다. 아래 새 분석 필드는 NSD의 기존 실제 컬럼이라고 주장하지 않는다.

**other owned data:** Horikawa events에는 onset/duration/trial_type/stimulus_name/stim_index가 확인됐다. 영상의 한 프레임을 편집하면 원래 영상 BOLD와 동일한 관측이 아니므로 첫 경로에 섞지 않는다. Emo-FilM consensus는 개인 연속 정답이 아니며 Spacetop clip 평정도 새 편집물의 평정이 아니다. Mind Captioning의 이름만으로 주석을 가져오지 않는다.

**new annotation contract:** **A:** 독립 사람에게 자극이 표현하는 부정적 정서 내용 강도를 0–100의 개발에서 문항·anchor를 고정한 척도로 평정하게 한다. 실제 label이 존재한다는 진술이 아니라 새로 수집할 운영 정의다. 개인 느낌의 뇌 정답으로 해석하지 않는다.

**preservation:** 객체 정체성·행동·관계·사건 결과의 동일성/변화, 가림, 전체/국소 색·대비·구조 변화와 자연성을 별도 항목으로 측정한다. 맹검 평가자가 원본–편집 pair를 평가하며 prompt를 보지 않는다.

**independence:** 개발/선별 주석자, 고정 절차의 독립 검증 주석자, fMRI 참가자의 실제 ID/중복을 확인한다. 파일이 다르다는 이유로 사람 독립이라고 하지 않는다.

**new neural contract:** 편집된 실제 이미지 O(원본), T(목표), C(비목표), I(무편집 왕복)를 새 참가자에게 제시한 BOLD가 필수다. 원본 BOLD 복사·모형 예측·특징 정렬은 대체 측정이 아니다.

## 8. 계산 모형

**input output:** 첫 단계는 정적 원본 RGB 이미지와 목표/비목표 텍스트 지시를 입력으로 받아 O/T/C/I family를 만든다. 음성·영상·장문 문맥으로 시작하지 않으며 모든 예측 baseline은 같은 제시 이미지에 접근한다.

**first editor:** 공식 P070 Prompt-to-Prompt와 P071 Null-text Inversion 경로를 첫 후보로 둔다. 실제 원본 inversion에서 unconditional embedding을 최적화하되 backbone을 새 뇌 자료에 fine-tune하지 않는다. inversion 자체의 I를 대조로 보존한다.

**second editor:** P078 FlowEdit의 공식 SD3 또는 FLUX 경로를 별도 실행·가중치·라이선스 확인 후 두 번째 지정 경로로 고려한다. 어떤 버전도 load 성공을 가정하지 않으며 checkpoint/commit/hash·scheduler·해상도·prompt·seed를 고정한다.

**realizations:** 최소 두 사전 seed realization을 각 family 안에서 제작한다. seed는 독립 사람/원본 표본이 아니다. 두 editor 비교는 두 경로 모두 동일 family 조건을 충족한 공통 지지에서만 하며 그보다 넓은 생성기 모집단에 일반화하지 않는다.

**screening:** CLIP ViT-B/32와 저수준 이미지 거리는 후보 정리와 감각/내용 baseline용이다. 인간 정서/의미 보존의 정답이 아니다. 공식 loader와 expected SHA256 40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af는 확인됐으나 load·추론은 미검증이다.

**encoding models:** 동일 새 실제 신경 target과 split에서 M0=감각 특징 ridge, M1=감각+독립 객체/행동/관계 의미 ridge, M2=M1+독립 A 또는 목표 대비 ridge를 비교한다. 목적함수는 제곱오차+L2이며 동일 정규화·차원 예산·inner tuning budget을 쓴다. A와 조건 지표를 추가하는 두 검정은 주/이차로 미리 구분한다.

**adaptation boundary:** frozen backbone 비교는 목표함수의 인과효과 검정이 아니다. 모델 입력은 실제 제시 이미지로 통일하고 생성 prompt·미래 문맥을 목표 모형만 받게 하지 않는다.

**resource:** 현재 CPU quota 4·32GiB, GPU 추론 미확인이다. 계획/로그·작은 캐시·모의 통계와 GPU 생성·새 인간 측정을 분리한다. 모델 논문의 VRAM을 이 환경의 실제 비용으로 바꾸지 않는다.

## 9. 신경 표적

**primary:** 개발 신경표본에서 고정한 자극 A 관련 분산 projection v에 대해 d_sf=v^T(Y_sf,T−Y_sf,C), theta=E_f E_s[d_sf | S_f=1]를 주추정량으로 한다. Y는 새 제시 자극의 실제 BOLD이며 v의 방향·정규화·mask를 확인 표본 전에 고정한다.

**construction:** 해부학적으로 사전 지정한 시각/연합피질 mask와 train-only 낮은 차원 특징을 쓰는 작은 ridge로 독립 개발 family의 A를 예측해 v를 정한다. 정서 주석과 분산/신뢰도가 확인돼야 하며 확인 표본의 편집 대비를 보고 v·ROI를 선택하지 않는다.

**fallback:** 방향 v를 독립적으로 정당화할 수 없으면 새 확인 자료를 열기 전에 반복 기반 cross-validated 신경 거리 질문으로 변경해 별도 등록한다. 부호 있는 정서 대비의 성공으로 섞어 보고하지 않는다.

**secondary:** 전체 고정 mask의 비부호 차이, editor 상호작용과 감각/관계 의미 모형의 설명은 별도 이차 지표다. 여러 ROI를 사후 골라 주결과로 바꾸지 않는다.



## 10. 분석·검증 계획

**eligibility:** 개발 자료에서 전체 후보 universe와 family-level S_f를 동결한다. 사전 지정한 O/T/C/I와 두 realization이 모두 자연성·감각/관계 의미 공통 지지를 만족하고 T−C의 A 변화가 최소 Δ_A를 넘는 family만 허용한다. 비목표 변화의 상한과 목표 A 하한을 분리한다. T와 C의 A 변화를 같게 매칭해 목표 조작을 없애지 않는다.

**three stages:** - 개발/선별: 개발 family·평정으로 Δ_A, 보존 허용폭, 자연성 기준, editor·seed 정책을 정한다. 고정 규칙을 새 후보 family의 별도 선별 주석에 적용해 S_f와 전체 통과/실패 목록을 동결한다. 별도 개발 신경자료에서 v와 최소 신경효과 δ를 최종 BOLD 전에 고정한다.
- 독립 주석 검증: 선별에 참여하지 않은 평가자가 이미 동결한 통과 목록과 지정 탈락 표본을 감사한다. 조작·보존·coverage가 실패하면 새 개발 버전으로 돌아가 새 확인 주석을 확보한다. 검증 점수로 family/seed를 재선택해 성공률을 부풀리지 않는다.
- 신경 확인: 동결된 허용 family를 새 참가자에게 실제 제시해 BOLD를 수집한다. 허용규칙·자극·주 지표·모형 튜닝은 확인 BOLD로 수정하지 않는다.

**primary comparison:** theta와 CI를 먼저 보고한다. 동강도 비목표·무편집 왕복의 대비, 자연 matched pair의 유사한 A 변화 대비를 병기하여 일반 편집 손상/관계 내용 설명과 비교한다. 자연/생성 자극은 교환가능하다고 가정하지 않는다.

**strong baseline:** 같은 독립 test family/참가자의 동일 Y 또는 v^T Y에 대해 M0/M1/M2의 held-out MSE 차이를 비교한다. 총 목표 대비와 측정한 감각/의미 조건부 예측 증분을 구분한다. 비정서 특징에도 같은 차원·비선형성·선택 예산을 허용한 sham 추가 특징 기준을 둔다.

**assignment:** 조건의 run/제시 위치 배정을 참가자 안에서 무작위화·균형화하고 같은 family 변형의 노출 순서를 counterbalance한다. 충분한 간격·반복·HRF 설계를 개발에서 정해 순서·기억·적응·carryover를 모형화한다. 실제 조건 할당은 자극 묶음의 효과를 식별할 수 있지만 정서만의 단일 인과요인을 식별하지 않는다.

**generalization:** family 내 변형·인접 원본은 같은 split에 묶는다. 새 family와 새 참가자가 가능한 확인 설계를 우선한다. editor j별 S_fj를 정의할 경우 두 editor 직접 비교는 S_f1=S_f2=1인 교집합을 별도 estimand로 등록한다. editor 효과는 고정효과이며 seed는 family 내부 요인이다.

**inference:** 참가자×family 교차 계층모형에 run·순서·realization 의존을 반영한다. 실제 부분 교차 구조를 따른 다요인 bootstrap 또는 계층 모의자료에서 오류율을 확인한다. TR·모든 variant를 독립으로 하는 t검정이나 무제한 라벨 셔플을 쓰지 않는다. 단지 제시 순서가 무작위라는 이유로 모든 T/C 교환을 유효하다고 하지 않는다.

**multiplicity and null:** 하나의 주 theta·v·δ를 고정하고 ROI/editor/다수 대비는 사전 이차 family로 오류를 보정한다. 실제 배정이 허용하는 제한적 randomization null 또는 nuisance·의존을 보존한 모의 null을 사용한다. 무편집·비목표·자연 matched 대조는 서로 다른 대안 원인을 검사한다.

**reliability power:** 독립 주석의 A·보존·자연성 신뢰도와 반복 BOLD 대비 신뢰도를 따로 추정한다. 개발의 참가자/family/잔차 분산·통과율로 δ 검출력과 등가성 CI 폭을 모의 계산한 뒤 새 수집 규모를 정한다. 현재 효과크기·N을 확정하지 않는다. 확인 자료의 신뢰도 높은 subset만 재선택하지 않는다.

**coverage and missingness:** 모든 시도·실패·제외 이유·원본별 통과율을 보고한다. 한쪽 조건이 빠진 family를 다른 성공 seed로 조용히 메우지 않는다. S=1 내부 BOLD 누락/탈락은 원인과 조건 차이를 감사하고 설계에 맞는 민감도 분석을 한다. 결정론적 S=0 영역을 역확률 가중으로 자동 복원하지 않는다.



## 11. 경쟁 설명

- **alternative:** 미측정 사건 관계·시각 단서
  
  **prediction:** 감각/관계 의미 M1이 목표 대비를 설명하고 자연 matched 대조에도 같은 효과가 나타난다.
  
  **decision:** 정서와 관련된 총 자극 대비는 남길 수 있지만 정서 고유성 주장을 낮춘다.
- **alternative:** inversion·질감·생성 artifact
  
  **prediction:** I 또는 C에서도 비슷한 신경 변화가 나타나거나 특정 editor/seed·자연성 손실에만 효과가 집중된다.
  
  **decision:** 해당 편집 경로의 효과로 제한하고 자연 대조 전이 없이 보편적 정서 대비라 하지 않는다.
- **alternative:** 허용집합 선별 편향
  
  **prediction:** 낮은 복잡도·특정 내용 family만 통과하고 기준 변화에 따라 효과/coverage가 크게 달라진다.
  
  **decision:** S=1 범위를 구체화하고 S=0 일반화를 하지 않는다. 확인 결과를 보고 문턱을 완화하지 않는다.
- **alternative:** 반복 노출·기억·순서/개인차
  
  **prediction:** 제시 위치·run·이전 family 노출에 따라 대비가 바뀌며 새 참가자에 전이하지 않는다.
  
  **decision:** 무작위화/균형화와 계층 모형으로 평가하고 잔여 제약을 해석에 보존한다.


## 12. 긍정·부정·혼합 결과

**positive:** 독립 조작/보존 검증과 충분한 신뢰도 아래 theta가 사전 최소효과를 넘고 새 family/참가자에서 방향을 유지하며 무편집·동강도 비목표 대안보다 크면 S=1의 실제 자극 묶음 대비를 지지한다. 내용 기준을 넘는 예측 증분과 두 지정 editor/자연 대조의 일치는 대안 일부를 약화하지만 정서만의 인과성을 증명하지 않는다.

**negative:** A 조작과 보존이 재현되고 설계 민감도가 충분한데 CI가 사전 등가영역 안에 들어오면 그 허용범위의 지정 신경 대비 가설을 약화한다. 단순 p>α나 넓은 CI는 반증·동등성 증거가 아니다.

**mixed:** - 신경 차이는 있으나 M1/무편집이 설명: 일반 내용 또는 생성 손상 설명을 우선한다.
- 한 editor에서만 효과: 편집 경로 의존성을 지지한다. 두 editor를 모집단처럼 평균하지 않는다.
- 두 editor에서 효과, 자연 matched에서는 없음: 공통 생성 artifact 또는 조작 차이가 남는다.
- 좁은 S=1에서 큰 효과: 해당 family 범위의 증거이며 원본 pool 전체 효과가 아니다.

**design failures:** - 독립 주석에서 A 변화 없음: 조작 실패; 뇌에 정서정보가 없다는 증거 아님.
- 의미/감각 공통 지지·family pair 부족: 해당 조작 실현성 실패.
- 낮은 BOLD 신뢰도·넓은 구간·선택적 누락: 판별불가; neural absence로 쓰지 않음.

**judgment changing evidence:** 충분한 독립 family에서 조작·보존·coverage가 재현되고 실제 새 BOLD·검정력 계획이 준비되면 수집 추진으로 올린다. 자연 matched 기준보다 조작/비용상 이득이 없으면 생성 필요성을 낮춘다. 충분한 조건에서 최소효과보다 작은 대비가 반복되면 해당 제한된 신경 가설을 기각한다.



## 13. 신경과학과 모델링 기여

**neuroscience:** 명시적으로 검증된 자극 정서 내용의 변화와 새 신경 대비가 함께 나타나는 범위를 찾고, 일반 감각/관계 의미 설명이 충분한 조건을 확인한다.

**modeling:** 모든 실패·허용집합·독립 검증·생성 경로 의존을 포함하는 자극 제작/평가 계약을 제공할 수 있다. 신규 생성 알고리즘을 개발했다고 주장하지 않는다.

**boundary:** 실제 제시 자극의 무작위 대비와 정서 단일 성분의 인과효과를 분리한다. 모델 feature 개입만으로 인간 뇌 인과성을 추정하지 않는다.



## 14. 한계와 위험

- 목표 정서 단서와 사건 의미는 구성적으로 겹칠 수 있으며 제한된 문항·embedding으로 의미 전체 보존을 증명하지 못한다.
- S=1 선택 자체가 적용 모집단을 바꾸고 결정론적 탈락 영역의 효과는 식별되지 않는다. family 내부 pair를 깨뜨린 선택도 편향을 만든다.
- 두 editor가 backbone·학습자료를 공유하면 공통 artifact가 남는다. seed 다양성은 생성기나 인간 모집단 다양성이 아니다.
- 주석 cohort와 신경 cohort의 실제 독립성, 편집물의 소유/제시 조건, BOLD의 HRF·순서·반복 신뢰도는 확인해야 한다.
- v를 기존 다른 자료에서 이식하면 공간·태스크·척도 이동이 추가된다. 기본안은 독립 새 개발 신경표본에서 정하고 이 비용을 숨기지 않는다.
- 현재 체크포인트 load·GPU 추론·사람 평정·새 BOLD는 미실행이다. 보유5종만으로 편집 신경 실험이 준비됐다고 하지 않는다.
- 생성기가 자연 matched 비교보다 필요한지와 최신 선행 대비 독창성은 아직 미결이다.

**status:** 별도 첫 3개 PILOT에 포함되지 않은 장기 카드의 단계다. 이 계획은 인간 측정 실행 결과가 아니다.

**revise or stop:** 주석 overlap·coverage가 없으면 해당 편집 규칙을 중단/새 개발로 돌린다. 자연 matched와 같은 정보를 더 큰 비용으로만 만들면 생성 확장을 중단한다. 새 BOLD 계획이 없으면 자극 타당성 방법 연구 또는 자연 자극 관찰 질문으로 낮추고 편집 신경 가설 검증이라 하지 않는다.

**execution readiness:** 새 주석·새 개발 및 확인 BOLD가 필요하다. 장기 수집 설계이며 현재 기존 자료 분석으로 완결 가능한 실행 파일럿이 아니다.
