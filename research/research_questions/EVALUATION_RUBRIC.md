# 질문 평가 기준

미션의10항목을 질문마다1–5점, 근거, 불확실성과 함께 기록한다. 점수는 문헌 기반 판단이며 실험적 측정값이 아니다. 부정적 결과도 과학적 의미가 있으면 반증가능성과 중요성을 낮추지 않는다.

| 항목 | 1점 | 3점 | 5점의 의미와 경계 |
|---|---|---|---|
| novelty | 기존 질문의 모델교체 | 계산 대비에 차이가 있으나 근접 연구와의 중복 가능 | 조사 범위에서 명확한 새 판별; 외부 전체 문헌의 부재를 뜻하지 않음 |
| neuro_importance | 성능표만 변함 | 정서 관련 표상 범위를 제한 | 대립 신경계산 설명의 핵심을 가름 |
| ai_necessity | 단순 baseline으로 같은 질문 | AI가 유용한 측정 도구 | 새 계산 조작·접근 없이는 해당 대비를 구성하기 어려움 |
| data_feasibility | 필요한 측정이 없음 | 보유자료의 스키마 조건부 | 필수 측정·단위·정렬을 실제 확인; 보유명만으로5점 금지 |
| rigor | 경쟁설명 식별 불가 | 주요 통제가 가능하나 일부 모호성 | 독립 검정·대안설명·선택과정을 구체적으로 통제 |
| falsifiability | 어떤 결과도 지지 | 부정 결과 해석이 있음 | 경쟁 예측과 동등성/중단 기준이 구체적 |
| interpretability | 예측=기전 혼동 | 조건부 표상 주장을 구분 | 관측·계산·인과 주장 수준과 대안 설명이 명확 |
| generalization | 동일 표본 내 적합 | 한 종류 외적 보류 | 자극·사람·환경 일반화를 분리 평가 |
| technical_feasibility | 구현·가중치 미식별 | 공식 구현·fallback 있으나 실측 자원 미확인 | 실제 환경·입력·checkpoint 동작 검증까지 완료; 이번 문헌 계획에서 임의5점 금지 |
| exploration_value | 중복 질문 | 중요한 비교 공백 | 다른 분야의 계산목적을 새 신경 질문으로 전이 |

네 순위를 분리한다: 과학적 잠재력, 독창성, 단기 실현성, 종합 우선순위. 정렬 점수는 참고 순서이며 최종 Top10/Pilot3은 내용·다양성·관측가능성 판단으로 선택하고 이유를 적는다. ‘현재 사용자가 데이터를 갖고 있음’과 ‘에이전트가 분석 준비를 검증함’을 혼동하지 않는다.

## 점수 해석의 한계

역할별 점수는 조건부 설계에 대한 서열 판단이며 실험 효과나 역할 간 교정된 척도가 아니다. 사전순 정렬의 동점은 RQ ID로 재현 가능하게 표시하되 과학적 우열을 주장하지 않는다. 종합 선정은 별도의 내용 판단이며 Round5 조건·소수 의견을 유지한다.
