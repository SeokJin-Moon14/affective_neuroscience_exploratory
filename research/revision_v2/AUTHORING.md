# 연구 질문 재구성

사용자의 최신 피드백을 반영한 새 기획이다. v1의 문헌·자료 확인 결과는 활용하지만 새 질문에 대한 토론이나 실험이 이미 수행됐다고 쓰지 않는다.

각 담당자는 자신의 agents 폴더에 `revision_v2_cards.json`을 작성한다. 공통 파일과 Git은 Coordinator가 관리한다. 긴 사전 조사보다 질문과 설계를 먼저 작성한다.

카드 형식은 JSON 배열이며 각 원소는 아래 필드를 가진다.

- proposal_id: RP01 등. 같은 파일명의 v1과 내용이 달라졌음을 통합 이력에서 밝힌다.
- rq_id: NQ01 등. 이전 RQ와 새 질문 ID를 구별한다.
- title: 누구나 뜻을 알 수 있는 질문 하나.
- summary: 구체적인 장면이나 현상에서 출발하는 2~4문장.
- why: 답이 정서를 처리하는 뇌에 관해 무엇을 알려주는지.
- hypotheses: 최소 두 설명. 객체 배열, 각 항목은 explanation과 prediction.
- neural_targets: 뇌 영역 또는 신경반응에서 비교할 항목. 문자열.
- approach: 문자열 배열. 데이터, AI 모델의 입력·출력, 비교, 평가를 순서대로 설명. 모델명 나열 금지.
- outcomes: 객체 배열. 각 항목은 result와 meaning. 음성 결과와 측정 한계를 구별.
- data: 보유 자료로 시작할 범위와 필요한 추가 측정. 문자열.
- limits: 중요한 해석 한계 2~4개. 문자열 배열.
- literature: 객체 배열. canonical paper ID(P001 등), role. 3~6개 직접 관련 문헌. 서지와 원문 확인 범위는 Coordinator가 papers.csv에서 표시.
- novelty: known, proposed, unresolved 필드. 이미 알려진 질문임을 숨기지 말고 이번에 구별하려는 설명을 구체화. 최초성 확정 금지.
- first_step: 실제 분석 전 첫 소규모 실험의 구체적 비교.
- previous_links: v1 RQ/RP에서 보존할 방법 및 폐기할 질문의 설명. 문자열 배열.
- feasibility: 기존 자료 탐색 / 추가 주석 필요 / 새 실험 필요 중 적합한 설명.

본문은 일반적인 한국어로 쓴다. '정서 대비 판독 접근성', '고정 타깃', '사전허용집합', '초과거리', '조건부 회수' 등을 제목·요약에 쓰지 않는다. 정확한 용어가 필요하면 짧게 뜻을 설명한다. 주된 주장은 뇌와 정서에 관한 것이어야 한다. decoder accuracy를 뇌의 인과 기제라고 하지 않는다.

Horikawa의 반복 측정을 가정하지 않는다. Emo-FilM 외부 consensus는 스캔 참가자 개인별 정서 궤적이 아니다. NSD 정서 라벨과 Mind Captioning의 자료 구조는 확인되지 않았다. 제외 주제는 유지한다. 최신 모델 자체를 신규성으로 삼지 않는다. 원문 확인을 새로 하지 않았다면 기존 확인 범위를 그대로 인정한다.
