사용자는 RP03을 선택한 것이 아니라, 여러 RQ를 실제로 토론하면서 모두에 필요성·중요한 결과·조건부 Conclusion·분야 기여를 넣으라고 요청했다.

- [독자용 질문과 기여](../proposals/README.md)
- [실제 비판과 수정](../discussions/revision_v3/SYNTHESIS.md)
- [통합·보류 판단](DECISIONS.md)
- [독립 원안 10개](independent_candidates.json), [첫 배정과 원본 해시](PEER_ASSIGNMENTS.json), [추가 2개 원안과 배정](ADDITIONAL_ASSIGNMENTS.json)
- [원저자 수정본 출처](AUTHOR_SOURCES.json), [읽기용 정본](catalog.json), [표현 수정 내역](EDITORIAL_CHANGES.json)
- [문헌 확인 범위](../literature/REVISION_V3_SOURCES.md), [기술적인 문서 검사](VALIDATION.json)
