# 선정·통합·보류 기록

7개 제안 역할이 만든 10개 원안을 데이터 담당과 동료들이 검토하고 저자가 수정했다. 서로 같은 MC 원안 5개는 1개로 합쳤고, 기여가 부족한 3개는 주력에서 보류했다. 현재 남긴 것은 아래 3개 파일럿 후보다. 모두 기존 관측으로 설계했지만 실제 주석·뇌 배열의 지원 범위와 직접 선행의 중복을 확인해야 하며, 검증된 발견이나 최초성이 확정된 주제라는 뜻은 아니다.

## V4-01: 비슷한 정서라도 범주가 달라지면 뇌에서 더 다르게 표현될까?

파일럿 후보로 선정. 주석의 척도와 경계 주변 영상이 실제 검정을 지원해야 한다.

D07-A의 두 동료 비판과 데이터 심사 뒤 저자가 수정했다. 국소 구조의 관찰과 연속/범주 모델의 승패를 분리한 점이 핵심이다. 기존 자료로 관찰할 대상과 그 결과가 바꿀 해석이 구체적이므로 파일럿 후보로 남긴다. 신규성과 실제 검정력을 확정한 채택은 아니다.

원안: D07-A

남은 확인: 범주 점수의 비교 가능한 척도, 실제 전환 부근의 영상·내용 겹침을 먼저 확인한다. 집계 점수의 전환을 개인이 느끼는 감정의 경계로 해석하지 않는다. P001과 범주지각 직접 선행의 중복 확인은 남아 있다.

## V4-02: 장면이 달라도 같은 정서를 나타내는 뇌 패턴은, 비슷한 정서도 잘 구별할까?

파일럿 후보로 선정. 기존 주석·내용의 겹침을 확인한 뒤 첫 분석 대상으로 권고한다.

D08-A는 동료 두 명과 데이터 담당의 비판을 반영해 동일 평가 영상·여러 대비의 상대적 보존·공통/영역별 모형의 차이를 명시했다. D07-A의 범주 전환 경계가 없어도 성립하는 별도 질문이며, 공통 정서 패턴 존재를 확인하는 데서 끝나지 않는다.

원안: D08-A

남은 확인: 여러 정서 대비가 서로 다른 내용군에도 있어야 한다. 동일 평가 영상을 고정하고 학습 내용군만 바꾼다. 한 대비의 성능 차이만 남거나 내용·감도 차이로 충분하면 표현의 분업을 주장하지 않는다. P001 및 직접 후속 선행과의 중복은 확인해야 한다.

## V4-03: 장면을 떠올릴 때, 정서와 관련된 차이는 다른 장면 정보보다 더 잘 남을까?

다섯 원안을 한 파일럿 후보로 통합. 기존 MC 시험영상과 심상 구간이 비교를 지원하는지 먼저 확인한다.

다섯 저자가 실제 토론으로 같은 핵심 관찰·결론임을 인정하고 통합했다. 시각 ROI와 visual latent 분석은 보조 분석이다. 특정 과제의 표현 변화를 검정하는 후보로 남기되, 적은 시험영상과 시점 분리가 가장 큰 실현성 조건이다.

원안: D02-A, D03-A, D04-A, D05-A, D06-A

남은 확인: 기존 71개 안에서 정서와 내용 설명이 실제로 다른 예측을 내야 한다. cue·심상·후속 실제영상의 신호와 처리 window를 확인한다. 개인의 심상 중 감정이나 객관적 기억 오류를 측정한 것으로 해석하지 않는다. U002와 직접 심상 선행의 동일 분석 여부도 남은 확인이다.

## 정서가 달라도 좋고 나쁨을 같은 뇌 신호로 읽을 수 있을까?

범주 내부 순서와 공정한 적응 비교로 개선했지만, 기존의 공통·유형별 표현과 맥락 의존성 결론을 넘어설 기여가 아직 약하다. 저자와 최종 검토자가 주력 미채택·조건부 보존에 동의했다.

일반적인 domain shift를 보여 주는 데서 끝나지 않고, 구체적인 공통 valence 해석을 수정할 반례와 직접 선행의 차이가 명확해질 때 재검토한다.

원안: D02-B

## 시각 디코더를 거치며 정서 정보가 사라지는가?

기존 자료로 계산할 수는 있지만 일반적인 압축·대리측정 손실 이상의 연구 필요성이 부족하다. 실제 분석은 생성 영상이 아니라 시각 특징 판독이다.

그 변환을 사용하는 구체적인 정서 연구에서 어떤 중요한 설명 선택이 달라지는지 정해질 때 검토한다. 단순 ROI 점수 역전으로 구제하지 않는다.

원안: D03-B

## 내용 설명에 맞춘 AI 학습이 정서 관련 뇌 차이를 놓치는가?

캡션 자체의 범위와 학습 과정의 손실을 구별하도록 개선했지만, 모델의 정보 손실이 바꿀 구체적인 신경과학 설명이 부족하다. D03-B와 합쳐 새 연구로 세지 않는다.

특정 시각·의미 계산 설명을 선택하는 실제 과학 질문에서 모델 목표 때문에 결론이 달라지는 경우가 명확해질 때 재검토한다.

원안: D04-B

## 여러 정서가 함께 드러나는 장면은 각 정서 표현의 합으로 설명될까?

Coordinator의 추가 발상을 정서·데이터 담당이 검토했다. 완전히 제외한 조합의 전용 interaction 계수는 학습할 수 없고, 기존 조합 분포도 미확인이다. 독립 원안10개에 포함하지 않는다.

다른 조합에서 배운 공유 구조가 실제 보류 조합의 뇌 반응을 예측할 수 있는 관측 범위가 있고, 단순 비선형 encoding 개선 이상의 결론이 분명할 때 재검토한다.
