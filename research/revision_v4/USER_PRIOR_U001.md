# U001 — 사용자가 제공한 가까운 최근 선행

**Human and Machine Annotations Predict Brain Responses to Naturalistic Movies Across Development**. Yiran Huang, Zeyong Zhang, Rounak Rahman, Bharat Biswal, Xin Di, Mengjia Xu. 사용자는 arXiv2611.13637, 2026-11-10 최초 제출 v1이라고 소개했다. 이 서지·본문 상태는 우선 사용자 제공 정보이며 에이전트의 직접 검증과 구별한다.

[초록](https://arxiv.org/abs/2611.13637) · [본문](https://arxiv.org/html/2611.13637v1) · [이전 연구와의 연결](https://arxiv.org/html/2611.13637v1#S2.SS2.SSS3).

사용자 요약: 애니메이션3편에서 인간 valence/ToM와 multimodal LLM 점수를 비교. 별도 뇌 예측에서 영화2편을 본66명의 시각 특징·장면 설명·사회정서 특징을 회귀에 사용. 시각 특징의 예측이 넓고 설명문의 기여는 제한된 영역에 집중, valence–뇌 대응은 영화에 따라 달랐으며 AI 평정은 인간 평정의 보완 수단으로 해석. 설명문도 시각 정보를 담고, 영화 내부 시간 분할 평가는 새 영화 일반화와 다름. 자극→뇌 예측은 뇌만으로 정서를 읽는 검증이 아님. Brain-Aligned Multimodal LLMs를 선행으로 인용하며 평정 자료 재사용에 유의.

이 요약을 직접 본문 검증 완료로 쓰지 않는다. 현재 프로젝트를 기존 EmoBrain의 가설과 결합하라는 지시로 해석하지 않는다. 사회정서·ToM은 이 논문의 범위 설명이며 프로젝트의 새 연구 축으로 도입하지 않는다.

기여에 대한 함의: 비슷한 특징들의 encoding 성능표를 새로 만드는 것만으로는 부족하다. 해당 논문이 있어도 남는 설명 차이 또는 실제 신경 측정의 판단을 명시해야 한다. 데이터셋·모델만 교체하거나 평가 분할만 강화한 것을 새로운 신경과학적 결론으로 포장하지 않는다.
