## 1. 가장 중요한 탐색 공백

현재 모델이 정서 관련 뇌반응을 예측한다는 결과만으로는, 정서 대비를 설명한 것인지 감각·의미·내용 ID·시간 문맥을 이용한 것인지 구분하기 어렵다. 더 높은 성능보다 **같은 관측을 설명하는 경쟁 가설이 언제 서로 다른 예측을 하는지**가 핵심 공백이다.

이를 네 문제로 좁혔다. 첫째, 판독 실패는 정보가 없어서인지 현재 readout이 접근하지 못해서인지 구분해야 한다. 둘째, shared/private·개인 공통공간·범주 경계가 특정 좌표와 측정 방법에 의존하는지 확인해야 한다. 셋째, 시간 상태와 HRF·관측 필터가 만드는 잔류를 구분해야 한다. 넷째, 그럴듯한 생성 결과 중 무엇이 뇌 관측의 제약이고 무엇이 모델 prior인지 확인해야 한다.

## 3. Discussion에서 지금 다시 다룰 문제

P008의 시각계 정서 schema와 recurrent feedback에 관한 후속 해석은 과거 문맥·상태를 명시적으로 비교하는 경로로 연결했다. 사건 구조를 연구한 P066과 시간 모델들은 경계 지표와 과거 상태의 갱신을 구분하는 RP03의 근접 비교가 된다. 이로부터 “뇌가 recurrent하게 구현된다”는 결론이 자동으로 나오지는 않는다.

P001의 고차원·분산 정서 표상은 새 분류기로 반복하지 않고, 내용 거리·주석 불확실성을 맞춘 국소 범주 경계(RP06), 정렬 전후 판독 접근성(RP01), 공간 평균 null-space(RP08)로 재구성했다. 기존 제한을 어떤 계산 원리로 풀 수 있다는 부분은 연구팀의 E3 추론이며, 지금 해결됐다고 보고하지 않는다.

## 4. Horikawa에서 실제로 먼저 볼 정보

공식 이벤트305개 파일은 5명×61런, 사람별2,196자극 이벤트를 확인했다. 실제 필드는 `stim_index`이며 README의 다른 표기와 구별했다. 공식 코드의 내용 중복 제외15개를 적용한2,181과 소개문2,185의 차이는 미해결이다. 원 ID/name의 고유성과 내용 중복을 구분하여 split manifest를 만들 필요가 있다.

범주34·차원14·의미73·시각1,000은 확인한 코드의 feature 그룹이다. 실제 보유본의 각 라벨명·값·척도·신뢰도가 모두 확인된 것은 아니다. 내용군 단위 test, 원 voxel과 평균/정렬 표현의 matched 비교, 개인 간 전이의 구체 조건은 기존 자원을 새 질문에 활용하는 경로다. 원 연구가 이 정보를 전혀 사용하지 않았다고 단정하지 않는다.

특히 내용 중복은 같은 사람의 독립 반복측정이 아니다. 독립 반복이 없으면 stimulus별 crossnobis나 반복 기반 개인 내 noise ceiling을 계산할 수 없다. 다른 사람이 본 동일 자극은 집단 재현성을 다루는 별도 관측이며 개인 내 반복을 대신하지 않는다. 5명에 대한 exact 양측 subject sign-flip 검정은 최소 p=0.0625이므로 과도한 모집단 유의성 주장을 피해야 한다.

## 5. 어떤 모델이 무엇을 검증하는가

Vision Decoding은 시각 정렬과 생성 prior가 정서 대비의 판독을 어떻게 바꾸는지 검정한다. 최종 이미지의 자연스러움은 일차 증거가 아니다. Brain Foundation Model은 입력하는 뇌 문맥·공간 해상도·관측 마스크를 명시해야 하며, 더 많은 신경 입력으로 얻는 이득을 신경 원리 발견으로 간주하지 않는다. Multimodal/Temporal Model은 실제 자극 제시된 모달리티와 시점에 맞춰 shared 병목, 모달리티 고유 정보, 상태 갱신을 경쟁시킨다.

출발점은 frozen feature와 작은 선형/비선형 기준모형이다. 공식 CLIP ViT-B/32 loader의 checkpoint URL·해시·코드 라이선스는 확인했다. 가중치 load와 추론은 수행하지 않았다. CortexMAE의 공간 입력, TRIBE v2의 평균 참가자·피질 예측, MindEye2의 NSD 적응을 Horikawa와 자동 호환된다고 가정하지 않는다. [공통 자원 계획](../pilots/RESOURCE_AND_MODEL_PLAN.md).

## 6. 단순 모델 교체를 어떻게 걸러냈는가

각 원안을 모델 적용 → 과학 질문 → 기존 가정에 대한 도전으로 다시 썼다. 두 외부 역할의 실제 비판을 받은 뒤, probe 성능 저하=정보 소실, scalar target의 최소 rank=신경 차원, 유한 recurrence=별도 함수군, error 좌표=새 정보라는 주장을 철회하거나 좁혔다. 위상·공간 null·생성 prior·선택편향 감사 중 독립 신경 질문이 부족한 항목은 공통 검증으로 옮겼다.

무작위 조합도 결과를 보고 재추첨하지 않았다. 34회 시도에서 구조적 중복4개만 재추첨해30개를 보존했다. 과학적으로 약한 조합은 보류·기각했으며, 같은 질문에 대응하는 R11/R27을 별개 RQ로 세지 않았다. [병합 대응표](../research_questions/candidate_crosswalk.csv), [독립 조합 감사](../agents/12_adversarial_review/combination_curation_audit.md).

## 7. 성능 외에 필요한 판별 증거

같은 test·입력 정보·선택 예산에서 강한 기준모형을 비교해야 한다. 정서 대비는 뇌 결과를 보기 전에 정하고, 같은 자극의 비정서 대비와 측정 신뢰도에 맞춘 대조를 포함한다. 양성 결과도 특정 관측/함수족에서의 예측 충분성 주장인지, 실제 신경 관측의 차이인지 구분한다.

부정 결과는 비유의성만으로 정보 부재를 뜻하지 않는다. 적절한 신뢰도·민감도와 사전 최소효과 기준이 확보되어야 동등성 또는 제한된 충분성을 판단한다. 생성 편집은 독립 주석과 실제 BOLD 검증이 필요하며, 계산적 latent 조작만으로 신경 인과 효과를 주장하지 않는다. 시간·내용·참가자 의존성과 nested 선택, 다중 비교도 각 계획에 반영했다.

## 8. 과학적 잠재력과 단기 실행의 균형

가장 위험하지만 가치 있는 방향은 독립 관측이 배제하는 witness(RP07), 정서 감독 없는 anchor의 자료 간 대응(RP09), 사전 허용 편집의 실제 신경 대비(RP10)다. 이는 관측의 식별 범위 자체를 묻지만 추가 주석·관측·지지집합 조건이 크다. 특히 NSD에는 검증된 측정 정서 라벨을 가정하지 않는다.

기존 데이터에서 축소해 시작할 방향은 Horikawa 정렬 접근성(RP01), 공간 null-space(RP08), Emo-FilM 경계 갱신(RP03)이다. Emo-FilM의 연속 주석과 clip validation은 같은 영화 시계를 쓰되 관측 단위가 다르고, scanner onset은 별도 정렬한다. 외부 합의 주석은 개별 스캐너 참가자의 연속 정서 정답이 아니다. Spacetop의 자극 후 평정도 영상 내 연속 라벨로 보간하지 않는다. Mind Captioning은 버전·태스크·텍스트 생성 출처를 확인하기 전 fMRI–caption 짝이나 심상 과제로 간주하지 않는다.

## 여덟 탐색 질문에 대한 종합 답

- **왜 아직 시도되지 않았는가:** 미시도 자체를 확정하지 않는다. 후보마다 입력 비대칭, 반복·주석 부재, 모델/관측 동등성, 분야별 평가 관행이 구별을 어렵게 만든 이유를 기록했다.
- **최근 무엇이 가능해졌는가:** 고정된 대규모 특징, 생성 후보의 통제, 상태모형, 모델 내부 분해로 경쟁 예측을 설계하기 쉬워졌다. 데이터의 식별 한계가 자동으로 사라지는 것은 아니다.
- **틀릴 수 있는 가정은 무엇인가:** 판독 실패=정보 부재, 높은 alignment=같은 의미, shared/private 좌표=실제 경로, 매끄러운 복원=뇌가 제약한 내용이라는 등식을 검정한다.
- **AI가 더 잘 포착할 수 있는 것은 무엇인가:** 장면·관계·시간 문맥의 높은 차원 특징이다. 실제 뇌 설명의 향상은 동일 조건의 대조를 통과해야 한다.
- **뇌가 모델보다 더 담을 수 있는 것은 무엇인가:** 독립 신경 문맥에서만 회수되는 정서 관련 대비를 후보로 남겼다. 누락 의미·공유 잡음·추가 정보량을 먼저 배제해야 한다.
- **외부 방법이 어떤 새 사실을 열 수 있는가:** null-space, 관측등가 witness, 재매개변수화, 합성적 일반화가 서로 다른 설명의 경계를 만들 수 있다.
- **기존 자료를 다르게 쓸 수 있는가:** 내용군 split, 정렬·pooling 비교, 경계 단서와 상태의 분리를 설계했다. 사용자 보유와 분석 준비를 구분한다.
- **결과가 이해를 바꾸는가:** 양성과 음성 모두 어떤 표현/관측/함수족이 충분한지 한계를 갱신할 수 있다. 새로운 예측 순위만 남으면 방법 비교로 낮춘다.

## 독립성·보존·재개

기존 EmoBrain의 과학 내용은 열람하거나 재사용하지 않았다. 공용 문헌·공식 데이터/모델 문서와 역할별 독립 탐색에서 출발했다. 기존 EmoBrain이 제공했을 법한 가설·모형·전처리를 추정해 상속하지 않았다.

사용자가 허용한 공개 GitHub 연구 브랜치에 단계별로 저장했다. 원 사용자 데이터 본체를 새로 올리지 않았고 사용자 컴퓨터에 다운로드를 요구하지 않았다. 최종 원격 상태의 정본은 저장소 `backup/LAST_SUCCESS.json`이다. 새 세션에서는 이 기록과 [현재 연구 상태](../RESEARCH_STATUS.md)를 먼저 읽는다. ChatGPT 프로젝트는 대화 관리 공간이며 GitHub 자동 동기화나 에이전트의 무기한 실행을 보장하지 않는다. [프로젝트 안내](../CHATGPT_PROJECT_BRIEF.md).

[산출물 구조 검증](validation_report.json)은 실제 역할·참조·수량·랜덤 재현성을 검사한다. 뇌 실험의 검증 결과로 읽지 않는다. [필수 산출물 목록](deliverables_manifest.json)과 [최종 독립 감사](FINAL_AUDIT.md)에 완료 범위와 남은 실행 조건을 보존한다.
