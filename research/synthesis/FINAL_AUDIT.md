# 최종 확인 범위

원안10개, 실제 데이터 심사10개, 동료 비판에 대한 저자 응답, 통합·보류 결정, 세 방향의 기존 관측 연결과 파일럿 계획을 확인한다. 구조·출처·링크 검사는 `scripts/validate_contribution_v4.py`의 [실행 결과](validation_report.json)를 따른다. 이 검사는 신규성·효과·검정력의 승인과 다르다.

과학 검토에서는 단순 encoding 개선, 공통 정서 패턴의 존재, 일반적인 압축 손실만으로 기여를 인정하지 않았다. D07은 국소 구조와 모델 설명을 분리했고, D08은 같은 평가 영상과 여러 대비의 상대적 보존을 명시했다. MC는 실제 통합과 데이터 시점 조건을 반영했다. 반대 결과가 기존 설명으로 충분한 경우와 자료 감도가 없어 판정할 수 없는 경우를 구별했다.

남은 핵심 한계는 보유 feature의 실제 척도·범위, BOLD·ROI·유효 신호, MC 심상 window와 모든 참가자의 반복, 가까운 원문·후속 선행의 중복 확인이다. 이 항목을 확인 완료나 단순 행정 절차로 쓰지 않았다. 중요한 비교가 기존 자료에서 성립하지 않으면 해당 질문을 보류한다.

v3의 새 실험 중심 선정은 역사적 기록이며 이번 판단의 근거가 아니다. [정정 이력](../revision_v4/DATA_FIT_REVIEW.md)과 [현재 선정](../revision_v4/DECISIONS.md)을 구별한다.
