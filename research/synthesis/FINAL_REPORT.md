# 보유 자료로 검증할 정서신경과학 질문

현재 제안은 세 방향이다. [질문과 기여](../proposals/README.md)에 필요성·중요한 관찰·조건부 Conclusion·분야 기여를 먼저 정리했다. 연구 기획과 실제 교차 토론·수정은 마쳤으며, 아직 뇌 분석 결과나 최초성이 확정된 논문 주제는 아니다.

1. **비슷한 정서라도 범주가 달라지면 뇌에서 더 다르게 표현될까?** 정서 이름을 분류할 수 있다는 사실에서 나아가, 기존 주석의 범주 전환 부근에 실제 신경 구별의 변화가 있는지 본다.
2. **장면이 달라도 같은 정서를 나타내는 뇌 패턴은, 비슷한 정서도 잘 구별할까?** 내용 일반화와 세밀한 정서 구별이 뇌에서 함께 좋아지는지, 서로 다른 정서 차이를 나누어 보존하는지 본다.
3. **장면을 떠올릴 때 정서와 관련된 차이는 다른 장면 정보보다 더 잘 남을까?** 같은 영상의 지각·심상을 비교해 정서 관계가 내용 관계와 같은 비율로 유지되는지 본다.

## 최근 선행을 반영해 달라진 점

사용자가 제시한 Huang et al.의 U001 이후에는 시각·캡션·정서 특징의 encoding 비교만으로 기여를 인정하지 않았다. P008에는 심상에서 시각 정서 코드가 활성화할 가능성이 이미 제시돼 있어, 단순 지각→심상 판독도 성과에서 제외했다. P009의 공통·유형별 정보와 맥락 의존성 논의 때문에 valence 후보 역시 주력에서 보류했다. [직접 확인 범위와 비교](../revision_v4/PRIOR_COMPARISON.md).

AI는 기존 장면의 내용·시각 관계를 상세히 표현하고, 서로 다른 신경 조직 설명이 어느 영상에서 다른 예측을 하는지 찾는 데 쓴다. 새 모델의 평균 성능 상승, 군집 그림, ROI 점수표만 남으면 이번 질문들의 핵심 기여가 아니다. 기존 고차원 category 분석에서 나아가 국소 구별, 내용 변화에 따른 관계 보존, 지각·심상 간 변화라는 서로 다른 관찰을 요구한다.

## 자료와 실행 판단

주력 비교는 Horikawa와 MC의 기존 관측으로 구성했다. NSD는 우선 데이터이지만 확인하지 않은 정서 정답을 있다고 가정해 세 연구에 강제로 넣지 않았다. Emo-FilM과 Spacetop은 후순위이며 과제·주석 단위가 맞을 때 확장을 검토한다. 개인의 실제 감정, 기억 정확성, 정서 조절을 이 자료에서 새로 측정한 것처럼 해석하지 않는다.

첫 분석은 Horikawa에서 내용 일반화와 세밀한 구별을 비교하는 방향을 권고한다. 범주 경계 질문은 척도와 전환 부근 표본 확인이, MC 질문은 최대71개 안의 대비와 심상 구간 분리가 먼저다. [파일럿3개](../pilots/README.md)와 [잠재력·실현성의 구분](../research_questions/RANKINGS.md)을 함께 본다.

## 토론 결과와 남은 한계

7개 제안 역할의10개 원안 중 MC5개는 한 연구로 통합했고, 기여가 부족한 B3개는 보류했다. 추가 독립 원안2개를 실제 교차 비판·수정해 세 방향을 남겼다. 질문 수를 채우기 위해 비슷한 원안을 별개 연구로 세지 않았다. [실제 교환 기록](../discussions/revision_v4/SYNTHESIS.md).

공개 이벤트·캡션 검산은 실행했지만 사용자의 실제 BOLD·정서 feature 본체는 현재 환경에 마운트된 것으로 확인되지 않았다. 효과·표본 지원·검정력을 아직 판단하지 않았다. U001은 사용자 요약, U002는 공식 문서·코드 확인 범위이며 가까운 원문 전체와 후속 연구의 중복 검토가 남아 있다. 따라서 이번 완료는 **기존 자료에 맞춘 연구 제안과 실행 계획의 완료**다.
