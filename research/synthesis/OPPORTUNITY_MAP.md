# 분야 간 기회 지도

12개 문헌 생성 전략을 모두 검토했다. 각 행의 신경 전이는 E3이며, 인용 문헌이 이 새 신경 질문에 답했다고 주장하지 않는다. 자세한 대비와 반증은 후보 원본 및 최종 질문 지도에 연결된다.

| 연결 | 원 분야 | 새 계산 능력·전이 | 연결 후보 |
|---|---|---|---|
| L01 Technology Transfer | 최적수송 |  서로 다른 좌표계의 거리관계를 비교하는 계산을 정서 의미 대응의 비유일성 검정으로 전이 | C07-04 |
| L02 Methodological Inversion | inverse problems |  단일 복원 성공을 같은 관측을 만족하는 여러 후보의 식별범위 문제로 뒤집음 | C09-02 |
| L03 Representation Competition | 조건부 예측과 정보원 비교 |  자극으로 설명되는 변동과 과거 신경으로 설명되는 변동을 같은 test에서 경쟁 | C04-02 |
| L04 Scale Bridging | 계층 시간범위 비교 |  영상 문맥의 길이를 감각–transmodal 위치별 정서 대비와 연결하되 HRF·공간null을 경쟁 | C08-02 |
| L05 Dynamics & Geometry | 지연공간 위상과 null |  정적 점구름 도식에서 시간 지연의 연결구조가 관측과정을 넘는지로 전환 | C07-03 |
| L06 Cross-Dataset Discovery | 관계쌍·측정 불변성 |  같은 라벨 이름 대신 독립 anchor·관계쌍을 비교 단위로 사용 | C01-04 |
| L07 Counterfactual Modeling | 생성 편집 타당성 |  모델 latent 편집과 실제 자극의 감각·사건 보존을 나눈 뒤 선택적 신경 대비를 설계 | C09-03 |
| L08 Brain-to-AI Reverse Inspiration | 신경정보 보존 제약 |  예측기가 신경자료에 맞는지를 넘어 신경 제약이 모델의 맥락 일반화를 바꾸는지 검정 | C11-05 |
| L09 Model Disagreement | 모형 불일치와 능동 설계 |  기존 관측에서 동등한 모형의 차이가 가장 큰 안전한 자극 대비를 찾음 | C12-03 |
| L10 Hidden Structure Discovery | 예측상태 추상화 |  정서 라벨을 쓰지 않은 상태를 만든 뒤 독립 정서–신경 대비로 검증 | C06-01 |
| L11 Unresolved Discussion Transfer | 재귀 계산 비교 |  P008 Discussion의 recurrent feedback 후속 제안을 유효 문맥·계산량이 같은 재귀/비재귀 비교로 연결 | C11-03 |
| L12 Assumption Reversal | 공유/고유 정보 통로 |  공통 공간이 충분하다는 전제를 고유 경로가 필요한지의 판별로 뒤집음 | C05-01 |

## 저자의 미래 제안과 새로운 연구자 제안의 구분

L11의 P008은 실제 확인한 Discussion의 recurrent feedback 제안을 출발점으로 삼았다. 공정한 유효문맥·계산량 비교 및 정서 대비 검정은 이번 연구자의 E3 재구성이다. 나머지 연결은 원논문 저자의 직접 후속 제안이라고 표현하지 않는다.
