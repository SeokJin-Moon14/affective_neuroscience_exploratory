# 다음 단계 진입 조건

이 문서는 연구 결과가 아니라 미션의 실행 판정 기준이다.

| 단계 | 요구 증거 | 승인 가능한 상태 |
|---|---|---|
| 독립 탐색 | 12역할 원본, 출처, 가정과 연결 | 일부만 수행했으면 실제 범위를 명시 |
| 데이터/문헌 | Horikawa 우선 4종 공식 메타데이터, 중복 제거 서지 ≥100 | 미달·원문 차단 시 해당 단계 부분완료 |
| Axis | 실제 문헌과 연결된 A–X 및 확장 subaxis | 미션 목록 복사는 확장 완료가 아님 |
| 토론 | 실제 독립 발견·교환·비판·새 연결·대립 가설 기록 | 가상 대화로 대신할 수 없음 |
| 조합 | 문헌 조합, 실제 난수 30개와 판정 | seed만 적거나 실행 안 한 것을 추출이라 하지 않음 |
| RQ | 중복 제거 30개, 방향40개 및 반증/경쟁설명 | 양적 기준 때문에 모델명만 바꾸지 않음 |
| Top10/Pilot3 | 가장 가까운 선행연구 역검색·데이터/모델 실현성 | 실행 가능하다는 확인 전 최종 확정 금지 |

검증 범위 밖의 후보는 탐색 노트로 보존한다. 미달이라는 이유로 보고서를 완성된 연구처럼 포장하지 않는다.
