# 뇌 × 정서 × AI: 독립 탐색 1차 보고

2026-11-12, Asia/Seoul. **12개 역할의 독립 조사와 네 데이터셋의 공개 메타데이터 감사를 수행했다. 전체 연구 미션은 미완료이며, 현재 Stage2의 문헌·데이터 품질 게이트에 남아 있다.**

사용자 요청에 따라 `RESEARCH_MISSION_v2.md`를 먼저 읽고 `AGENTS_codex_v2.md`를 이어 확인했다. 첨부는 연구 사양과 운영 참고로 적용했으며 사용자 요청·상위 권한 지침을 대체하는 것으로 취급하지 않았다. 새 독립 폴더에서 시작했고 기존 EmoBrain 내용은 열람·수정하지 않았다.

## 연구 설계를 바꾸는 주요 발견

1. **Horikawa의 자극 ID와 영상 내용의 고유성은 다르다.** 305개 이벤트 파일을 파싱하고 Coordinator와 별도 Agent가 재검산했다. 5명 각각61런·2,196개 자극 이벤트, 실제 필드 `stim_index`를 확인했다. 공식 코드의 중복 제외 인덱스15개와 소개문2,185개/분석2,181개의 차이를 보존했다. 실제 영상·처리본 매핑을 확인하기 전 ID만으로 split을 확정할 수 없다.
2. **EmoNet–Horikawa 비교에는 원자극 풀 중복 감사가 필요하다.** 두 연구가 Cowen–Keltner 영상 풀을 사용한다는 근거는 있지만, 모든 개별 학습·평가 영상이 중복됐다고 확정한 것은 아니다. 독립 OOD 검증이라는 해석에 선행 검사가 필요하다.
3. **Emo-FilM의 영화·스캐너 시간축과 평정 단위를 분리해야 한다.** 연속 주석과 clip validation은 영화 시간축을 공유하며 측정 단위가 다르다. 실제 annotation 숫자 시계열은 git-annex 포인터 때문에 확보하지 못했다. `lins_ccc` 기본값의 Pearson 상관 반환도 공식 코드에서 확인했다.
4. **Spacetop의 README 인원과 현행 메타데이터 행 수는 다르다.** 101명과117행을 어느 하나의 분석 가능한 표본 수로 단정하지 않았다. NSD에서 정서 정답이 제공된다고 가정하지 않았고, AI 생성 점수와 인간 평정을 구별했다.
5. **최신 모델의 실제 계산과 평가 조건을 확인해야 한다.** Brain-IT를 정확히 식별했고, MindEye2의 검색 방향 정정과300-way 평가 조건을 기록했다. 양방향 영상 모델·masked objective의 성능을 과거만 사용하는 신경 예측으로 해석하지 않았다.

각 사실의 근거·범위·미확인 항목은 [초기 발견 상세](phase1_findings.md)에 있다. 이 문서는 별도 사실검사 후 시간축, 참여자 비중복, 중복 영상 매핑, 평가 조건, 프레임 표집 표현을 수정했다. 이 검사는 5라운드 과학토론을 대신하지 않는다.

## 잠정적으로 중요한 탐색 경로

다음은 **E3 연결이며 신규성이 확정된 연구 질문이나 순위가 아니다.**

- 시각·언어·공통 잠재공간에 정렬할 때, 높은 예측력과 함께 어떤 재현 가능한 정서 관련 신경정보가 소실되는지 비교한다. 해석하기 쉬운 개별 축과 안정적인 분산 하위공간을 구별한다.
- 현재 장면, 관찰 과거, 사건 진행, 예측 상태를 구분한다. 미래 입력·위치 암기·HRF·움직임만으로 설명되는 효과를 먼저 점검한다.
- 공통/고유 정보, 분산 가산 모형, 네트워크 상호작용을 경쟁시킨다. joint 모델 성능 향상만으로 신경 시너지를 주장하지 않는다.
- 생성 편집과 모델 내부 개입을 신경 인과 실험과 분리한다. 의미 보존·분포 이탈·모델 불확실성을 검증한 뒤 새 실험을 설계한다.

역할별 보고서는 각각 숨은 가정, 방법 기회, 타 분야 전이, 예상 밖 연결, 반증 조건과 수정/폐기 근거를 제시한다. 초기 제안이 여러 역할에 반복되었다는 이유로 우선순위를 높이지 않았다.

## 미완료와 실제 차단 요인

- **문헌 수량 목표는 충족, 서지 보류는 유지.** Spacetop과 PID의 공식 자료 내 저자 표기 충돌, e-prop의 발표연도 미확인3편은100편에서 제외했다. 초기 미확정이던 NSD는 공식 eLife XML 참고문헌에서2021 preprint의 제목·저자·연도·DOI를 추가 대조해 포함했다. NSD2022 정식판 서지와 본문은 미확인으로 남겼으며 두 버전을 별도 연구로 세지 않았다. Snoek·EmoPathway 등 별도 후보는103편 목록 밖에 있다.
- **핵심 데이터 실물 미확인.** Horikawa의 정확한 라벨명·척도·평정자·특징 행렬, 처리본 정렬과 영상 접근이 남았다. Emo-FilM의 숫자 시계열·평정 지연·품질 수치, Spacetop의 유효 코호트·전체 결측도 남았다.
- **검색 범위 제한.** 실행 환경은 GitHub 및 패키지 출처 위주로 허용돼 있다. Crossref·arXiv·출판사·데이터 호스트 요청은 실제403이었다. 허용된 공식 저자/출판사 저장소를 사용했으나 최신2024–2026 신경과학 문헌과 가장 가까운 선행연구를 체계적으로 검색했다고 할 수 없다. Cowen2017·Horikawa2020 Discussion도 직접 확인하지 못했다.
- **후속 게이트 미충족.** 완성된 Axis Encyclopedia, Round2–5 교차 토론, 실제 무작위30개, 중복 제거 연구질문30개, Top10·Pilot3은 아직 수행/확정하지 않았다. 독립보고의 잠정 질문을 이를 대체하는 것으로 집계하지 않았다.
- **실험 결과 없음.** 모델 학습·추론·fMRI 분석·가중치 실행·새 자극 실험은 하지 않았다.

## 다음 작업의 구체적 순서

1. 환경 설정에 저장한 학술·데이터 호스트 허용 초안을 검토·저장하고 Publish한 후, 새 연결로 접근을 재검증한다. 초안 저장은 실행 환경 적용이 아니다. 마지막 확인에서도 현재 적용 revision1과 사용자 추가 허용 목록 없음이 유지됐다.
2. 보류 서지를 해결하고 부족한 최신 신경과학·방법론 영역을 보강한다. 100편이라는 수량 목표 달성과 체계적 탐색 공백 해소를 구별한다.
3. Horikawa feature 본체·라벨 사전·원영상 대응, Emo-FilM 실제 주석과 스캐너 매핑 등 연구 설계의 필수 전제를 검증한다. 영상 신청 폼 제출은 수행하지 않았다.
4. 독립 하위축을 통합하고 실제 교차 교환·비판·새 연결·대립 가설 토론을 수행한다. 그 기록에 근거해 조합·RQ·신규성 심사·10개 카드·3개 파일럿으로 진행한다.

현재까지의 부분 결과를 다음 세션에서 그대로 이어 쓸 수 있도록 [상태 파일](../RESEARCH_STATUS.md)과 실행·검증 스크립트를 저장했다.
